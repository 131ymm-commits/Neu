# Предложение автора 07.10.2026: сложные игры, агенты против друг друга

Слова автора: «Игры сложные игры в которых агенты играют друг против друга».
По правилу 28.09 предложение получает прогон; проект — совету (заседание 27).

## Что доступно (проверено 07.10)
- OpenSpiel (`pip install open_spiel`, ставится через PyPI, 126 игр): chess, go, hex, havannah, amazons, backgammon, dots_and_boxes; с неполной информацией — leduc_poker, universal_poker, liars_dice, kriegspiel, dark_hex, phantom_ttt, bridge; кооперативные — hanabi, coop_box_pushing, colored_trails. Venv: scratchpad `gvenv`.
- В OpenSpiel есть сильные боты кода (MCTS, CFR/решатели для малых покеров) и **точная эксплуатируемость** стратегии для малых игр (leduc, liars_dice малые) — правда от кода, не от судьи.
- Модули python-chess. Stockfish в контейнере нет.

## Набросок для совета (как это отвечает на главный вопрос)
- Игра — среда с противником, который подстраивается: «давление отбора» создаёт сам соперник. Правда — исход партий против фиксированных ботов кода и эксплуатируемость, головам недоступна.
- Возможные руки: одна голова против системы голов (совет / эстафета / голова + оценщик ходов) при равном бюджете токенов; самоигра с отбором стратегий по самооценке против отбора по результату против ботов.
- Самообман: заявка головы «моя стратегия выигрывает X %» против правды; проклятие победителя при выборе лучшей из k стратегий по заявке (связь с SELECT-01).
- Формы: головы ходят сами (дорого: вызов на ход) или пишут программу-стратегию (дёшево, как SOLVERS).
