# Ворота 1 — REC-01 (2026-09-05), записано ДО поиска занятости

Мандат: «ещё один долгий заход». Откуда: SPEC-01/HUB-PRIOR-ART-5 — спектр LJ13 при сосуществовании принадлежит классу
REM/ловушек (реньевская иерархия), дипептид — уровень-выброс, сон — континуум. Класс спектра — статика. Вопрос: как класс
спектра проявляется в ДИНАМИКЕ рождения уровня охлаждением? В классе ловушек «рождение уровня» = локализация в глубочайшей
долине, и путь к ней по построению идёт через всё более глубокие промежуточные долины — рекорды. Это и есть D5 («рождение
через попытку») в чистом виде, и у него есть готовая количественная форма — лог-пуассоновская рекорд-динамика.

## Гипотеза одной фразой
В системе класса ловушек (LJ13, синаевский ландшафт) рождение уровня после закалки идёт как рекорд-динамика: последовательность
новых глубочайших посещённых собственных структур (рекордов) лог-пуассонова — интервалы между рекордами экспоненциальны в ln t,
число рекордов растёт ∝ ln t, — и уровень основного состояния достигается через k ≥ 2 промежуточных рекорда-попытки в
большинстве закалок; в системе класса выброса (дипептид) рекорды исчерпываются немедленно (k ≤ 1) и роста ∝ ln t нет.

## Собственные ожидания (до поиска)
1. LJ13, закалка из жидкости (T = 0.36) в T_q = 0.20: медиана числа рекордов до икосаэдра ≥ 3 (дефектные изомеры как попытки);
   при T_q = 0.24 — меньше (тепловая активация перескакивает промежуточные), но ≥ 2.
2. Лог-Пуассон: объединённые по закалкам интервалы ln(t_{k+1}/t_k) экспоненциальны (KS не отвергает), число рекордов
   ∝ ln t с R² ≥ 0.9 на объединённой кривой.
3. Синай (ходок на броуновском ландшафте, старт из случайной точки при низкой T): рекорды глубины посещённой долины
   лог-пуассоновы, число ∝ ln t — нуль-вселенная рекорд-динамики; в отличие от LJ13 рекорды не исчерпываются (нет дна).
4. Дипептид (закалка 700 → 300 K): число различных бассейнов-рекордов ≤ 2, насыщение за первые проценты времени.
5. Контррасчёт против себя: LJ13 слишком мал — 1500 минимумов, воронка крутая — закалка идёт прямо в икосаэдр (k ≤ 1
   в большинстве), и тогда «спектр класса ловушек, динамика класса выброса»: статический класс не предсказывает динамику.
   Второй контррасчёт: рекорды пуассоновы в линейном времени (обычное экспоненциальное ожидание), а не в ln t — иерархии
   во времени нет.

## Что меряю (предварительно)
Собственные структуры (квенч L-BFGS из текущих координат) каждые 250 шагов; рекорд = новый минимум квенч-энергии
(допуск 1e-3 ε); t_k — шаг рекорда; k_gs — число рекордов до первого попадания в основное состояние (E = −44.3268);
интервалы Δ_k = ln(t_{k+1}/t_k); число рекордов n(t) против ln t.
