# Ворота 1 — LIFT-01b: контроль правила стенки и тонкая сетка по p для LIFT-01 (2026-09-14)

Гипотеза одной фразой: **рождение уровня при 2-блочном огрублении лифтированного пути в окне спектрального оптимума (LIFT-01) не
зависит от правила стенки — при апериодичном варианте «переворот и шаг назад + ленивость ε = 0.05» R(mid) при p* остаётся > 1 для
L ≥ 64 и ≥ 1.2 для L ≥ 128; окно рождений по p имеет ширину ×1.5–×3.5; R(mid; p*) сходится по L к ≈ 1.3, p*·L → 2–3.5.**
Контррасчёт: эффект LIFT-01 был артефактом правила «переворот и стояние» (стояние у стены создаёт ленивость только на краях —
локальную ловушку), и при апериодичном варианте B_ε рождений нет ни при каком p.
Занятость — та же, что у LIFT-01 (Robichon–Monthus–Krauth 2609.05183; Lamperski 2606.07839); новых поисков не требует.
