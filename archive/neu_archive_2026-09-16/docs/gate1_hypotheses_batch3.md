# Ворота 1 — гипотезы DET-006, DET-007, DET-008 (записаны ДО поиска)

Дата: 2026-08-23. До веб-запросов. Все три — возвраты: P2 (LEV-001/002, класс C), плато (P-N1/P-C1, класс B), бюджет (P-R1, класс C).

## DET-006 — «щель → время жизни»: режимная карта вместо лозунга

- **H1 (калибровка обмена):** эмпирическая t₂ с малого бюджета оценивает ВРЕМЯ ОБМЕНА t_exch = 1/(1/T_hl + 1/T_lh) мультипликативно точно (в пределах ×1.5) по всей (V, fr)-сетке с диапазоном времён ≥ 10×.
- **H2 (режимная оговорка как закон, в обе стороны):** t₂ совпадает со временем ЖИЗНИ нового уровня T_hl только в заявленной подобласти T_hl < T_lh/3; в подобласти T_hl > T_lh совпадение ОБЯЗАНО ломаться (t₂/T_hl < 2/3). Заранее размеченная карта «где формула работает, где обязана врать».
- **H0:** малый бюджет (B2, короткие траектории) систематически смещает t₂ на глубоких барьерах (редкие обмены) — калибровка ломается уже на уровне t_exch при больших временах.

## DET-007 — плато-фикс: причина лаг-неустойчивости — грубый биннинг

- **H1:** лаг-неустойчивость неявных |λ| осциллирующих мод (провалившая P-N1/P-C1) — следствие немарковости огрубления; при измельчении биннинга (40 → 80 → 120) разброс плато на точках детекции падает и при nb = 120 проходит порог 20%.
- **H2 (инвариантность выводов):** тайминг детекции второй ступени (K\* = 3.44) не зависит от nb — правка чинит критерий, не двигая результат.
- **H0:** плато не чинится биннингом → причина не в огрублении, а в самом оценщике (нужна экстраполяция по лагу или другой инструмент); тогда плато для осцилляторных мод отставляется как критерий с записью.

## DET-008 — бюджет × длина цикла

- **H1:** молчание 8 сидов DET-002R — бюджетное: при T, масштабированном по замеренному времени зажигания (T = 4×медианы T_ig), детекция в {K_cycle, K_cycle+1} появляется у большинства (≥6/8).
- **H2 (направленно):** требуемое время зажигания растёт с ДЛИНОЙ первого цикла (Spearman > 0 между L_cycle и T_ig по всем 20 сидам).
- **H0:** молчание не бюджетное (детекция не появляется и при масштабированном T) → граница структурная, не бюджетная; класс C переквалифицируется.
