# Ворота 1 — гипотезы DET-004, DET-005, OL-001b, DET-002R (записаны ДО поиска)

Дата: 2026-08-23. Записано до веб-запросов этого хода. Все четыре — хвосты предыдущих ходов, не новые темы (по указанию: «следующим проходом то, что не сделал»).

## DET-004 — третий маршрут: тор/Неймарк-Сакер

- **H1:** при NS-рождении (шумная запаздывающая логистика, r₁ = 2.0) отделяется КОМПЛЕКСНАЯ ПАРА мод; угол θ лежит в промежуточной полосе (π/6..5π/6) — ни фолд, ни флип; классификатор из трёх полос разделяет все три маршрута на данных трёх серий.
- **H2 (обобщение детектора):** R_c обобщается на группы мод по модулю: медленная ГРУППА (сопряжённая пара) против следующей группы; парная структура (|λ₃|/|λ₂| ≈ 1, θ₃ ≈ −θ₂) — сама по себе структурный различитель NS от fold/flip (там мода одиночная).
- **H0:** пара не разрешается из конечных данных (модули пары расщепляются шумом, угол нестабилен) — детектор не обобщается на пары; NS остаётся слепым пятном.

## DET-005 — вторая ступень каскада (удвоение 2→4)

- **H1:** при σ = 0.005 рождение 4-цикла видно оператором как отделение пары θ ≈ ±π/2 при r ∈ [3.44, 3.52] (истинная точка 3.4495); вырожденные точки (2-цикл, r ≤ 3.3) её не имеют.
- **H2 (эксплораторно, без убийцы):** при σ = 0.001 видна и третья ступень (пара θ ≈ ±π/4, r ∈ [3.54, 3.57]); тогда грубое δ̂ = (r₂*−r₁*)/(r₃*−r₂*) сравнимо с 4.67 по порядку величины.
- **H0:** шум съедает ступень (окна каскада уже σ-размытия) — оператор видит каскад не дальше первой ступени; δ-территория из траекторий недоступна этим инструментом.

## OL-001b — где сидит ручка аденина

- **H1:** аденин-доминирование — свойство валютного/хабового слоя, не всего меченого мира: доля аденина среди меченых КАРКАСНЫХ метаболитов заметно ниже валютной (1.00) и ниже 0.6 в большинстве организмов (в каркасе живут GTP/UDP/CTP-семейства).
- **H2:** среди меченого каркаса доля аденина растёт со степенью (чем хабовее меченый метаболит, тем вероятнее его ручка — аденин).
- **H0:** аденин доминирует везде одинаково — «ручка» есть свойство меченого мира вообще, и результат P-O2 переинтерпретируется как общий, а не валютный.

## DET-002R — репликация ступени замыкания

- **H1:** ступень детекции точно на закрытии первого цикла воспроизводится по ансамблю квенчённых графов (≥16/20 сидов: K* ∈ {K_cycle, K_cycle+1}; DAG-двойники молчат на всех).
- **H2:** максимум ΔR приходится на шаг закрытия в большинстве сидов (≥14/20).
- **H3 (вторичный):** на миниатюре реальной топологии (индуцированный подграф метаболической сети) ступень тоже на закрытии.
- **H0:** эффект LEV-002 — свойство конкретного квенчённого графа (seed 4242), на ансамбле рассыпается.
