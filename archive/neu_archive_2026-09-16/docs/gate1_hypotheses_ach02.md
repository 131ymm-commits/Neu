# Ворота 1 — ACH-02: относительная форма косинуса и знак — предрегистрация на свежих данных (2026-09-14; до поиска)

ACH-01 пост-хок: относительная форма c − c_min(цепи) по положительным рождениям даёт AUC 0.93 (против 0.62 в абсолютной), 45 %
рождений — отрицательные и требуют косинуса к нижнему вектору. Гипотеза одной фразой: **на свежих семействах (новые сиды, N = 6
и N = 8, кирхгофовы токи) относительная форма c⁺ − c⁺_min ранжирует разбиения на положительно рождающие с AUC ≥ 0.9 в пуле, а
c⁻ − c⁻_min (к нижнему вектору S, порог из той же оценки с λ_min) — на отрицательно рождающие с AUC ≥ 0.85; абсолютная форма
остаётся ≤ 0.7.** Контррасчёт: пост-хок 0.93 — переобучение на сиде 2026; на свежих сидах и при N = 8 относительная форма
даёт ≤ 0.75. Занятость — как у ACH-01 (форма Дирихле, дирихлеев зазор); новых ходов нет.
