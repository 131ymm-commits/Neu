## 1. Формула Crystal Score НАЙДЕНА — сшивка с детектором сделана

`exp_hub_001.py`: **M1 = λ₂/λ₁ матрицы смежности наибольшей связной компоненты** (неориентированный граф, верхние два собственных значения A).

Точное соотношение с LEV-детектором:

| | M1 (Crystal Score) | R = t₂/t₃ (LEV) |
|---|---|---|
| объект | структура (adjacency) | динамика (оператор переноса на лаге τ) |
| пара мод | 2-я к 1-й (к Перрону) | 2-я к 3-й (медленные между собой) |
| вопрос | «насколько система кристалл vs хаб» (M1→1 решётка/кольцо, →0 звезда) | «отделился ли новый медленный уровень» |
| режим | статический портрет | рождение/тайминг |

Для случайного блуждания на регулярном графе λᵢ(P) = λᵢ(A)/d — тогда M1 совпадает с отношением мод блуждания; в общем случае это разные операторы. Вывод: **не конкуренты и не синонимы — портрет и детектор.** Пара (M1, R) — двухглазый инструмент в духе записи №34/35 карты границ (см. §4).

## 2. Правка рамки LEVELS-01 §1: уровень — ДВЕ оси, не одна

Запись №24 карты границ («модульность без памяти», CULT-001: D = −7.4 при τ = 2.0) прямо показывает: **замкнутость агрегатов (ε/D) и медленность зарядов (τ) — разделимые оси.** Есть модульность без медленных мод. Моя формула «уровень = медленная коллективная переменная…» была ОДНООСЕВОЙ и в этой части неполна — внутренне опровергнута измерением программы.

→ Рамка исправлена: **уровень заявляется только по обоим инструментам** — приближённая замкнутость (ε-lumpability, дефицит D) И медленный заряд (τ); третья ось — заменимость хаба (шкала R, двумодальная: среда R≈0 ↔ шунт R≈0.7, пустой промежуток 0.658, записи №44/48/49). LEVELS-01 обновлён.

## 3. Предупреждение для O1-на-LoRA: спектральная интуиция уже проиграла внутри программы

EXP-LLM-001 (запись №42): предсказание «уровни появляются сверху вниз, по величине собственных значений» — **P-L1 FAIL**; уровни приобретаются снизу вверх, по вероятностной массе (мелкий на шаге 19, грубый на 35 при большем собственном значении грубых мод). После REAL-001 (записи №44/45): «слой = ярус» отозвано (артефакт бюджета), остаётся: порядок — по массе; различается ПОЛНОТА приобретения, падающая с истинной щелью; пороги задавать долей истинного разделения, не абсолютом.

Следствие: будущая предрегистрация детектора рождения на траекториях обучения ОБЯЗАНА нести массовую контр-гипотезу (порядок отрыва мод следует массе данных, не спектру) как P1b. Наивный перенос «BBP-отрыв = первым отделяется самое крупное» уже опровергнут в этой программе на игрушечных моделях.

## 4. Мета-паттерны карты границ, принятые в дисциплину LEV-серии

- **№34/35: слепота принадлежит оператору; разрешающая сила = совместная ёмкость ПАРЫ разнородных наблюдаемых** (λ₂/λ₁ один — 29.1% слепоты; тройка — 0%). LEV-003+ отчитывается парой: спектральный детектор + агрегационный (D-дефицит) на одних данных.
- **№27/28 (проспективно измерено):** направленные предсказания переносимы (4/4), числовые — нет (2/6), смещение — к НЕДООЦЕНКЕ структуры. Прогнозы LEV впредь: направление + порог, точечные числа — с асимметричными интервалами.
- **№14/45 (три повторения):** абсолютный порог выше истинной щели = невозможность засчёта. У LEV это уже есть (плато-критерий), закрепить: меры задавать долей истинного разделения.
- **BOUND-002:** максимум информации — у кромки обрыва (Δτ = +13 при выживании 0.08). Планировать измерения околопорогово.

## 5. Кросс-линк: LEV-002 ↔ origin_of_life P4 (взаимное подтверждение)

origin_of_life.md, следствие **P4**: «автокаталитическое замыкание в богатых смесях появляется скачком по плотности катализа; околопороговые смеси максимально информативны» (двойная фазовая граница: перколяция замыкания + порог Эйгена; башня линеаризует экспоненциальный барьер).

**LEV-002 — прямое in-silico подтверждение P4:** ступень детектора точно на ребре, замыкающем первый цикл (ΔR = 5.6 против медианы 0.58), DAG-контроль равной плотности молчит. Приоритет формализации — origin_of_life (и Хордейк–Стил в prior_art); вклад LEV-002 — предрегистрированный прогон с контролем «замыкание vs плотность» и тайминговой привязкой. Отмечено в PRIORITY. Обратный подарок: BOUND-002 (μ_c = 1 − 1/⟨k⟩, обвальный переход) — та же перколяционная семья с ПРОТИВОПОЛОЖНОЙ стороны (смерть связности), вместе с LEV-002 (рождение замыкания) они окаймляют один механизм с двух сторон.
