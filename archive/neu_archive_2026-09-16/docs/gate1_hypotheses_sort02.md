# Ворота 1 — SORT-02: второй радиус ρ₊ (медленнейшая нечередующаяся мода) — постоянный сорт при шуме, счёт рождений ЭЭГ, поздние рождения на данных (2026-09-15; в личине; записано ДО поиска)

Откуда: SORT-01 P-S6 (класс B) — при локальном шуме s > 0 спектральный радиус по модулю ρ переходит к чередующейся ветви
(отрицательное вещественное λ ≈ −ρ), которую ни одно монотонное описание не видит; постоянный сорт «исчез» при s ≥ 0.03 не
потому, что описание перестало быть медленным, а потому, что ρ стал мерить чередование. Та же ловушка — ROT-01 («рождённые
уровни вещественны»), ACH-01 (отрицательные рождения), DET-серия (осцилляторные моды).

Личина (что делает морфизм «сжатие» с чередующейся модой): вес чередующейся моды в любом описании с C₁ > 0 экспоненциально
мал по её угловой частоте относительно лага; спектральный радиус — свойство оператора, а «медленнейшая мода, с которой описание
может конкурировать» — свойство пары (оператор, класс описаний). Второй радиус: **ρ₊ = max{|λ| : λ ≠ 1, Re λ > 0}** — модуль
медленнейшей моды с периодом > 4 лагов. Для нормальных операторов рождений нет ни по ρ, ни по ρ₊ (W(A) = conv σ(A)); ρ₊ ≤ ρ,
поэтому рождения по ρ₊ ⊇ рождения по ρ. ρ остаётся первичным (огибающая любой моды); ρ₊ — диагностика стороны EP и постоянства.

Гипотеза одной фразой: **по второму радиусу постоянный сорт на лифтированном пути с шумом существует при всех s < s_c (a₊ > 1,
C_n > ρ₊ⁿ до n_max) ровно на вещественной стороне EP положительной ветви; на ЭЭГ Бонна ведущая мода оценённых цепей и так
положительна (ρ₊ = ρ) у большинства сегментов, счёт рождений PCCA(2) почти не меняется (7/25 → 7–10/25), и постоянных/поздних
рождений на ЭЭГ нет: вес a₊ ≤ 1 — все 7 рождений транзиентны (согласно PERS-01: r(n) → 0.5–0.9).**

Контррасчёт: (i) на ЭЭГ ведущая мода часто комплексна или отрицательна (оценка на вложении запаздываний даёт осцилляторные
моды) — тогда ρ₊ < ρ у многих сегментов и счёт по ρ₊ вырастет заметно (> 10/25), и «7/25» COG-01 — заниженная оценка;
(ii) у части сегментов a₊ > 1 — поздние рождения есть и в данных (тогда PERS-01 «транзиент по лагу» — не вся правда).

Ожидание по поиску (ворота 2): спектральная абсцисса против радиуса — стандарт для непрерывного времени (устойчивость);
для дискретных цепей «модуль медленнейшей нечередующейся моды» как отдельная величина — не найдено (ожидание); соседи —
aperiodicity/laziness (ленивые цепи убивают −1), «Ramanujan»/спектральные оценки перемешивания (по модулю).
