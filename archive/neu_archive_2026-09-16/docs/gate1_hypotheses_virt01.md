# Ворота 1 — VIRT-01: виртуальные состояния квантовой механики в рамке программы (2026-09-14, вечер; в личине; записано ДО поиска)

Вопрос Димы: «приложи нашу систему к виртуальным состояниям в квантовой механике». У слова два смысла, оба берём:
(A) **виртуальный (антисвязанный) уровень** теории рассеяния — полюс S-матрицы/резольвенты на нефизическом листе у кромки
непрерывного спектра (синглетный np-уровень дейтрона, большая отрицательная длина рассеяния a);
(B) **виртуальное промежуточное состояние** теории возмущений — рамановский переход 1 → 3 через далеко отстроенный уровень 2,
который «не заселяется» (населённость ~ Ω²/4Δ²), но переносит амплитуду.

Личина (что делает морфизм с уровнем, которого нет в спектре):
- Эрмитов H — нормальный оператор: числовой образ = выпуклая оболочка спектра ⇒ **никакое сжатие (ортогональное огрубление)
  не даёт собственного значения вне оболочки** — рождений нашего сорта у замкнутой квантовой системы нет (интерлейсинг Коши).
  Значит (A) — не рождённый уровень сжатия. Он — полюс **точной редукции** (дополнение Шура / проектор Фешбаха:
  H_eff(E) = PHP + PHQ(E − QHQ)⁻¹QHP), т.е. ядра памяти Мори–Цванцига, продолженного за кромку континуума. В марковском словаре:
  сжатие = лумпинг (наши рождения), точная редукция = память D(n) (OBL-01). Виртуальный уровень живёт в памяти, не в сжатии.
- Одна фраза (A): «виртуальный уровень — псевдоуровень описания у кромки непрерывного спектра: у эрмитовой динамики память
  всегда положительна (D(n) ≥ 0 по Йенсену), уровень описания подходит к кромке снизу (выравнивание без ненормальности), а его
  время жизни — a² (квадрат длины рассеяния) в единицах решётки; наши сертификаты: ω − ρ ≡ 0 отличает его от рождения, знак
  памяти — нет».
- Одна фраза (B): «виртуальное промежуточное состояние — механизм, который делает описание населённостями лифтированной цепью:
  когерентность ρ₁₃ — скрытая настойчивая переменная (σ лифтированного пути), населённость — описание; лиувиллиан ненормален;
  сжатие e^{Lτ} на населённости даёт рождённый уровень (λ₂ населённостей > max|e^{λτ}| по ненулевым модам) в окне вокруг
  исключительной точки эффективного генератора (критическое затухание рамановского осциллятора Γ ≈ 2Ω_R), и не даёт ни в
  когерентном пределе (Γ ≪ Ω_R), ни в паули-пределе (Γ ≫ Ω_R, где населённости марковские)».
  Провeряемое до прогона: для двухмодового осциллятора населённости w'' + Γw' + Ω_R²w = 0 с w(0) = 1, w'(0) = 0 в передемпфированной
  области w(t) = A e^{λ_s t} + B e^{λ_f t}, A = λ_f/(λ_f − λ_s) > 1 — вес медленной моды в описании больше единицы: это и есть
  рождение (C(τ) > e^{λ_s τ} при больших τ); в EP w = (1 + Γt/2)e^{−Γt/2} — превышение (1 + Γt/2) над спектром, жорданова клетка.
  Аналог LIFT-01c (окно вокруг EP лифтированного пути) и FLOCK-01 (окно у перехода).

Прогнозы качественно (числа — после пилотов, ворота 4): (A) 0 рождений при всех V (теорема — проверка кода), D(n) ≥ 0 всегда,
время жизни псевдоуровня n_c ∝ a² = (1 − V)⁻² с показателем 2; (B) рождения населённостей в окне Γ_2/(2Ω_R) ∈ (окно вокруг 1),
максимум u в EP; нет рождений при Γ_2/(2Ω_R) ≫ 1 и ≪ 1; контроль — прямая связь 1–3 с теми же Ω_R и Γ (без виртуального уровня)
даёт те же рождения: виртуальное состояние — не причина рождения, а способ создать скрытую переменную.

Ожидание по поиску (ворота 2): (A) связь виртуальных состояний с ядром памяти/самоэнергией — фольклор (Фешбах 1958, Фано);
марковский аналог (случайное блуждание с убиванием/источником в начале, порог возвратности) — известен как h-преобразование
Дуба, но чтение через «уровень описания с временем жизни a²» — не найдено (ожидание). (B) немарковость населённостей открытой
квантовой системы (Накаджима–Цванциг, «non-Markovian population dynamics») — занято; «сжатие лиувиллиана на населённости даёт
собственное значение медленнее любой моды лиувиллиана» — ожидаю `не найдено`; соседи: квантовый эффект Зенона (плоское начало
автокорреляции населённости), Liouvillian exceptional points (Minganti et al. 2019), Liouvillian skin effect/pseudospectra.
