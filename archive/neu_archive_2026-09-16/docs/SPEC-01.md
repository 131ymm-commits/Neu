# SPEC-01 — Уровень как выброс в статистике лог-зазоров спектра; синаевский ландшафт как нуль-вселенная (2026-09-04, вечер)

## 1. Вопрос

CORE-01′ закончил тем, что «число уровней» — функция допуска g* с состоянием отказа. Допуск остаётся выбором. Есть ли форма критерия
уровня БЕЗ допуска? Единственная безмасштабная величина любого спектра — его собственная статистика расстояний. Уровень = отделимая
шкала = верхний логарифмический зазор спектра, аномально большой ОТНОСИТЕЛЬНО распределения остальных зазоров того же спектра.
Нуль тогда — не «нет медленной моды», а «зазоры такие же, как все остальные» — иерархия без выделенной шкалы.

Нормировка Реньи: если глубины долин — н.о.р. экспоненциальные величины, то расстояния между их порядковыми статистиками
D_k = X_(k) − X_(k+1) независимы и экспоненциальны со средним θ/k; значит z_k = k·s_k, где s_k = ln(t_k/t_{k+1}), должны быть
одинаково распределены. Тест: p₁ = exp(−z₁/z̄_rest), z̄_rest — среднее z₂…z_m. Отпечаток: ζ = z₁/z̄_rest.

## 4. Что это значит

1. **Три спектральных типа.** ζ ≫ 1 — уровень-выброс (дипептид: φ-переворот — отделимая шкала без всякого допуска); ζ ≈ 1 —
   реньевская иерархия без выделенной шкалы (LJ13 при сосуществовании; синаевский ландшафт при малом L / низкой T); ζ < 1 —
   континуум/отталкивание (сон, жидкий LJ13, случайные цепи, Синай при большом L).
2. **LJ13 — не двойная яма.** Уровень «твёрдое/жидкое», сертифицированный допуском 3 и физической разметкой (MOL-002, CORE-01p-b),
   спектрально не выделен: g₁ : g₂ : g₃ ≈ 1 : ½ : ⅓ в логарифме — ровно порядковые статистики экспоненциальных глубин. Кластер при
   сосуществовании устроен как синаевский ландшафт (иерархия изомеров/дефектов), и «число его уровней» — функция допуска по построению.
3. **Сон — континуум**, а не иерархия: верхний зазор меньше реньевского; это сильнее, чем «нет зазора ≥ 3» (BRAIN-001, CORE-01′).
4. **Рождение уровня из нуль-вселенной**: в синаевском ландшафте уровень появляется при охлаждении (глубочайшая долина — локализация),
   и исчезает с ростом системы. Ручка T рождает уровень там, где его не было по построению — ещё одна клетка для карты D3/D5.
5. **Число уровней как функция допуска** имеет для иерархий степенной вид с показателем, растущим с T сублинейно; мой наивный
   линейный прогноз убит — честный результат части A.

## 5. Границы

Тест требует ≥ 3 разрешённых зазора — на континууме ниже лага он отказывает (LJ13 0.18/0.22, дипептид 300 K); реньевская
нормировка предполагает экспоненциальные глубины — на континууме делает тест консервативным (ζ < 1 читается как «нет»); порог
0.05 — конвенция, но не масштаб; точность точной диагонализации ограничена глубиной/T ≲ 35. Приоритет по спектру Синая и по
эвристике зазора — чужой; сертификат, его калибровка и три класса наших систем — наше.
