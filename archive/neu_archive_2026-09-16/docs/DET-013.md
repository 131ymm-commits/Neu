# DET-013 — Ω-масштабирование запаздывания траекторной детекции у Хопфа

Дата: 2026-08-23. Предрегистрация: PREREG.md § DET-013 (заморожена до прогона; ворота 1–4, gate.py OK). Поименованный возврат DET-012b: чем задано запаздывание детекции (b_det = 5.4727 при Ω = 500 против Хопфа 5.0) — шумом или конструкцией пола? Конкурирующие прогнозы: шумовой предел Δb ~ Ω⁻¹ против H0 «предел конструкции» (узел не движется).

## Результаты по букве

Протокол DET-012b без изменений, Ω ∈ {2000, 8000}, полы пере-заморожены на каждом Ω своим вырожденным этапом A.

| Ω | b_det | Δb = b_det − 5.0 |
|---|---|---|
| 500 (DET-012b) | 5.4727 | 0.4727 |
| 2000 | 5.1818 | 0.1818 |
| 8000 | 5.0364 | 0.0364 |

| прогноз | исход |
|---|---|
| P-D1 (монотонный спуск узла с Ω) | **ПОДТВЕРЖДЁН**: 5.4727 → 5.1818 → 5.0364 |
| P-D2 (шумовой масштаб γ = 1: узлы {5.0364, 5.1818} при 2000 и 5.0364 при 8000) | **ПОДТВЕРЖДЁН по узлам**; лог-лог наклон по трём точкам ≈ −0.93 при квантованной сетке (достижимые Δb: 0.036/0.182/0.327/0.473) — совместимо с γ = 1, несовместимо с γ = ½ |
| H0 (запаздывание задано полом L\* и конечным T) | **ОПРОВЕРГНУТ**: узел сдвинулся на три шага сетки при неизменных поле и T |
| P-D3 (специфичность не платит за чувствительность) | **ПОДТВЕРЖДЁН**: при всех Ω вырожденные и подкритика молчат; при Ω = 8000 исчезло даже подпороговое срабатывание радиусной ножки (квазицикловое раздувание сжалось под пере-замороженный пол: R_late = 0.16 < 0.095... порога связка не достигает нигде ниже 5.0) |
| P-D4 (масштабная инвариантность подкритики) | **подтверждён**: подкритические L_rot = 2.0 при всех трёх Ω — угловая статистика линеаризованных флуктуаций не зависит от амплитудного масштаба, как и предсказывала OU-картина |

## Что это значит

**Запаздывание траекторной детекции — физика, не артефакт конструкции: b_det − b_Хопф ≈ const/Ω.** Сертификат детектирует не детерминированный порог, а границу, где радиус цикла обгоняет внутренний шум (radius ~ √Δb против noise ~ Ω^{−1/2} ⇒ Δb\* ~ Ω⁻¹) — и эта граница управляемо стягивается к Хопфу при росте системы. Для программы «рождение уровней» это содержательный пункт: **у конечной системы рождение уровня — не точка детерминированной бифуркации, а шумозависимая граница, и её сдвиг измерим и масштабируется.** Сама точка Хопфа восстанавливается экстраполяцией Ω → ∞.

## Честные оговорки

(1) Три значения Ω, наклон γ оценён на квантованной сетке — «γ = 1 совместим», не «γ = 1 измерен». (2) Контроль «счётчик серий ≥ 100» нарушен на глубоких закритических узлах (n = 80–84: серия = вся траектория, счёт ограничен числом траекторий) — в том числе на ВТОРОМ узле каждой детекционной пары (Ω = 2000: 5.3273, n = 84; Ω = 8000: 5.1818, n = 80); первый узел пары чист (176 и 252). Механизм насыщения записан; вердикты не переиграны. (3) Проверка невырожденности нуля прошла формально (2.0 ≥ 2.0 на каждом Ω) — как и в 012b, слабая форма; несёт константный член пола.

## Классификации

Все прогнозы предрегистрированы и подтверждены; отзывов нет. Открытые возвраты: γ на непрерывной шкале (больше Ω, тоньше сетка — если понадобится сила утверждения «γ = 1 измерен»); перенос транзиент-сертификата на не-шлёгловскую бистабильную CME (DET-014, уже в воротах); лаго-согласованный оценщик.
