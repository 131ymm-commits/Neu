# PRE-009 — Горизонтная кривая: близость рождения читается на ~4 шага вперёд

Дата: 2026-08-26. Предрегистрация: PREREG.md § PRE-009 (до прогона; gate.py OK). Внутренний возврат линии PRE-002/003b (горизонтная кривая поименована в SYNTH-01 §7); данные — сохранённые AUC читаемых ветвей (α ∈ {0, 0.5} × K_u ∈ {6, 8, 10}) плюс заполненная лакуна d ∈ {3, 4} (по 8 графов на ячейку, конвейер без правок; лакуна — артефакт меток imm/dist, пропускавших 3–4 по построению).

## Постановка

Горизонт d = Kc − K* — на сколько шагов роста вперёд лежит рождение. MW_d = стратифицированная (внутри ячеек, взвешенная min(n, n_ref), пул запрещён как конфаундер уровней) раздельность AUC на расстоянии d против референса d ≥ 7. Достижимость бинов пересчитана бухгалтерией до заморозки (референс 7–16 на ячейку; правило min-n = 4).

## Результаты

Кривая MW(d): **0.668 / 0.689 / 0.568 / 0.623 / 0.485 / 0.533** (d = 1…6); перестановочные p: d=1 → < 0.001, d=6 → 0.31.

| прогноз | исход |
|---|---|
| P-H1 (невозрастание, допуск +0.04) | **не установлен** — макс. рост +0.055 (зигзаг в полосе шума ±0.05; между допуском и убийцей) |
| P-H2 (кромка d_h ∈ [3, 6]) | **ПОДТВЕРЖДЁН**: d_h = 5; LOO по ячейкам 5, 5, 6, 5, 5, 3 — сдвиг до 3 при выпадении одной ячейки (α=0.5\|K10) записан |
| P-H3 (MW_1 ≥ 0.65) | ✓ 0.668 — якоря PRE-003b воспроизведены |

## Итог (слабая форма)

**Читаемость близости рождения из снимка простирается на ~4 шага роста** (MW ≥ 0.62 до d = 4 с сильным началом) **и падает к неразличимости на d = 5–6** (MW 0.49–0.53, p ≈ 0.3). Гладкость затухания не установлена: кривая зигзагом в полосе шума этой мощности (n_d = 10–24 на ячейку суммарно), кромка LOO-чувствительна к одной ячейке. Вместе с PRE-001 (готовность растёт монотонно) и PRE-001b (момент слабо записан): накопление видно всегда, близость — на конечном горизонте ~половины типичного пути от K* до рождения, дальше мир недетерминирован для наблюдателя снимка.

## Классификации и возвраты

P-H1 — не установлен честно (между допуском и убийцей; мощность). Возвраты: n = 16 на бин для гладкости; горизонт во ВРЕМЕНИ (шаги ≠ время при разной канализации — пересчёт через медианные скорости роста ветвей); связка с плато PRE-007 (читаемость и внезапность на одной сетке α).
