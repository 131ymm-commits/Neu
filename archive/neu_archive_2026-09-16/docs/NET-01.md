# NET-01 — уровень = пара (динамика, класс наблюдения): одна траектория LJ13, три разбиения (2026-09-08, ночь)

Мотив: Cameron & Vanden-Eijnden 2014 — в сети 71 887 минимумов LJ38 мода выхода из икосаэдрической воронки стоит 245-й по
медленности, «заметной щели нет»; ZETA-01/SYNTH-05 — «нет уровня в C ≠ нет уровня». LJ38-01 (выброс при низкой T) по воротам 2 —
`занято`, контррасчёт подтверждён литературой, не запускался. NET-01 — та же мысль на LJ13 и на одной траектории: сменить класс
наблюдения, не меняя динамики. Ворота 1 — gate1_hypotheses_net01.md; ворота 2 — PRIORITY (`занято, но с другой стороны`: сети
минимумов Doye–Massen 2005, метабассейны Доливы–Хойера); ворота 3–4 — PREREG, gate.py пройден. Код: net01_sim.py (MD с квенчем на
каждом кадре), net01_analyze.py; net01_T*_s*.npz, net01_results.json.

## 1. Постановка
LJ13, T = 0.25 и 0.28 × сиды 401–403, 10⁶ шагов, 20 000 кадров по 50 шагов; на кадре — отсортированные расстояния (наблюдаемая
SPEC-01) и квенч L-BFGS (собственная структура, идентичность по E_IS с точностью 10⁻³); T = 0.36 — вырожденный контроль (жидкость).
Разбиения: (A) сеть IS (75–82 минимума при 0.25, 250–300 при 0.28, 669 при 0.36); (B) 100 микросостояний по расстояниям; (C) 10
квантильных бинов E_IS. Для каждого — обратимая MSM (лаг 2 кадра), ранг r_ico собственного вектора с максимальной |corr| с
индикатором икосаэдра (E_IS ≤ −44.32), ζ и решение по точной форме (FISH-01). Контроли: блочная перестановка кадров, половина кадров.

- **P-T3 ✓** — огрубление по энергии IS возвращает моду на ранг 1 на 6/6.
- **P-T4 ✓** — ζ_A < ζ_B на 5/6: спектр сети площе (иерархия ловушек), спектр по наблюдаемой — с более выделенной верхней шкалой.
- **K3 нет** — жидкость: «уровня» нет ни в одном разбиении; в (A) и (B) мода не определена (|corr| < 0.3).

## 4. Чтение
1. **Тезис SYNTH-05 §2 получил опору in silico**: одна и та же динамика — и разные спектральные ответы: по наблюдаемой уровень
   «твёрдое/жидкое» — верхняя мода (6/6, устойчиво), по сети собственных структур над ним на 4/6 траекторий стоят 1–4 моды, несомые
   минимумами с занятостью < 0.2 % — эффект «245-й моды» Cameron в миниатюре. Разница классов наблюдения — не косметика:
   ранг в сети нестабилен по выборке, ранг по наблюдаемой — нет.
2. **Огрубление — не потеря, а выбор уровня**: 10 бинов энергии оставляют одну шкалу над лагом — «уровень» как единственная мода
   возникает из разбиения, не из динамики (это и есть «число уровней — функция допуска» в другой форме).
3. Слабее, чем ожидалось: ранг ≥ 3 лишь на 3/6; в LJ13 при 20 000 кадрах ловушки над модой — единичные редкие минимумы, не
   сотни, как в LJ38; при большем горизонте они, вероятно, исчезают (сходимость по половине: больше кадров — ниже ранг в 4/6).
   Прямой перенос числа 245 на LJ13 не ожидался и не наблюдается.

## 5. Границы
Идентичность IS по энергии (перестановочные изомеры и вырожденные минимумы слиты); 20 000 кадров; ранг определён через |corr|
с одним индикатором (икосаэдр); блочная перестановка (блоки по 10) сохраняет внутриблочную кинетику — ITS падают до ~длины блока,
но |corr| в (B) держится; при T = 0.25 сеть мала (75–82 минимума). Не проверено: зависимость ранга в (A) от горизонта (10⁵ кадров).

   многоворонковых ландшафтов с несходящейся выборкой).
