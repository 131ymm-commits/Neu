## 2. Вердикты
- **P-I1 УБИТ (K1)**: сдвига ζ к приступу нет; наблюдение ZETA-01 на 5 сегментах было шумом (контррасчёт подтверждён).
- **P-I2 ✓, K2 нет**: «уровень» — 0 из 500 сегментов: приступ спектрально не двухъямен; класс выброса остаётся молекулярным.
- **P-I3 ✗**: порядок медиан C < D < B < E < A — обратный ожидаемому (5 инверсий): у здоровых ζ выше, у интериктальных ниже.
- **P-I4 ✓ (конкурирующий)**: t₁ приступа (21) выше здоровых A∪B в ≥ 1.5 раза, но интериктальные наборы C/D ещё медленнее (37–39):
  патология читается по верхней шкале — замедление, — а не по классу спектра; при этом класс везде континуум/граница иерархии.
- **K3 нет**: суррогаты E дают ζ 0.66 против 0.86 у данных (Δ_сурр = +0.22) — в приступе есть структура сверх спектра мощности;
  у здоровых A суррогаты ≈ данные (0.97 против 0.88) — здоровая ЭЭГ по этому тесту неотличима от линейного гауссова процесса.

## 3. Чтение
1. ζ (класс спектра) для ЭЭГ — не маркер состояния: все пять наборов сидят в полосе континуум/иерархия (0.67–0.96), и
   разница между ними меньше, чем разброс внутри набора. Что различает наборы — верхняя шкала t₁ (интериктальные медленнее
   всех: 37–39 против 11–21) и нелинейность сверх спектра при приступе (данные − суррогат +0.22).
2. Для §2 рамки: третий отрицательный результат по реальным рядам подряд (ZETA-01, DUST, ICT) в одном направлении — класс
   спектра реальных скалярных рядов почти не двигается (континуум/иерархия), двигаются шкалы. Координата ζ различает
   молекулу и синаевскую физику, но внутри одного домена реальных данных она почти константа.
3. Контроль сходимости (первые 50 против 100) не прошёл для B (0.58 → 0.82) и A (0.88 → 0.96): сегменты внутри набора
   неоднородны (пять испытуемых; порядок файлов, вероятно, по испытуемым) — медиана набора зависит от состава; бутстреп по
   сегментам это учитывает лишь частично (граница).

## 4. Границы
Один словарь (m = 5, шаг 2, k = 30, τ = 2 = 11.5 мс) — выбран в ZETA-01 без настройки; 23.6-секундные сегменты; неоднородность
испытуемых; суррогаты и сиды — по 20 сегментам. Ничего из этого не классификатор: точность не мерилась и не претендует.

## 5. Возвраты
Не планируется: направление закрыто (ζ не маркер). Если возвращаться к ЭЭГ — по t₁ и по избытку над суррогатом, с разбивкой
по испытуемым.
