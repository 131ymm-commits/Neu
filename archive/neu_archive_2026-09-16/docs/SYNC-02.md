## 1. Главная правка: угол O3 переформулирован — наивная форма опровергнута твоей же программой

O3 в LEVELS-01 звучал: «устойчивость уровня растёт с числом независимых носителей записи».
**BEHAV-004 (P6) это опровергает прямо:** без коррекции рост избыточности в 58 раз (N = 11 → 641) не даёт ничего — удержание 78/67/88/76 шагов, плоско по N. А **BEHAV-002** даёт правильную форму: избыточность работает только вместе с коррекцией по большинству выше порога — μ_c(N), порог Эйгена; R3 — «не R2 с большим τ, а другая фаза с порогом».

→ O3 исправлен: **«уровень стабилизируется избыточностью × коррекцией выше порога, а не избыточностью самой по себе»** — и в этой форме он внутренне занят (BEHAV-002/004; внешне — Eigen 1971). Что остаётся открытым: перенос ПОРОГОВОЙ структуры (не просто редундантности) на неквантовые носители памяти агентов и связь с квантовым дарвинизмом, где коррекции нет — почему там избыточность работает без неё (декогеренция как «коррекция средой»?) — вопрос жив, теперь точнее. Строка в PRIORITY обновлена.

## 3. Структурное ограничение BEHAV-040 — и что оно значит для LEV

«Возврат содержания измерим только у систем с внешней записью истории; внешняя запись и есть внешний эталон → методом "сломай и проверь" можно показать наличие эталона, но не его отсутствие».

Для дорожной карты LEV это хорошая новость по третьему домену: **обучение весов ИМЕЕТ внешнюю запись (чекпойнты, git данных)** — по критерию BEHAV-040 подпись там измерима. Плохая — для «поведения без записи»: там LEV-детектор может стать обходом (спектр меряет динамику, не требует записи утрат/возвратов) — кандидат на долг №5 пула («распознавание R3-слоя в системе с неизвестным устройством»): слои носителей должны оставлять след в спектре времён релаксации содержания. Это гипотеза для будущего хода, не утверждение.

## 4. Открытый вопрос пула «падение возврата с глубиной» — кандидат-механизм из рамки уровней

Факт (BEHAV-032…038, 6 контролей, механизм неизвестен): доля возврата откатанного падает с прожитым временем 0.71 → 0.44.
Кандидат из рамки: **ко-адаптация окружения = гистерезис**. Чем дольше содержание жило, тем сильнее окружение перестроилось вокруг него; после отката система релаксирует в новый бассейн (обходные пути, замены), и обратный переход дорожает со временем жизни. Это уточнённая версия их непроверенного кандидата «б» (сцепление) — и она даёт наблюдаемую: возврат должен падать с числом ПОСТ-откатных изменений в файлах, зависевших от откатанного (а не с самим временем жизни). Упирается в ту же проблему выгрузки путей; записано как кандидат, не результат.

## 5. UAF-6.1.0: что там есть и чего нет

- **Химическая нога «щели» уже начата:** chem/huckel.py считает HOMO-LUMO щель и λmax π-систем реальных молекул (ПАУ, полиены, аннулены, правило 4n+2) — H3 карты («щель = защита уровня») имеет в программе живой химический стенд. Для LEV это готовая площадка: связь HOMO-LUMO щели с устойчивостью/временами — кандидат на сшивку «щель молекулы ↔ щель динамики».
- Кросс-доменные сети (metabolic/powergrid/protein edgelists) — готовые графы для репликации LEV-002 на реальных топологиях (вместо случайных квенчённых).
- Кейсы: Египет-BGP (Q97.2: тяжёлый хвост есть, коллапс экзогенный — «уровень убит извне», не структурой), банки (Q90: нуль — банкротства не идут по сети владения). Полезные отрицательные эталоны для карты.
- **Формулы Crystal Score в репо нет** — ядро UAF (v6.x докуметы с определением λ₂/λ₁ и Coupling Hypothesis) всё ещё не загружено.
