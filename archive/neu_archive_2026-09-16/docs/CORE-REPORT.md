## 1. CORE-03 (главный) — три угла «коллективности»

Переопределил ψ′-коллективность как несводимость ОТНОСИТЕЛЬНО класса предикторов:
f_C = (I(S_t;S_{t+τ}) − max_{c∈C} I(c(x_t);S_{t+τ})) / I(S_t;S_{t+τ}). По построению f_nonlin ≤ f_lin ≤ f_axis.
- C = {оси} → f_axis (моя старая f; базис-зависима),
- C = {линейные} → f_lin (через Fisher LDA; ИНВАРИАНТНА к обратимым линейным заменам — проверено:
  std под вращением 0.000, обратимая замена тождественна),
- C = {все функции} → f_nonlin (out-of-fold гибкий классификатор).
Отпечаток уровня: **D = f_axis − f_lin** (распределённость по осям / базис-чувствительность),
**N = f_lin − f_nonlin** (нелинейность параметра порядка).

Замечание о ходе: механическая калибровка оценщика ДО заморозки прогнозов поймала два бага
инвариантности (z-нормировка по столбцам и отбрасывание мало-дисперсных PC ломали инвариантность;
сигнал REM жил в НИЗКО-дисперсной оси, которую PCA выбрасывала). Финал — LDA, инвариантный по
построению. Это и есть работа калибровки: правильно измерять до того, как измерять «результат».

базисным (D) эффектом.

### Своё: дефляция «коллективности»

ψ′-коллективность уровня — не единая холистическая величина, а СУММА трёх измеримых и по-отдельности
устранимых причин:
1. **D (базис)** — сигнатура распределена по осям выбранных координат; артефакт выбора координат,
   снимается инвариантной f_lin.
2. **N (нелинейность)** — параметр порядка есть КРИВАЯ функция наблюдаемых (дипептид: φ — дихедраль,
   нелинейна в расстояниях; N до 0.67), но всё ещё СКАЛЯРНАЯ функция микросостояния (f_nonlin ≈ 0).
3. **f_nonlin > 0 (остаточная несводимость)** — возникает ТОЛЬКО когда наблюдаемая НЕПОЛНА (пропускает
   степени свободы, от которых зависит макросостояние). Сон REM из одного канала: 0.15–0.32. Прогноз:
   добавить ЭОГ/ЭМГ → f_nonlin → 0.

Вывод: «коллективность» уровня всегда есть одно из {не тот базис, нелинейное кодирование, неполная
наблюдаемая} — а не эмерджентный холизм, несводимый в принципе. Это дефляционное, но полностью
операциональное и фальсифицируемое утверждение: каждую из трёх причин можно снять конкретным действием
(инвариантный базис, нелинейный редуктор, дополнение сенсора). И оно закрывает всю сагу «f растёт /
плоско / падает с весом» (LJ13 / дипептид / сон): весовая зависимость жила в D и в полноте наблюдаемой,
а инвариантная коллективность f_lin от веса почти не зависит (ρ = −0.12).

Отношение к литературе (интегрировано, ворота 2): координатная зависимость мер эмерджентности —
известная болезнь; Barnett–Seth «Dynamical independence» (PRE 2023, оптимизация линейного подпространства
для гауссова процесса), Zhang et al. «Causal emergence via SVD» (npj Complexity 2025, сингулярные числа
TPM), NIS+ (обучаемое огрубление) — три семьи лекарств. Мы НЕ добавляем меру: мы показываем, что для
НАШЕЙ дискретной ψ′ на трёх реальных системах «коллективность» полностью объясняется тремя устранимыми
причинами, и даём двухчисловой отпечаток (D, N) + остаток f_nonlin как классификатор уровня.

## 2. CORE-01 — относительный критерий уровней: честный провал на своём же пороге

Пытался заменить абсолютный зазор ≥ 3 (семья №14/45) на относительный: мода = уровень, если её
implied timescale выше P95 блочного суррогата И проекция бимодальна (ΔBIC ≥ 6). **P-C1 УБИТ**:
одноуровневые контроли дали ≥ 2 (LJ 0.36 → 3, дипептид 300 K → 2). P-C2/P-C3 «прошли» лишь по букве
(сон → 6, LJ 0.28 → 4 — грубая переоценка).

Диагноз — я попал в ту же семью №14/45, ПЫТАЯСЬ её чинить: ΔBIC масштабируется с n, поэтому при
n ~ 10⁴ даёт 85 … 961 749 для любой тривиальной негауссовости и НИКОГДА не отклоняет. Рабочей оказалась
только суррогат-медленность (корректно отклонила ложно-медленную моду кристалла при 0.18: its 6.0 ≤ P95
6.4, тогда как бимодальность-в-одиночку дала ΔBIC 3432 от дискретных оболочек решётки).

Конструктивно (описательно, следующий предрегистрируемый шаг): масштабно-инвариантный коэффициент
бимодальности Сарла BC ≥ 0.555 вместо ΔBIC чинит грубое — LJ 0.36 → 1 (BC медленной моды 0.381 < 0.555,
«медленный дрейф, не две ямы»), сон 2–3 вместо 6. Но целого оракула не даёт (дипептид 300 K → 2 через
дихедраль ψ; LJ 0.28 → 3). **Глубокий урок**: «число уровней» — не резкое целое ни в молекулах, ни во
сне; есть ИЕРАРХИЯ слабо-разделённых медленных мод, и счёт зависит от порога и наблюдаемой. Это ровно то
же, что показал CORE-03 про коллективность — всё в грамматике уровней порого- и базис-относительно.

## 2′. CORE-01′ (CORE-01p / CORE-01p-b, 2026-09-04) — тройка решений вместо целого

Заимствование из HUB-PRIOR-ART-3/4: байесовский постериор матрицы переходов (deeptime, эффективные счётчики;
родственник — Dirichlet-MMSE в mMSM) как ВАРЬИРУЮЩИЙ нуль зазора. Наблюдаемая — не точечный зазор g₁ = t₁/t₂,
а его надёжность P₁ = P_post(g₁ ≥ g*) при допуске g* = 3; решение: «уровень» (P₁ ≥ 0.95), «нет» (≤ 0.05),
«отказ — данных не хватает» (между).

**Первый прогон (500 000 шагов LJ13) недействителен по собственному контролю** — и это главный урок: контроль
невырожденности «половина кадров → постериор шире» провалился 21/29 не потому, что постериор не зависит от данных,
а потому что при потере редких вылазок (0.22: 2–8 за траекторию) он становится УВЕРЕННО узким в ложную сторону
(P₁ 0.45 → 0.00 при ширине 1.59 → 0.09). Байесовский нуль не выражает «не наблюдалось». Плюс класс C: 500k
заморожены при эталоне MOL-002 в 1M (оценщики совпали 18.4/18.4 — расхождение в данных).

**Повтор при 1M (CORE-01p-b) с отказом по числу committed-вылазок n_exc < 10 — 4/4 прогноза ✓ на 15/15 наборах**:
0.18/0.36 → «нет» 6/6; 0.22 → постериор уверен (P₁ ≥ 0.99) при 4–7 вылазках → отказ 3/3 (переуверенность
для редкого уровня — результат, не сбой); 0.25/0.28 → 3 «уровень» + 3 «отказ» при точечных g₁ = 3.1–4.3 —
кромка порога 3 видна как кромка; под-уровень g₂ = 1.6–2.3 (t₂ ≈ 11–15 против t₃ ≈ 6–8) надёжен 6/6 и невидим
правилу 3. Не зависит от длины: сон — «нет уровня» 6/6 ночей (P₁ ≤ 0.015; негатив BRAIN-001 надёжен при объёме
одной ночи); дипептид 300 K — «нет зазора ≥ 3» при ±0.07 (медленная мода есть, зазора нет), 400–700 K — 1.00.

Итог по «числу уровней»: это функция допуска g* с состоянием отказа, а не целое; v1 («зазор ≥ 3») понижен до
допуска и обёрнут в тройку решений; v2 (ΔBIC) не возвращается. Побочно: KL-замыкание огрубления (CE 2.0) при
нуле случайных разбиений вырождено — случайное разбиение «замкнуто», потому что не несёт медленной информации;
замыкание сертифицирует уровень только в паре с информативностью. Возврат: ψ′ при жёстком PCCA+ отрицателен
там, где k-means по собственному вектору давал +0.15 — чувствительность ψ′ к способу разметки (касается CORE-03).

## 3. CORE-02 — рождение через попытку: усечение окна, петля с MOL-004 закрыта

Хотел R(скорость) = доля рождений жидкого уровня через неудачную попытку, по 20 реплик на плечо рампы.
**P-R1 не установлен, P-R2 УБИТ** — но по причине класса B, не физической: число реплик, где жидкое
ВООБЩЕ committed-родилось за плечо, коллапсирует с ускорением рампы (20 → 14 → 8 → 0 из 20), поэтому
R = 0.25 → 0 → 0 → н/д отражает усечение окна наблюдения, а не «быстрая ручка → нет попыток». То же, что
середина в MOL-004. Вывод (закрывает возврат MOL-004): рампы — неверный инструмент для крамерсовой
статистики попыток в конечной системе; нужен фиксированный-T ансамбль у сосуществования (0.28) с длинным
наблюдением — спонтанные попытки в единицу времени, без ручки. Это переносится в поименованный возврат.

## 4. Что арка добавила к программе

1. **Дефляция коллективности (своё).** Стрелка 6 FORMATIONS §4 («коллективность — свойство пары
   уровней») переформулирована операционально: пара уровней коллективна ровно в той мере, в какой её
   разделение (a) распределено по осям базиса (D — устранимо инвариантностью), (b) нелинейно кодировано
   (N — устранимо нелинейным редуктором), (c) зависит от степеней свободы вне наблюдаемой (f_nonlin —
   устранимо дополнением сенсора). Ни (a), ни (b), ни (c) не есть несводимый холизм.
2. **Парадокс вырождения (BRAIN-002 P-M2) растворён численно**: ψ′ — несводимость к классу предикторов,
   а не к любым функциям; расширение класса до всех функций тривиально обнуляет её для любого
   детерминированного огрубления.
3. **Семья №14/45 подтверждена изнутри**: абсолютный порог опасен настолько, что я воспроизвёл ошибку,
   пытаясь её лечить (CORE-01, ΔBIC). Относительная форма нужна ОБЕИМ половинам критерия.
4. **«Число уровней» — не целое.** И молекулы, и сон дают иерархию слабо-разделённых мод; счёт
   порого-относителен — согласуется с дефляцией коллективности.
