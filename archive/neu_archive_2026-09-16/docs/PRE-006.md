PRIORITY: `занято, но с другой стороны` — задача классификации типа бифуркации из одной серии занята DL-линией (Bury и др., PNAS 2021; продолжения 2022–2025); наша сторона — интерпретируемое ЗАМОРОЖЕННОЕ дерево из признаков собственной батареи, форензика ПОСЛЕ перехода, слепой протокол калибровка/тест раздельными сидами. Репетиция внешних данных (№4 плана): наблюдателю доступна одна запись — твины, ансамбли, модельные суррогаты запрещены.

## Постановка

Три системы PRE-004 (Шлёгль V=20 — фолд; Ферхюльст Ω=50 — транскритика; Брюсселятор Ω=500 — Хопф), дрейф через рождение за T=600, 6000 отсчётов. Классификатор обязан назвать маршрут по одной записи. Пороги замораживаются на калибровочных сидах с явными УСЛОВИЯМИ ЖИЗНИ признаков (разделение классов до теста — урок: кромку сверять с арифметикой и сигнального класса, не только нуля); тест слепой; матрица ошибок предрегистрирована (≥ 12/15 и 0 перепутываний фолд ↔ Хопф).

## Тест 006c подробнее

Матрица: фолд 4/5 (+1 «нет рождения»), транскритика 4/5 (+1 «фолд»), Хопф 5/5. Контроли: «нет рождения» 7/9 — оба ложных на предсказанной заранее кромке (бездрейфовый Брюсселятор: квазициклы НАМАТЫВАЮТ z = 9.7/10.6 при пороге 9.57 — порог лежит внутри полосы Хопф-нуля). Оба промаха кромочные, с механизмами: fold#5 — побег в самом конце записи (rise 1.7σ — rise-гейт слеп к поздним побегам; S при этом 78!); trans#5 — стохастическая задержка старта роста (t_wait ↑, S = 11.7 > 8.64).

## Итог (слабая форма)

**Маршрут рождения читается из одной дрейфовой записи** интерпретируемым деревом из трёх траекторно-внутренних признаков, и все три — прямые потомки батареи сертификатов: вращательный сертификат → намотка фазы; транзиент-сертификат → C1-отношение ожидание/пересечение; подъём. Резкость (обе формы) на медленных часах мертва: **разрыв/непрерывность различает временна́я структура (плато → переезд), не крутизна** — согласуется с конечно-размерной физикой (№52: рождение — граница, скачок размывается медленными часами малого V). Хопф не путается ни с чем (0 перепутываний во всех трёх версиях — вращение ортогонально обоим скалярным маршрутам). Ограничения: три системы одного (CME) класса, по 5 тестовых записей, одна скорость дрейфа; кромка Хопф-нуля (порог намотки внутри полосы бездрейфовых квазициклов) названа и не закрыта.

## Классификации и возвраты

J (006) — класс B (не та наблюдаемая в признаке: амплитуда вместо резкости); R (006) — семья №50, новая разновидность: пол обязан быть достижим для СИГНАЛЬНОГО класса (пол из максимума перестановки > медианный пробег чистого вращения; второй случай max-раздувания после PRE-004c); J2 (006b) — честный негатив: резкости нет в данных на этих часах (физика, не конструкция). Возвраты: порядок ножек S ↔ rise-гейт (поздние побеги); порог R2 из квантилей бездрейфового Хопф-нуля; перенос дерева за CME-класс — на LoRA/BEHAV-записи (№5 плана).
