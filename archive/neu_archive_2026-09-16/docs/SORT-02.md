## 0. Определение
ρ = max|λ| (λ ≠ 1) — огибающая любой моды; **ρ₊ = max{|λ| : λ ≠ 1, Re λ > 0}** — модуль медленнейшей нечередующейся моды
(период > 4 лагов). ρ₊ ≤ ρ; рождения по ρ₊ ⊇ рождения по ρ; у нормальных операторов рождений нет ни по одному (W(A) = conv σ(A)).
ρ остаётся первичным; ρ₊ — эталон стороны EP и постоянства для монотонных описаний.

Итог одной строкой: **второй радиус возвращает исключительной точке её роль при шуме (постоянный сорт живёт на вещественной
стороне при всех s ≤ 0.2, ρ₊-окно закрывается при s ≈ 0.36 ≈ 1 − 2/π, а «хрупкость» SORT-01 была чередующейся ветвью в роли
радиуса); на ЭЭГ он ничего не меняет, рождения PCCA(2) и веса a₊ лежат над конечновыборочным обратимым нулём — но правильный нуль
для оценённых цепей — обратимый процесс через тот же конвейер вложения, и его ещё нет.**

## 4. Чтение в личине
1. Радиус — свойство пары (оператор, класс описаний): монотонные описания конкурируют с нечередующимися модами. ρ₊ — не
   замена ρ, а второй эталон; DET/ROT/ACH упирались в один и тот же морфизм «модуль стирает знак».
2. Два нуля для оценённых цепей: выборочный (обратимая MSM на микросостояниях; ЭЭГ над ним) и конвейерный (обратимый процесс
   → вложение → кластеры → MSM; телеграф даёт рождения). COG-01 «PCCA рождает уровень у 7/25 ЭЭГ» доказал первое и не проверял
   второе; PERS-01 «транзиент по лагу» согласуется с обоими.
3. Личина обязана сказать: a₊ > 1 у F001 — одно наблюдение при пилотном максимуме артефакта 1.94; не постоянное рождение мозга,
   а кандидат до SORT-03.
