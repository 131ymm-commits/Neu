## 2. Вердикты
- **P-U12a ✓, K1 нет** (на оценимых нулях): смена режима даёт «не по Пуассону» в 50–55 % пар при N_c ≥ 30 против 0 % у
  стационарного L = 40 — ровно арифметика PREREG (одна из двух пар префикса пересекает смену). Нуль L = 320 для статистики пуст
  (ни одной пары с N_c ≥ 30 — кромка не проверена арифметикой для этого семейства; семья №14/45, случай без последствий для вердикта).
- **P-U12b ✗ по букве, K2 нет**: смена — расхождение префикс/суффикс у 10/10, стационарный L = 40 — 0/10 ✓, но стационарный
  L = 320 — 5/10: при N_c ≤ 12 глобальные β шумят на ±0.3 сами по себе (HOR-02). Признак расхождения специфичен только когда обе
  половины разрешены (N_c ≥ N* в каждой) — поправка формулировки, не смерть.
- **P-U14 ✓, K3 нет**: 3/4 разрешённых (75 % ≥ 60 %) и 11/12 всех — скачок читает зазор и на реальных рядах; контррасчёт
  («эпоха внутри окна — скачок систематически больше зазора») не подтверждён: Δ обоих знаков, медиана −0.15.

## 3. Чтение
1. Сертификат нестационарности P-U12 работает в предсказанном виде: «шкала сошлась (N_c ≫ N*), но при удвоении окна прыгнула»
   — событие, которого у стационарного процесса нет (0/40), а у смены режима есть у половины пар. Ложных тревог на стационарном
   нуле нет; чувствительность — одна пара на смену, т.е. сертификат ловит смену только окном, её пересекающим.
2. Расхождение префикс/суффикс — признак второго сорта: он ловит смену (10/10), но врёт при малом N_c. В атласе шкал его надо
   обусловливать на N_c ≥ N* в обеих половинах.
3. «Скачок = зазор» — не свойство синтетики: NGRIP даёт 4.3 бита при зазоре 3.3–3.8 (ледниковье ↔ голоцен), корь 1.5 при 1.0,
   COVID US 1.2 при 1.2. Единственный промах — NGRIP-2D W (−2.8): первый оборот на полном окне — дегляциация, и в коротком
   префиксе t₁ выше, чем после (K4 DUST-02 в новой форме).

## 4. Границы
Одна форма смены (скачок L на середине), одна амплитуда; сертификат P-U12 проверен на 2 семействах × 10 сидов; P-U14 — 4
разрешённых ряда (+ 8 описательных). t₂ полного спектра — по обратимой MSM (завышено при вложении, EST-01).
