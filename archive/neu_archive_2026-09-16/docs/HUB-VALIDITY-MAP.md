# Карта границ применимости (validity map)

Дата: 2026-08-12. Принцип: исключение — не опровержение, а точка на границе
области применимости; граница принадлежит теории. Каждое «не работает» получает
три координаты: ГДЕ (что такое «здесь»), ПОЧЕМУ (механизм), ГРАНИЦА (измеримая
переменная, по которой заранее видно, применим ли закон). Закон без границ —
лозунг.

## EXP-BOUND-001: шкала хаб-шунт / хаб-среда (измерено, seed=42)

R = доля LCC после удаления хаба. Пререгистрация в exp_bound_001.py; счёт 4/5
(провал (d) для grid на 0.003 — см. ниже).

| система, удаление | R |
|---|---|
| star − хаб (контроль «чистая среда») | 0.000 |
| ядро Linux − include-слой | 0.037 |
| ядро Linux − top-5% по степени | 0.615 |
| ACTIVSg2000 − слои 500+230 кВ | 0.695 |
| метаболизм − валютные метаболиты | 0.708 |
| FX 1890 − {GBR, FRA, DEU} | 0.733 |
| ACTIVSg2000 − top-5% | 0.769 |
| авиация − top-5% | 0.772 |
| FX 1910 − {GBR, FRA, DEU} | 0.778 |
| ACTIVSg2000 − слой 500 кВ | 0.800 |
| BA(60,2) − top-5% | 0.883 |
| метаболизм − top-5% | 0.917 |
| рельсы Индии − top-5% | 0.929 |
| clique − top-5% (контроль «чистая база») | 0.950 |
| решётка 8×8 − top-5% | 0.953 |

Три синтеза из шкалы:

1. **Среда — свойство класса, не узлов.** Ядро: top-5% по степени → R=0.615,
   include-слой целиком → R=0.037. Разрыв ×17: интерфейсный класс внутренне
   избыточен (средние заголовки подменяют крупные), но эксклюзивен как класс.
   Дихотомия шунт/среда определяется ролью слоя, не центральностью узлов.
2. **R предсказывает режим смены хаба.** Шунт (R≈0.7–0.8: резервная валюта,
   500 кВ, валютные метаболиты) допускает эрозию и ЗАМЕНУ — фунт→доллар прошёл
   без коллапса, и R(FX) вырос 0.733→0.778 за 1890–1910 (третье независимое
   измерение эрозии, вместе с ρ₁↓ и b₁↑). Среда (R≈0.04: include, генетический
   код) незаменима — только ОБХОД новой картой (C3 в абсолютной форме).
   Проверяемое следствие: у талии IPv4 должен быть низкий R — потому её и
   обходят (NAT, QUIC), а не заменяют.
3. **Граница закона «удаление хаба обнажает базу»**: работает при R ≥ ~0.7
   (метаболизм, P1b PASS), отказывает при R ≈ 0.04 (ядро, P-K5 FAIL).
   Зона 0.04–0.6 не промерена — открытый интервал.

## Двенадцать исключений: где / почему / граница / статус

1. **M1=λ₂/λ₁ слеп к star vs clique.** Где: задачи детекции хаба. Почему:
   спектральная щель меряет скорость перемешивания, оба — быстрые миксеры.
   Граница: M1 валиден для счёта метастабильных кластеров (уровней); для
   концентрации — тройка (M1, M2, ρ). Статус: измерено (Stage 0), закрыто.
2. **atp_c ранг 11, протон топ (метаболизм).** Где: невзвешенные
   субстрат-продуктовые графы. Почему: топология видит участие (слой
   расслоения), не свободную энергию; валюты — координаты слоя. Граница:
   наличие moiety-структуры (rank K > 0) → сырые центральности меряют слой,
   ценность базы требует квотиента или весов ΔG. Статус: объяснено
   калибровочной картиной, подтверждено P1b. Закрыто.
3. **mech победил в энергографе.** Где: малые ручные графы с периферийными
   монополиями (grav/elast только через mech). Почему: путевая betweenness
   меряет монополизацию тупиков; гранулярность n=8. Граница: дисперсия
   реальных потоков — при Sankey≠топологии путевые метрики невалидны.
   Статус: разрешено потоками (тепло ≥82%, HUB-003a). Закрыто.
4. **«Нулевая энтропия» ненаблюдаема топологией.** Где: все чисто структурные
   тесты. Почему: качество — монотон ресурсной теории, не структура. Граница:
   топология ↔ слой цен; нужен эксергетический вес. Статус: открыто, помечено.
5. **«Алфавит» 1890–1910 оказался звездой.** Где: домены с вырожденным argmin
   (заряды не форсируют число образующих). Почему: rank(K|T) задаёт множество
   возможных режимов, выбор делает история (множественные равновесия
   Кийотаки–Райта). Граница: вырожденность решения; классификация предсказывает
   множество, не точку. Статус: переквалифицировано из закона в ограничение.
6. **HUB-005: 8/15 при пороге 9.** Где: фиксированный горизонт при конечной
   глубине слоя (~9–10). Почему: после исчерпания слоя детектор ест базу.
   Граница: правило остановки по плато M1. Статус: 005b в очереди.
7. **M2 упал вместо роста при удалении валют.** Где: графы с плотным ядром.
   Почему: вектор Перрона локализуется на плотности, не на хабе. Граница:
   M2 ≈ мера локализации-на-плотности; при плотном ядре не интерпретировать
   как хабовость. Статус: зафиксировано в методичке.
8. **L1 ядра — не уровень (D=+1.8), L2 — уровень (D=−35.6).** Где:
   спроектированные таксономии. Почему: имена ≠ взаимодействия; drivers —
   корзина. Граница: сама D — измеримое расхождение декларированной и
   динамической башен; декларация без проверки D — не уровень. Статус:
   превращено в измерение. Закрыто.
9. **P-K3: ×2.7 при пороге ×3.** Где: слои большого размера (18.8% узлов).
   Почему: ненормированный lift; при доле s порог ×3 требует 3s топа.
   Граница: нормировка lift/(1/s) или доля топа против s с поправкой.
   Статус: методическая правка, перепроверка в следующем доменe.
10. **P-K5: удаление include распылило граф.** Где: хаб-как-среда (база без
    собственных рёбер: .c не включают .c). Почему: вся связность через
    квотиент. Граница: R — измерена, см. шкалу; закон применим при R⪆0.7.
    Статус: превращено в ось. Закрыто как исключение, открыто как интервал.
11. **Хвостовые инверсии (Гренландия, архипелаги, штаты τ=300).** Где: все
    реальные многоуровневые системы. Почему: изоляция локально сильнее
    иерархии. Граница: законы уровней — о медианах; хвосты несут отдельную
    информацию (изолируемость). Статус: систематика, не исключение.
12. **τ ядра микроскопичны (4 против 96–264 у сетей).** Где: хаб-среды.
    Почему: среда закорачивает блуждания за 2–4 шага. Граница: амплитуда
    τ-закона ∝ (1−доля потока через хаб); при R→0 закон вырождается в
    тривиальный. Статус: связано с осью R.

## Провал этого захода (честно)

Предсказание (d): «grid top-5% > aviation top-5%» — FAIL: 0.769 < 0.772.
Разрыв 0.003 в пределах шума, но порог шума зарегистрирован не был → FAIL по
букве. Урок: направленные предсказания на близких величинах регистрировать
с минимальным зазором. Содержательно: техасская сеть менее избыточна, чем
планарная интуиция (деревья фидеров на подстанциях).

## Обобщение

Из двенадцати исключений: пять закрыты (превращены в калибровку инструмента
или разрешены данными), три превращены в новые измеримые оси (D, R, глубина
слоя), два — в методические правки порогов, одно — в систематику хвостов,
одно (нулевая энтропия) остаётся открытым и требует нового слоя измерений.
Ни одно не потребовало отбросить закон целиком — каждое сузило координаты
его действия. Это и есть нормальный рост эффективной теории.

    теоретических 0.75/0.83/0.90/0.95), двумодальность R сохраняется
    (промежуток 0.644).

## Запись №49 (EXP-HIST-001)

49. **Различие политических конфигураций есть инверсия назначения
    режимов, а не степень концентрации.** Где: сравнение систем
    управления. Почему: слоёв всегда два (процедура и аппарат), режима
    два (среда R≈0 и шунт R≈0.7), промежуточного нет (пустой
    промежуток 0.658); различается, какому слою достался режим среды.
    Устойчивость обеих конфигураций задаётся одной величиной
    μ_c = 1 − 1/⟨k⟩, и переход через порог ОБВАЛЬНЫЙ: при ⟨k⟩ = 10
    удержание падает 0.63 → 0.30 на интервале 0.02 по μ. Граница:
    аппарат измеряет устойчивость, а не желательность; исторические
    значения ⟨k⟩ и μ не измерены никем и в разборе даны как
    иллюстрация правила; прогноз даётся только направленный —
    по измеренной калибровке программы (направления 4/4, величины 2/6).
