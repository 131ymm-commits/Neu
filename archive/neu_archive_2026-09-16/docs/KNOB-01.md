# KNOB-01 — ненормальность как ручка: бездивергентный ток, запас δ, рождения на разбиениях; δ против производства энтропии (2026-09-09)

Ворота 1 — gate1_hypotheses_knob01.md; ворота 2 — PRIORITY (`занято, но с другой стороны`: ток ускоряет моды — Ichiki–Ohzeki,
lifting, Bierkens; наша сторона — невидимость тока для 2-блочных описаний и ранжирование рождений δ против σ); ворота 3–4 —
PREREG с поправкой после первого запуска (конструкция K = M − Mᵀ оказалась вырожденной ручкой, θ_max ≈ 0.001; заменена на
циклические токи Кирхгофа; первый запуск не интерпретируется). Код: knob01_run.py; knob01_results.json.
Семейство: P_θ = P₀ + θ·D⁻¹K, P₀ — случайная обратимая цепь (N = 6), K — сумма трёх случайных циклических токов; 200 пар,
11 узлов θ ∈ [0, θ_max], θ_max ≈ 0.4–1.0 (положительность).

## 0. Лемма (точная, проверена в коде как контроль)
В симметризованной форме A_θ = S + θT, T антисимметрична. Для любой вещественной наблюдаемой g: ⟨A_θ g, g⟩ = ⟨S g, g⟩ — не
зависит от θ. В частности, **λ₂ любой 2-блочной лумпированной цепи не зависит от тока** (нарушений 0 из 2200 проверок при
допуске 10⁻¹⁰). Ток невидим для любого двухсостоянного описания на лаге τ; он двигает только моды.

- **P-K2 ✗, K1 сработал**: доля рождений при θ_max 1.3 % < 2 %: ручка двигает δ (и ρ), но достижимость на 2-разбиениях остаётся
  редкой — ускорение мод на ~10 % редко опускает ρ ниже лучшего 2-блочного ⟨Sg, g⟩ (тот по интерлейсингу ≤ ρ(0), обычно заметно
  ниже). Контррасчёт (а) по этой кромке верен.

## 3. Чтение
1. **Механизм рождения расшифрован до леммы**: ток бездивергентный не меняет ни одного двухсостоянного описания на лаге τ и
   не меняет числовой радиус, но ускоряет моды (ρ ↓ ∝ θ²). Рождение уровня при огрублении = моды стали быстрее, чем самое
   медленное грубое описание, которое тока не видит. Это — точная форма «ускорения необратимостью» (lifting, skew detailed
   balance), увиденная с грубой стороны: ускорение невидимо грубому наблюдателю.
2. **Производство энтропии не предсказывает рождений (AUC ≈ 0.5), ненормальность — предсказывает (0.83).** Необратимость и
   ненормальность — разные вещи: нормальная необратимая цепь (вращение) производит энтропию, но не рождает; ненормальная — рождает.
   Для программы это закрывает искушение мерить «токи» через σ: правильный инвариант — δ.
3. Достижимость — узкое место (как в COG-01 «цикл + сброс»): δ — верхняя граница, разбиения её реализуют редко; на данных
   реализуют PCCA-огрубления ЭЭГ, не случайные блоки.

## 4. Границы
N = 6, три цикла, 200 пар; θ_max задан положительностью; рождение считается только по 2-блочным разбиениям (у k-блочных
инвариантности по θ нет — не мерилось); первая конструкция ручки была вырожденной и заменена до вердиктов.
