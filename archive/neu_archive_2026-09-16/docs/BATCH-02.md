## DET-004 — тор/Неймарк-Сакер: классификатор трёх маршрутов работает, два критерия сломались конструкцией

**Числа.** T\* = 16.6 (этап A). Пара θ/π = 0.27–0.35 во всём окне, круговой джекнайф-разброс ≈ 0; порог t₁ ≥ T\* пересекается устойчиво с r = 1.958 (в заявленном окне [1.93, 2.10]); вращение θ(ℓ) = ℓθ(1) — во всех точках; вторая гармоника (≈2θ) видна во всех точках окна; суррогаты и вырожденные молчат.

- **P-N2 (классификация трёх маршрутов) ПОДТВЕРЖДЁН: 8/8 без единой ошибки** (2 формальные NS-точки детекции θ ≈ 0.27–0.28π + 3 flip θ = π + 3 fold θ = 0; девятой точки не стало из-за плато — см. ниже).
- **P-N4 (вращение) и P-N5 (гармоническая лестница) подтверждены; H0 о неустойчивости несимметризованной оценки опровергнут** (разброс θ ≈ 0).
- **P-N1 формально FAIL:** плато-компонента (t₁ по лагам {2,4,8}) ломается на вращающихся модах во всём окне; первая точка, прошедшая ВСЕ компоненты, — r = 2.19 (вне окна). Разложение (пост-хок, помечено): пороговая компонента пересекает T\* ровно в окне (1.958); ломается только плато.
- **P-N3 (парный различитель) УБИТ собственным критерием:** fold-точки тоже прошли парный тест — зарегистрированное правило пары (|λ₃|/|λ₂| > 0.95, |θ₂+θ₃| < 0.2) вырождается на двух ВЕЩЕСТВЕННЫХ близких модах (θ ≈ 0 у обеих ⇒ сумма углов ≈ 0 тривиально). Дефект конструкции: нет требования ненулевого угла. Задним числом не чинится; классификацию несёт θ (P-N2), которому пары не нужны.

**Методическая запись (главный урок партии, повторён дважды — см. DET-005):** плато по неявным временам и парный критерий, сконструированные и отлаженные на вещественных модах (fold/flip), НЕ переносятся на осцилляторные моды без правок: (i) неявное |λ| осциллирующей моды лаг-неустойчиво при грубом биннинге (несоответствие >20% между лагами — не шум, а систематика оценщика); (ii) правило пары обязано требовать |θ| > 0. Правки поименованы, применять только в будущих предрегистрациях.

## DET-005 — вторая ступень каскада: видна точно там, где предсказано; плато-компонента ломается той же поломкой

**Числа.** R₂\* = 4.0 (вырожденные: π/2-группы нет вовсе). R₂(B3): 1.5 (r=3.40) → 2.7 → **5.65 (r=3.44, пересечение)** → 6.8 → 6.7 → 9.6 → 10.7 (3.52) → 8.9; θ = π/2 точно; j16 ≈ точечным; суррогаты молчат. Третья ступень при σ=0.001 (эксплораторно): π/4-семейство остаётся глубоко в объёме (max|λ| 0.16–0.26) — НЕ видна; δ̂ не вычисляется.

- **P-C1 формально FAIL по букве** (в критерий входило плато): плато не проходит ни в одной точке. Разложение (пост-хок, помечено): пороговая и тайминговая компоненты попадают точно — устойчивое пересечение R₂\* с r = 3.44 при истинной точке 3.4495, в заявленном окне [3.44, 3.50]; контроли чистые. Причина провала плато — та же лаг-неустойчивость |λ| осциллирующих мод (диагностический пример: |λ|(lag1) = 0.865 vs implied(lag3) = 0.938 → t 6.9 vs 15.6).
- **Отклонение от предрегистрации, зафиксировано:** идентификация мод перенесена на лаг 1 (углы различимы только там), плато — на {1,3} вместо {2,4,8}; поименовано до анализа окна, в отчёте не смягчается.
- **Честный итог:** оператор видит вторую ступень каскада (порог+тайминг+контроли), третья ступень при этом шуме недоступна; каскад из траекторий обрывается на второй ступени; δ-территория требует либо меньшего шума, либо другого оценщика.

## OL-001b — ручка аденина валютная, а не степенная

**Числа.** Аденин-доля среди меченого КАРКАСА: 0.346 / 0.440 / 0.610 / 0.426 (n = 81/75/105/108) против 1.00 у валют во всех четырёх организмах; не-аденин каркас — CDP-липиды, CTP/CMP, UDP-сахара, ADP-гептозы. Spearman ρ(log₂-степень, аденин | меченый каркас) = 0.004, p_perm = 0.47, LOO стабильно около нуля.

- **P-A1 ПОДТВЕРЖДЁН:** < 0.6 в 3/4 (дрожжи 0.61 — на волосок выше), всюду ниже валютной; убийца (≥0.8 в ≥3) далеко не сработал.
- **P-A2 не установлен:** градиента по степени НЕТ (ρ ≈ 0). Это уточняет OL-001 неожиданно чисто: TAG-метка следует за степенью (OL-001), но ВЫБОР ОСНОВАНИЯ — нет: аденин-эксклюзивность — свойство именно валютной корзины, а не хабовости вообще. Два сигнала разделились: «нуклеотидность» — степенная, «аденин» — валютная.

## DET-002R — ступень универсальна; критерий детекции — бюджетно-ограничен

**Числа.** 20 квенчённых графов (+1 исключён mean-field'ом не был — все прошли), DAG-двойники на каждом K. **DAG: 0/20 срабатываний.** Ступень (max ΔR на шаге закрытия): **19/20**. Устойчивая детекция в {K_cycle, K_cycle+1}: 11/20; среди сидов, где детекция вообще была (12), попадание 11/12. Молчащие сиды систематически с ПОЗДНИМ закрытием: K_cycle молчащих [8,11,12,12,13,13,15,19] против детектированных [2..11] (медианы ~12.5 vs 5.5). Миниатюра реального графа (метаболический edgelist, 15 узлов): K_cycle = 11, ступень на закрытии ✓, детекция молчит — согласуется с паттерном.

- **P-R2 ПОДТВЕРЖДЁН (19/20):** ступень на закрытии — не свойство seed 4242. H0 о единичном графе опровергнут в этой части.
- **P-R1 формально УБИТ (11/20 ≤ 12):** критерий устойчивой детекции LEV-002 не универсален. Разложение (пост-хок, помечено): провал не случаен — детекция гаснет при позднем/длинном первом цикле: зажигание требует ко-подъёма большего числа узлов, обмен становится реже окна наблюдения (T = 400, B2). Это та же граница «детектору нужно окно ≫ времени обмена», теперь с третьей стороны (LEV-002: быстрый обмен ≈ лаг; здесь: редкий обмен ≫ окна).
- **Синтез:** рождение замыканием универсально ОСТАВЛЯЕТ СТУПЕНЬ в R(K); превращение ступени в формальную детекцию — вопрос бюджета, масштабируемого длиной первого цикла. Кандидат-закон (не зарегистрирован): порог бюджета ~ время зажигания растёт с длиной цикла; проверка — отдельный ход с T, масштабируемым по K_cycle.
