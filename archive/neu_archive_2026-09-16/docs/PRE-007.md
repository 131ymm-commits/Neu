# PRE-007 — α-граница внезапности: не точка, а плато с обрывом у хабового края

Дата: 2026-08-26. Предрегистрация: PREREG.md § PRE-007 (до прогона; gate.py OK). Продолжение линии PRE-002/003/003b её же замороженным конвейером (согласование K* по выживанию, метки imm/dist по близости Kc к K*, AUC при K*, MW-разделение); занятость покрыта строками линии.

## Постановка

Якоря PRE-003b: D(0.5) = 0.692, D(1) = 0.518 — читаемость близости рождения из снимка падает где-то в (0.5, 1). Сетка α ∈ {0.625, 0.75, 0.875}, n = 24 + 24 на ячейку, три пары K_u, D(α) = медиана MW; граница = пересечение уровня D_mid = 0.605 линейной интерполяцией (форма заморожена).

## Результаты

Кривая D(α): **0.692 → 0.589 → 0.618 → 0.635 → 0.518** (α = 0.5 … 1).

| прогноз | исход |
|---|---|
| P-L1 (невозрастание с допуском +0.03) | ✓ формально — макс. рост +0.030 РОВНО на допуске (0.589 → 0.618) |
| P-L2 (α_b ≥ 0.75) | **УБИТ**: формальная кромка α_b = 0.61 — но см. ниже: оценка держится на провале одной точки |
| P-L3 (медианы Kc убывают) | ✓ 8 / 8 / 7 — тренд канализации 9 → 8 → 7 продолжается |

Ячейки середины сетки: MW = 0.543–0.648 при перестановочных p = 0.02–0.31 — большинство на грани различимости при n = 24; якорь α = 0.5 сильный (p ≈ 0.01 в 003b), якорь α = 1 мёртвый (p = 0.4–0.6 — полная нечитаемость).

## Итог (слабая форма)

**Обвал читаемости по α — не точка.** Середина сетки [0.625, 0.875] лежит промежуточным плато D ≈ 0.59–0.65 (частичная читаемость, на грани мощности n = 24); полная потеря наступает только между 0.875 и 1 — у самого хаб-доминированного края. Формальное пересечение уровня 0.605 при α ≈ 0.61 — артефакт немонотонности (провал в 0.625, затем частичное восстановление 0.618/0.635): точечная локализация границы уровнем на шумной кривой с перепадом ~ шуму неустойчива. Убийство P-L2 записано как честный промах направленного прогноза в ЗАМОРОЖЕННОЙ метрике; содержательная замена — двухступенчатая картина «плато → обрыв».

## Классификации и возвраты

P-L2 — класс F-с-поправкой (сильная точечная формулировка на кривой, которая оказалась плоской в середине); методическая запись: локализация границы уровнем на кривой с шумом ≳ перепада требует либо мощности, либо изотонической регрессии — кандидат-разновидность семьи №50 для кривых (первый случай; в PREPROMPT не вносится). Возвраты: изотоническая оценка с n = 48 на плато; вопрос о механизме плато (частичное восстановление читаемости при промежуточной канализации — эффект или шум); MW(Δ)-горизонтная кривая (следующий пункт №5).
