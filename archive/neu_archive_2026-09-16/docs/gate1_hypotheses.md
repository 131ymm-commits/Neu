# Ворота 1 — гипотезы, сформулированные ДО поиска

Дата: 2026-08-23. Ход: LEVELS-01 (поиск механизма появления новых уровней; приоритет — физика и химия).
Файл записан до первого вызова веб-поиска в этом ходе.

## Гипотезы о механизме (одной фразой, с направлением)

- **H1 (слабые связи → резкость).** Новый уровень строится из многих индивидуально слабых взаимодействий, а не из немногих сильных; резкость перехода растёт с числом связей при падении их индивидуальной силы (кооперативность даёт «всё-или-ничего», сильные одиночные связи — постепенность).
- **H2 (шаблон/дефект).** Новый уровень возникает преимущественно на дефектах, границах и шаблонах старого уровня, а не в его однородной толще; скорость появления «на интерфейсе» на порядки выше объёмной.
- **H3 (щель = защита уровня).** Уровень устойчив там, где есть щель — энергетическая, временная или масштабная; время жизни/автономия уровня растёт с величиной щели, без щели уровни размыты. (Связь с UAF: Crystal Score λ₂/λ₁ — это и есть мера щели.)
- **H4 (универсальность темпа).** «Копится медленно — происходит быстро» — общий признак активированных переходов: время ожидания экспоненциально по барьеру, время самого перехода коротко и почти от барьера не зависит; значит, темповая интуиция верна для целого класса, но не специфична для какого-то одного механизма.
- **H5 (двухступенчатость).** Рождение упорядоченного уровня идёт через неупорядоченный промежуток (сначала концентрация/плотность/близость, потом структура); прямой путь «сразу в порядок» редок.
- **H6 (замыкание сети).** Переход к само-поддерживающемуся уровню (химия → биология) — порог по СВЯЗНОСТИ графа реакций (замыкание на собственный катализ/собственные границы), а не по энергии; появляется скачком как целое при плавном росте разнообразия.
- **H7 (избыточная запись).** Уровень становится устойчивым/«объективным», когда его состояние избыточно записано во многих независимых носителях; устойчивость растёт с избыточностью записи, а не с прочностью одной записи. (Связь с Neu: R2-ext не деградирует, R3 деградирует.)
- **H8 (экспоненциальность для отбора).** Дарвиновский уровень требует экспоненциального самовоспроизведения; суб-экспоненциальный (параболический) рост даёт сосуществование без отбора — кинетическое предусловие целого уровня.

## Контргипотеза (контррасчёт против собственной рамки)

- **H0 (уровни без событий).** Никакого единого механизма «появления» нет: часть уровней — свойство описания по масштабу (огрубление/RG), а не события во времени; они не «возникают», у них нет ни предусловий, ни накопления, ни быстрой смены.

## Прогноз занятости (до поиска, честно)

Ожидаю «занято» по большинству H1–H8 (база: ~90% переоткрытий в пуле). Ценность хода — карта + строки приоритета + выделение реально пустых углов, а не открытие.
