ворота 3–4 — PREREG, gate.py пройден. Данные: те же T = 0.25/0.28 × сиды 401–403, но 5·10⁶ шагов = 10⁵ кадров с квенчем каждый

## 2. Вердикты
- **P-N2a ✗ на одну траекторию**: r_ico(A) = 1 при 10⁵ кадрах на 4/6 (кромка 5/6); K1 нет (≥ 2 лишь на 2/6).
- **P-N2b ✓**: ранг не возрастает по горизонту на 5/6 (исключение — 0.28/s402: 1 → 1 → 3, появилось новое редкое состояние).
- **P-N2c ✓, K2 нет**: по наблюдаемой ранг 1 на 6/6 при всех горизонтах.

## 3. Чтение
1. При T = 0.25 (сеть ~200 минимумов, почти насыщена: рост 75 → 201 замедляется) ловушки над модой — **выборочные**: их шкалы
   тают с горизонтом (103 → 33, 112 → 36 кадров), ранг → 1, корреляция моды с индикатором растёт (0.5 → 0.7). При T = 0.28 сеть
   не насыщается (250 → 484 и продолжает расти), редкие минимумы появляются быстрее, чем досэмплируются старые, и ранг 2–3
   держится на 2/6: там «ловушки» — смесь ландшафта и выборки, и она не уходит при ×5.
2. Это уточняет NET-01 и связку с Cameron 2014: «245-я мода» LJ38 — свойство *асимптотической* сети (все минимумы известны,
   ставки гармонические); в конечной выборке тот же эффект воспроизводится выборочно и исчезает лишь при насыщении сети —
   которое для LJ38 (72 000 минимумов) недостижимо ни в какой траектории. Ранг физической моды в сети IS — не константа системы,
   а функция (горизонт, насыщение сети); ранг по наблюдаемой устойчив 6/6 при всех горизонтах.
3. Для §2 рамки: класс наблюдения «сеть минимумов» несёт в себе собственную нестационарность (растущее число состояний) — ещё
   одна причина, почему уровень читается по наблюдаемой, а не по сети.

## 4. Границы
Идентичность IS по энергии с точностью 10⁻³; 10⁵ кадров — ×5, не ×50; критерий ранга по |corr| с индикатором икосаэдра;
при T = 0.28 корреляция моды 0.46–0.84 — сама мода мешается с ловушками.
