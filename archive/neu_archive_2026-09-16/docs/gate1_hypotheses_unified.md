# Ворота 1 — объединённая теория переходов (записано ДО поиска, 2026-09-03 ~20:10 UTC)

Задача: не «ещё одна мера» и не «периодическая таблица переходов», а единая рамка для всей области
(бифуркации, катастрофы, фазовые переходы, крамерсовы/шумовые переходы, rate-induced tipping,
метастабильность и операторы переноса, эмерджентность, переходы в обучении и в обществах).
Образец подхода — теория струн: (1) общий объект, чьи «моды» дают разные явления; (2) дуальности —
«противоречащие» описания есть один объект в разных пределах; (3) пространство модулей вместо
единственной теории; (4) условия согласованности; (5) защищённые (инвариантные) величины, одинаковые во
всех дуальных картах. Плюс честный список того, что НЕ разрешается — аномалий, которые не сокращаются.

## U0. Что, по-моему, было «неразрешимым» в попытках объединения (моя догадка до поиска)
- Программа Тома (катастрофы) объединяла только ГРАДИЕНТНЫЕ системы (потенциал) и только локальные
  вырожденные критические точки; осцилляторные (Хопф) и глобальные маршруты выпадали. Крах — критика
  1977 года.
- Классификация бифуркаций полна лишь в малой коразмерности; структурная устойчивость не генерична в
  размерности ≥ 3 (Смейл). Конечной «таблицы» переходов быть не может.
- В шумных системах нет резкой бифуркации: детерминированная классификация растворяется; B-типпинг и
  N-типпинг выглядят одинаково на одной реализации.
- Для неградиентных систем нет ландшафта: квазипотенциал Фрейдлина–Вентцеля негладок; «рождение ямы»
  не всегда осмысленно.
- R-типпинг: переход без потери устойчивости какого-либо равновесия — механизм, не сводимый к
  бифуркационному.
- Эмерджентность: нет согласованного определения, меры расходятся; «сильная эмерджентность»
  нефальсифицируема.
- Неразрешимость: вопрос «перейдёт ли система» в общем случае невычислим по конечному наблюдению.

## U1. Общий объект
Не потенциал (ошибка Тома) и не поле, а ПАРА: (генератор динамики / оператор переноса L_τ, класс
наблюдения C). «Уровень», «переход», «коллективность» — свойства не динамики самой по себе, а тройки
(L_τ, C, порог). Это измерено: CORE-01 (число уровней порого-относительно), CORE-03 (коллективность
относительна классу предикторов), LEV-PLK-001 (уровень ↔ эпоха зависит от окна). Аналогия: в теории
струн спектр частиц зависит от фона/компактификации; здесь спектр «уровней» зависит от класса наблюдения.
Годограф петли (программная грамматика: маршрут = как годограф петли пересекает критическую точку) — это
и есть «мода» общего объекта: он строится на усилении петли (Найквист), а не на потенциале, поэтому
покрывает Хопф-маршруты, где катастрофы бессильны.

## U2. Дуальности (разрешение «противоречий»)
- D1 (B ↔ N): детерминированный фолд и крамерсов выход — одно явление в двух пределах (V → ∞ / V конечно).
  Разделяет их сертификат часов (CV ведомых ≈ 0.02–0.09; крамерсовых 0.5–1.2), а не онтология. Данные:
  Шлёгль — рождение ведомое, смерть шумовая при V = 200; оба ведомые при V = 2000 (TH-008); DO-события:
  крамерсовы часы у «фолда» (TH-007). Тип типпинга — точка в пространстве модулей (система, направление, размер).
- D2 (непрерывный ↔ разрывный, маршрут ↔ скорость ручки): резкость перехода — свойство пары (система,
  скорость ручки), не системы (GROK-004; горелка ρ = 1.00). «Первого/второго рода» — не интринсивно.
- D3 (уровень ↔ эпоха): рекуррентность в окне решает; один и тот же сдвиг режима есть «уровень» при
  длинном окне и «эпоха» при коротком (LEV-PLK-001).
- D4 (эмерджентность ↔ сводимость): ψ′ есть несводимость к КЛАССУ предикторов; при расширении класса до
  всех функций она ≤ 0 для детерминированных огрублений; остаток = неполнота наблюдаемой (CORE-03).
  «Эмерджентно» и «сводимо» — дуальные описания, параметризованные C и полнотой сенсора.
- D5 (рождение через редкое состояние ↔ рождение сразу): одна ручка — отношение скорости ручки к
  крамерсову времени; медленно → визиты-попытки, быстро → сразу (перенос: молекулы да, социальные шоки нет).

## U3. Пространство модулей
Координаты: (скорость ручки / внутренние часы; шум / размер Ω; усиление и кооперативность петли;
задержка / фаза; класс наблюдения C; окно τ и порог). Маршруты (фолд / осциллятор / непрерывный / flip;
ведомый / крамерсов) — области; сертификаты — карты (координатные функции). Атлас программы (73 рождения в
плоскости (log S, z)) — буквально карта этого пространства.

## U4. Условия согласованности (аналог сокращения аномалий)
- Монотонность по классу: f_nonlin ≤ f_lin ≤ f_axis (неравенство обработки данных для коллективности).
- Гистерезис ≥ 0 и растёт с размером к детерминированному пределу (UNI-07/12: 0.25 → 0.93 → 1.0).
- CV ведомых часов → 0 при (драйв/шум) → ∞; крамерсовых → ~1.
- Зазор implied timescales сам по себе не сертифицирует уровень (медленная гауссова мода даёт зазор);
  нужна медленность ∧ бимодальность (CORE-01) — и обе в ОТНОСИТЕЛЬНОЙ форме.
- Транзиент-сертификат S переворачивает порядок классов в клетке «шум ∧ припаркованный параметр» —
  обязательная клетка отказа любой единой рамки (TH-арка).

## U5. Защищённые величины (одинаковы во всех дуальных картах)
Тип часов (CV); знак и размерный скейлинг окна гистерезиса; сигнатура волн по совокупности (DI ≫ 1);
направление смены маршрута со скоростью ручки; порядок f_C; инвариантная f_lin.

## U6. Что не сокращается (честно)
Нет конечной классификации; нет ландшафта для неградиентных систем; неразрешимость предсказания в общем
случае; наблюдение-относительность «уровня». Поэтому единая теория здесь — теория ЧТЕНИЙ (сертификатов с
явным состоянием отказа), а не теория ВЕЩЕЙ.

## U7. Новые проверяемые следствия (для предрегистрации)
- P-U1 (D1 количественно): при уменьшении размера / росте шума на ОДНОЙ системе часы перехода меняют тип
  (CV растёт от ведомого к крамерсову) РАНЬШЕ, чем закрывается окно гистерезиса; существует зона, где
  CV ≥ 0.5 при гистерезисе ≥ 50 % детерминированного.
- P-U2 (D4): f_nonlin монотонно → 0 при добавлении каналов наблюдения (сон: + ЭОГ/ЭМГ).
- P-U3 (иерархия): калиброванное число уровней не убывает при уменьшении τ и воспроизводимо по сидам.
- P-U4 (D2): ширина перехода по ручке растёт со скоростью ручки степенным образом; показатель — свойство
  класса маршрута.
