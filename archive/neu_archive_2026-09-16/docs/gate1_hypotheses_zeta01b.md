# Ворота 1 — ZETA-01b (P-U13): классы ζ ZETA-01 при τ ≥ m·шаг — до поиска (2026-09-09)

Одной фразой: **при τ' = m·шаг (где обратимый оценщик завышает t₁ лишь на ~1.3, EST-01) классы ζ тех же 37 вложенных рядов
меняются мало — число «иерархий» среди 25 сегментов ЭЭГ падает не более чем вдвое (9 → ≥ 5), «выброс» не появляется ни у кого.**
Контррасчёт: иерархии ЭЭГ были артефактом обратимости — при τ' их остаётся ≤ 3 из 9, а континуум становится единственным классом
реальных скалярных рядов.
Контроль подмены: сам сдвиг τ не должен разрушать класс — телеграф (истинный выброс) остаётся выбросом при τ = 1 и τ = m,
иерархический телеграф остаётся иерархией.
