## 1. Что в статье (в их обозначениях)
Три шага: путь с шагом p/2 (обратимый, спектр λ(h) = (1−p) + p cos(πh/N), зазор pπ²/2N²); лифтированный путь — две копии с
вертикальным переключением ε (обратимый, два «веера» на расстоянии 2ε); необратимость δ — смещение p/2 ± δ по часовой/против
без изменения стационарного (плоского) состояния. **Точный спектр**: λ₀ = 1, λ(h = N) = 1 − 2(p + ε) и N − 1 пар
λ±(h) = (1 − p − ε) + p cos(πh/N) ± √(ε² − 4δ² sin²(πh/N)). Пары сходятся по δ², встречаются при δ_c = ε/(2 sin(π/N)) —
матрица там **недиагонализуема**, зазор максимален, дальше пара уходит вертикально в комплексную плоскость. Зазор при δ_c ~ ε/N·N…
для ε = ε̃/N — порядка 1/N (баллистика) против 1/N² (диффузия) — это «гибридизация двух вееров». Матрица Грина G даёт
времена первого достижения и время Кемени τ_K = Σ_k 1/(1 − λ_k); для лифтированного пути при δ = p/2 (петля только по часовой):
τ_K = (1/(p+ε))(N − ½ + (ε/p)(N² − 1)/3) — минимально при ε = 0, где цепь периодична и обратный зазор бесконечен: Кемени —
время достижения, не релаксации. Далее — прямоугольное (square-wave), клиновидное и V-образное стационарные состояния с
метрополисовским фильтром: на лифтированном пути τ_rel ~ N (square-wave), ~ M (клин), ~ N² (V; против N² log N), спектры численно.
Заключение: механизм гибридизации ожидается и в сложных системах.

## 2. Ожидания против текста

  при максимальной необратимости δ = p/2, p → 1 это ε_c ≈ π/N — **наш p* = 3.0/L (LIFT-01b) есть π/L на целой сетке c**.

- **E3 ✓**: Кемени ~ N и минимально при ε = 0 (периодичность) — они сами подчёркивают разрыв между интегральным временем и
  спектральным; сравнения спектра с лаг-1 автокорреляцией описаний нет.
- **E4 — частично**: в комплексной области модуль пары не зависит от h (детерминант фурье-блока): для нашей цепи

- **E5 ✓**: непостоянные π — численно, EP-структура сохраняется (гибридизация); **E6 ✗ по форме**: не только «onset» — они доходят

## 3. Что даёт текст нашей программе — замкнутая форма окна рождений
Для нашей цепи (переворот с вероятностью p, затем шаг; фурье-блок [[ (1−p)e^{ik}, p e^{−ik} ], [ p e^{ik}, (1−p)e^{−ik} ]]):
λ± = (1−p)cos k ± √((1−p)²cos²k − (1 − 2p)), det = 1 − 2p. Комплексная область (p < p_EP ≈ k = π/L): |λ|² = 1 − 2p —
**плоский модуль**, ρ ≈ 1 − p. Вещественная область: λ₊ ≈ 1 − p + √(p² − k²) (при p, k ≪ 1). Описание половин — точно
λ₂(mid) = 1 − 2(1−p)/L (LIFT-01). Отсюда (c = pL):
- рождение половинного разреза ⇔ зазор лифтированной цепи > 2/L ⇔ **c ∈ (2, 1 + π²/4 = 3.467)**; нижняя кромка — комплексная
  ветвь (c > 2), верхняя — вещественная (c − √(c² − π²) = 2);
- **R_max = π/2 = 1.571 в исключительной точке c = π**, а не 3/2 (LIFT-01b: 1.50–1.53 при c = 3 — сетка целых c);
- смена вещественности ведущей пары ровно в c = π; у стенки и при ленивости кромки сдвигаются на O(1/L).
Это переводит «рождение = окно спектрального оптимума» (LIFT-01 §3.3, тогда — по аннотации) в точное утверждение: **окно
рождений — окрестность исключительной точки, где гибридизованная (комплексная) пара живёт на модуле 1 − p ниже уровня
описания 1 − 2/L**. Предрегистрировано как LIFT-01c (PREREG, тот же вечер).

Чтение в личине: гибридизация двух вееров у них — это наш «скрытая настойчивая переменная σ» (второй веер — моды направления)
и её слияние с описанием; недиагонализуемость в EP — жорданова клетка, у которой сжатие на описание даёт максимальное
превышение над спектром (транзиентный рост (1 + t·γ)e^{−γt}). Тот же объект, что критическое затухание в VIRT-01 (Λ-система).
