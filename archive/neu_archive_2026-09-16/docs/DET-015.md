# DET-015 / 015b / 015c — корне-согласованный оценщик времён: три итерации за ход

Дата: 2026-08-23. Предрегистрации: PREREG.md §§ DET-015, 015b, 015c (каждая заморожена до своего прогона; gate.py OK). Последний разрыв сертификационной арки: ЧИСЛА t₂/θ на осцилляторных модах, где ITS-плато отставлено (DET-007), при обязательном «не сломать фолд».

## Конструкция

Для истинной моды λ оценка на лаге ℓ обязана быть λ^ℓ. Оцениваем верхнюю нестационарную моду на ℓ ∈ {1,2,3,4,6,8}, берём ℓ-е корни с выбором ветви по близости к лагу 1 и требуем **кучности корней**: ρ = max|z_ℓ − λ̄| ≤ ε (ε = 2.5 × max ρ калибровочных случаев = 0.064, этап A). t₂ = −1/ln|λ̄|, θ = arg λ̄ — из среднего корня, не из одного лага.

## Три итерации

**v1 (DET-015):** flip — **P-F1 ПОДТВЕРЖДЁН 3/3** (ρ = 0.0003–0.002; t₂ = 85/215/587; θ = π; бюджет ≤ 2%); фолд — **P-F3 ✓** (расхождение с плато 4%, корневая оценка чуть выше — знакомый заниженный сдвиг ITS устранён); суррогаты — **P-F4 ✓** (отвергнуты: ρ > ε и t₂ < 1 шага). Но NS — **P-F2 УБИТ 0/3** (ρ = 0.31–0.83), вырожденная NS тоже (P-F5). Сигнатура чистая: прошли ровно все вещественные случаи, провалились ровно все комплексные.

**v2 (015b):** диагноз «сопряжённая неоднозначность, чинится канонизацией Im(λ) ≥ 0» — **УБИТ** (P-G1 0/3; починилась только бюджетная нестабильность одной точки). Диагностика (помечена как разведка): на лагах, где ℓθ mod 2π попадает в нижнюю полуплоскость (ℓ = 4, 6 при θ = 0.311π), истинный λ^ℓ сам лежит внизу — канонизация СОБСТВЕННОГО ЗНАЧЕНИЯ подменяет его сопряжённым. Неоднозначность реальна, но разрешать её надо на уровне корня. Классификации: диагноз v1 — класс D (верно-но-иначе), правка v2 — класс B.

**v3 (015c):** ветвь выбирается из ℓ-х корней ОБОИХ членов пары {λ_est, λ_est\*}. **P-H1 ПОДТВЕРЖДЁН 3/3**: ρ = 0.0014–0.0015 (улучшение ×200, глубоко под ε), θ/π = 0.303–0.318 (детерминированная фаза π/3 на пороге — в допуске), бюджет ≤ 2%; t₂ = 262–290 (оценки v1 ~60 были искажены смешением ветвей). **P-H2 ✓**: вещественные случаи тождественны v1 (diff 0.000) — правка не тронула работавшее. **P-H4 ✓**: суррогаты отвергнуты.

## Измеренная граница применимости

**P-H3 не подтверждён**: вырожденная NS (r = 1.55, t₂ = 1.9) рвёт кучность и в v3 (ρ = 0.24). Механизм физичен: при t₂ ≪ max lag мода выгорает раньше длинных лагов (|λ|⁸ = 0.015 — под полом оценивания), и верхняя мода лага 8 — уже не λ⁸. **Оценщик применим при t₂ ≳ max lag**; для быстрых мод нужен укороченный набор лагов — поименованное уточнение, не прогнано. Кучность честно ОТКАЗЫВАЕТ там, где мерить нечем, — это свойство, а не дефект: отказ отличим от ответа.

## Итог линии и арки

**Корне-согласованный оценщик v3 — рабочая замена отставленного плато: flip, NS и фолд меряются одной конструкцией, суррогатный нуль отвергается, вещественные случаи не тронуты.** Сертификационная арка закрыта целиком: рождения сертифицируются траекторной тройкой (DET-009v4/010/011, перенос 012–014), времена и фазы меряются корневым оценщиком (015c). История v1→v2→v3 — третий за день случай семьи «правильный диагноз, неверная операционализация» (ср. DET-009 v1→v4): правка структурой, не порогом.

## Классификации

P-F1/F3/F4, P-H1/H2/H4 — подтверждены предрегистрированно. P-F2 — класс B (конструкция ветви; исправлена v3). Диагноз v2 — класс A/D (канонизация опровергнута; неоднозначность подтверждена на уровне корня). P-F5/P-H3 — класс C (режимная граница: быстрые моды против набора лагов; уточнение поименовано). Оговорка: ε калиброван на двух случаях, один из которых (fr = 0.618) — также мишень P-F3 по t₂ (двойная роль записана в PREREG).
