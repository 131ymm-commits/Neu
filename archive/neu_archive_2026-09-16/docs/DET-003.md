# DET-003 — результат: угол отделяющейся моды классифицирует маршрут рождения; детектор пережил несимметризацию

Дата: 2026-08-23. Предрегистрация: PREREG.md, раздел DET-003 (до прогона; не менялась). gate.py пройден. Порог R\* = 6.23 заморожен этапом A до анализа окна. Seed 20260825. Прогон 8 с.

## Итог одной строкой

Все четыре прогноза подтверждены: несимметризованный детектор ловит flip-рождение (2-цикл шумной логистики) устойчиво с **K\* = 3.08** (в заявленном окне [3.02, 3.15]); угол отделяющейся моды **классифицирует маршрут 6/6** (флип θ = π ± джекнайф-разброс ≈ 0; фолд-компаратор Шлёгля θ = 0.000); знакочередование Re λ₂ по лагам — 100%; вырожденные точки и суррогаты молчат. H0 («без симметризации угол не восстановится») опровергнут. Fold-only ограничение серии снято.

## Что это значит (и что НЕ значит)

1. **Детектор стал двухканальным:** |λ| (через R_c = t₂/t₃) даёт РОЖДЕНИЕ и тайминг; арг λ₂ даёт МЕХАНИЗМ (fold θ≈0 / flip θ≈π). Вместе с формой кривой по контрольному параметру (ступень у замыкания — LEV-002, плавный рост у фолда — LEV-001) — три отпечатка механизма из одних данных.
2. **Угол — маркер маршрута, не рождения** (зафиксировано ещё точной калибровкой): θ = π виден и ниже r₁ = 3.0 (осцилляторный распад к неподвижной точке) — ровно как «подход к flip» у скалярных предшественников. Классификация валидна в точках ДЕТЕКЦИИ.
3. Симметризация C+Cᵀ в LEV-001/002 была не обязательным условием работоспособности, а упрощением: на этих данных несимметризованная оценка так же стабильна (джекнайф-разброс углов ≈ 0, R_c совпадает с точечным до <1%).
4. Приоритет скалярных предшественников отмечен: классификация маршрутов по форме спектра мощности — [Bury et al. 2020]; доминантное с.з. → −1 перед удвоением из автокорреляции — [DE-AC, 2026]. Вклад хода — операторная версия, единая с детектором рождения, и прямое парное сравнение flip/fold в одном конвейере.
5. Побочное наблюдение (вне предрегистрации, помечено): R_c после пика 3.28 спадает к r = 3.40 — приближение второго удвоения поджимает t₃; связь с каскадом (и δ) — кандидат следующего хода, не утверждение.

## Ограничения

Одна flip-система (шумная логистика), один σ = 0.02; тор/Неймарк-Сакер (θ иррациональный) не проверен — детектор пока различает два маршрута из трёх; крупные σ могут размывать угол; переносимость угла на многомерные системы не проверена.

## Классификация на случай отзыва

Если на других flip-системах классификация падёт — класс C (не тот режим); внутри этой постановки все прогнозы держатся на заявленных порогах.
