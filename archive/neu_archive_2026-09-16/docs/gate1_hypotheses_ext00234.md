# Ворота 1 — гипотезы арки EXT-002/003/004 (записаны ДО поиска репозиториев и ДО вскрытия их содержимого)

Дата: 2026-08-27. Задача пользователя: три эксперимента на РЕАЛЬНЫХ данных,
найденных на GitHub (клонирование — штатный канал среды). Гипотезы пишутся
до поиска; конкретные датасеты неизвестны — гипотезы привязаны к КЛАССАМ
записей, которые ищутся, и к замороженным инструментам.

- **H1 (внешняя матрица ошибок):** на реальных лабораторных/полевых записях
  с ЛИТЕРАТУРНОЙ меткой типа перехода (Хопф/фолд/транскритика — метка чужая,
  из статьи-источника данных) замороженное дерево PRE-006c (пере-калиброванное
  на геометрию каждой записи фазой A по протоколу EXT-001) воспроизводит
  литературные метки выше случайного: ≥ 2/3 верных на ≥ 3 системах.
- **H2 (позитивная внешняя валидация осциллятор-ножки):** на реальной записи
  рождения колебаний (термоакустика/аналог — Хопф по литературе) намотка
  R2 зажигается в пост-переходной фазе и молчит в до-переходной — первая
  ПОЗИТИВНАЯ внешняя проверка вращательной ножки (в EXT-001 она была
  однобока: только нуль-калибровка).
- **H3 (фолд-подобность других палеопереходов):** реальные резкие
  палеопереходы, для которых литература заявляет CSD/фолдовую картину
  (конец африканского влажного периода, оледенения и т.п.), на полной
  геометрии окна получают метку «фолд» чаще прочих меток; стадиальные/
  спокойные контрольные окна — «нет рождения» (перенос-нуль, как в EXT-001).
- **H0 (контр):** лабораторные записи с высокой частотой дискретизации и
  палеозаписи с неравномерной сеткой ломают замороженные формы (лаг намотки,
  медфильтр, σ_E) — дерево не переносится за пределы 20-летней геометрии
  EXT-001; фиксируется как граница переносимости, эксперимент честно
  отрицательный.

Правила: содержимое рядов не вскрывается до предрегистрации соответствующего
эксперимента (структура файлов/каталогов — можно); литературные метки берутся
из README/статьи источника ДО прогона и замораживаются в PREREG.
