# Ворота 1 — WORM-01: уровень «бег / пируэт» в позной динамике C. elegans — рождение сверх нуля конвейера, два радиуса на реальном осцилляторе, сорт по постоянству (2026-09-16; в личине; записано ДО поиска)

Данные (новые для архива): позная динамика одного червя N2 — 5 коэффициентов собственных поз («eigenworms», Stephens et al. 2008),
33 600 кадров (35 мин, 16 Гц), из учебного репозитория Physics-of-Behavior-Tutorials (OIST, Stephens lab; git clone). Хорошо
описаны: Stephens 2008/2011, Costa–Ahamed–Jordan–Stephens 2024 (марковская модель поведения: вложение запаздываний K = 11 кадров,
1000 микросостояний, τ = 0.75 с; второй собственный вектор обратимизированного оператора = «бег / пируэт»).

Личина (что делает морфизм «вложение → разбиение → оценка при лаге τ → двухблочное описание» с системой «осциллятор + медленные
переключения»): ползание — бегущая волна, т.е. вращение в плоскости (a₁, a₂) с периодом T_und; реверс — вращение в обратную
сторону; пируэт — реверс + омега-поворот — направленная последовательность (бег → реверс → поворот → бег), необратимая во времени.
Оценённая при лаге τ цепь несёт ундуляционную моду с фазой 2πτ/T_und: при τ ≈ T_und/2 она чередующаяся (Re λ < 0), и радиус по
модулю ρ может достаться ей, а не медленной положительной моде переключений — второй радиус ρ₊ = max{|λ| : Re λ > 0} тогда
строго меньше ρ (SORT-01/02: «модуль стирает знак» — впервые на реальном осцилляторе). Двухблочное описание «бег / пируэт» —
уровень динамики, не конвейера: линейный обратимый суррогат (многомерный iAAFT — те же авто- и кросс-спектры, то же
распределение, одно направление вращения) не содержит направленной последовательности переключений, и рождение (C₁ > ρ₊) у него
не должно воспроизводиться — в отличие от ЭЭГ (SORT-03/04/05), где уровни были конвейерными.

Гипотеза одной фразой: **на позной динамике червя двухблочное описание «бег / пируэт» рождается (C₁ > ρ₊) сверх линейного
обратимого нуля конвейера и совпадает с направлением бегущей волны (вперёд / не вперёд); при лаге около половины периода ундуляции
радиус по модулю несёт чередующаяся ундуляционная ветвь и ρ₊ < ρ, при лаге около периода ρ₊ = ρ.**

Контррасчёт 1: ундуляция когерентна короче, чем длится бег, — её мода быстрее переключательной при всех лагах, ρ₊ = ρ везде, два
радиуса на червe не различаются. Контррасчёт 2: рождение «бег / пируэт» воспроизводится и суррогатом (кросс-спектр задаёт
направление вращения, а разбиение по вложению делает цепь ненормальной и у линейного процесса — как у ЭЭГ): избыток внутри
P95 нуля, уровень конвейерный и здесь. Контррасчёт 3 (EST-01 на поведении): обратимый оценщик при τ < K завышает медленную шкалу
относительно ρ₊ в разы (f = t_w/t_ρ ≥ 1.5), при τ ≥ K — нет.

Ожидание по поиску (ворота 2): марковская модель поведения червя и уровень «бег / пируэт» — занято (Costa et al. 2024, Ahamed et
al. 2021); необратимость времени позной динамики — вероятно занято (тесты обратимости, производство энтропии в поведении);
«нуль конвейера для поведенческих уровней (линейный обратимый суррогат через то же вложение и разбиение) и два радиуса при лаге
у половины периода» — не найдено (ожидание).
