# ACH-01 — достижимость рождения при огрублении как косинус: точное тождество λ₂ = ⟨S g_B, g_B⟩, порог косинуса и знак рождённого уровня (2026-09-14, в личине; бюджет 2 %)

## 0. Утверждения (математика; проверены численно — 0 нарушений на 81 925 огрублениях)
Пусть A₀ — сужение симметризованного оператора переноса на дополнение к константам, S = (A₀ + A₀ᵀ)/2 — его симметричная часть,
λ_max ≥ λ₂(S) ≥ … ≥ λ_min — спектр S, f* — верхний собственный вектор, g_B — π-ортонормированный центрированный индикатор блока B,
c_B = |⟨g_B, f*⟩|.
1. **Тождество**: у всякого 2-блочного огрубления λ₂(P_Y) = ⟨S g_B, g_B⟩ (с знаком). Антисимметричная часть A₀ в 2-блочное
   описание не входит вовсе — обобщение леммы KNOB-01 с токов на любой ненормальный оператор. Эквивалентно: λ₂ 2-блочного
   лумпинга P совпадает с λ₂ того же лумпинга **аддитивной обратимизации** P_s = (P + P*)/2.
2. **Двусторонняя оценка**: c²λ_max + (1 − c²)λ_min ≤ λ₂(P_Y) ≤ c²λ_max + (1 − c²)λ₂(S).
3. **Следствия**. (а) Запас рождения для вещественных 2-блочных уровней — не числовой радиус w, а **числовая абсцисса**
   ω = λ_max(S) = max Re W(A₀): рождение возможно ⇔ ω > ρ; ω ≤ w, так что это уточнение COG-01 в сторону ROT-01 («рождённые
   уровни вещественны»). (б) Положительное рождение требует c_B ≥ c_min = √((ρ − λ₂(S))/(λ_max − λ₂(S))) — порог **свой у каждой
   цепи**. (в) Отрицательное рождение (λ₂ < 0, |λ₂| > ρ — чередование блоков с периодом 2τ) требует выравнивания с *нижним*
   вектором S и косинусу к f* невидимо по построению.

## 2. Вердикты
- **P-A4 ✓, K0 нет**: тождество и двусторонние оценки — 0 нарушений (62 000 + 12 400 + 7 525 огрублений).
- **P-A1 ✗; K1 сработал по букве** (ручка 0.593 ≤ 0.6; случайные 0.620). Класс **B — не та наблюдаемая, дважды в одной
  предрегистрации**: (i) абсолютный косинус в пуле по цепям с *разными* порогами c_min — семья №14/45, **9-й случай**, допущен при
  действующем правиле ворот 4 (внутри цепи AUC 0.97 / 1.00; относительная форма 0.93 — пост-хок, не в зачёт); (ii) категория
  «рождение = |λ₂| > ρ» шире гипотезы о выравнивании с *верхним* вектором — 45 % рождений отрицательные и наблюдаемой невидимы
  (ворота 3 п. 2, семья BEHAV-029/030/032/036 + ACH-01).
- **P-A2 ✗, K2 нет** (0.632 / 0.628 > 0.6): «цепь родит» решает не геометрия лучшего разбиения, а спектр S (AUC 0.75–0.77 у
  λ_max(S) − ρ); контроль (c) прошёл — у обратимых c_max такой же (0.929), рождений 0: косинус рождений не создаёт.
- **P-A3 ✓, K3 нет** (25/25): PCCA(2) на ЭЭГ — почти реализация верхнего вектора S (обратимая MSM оценивает симметричную часть —
  EST-02), т.е. приближённый максимизатор той самой квадратичной формы. Но выравнивание — необходимое условие, не достаточное.

Итог одной строкой: **достижимость — не косинус, а произведение двух вещей: запаса числовой абсциссы (ω − ρ, свойство цепи) и
выравнивания (c_B ≥ c_min, свойство разбиения); косинус ранжирует разбиения внутри цепи почти идеально и цепи между собой — никак.**

## 3. Чтение в личине
1. Тождество — «поднявшееся море»: функтор «2-блочное описание ↦ λ₂» пропускает антисимметричную часть целиком. Все 2-блочные
   уровни необратимой цепи — это уровни её аддитивной обратимизации P_s. Рождение при 2-блочном огрублении = **медленная мода
   обратимизации, которой у тонкой необратимой цепи нет** (ρ(P) < λ_max(P_s)). Это точная форма «уровень живёт в несовпадении
   сопряжённых сторон» (PERSONA-01 §4): P_s — их среднее, и лишнее рождается ровно из разности P − P*.
2. Запас — числовая абсцисса ω = max Re W(A₀), не числовой радиус: для разбиений (вещественных описаний) доступна только правая
   опорная точка числового образа. ROT-01 и COG-01 сшиты: WMAP-01 «форма образа не установлена» — и не нужна для 2-блочных
   рождений: нужна одна опорная точка.
3. Порог c_min — своё число у каждой цепи; сравнивать косинусы между цепями бессмысленно так же, как сравнивать ζ между
   словарями (DUST-01). Программа второй раз попадает в одну ловушку: абсолютная величина там, где физика относительна.
4. Личина обязана сказать: тождество элементарно (частное Рэлея), и его чтение через обратимизацию Филла (1991) и числовую
   абсциссу (Трефетен–Эмбри) почти наверняка известно специалистам по лумпабельности — поиск не делался (бюджет). Наше — не
   тождество, а его применение: рождение уровня при огрублении = зазор ω − ρ + выравнивание, и измеренные доли (57 % цепей с
   ω > ρ, из них рождают 48 %; ЭЭГ 7/25 при 25/25 выравнивании).

## 4. Границы

чаще); отрицательные рождения посчитаны только у случайных цепей; относительная форма и знак — пост-хок; ЭЭГ — 25 сегментов,

## 5. Возвраты
1. Переопределить «рождение» для программы: положительное (λ₂ > ρ) отдельно от чередования (λ₂ < −ρ) — ворота 3 п. 2.
2. ACH-02 (если будет): предрегистрировать относительную форму c − c_min и знак; кромка ≥ 0.9 по положительным рождениям.
3. Поиск ворот 2 по «additive reversibilization lumping», «numerical abscissa Markov chain» — при появлении бюджета.
4. K блоков: тождество ломается — измерить долю вклада антисимметричной части в λ₂ 3-блочных рождений (ROT-01: det растёт на θ²T₁₂²).
