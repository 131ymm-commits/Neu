# Ворота 1 — гипотезы EXT-001 (записаны ДО поиска)

Дата: 2026-08-26. Первые ВНЕШНИЕ данные серии (дефицит №1 по SYNTH-01 §7):
применить ЗАМОРОЖЕННОЕ дерево PRE-006c к реальной записи резкого перехода
вне нашего класса систем. Кандидат по памяти (проверить поиском): гренландские
ледовые керны (δ18O, NGRIP), переходы Дансгаарда–Эшгера — резкие потепления
с продолжающимся спором о механизме; если данные недоступны разрешёнными
каналами — падать на следующий пункт горизонта (задержка как параметр),
записав причину.

- **H1 (перенос инструмента):** дерево из трёх траекторно-внутренних ножек
  (намотка / rise-гейт / C1-отношение S), масштабированное к длине записи по
  ЗАРАНЕЕ замороженным правилам (окна — доли записи, не абсолюты) и
  ре-валидированное на наших CME-записях, пересэмплированных к длине внешней
  записи, сохранит на них разделение маршрутов (≥ 12/15 на свежих сидах).
- **H2 (внешняя метка):** на записях DO-переходов дерево выдаст «фолд»
  (плато → быстрый переезд: S высокое, намотка молчит) в большинстве событий —
  согласовано с B-типпинговой/фолдовой диагностикой части литературы; метка
  «Хопф» (намотка) на большинстве — удар по переносимости ИЛИ довод в пользу
  осцилляторного механизма DO (релаксационные колебания) — интерпретировать
  слабо, двумя ветвями.
- **H3 (контроль):** на стационарных отрезках без перехода (межсобытийные
  окна) дерево обязано давать «нет рождения» в большинстве; систематические
  «рождения» на спокойных окнах = инструмент не переносится (красный шум
  климата наматывает/поднимает ложно) — это тоже результат.
- **H0 (контр):** климатическая запись (красный шум, нестационарная σ,
  неравномерная дискретизация) ломает все три ножки — честный итог
  «инструмент класс-специфичен», фиксируется как граница переносимости.
