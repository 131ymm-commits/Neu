# Ворота 1 — асимметрия часов «смерть шумовее рождения» и порядок «окно раньше часов»: универсалия или свойство Шлёгля? (записано ДО поиска, 2026-09-04 03:55 UTC)

Отправная точка: UNI-T1 на Шлёгле — CV_смерти ≥ CV_рождения при всех V ≤ 500 (P-U1b ✓) и «окно гистерезиса
закрывается раньше, чем часы становятся крамерсовыми» (P-U1′ ✓). Одна модель. Рамка объявила это защищённой
величиной — значит, надо проверить на структурно других системах И объяснить механизмом.

- H-A0 (чистота наблюдаемой). CV = std(w)/mean(w), где w — смещение параметра пересечения от СТАРТА рампы, —
  зависит от произвольной точки старта (вперёд 0.30 → фолд ~1.0; назад 1.10 → фолд ~0.1 — знаменатели 0.69 и
  1.04). Честная мера дисперсии часов под рампой — std параметра пересечения δλ (в единицах параметра), не CV.
  Прогноз: асимметрия на Шлёгле переживёт смену меры: δλ_смерти > δλ_рождения при V ≤ 500.
- H-A1 (механизм на Шлёгле, предсказание из детерминированной геометрии). Для процесса рождения-смерти
  квазипотенциал ВКБ Φ(x;λ) = ∫ ln(b⁻/b⁺) dx; барьер занятого состояния ΔΦ(λ) → 0 у фолда. Под рампой
  скорость выхода k ∝ exp(−V·ΔΦ(λ(t))) меняется в e раз на интервале δλ ≈ 1/(V·|dΔΦ/dλ|). Значит дисперсия
  пересечения ∝ 1/(V·|dΔΦ/dλ|) в точке пересечения: НАПРАВЛЕНИЕ, у которого барьер рушится вдоль рампы медленнее
  (меньший |dΔΦ/dλ|), шумовее. Прогноз: |dΔΦ/dλ|_смерти < |dΔΦ/dλ|_рождения у соответствующих пересечений, и
  отношение δλ_смерти/δλ_рождения ≈ |dΔΦ/dλ|_рожд/|dΔΦ/dλ|_смерти (с точностью до множителя ~2) при V = 200…1000.
  Если так — асимметрия не универсалия «смерти вообще», а следствие геометрии барьера: универсально лишь
  правило «шумовее то направление, где барьер рушится медленнее».
- H-A2 (перенос на flip-flop сна, ось шума σ). Ручка — гомеостатическое усиление kh, медленная развёртка
  вверх (рождение сна) и вниз (смерть сна). (a) Порядок D1: окно гистерезиса по kh падает ниже 0.5
  детерминированного при σ, где CV пересечения ещё < 0.2; (b) асимметрия: δkh одного направления систематически
  больше другого при всех σ — и знак предсказывается правилом H-A1 (медленнее рушащийся барьер шумовее), если
  барьеры можно оценить хотя бы по времени релаксации.
- H-A3 (перенос на LJ13, рампы T по 20 репликам). Плавление = рождение жидкого уровня, замерзание = смерть.
  Прогноз по «правилу барьера»: у LJ13 переохлаждение (жидкость держится ниже T_m) обычно шире перегрева
  (кристалл выше T_m редок) → барьер к замерзанию рушится медленнее → δT_замерзания > δT_плавления.
  Контррасчёт: конечный кластер с сильными флуктуациями даёт симметричный разброс (|разница| < 20 %).
- H-A4 (перенос на обучение, гроккинг). Рождение обобщения при полнобатчевом GD — ведомые часы (CV 0.020,
  GROK-005). Смерть по ступенчатому wd (3e-4 → 3e-3) — время до val < 0.5 от переключения; CV по 6–8 свежим сидам.
  Прогноз: CV_смерти > CV_рождения (смерть — медленная эрозия решения регуляризацией, рождение — резкая
  реорганизация). Контррасчёт: ступенчатая ручка — быстрая, смерть тоже ведома, CV ≤ 0.05.
Ожидание: H-A0, H-A1 — почти уверен; H-A2 — ставка на порядок, знак асимметрии не знаю; H-A3, H-A4 —
подлинная неизвестность. Если H-A1 верна, то формулировка «смерть шумовее рождения» из UNIFIED-THEORY §6
должна быть заменена на «шумовее направление с медленнее рушащимся барьером» — и это будет честная поправка
защищённой величины.

## Дополнение (записано ДО поиска, 2026-09-04 ~04:20 UTC) — слепой тест правила барьера на неградиентной системе
UNI-T2 предсказало знак асимметрии из барьера только на Шлёгле (1D, градиентный по эффективному потенциалу).
На flip-flop знак («рождение шумовее») был лишь объяснён ПОСТФАКТУМ. Чтобы правило считалось проверенным на
неградиентной системе, нужно предсказать знак ДО измерения на параметрах, где он ещё не измерен.
- H-B1. Для 2D неградиентного flip-flop квазипотенциал Фрейдлина–Вентцеля ΔΦ(b) от каждого узла до седла
  вычислим (ордered-upwind / минимальное действие); правило «шумовее направление с меньшим |dΔΦ/db| в точке
  пересечения» предскажет знак асимметрии на ≥ 3 НОВЫХ наборах параметров (CW, G, порог) до симуляции.
- H-B2. Наборы выбрать так, чтобы правило предсказывало РАЗНЫЕ знаки (хотя бы один «смерть шумовее») —
  иначе тест вырожден (любое правило «рождение шумовее» прошло бы).
- H-B3 (контррасчёт). Если знаки не совпадут ≥ 2 из 3 — правило барьера не переносится на неградиентные
  системы; тогда честная формулировка: «работает для 1D/градиентных, для неградиентных — открыто».
Ожидание: инструмент для квазипотенциала — искать на GitHub (QPot / OLIM / gMAM), не писать своё, если есть.
