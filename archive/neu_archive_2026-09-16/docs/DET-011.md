# DET-011 — NS-сертификат рождения v2: валидация; тройное разделение маршрутов

Дата: 2026-08-23. Предрегистрация: PREREG.md § DET-011 (заморожена до прогона; ворота 1–4, gate.py OK). Возврат класса B из DET-010 (P-Y4): суррогат-отношение для символа вращения слепо при одностороннем маргинале — заменено вырожденным полом. Закрывает **NS-половину** осцилляторной дыры BATCH-03.

## Конструкция (что изменилось против DET-010-P-Y4)

- **O1′ (вращение):** символ — знак свёрнутого приращения угла Δφ вокруг фокуса x\* в координатах (x_t, x_{t−1}); L_rot — медиана однознаковых серий. Критерий: L_rot ≥ L\*_rot = max(8, 2.5 × max вырожденных) = **8** (вырожденный максимум 1.0 — пол задан константой, P-Z3 ✓). Суррогата НЕТ: односторонность маргинала несут и вырожденные точки — пол поглощает смещение, которое перемешивание поглотить не могло.
- **O2′ (радиус):** ансамбль 80, старт НА детерминированной инвариантной окружности (релаксация карты σ = 0; при r ≤ 2 — фокус + 0.15). Критерий: R_late/R_early ≥ 0.7 И R_late ≥ 2 × вырожденный пол = **0.038**.
- Детекция: O1′ ∧ O2′, 2 подряд. Система: запаздывающая логистика σ = 0.01 (та же, что DET-004), 320 × 3000, 12 точек в [1.90, 2.22], seed 20260834.

## Результаты по букве

| прогноз | исход |
|---|---|
| P-Z1 (r\* ∈ [2.02, 2.16], вырожденные молчат, ложных ниже 2.0 нет) | **НЕ УСТАНОВЛЕН — детекция РАНЬШЕ кромки**: r\*_NS = 2.0164 < 2.02. Убийца не сработал (детекция есть, не позже 2.19, ложных ниже 2.0 нет) |
| P-Z2 (ни flip, ни фолд не проходят O1′) | **ПОДТВЕРЖДЁН**: flip r = 3.16 → L_rot = 1.0; Шлёгль-фолд → L_rot = 1.0; оба ≪ 8 |
| P-Z3 (вырожденный максимум < 8) | **подтверждён**: max L_rot вырожденных = 1.0 |

Честно о P-Z1: сертификат сработал на **первой закритической точке сетки** (2.0164, порог NS r₁ = 2.0), а нижнюю кромку прогноза 2.02 я положил МЕЖДУ узлами сетки (2.0164 и 2.0455) — прогноз не мог попасть в [2.02, 2.16] иначе как со второй точки. Ошибка постановки кромки, не конструкции; по букве — не установлен, перезаявлять «подтверждён» нельзя. Содержательно: H0 («пол без суррогата недостаточен») **опровергнут** — ниже порога L_rot = 2 при поле 8 (запас 4×), ложных срабатываний связки нет (O2′ одиночно вспыхнул на r = 1.958 — поглощено конъюнкцией), детекция немедленная.

Деталь: при r ∈ [2.045, 2.19] серия = вся траектория (0 проскальзываний за 320 × 2849 шагов); при r = 2.22 L_rot падает до 90 — проскальзывания возвращаются (окрестность резонансной гребёнки / начало разрушения окружности). Счётчик серий ≥ 320 на всех точках.
