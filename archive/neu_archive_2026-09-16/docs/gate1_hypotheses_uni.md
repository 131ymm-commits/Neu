# Ворота 1 — гипотезы UNI-арки (записаны ДО поиска)

Дата: 2026-08-27. Мандат: объединение. Кандидат в единый объект — ГОДОГРАФ
РАЗОМКНУТОЙ ПЕТЛИ L(iω) (петлевая передаточная функция линеаризации вокруг
до-рождения состояния). Подозрение: всё, что программа мерила два дня, — это
проекции одного факта: рождение уровня = пересечение годографом критической
точки, и МАРШРУТ = сторона/частота захода.

- **H-U1 (грамматика-предиктор):** маршрут рождения читается из СУБкритического
  годографа: частота ω*, на которой L(iω) ближе всего к критической точке,
  предсказывает маршрут (ω* = 0 → стационарная ветвь: фолд/транскритика,
  различаются касанием/трансверсальностью нуля; ω* > 0 → осцилляторная ветвь:
  Хопф/NS; для карт заход через −1 → flip). Предиктор, применённый вслепую к
  ≥ 10 нашим замороженным системам, угадывает маршрут ≥ 8/10.
- **H-U2 (мост к траектории):** расстояние годографа до критической точки при
  данном параметре монотонно связано с измеримой шкалой затухания τ_sp —
  предвестники всех школ (CSD, софтенинг, квазициклы) = одна координата.
- **H-U3 (ручки = координаты годографа):** задержка/длина цепи двигает ФАЗУ,
  кооперативность/AND-композиция — форму УСИЛЕНИЯ, шум/Ω — облако вокруг
  годографа, разрушение петли — стягивание годографа в точку. Следствие с
  зубом: добавление задержки в ФОЛДОВУЮ систему (Шлёгль с запаздывающей
  петлёй) при предсказуемой критической задержке МЕНЯЕТ МАРШРУТ рождения
  со стационарного на осцилляторный — смена маршрута в одной системе одной
  ручкой, предсказанная из годографа до прогона.
- **H-U4 (атлас):** все измеренные рождения программы (модельные и внешние)
  ложатся на одну плоскость траекторных координат (S, z) кластерами маршрутов;
  разделимость кластеров переживает перестановочный нуль.
- **H-U5 (rate-мост к внешним):** сдвиг точки онсета термоакустики по скорости
  рампы (19 записей в руках) имеет тот же знак и монотонность, что наша
  миграционная кривая по дрейфу (PRE-004c: медленнее — раньше по параметру;
  у рамп ожидается позже по параметру при быстрее — совместимо с
  rate-induced лором) — одна физика запаздывающего слежения.
- **H-U0 (контр):** годограф-предиктор ломается на системах, где рождение
  задано глобальной структурой (побег из метастабильности вне линеаризации):
  фолд-системы с шумовым побегом могут читаться неверно; если предиктор
  ≤ 6/10 — «грамматика» не единый объект, а метафора; фиксируется честно.
