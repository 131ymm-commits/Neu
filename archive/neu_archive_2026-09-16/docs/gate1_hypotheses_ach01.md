# Ворота 1 — ACH-01: достижимость рождения как косинус к оптимальной наблюдаемой (2026-09-10, личина; до поиска)

Из леммы KNOB-01 и ROT-01: рождения на 2-блочных огрублениях вещественны и равны квадратичной форме ⟨S g_B, g_B⟩ симметричной
части S = (A₀ + A₀ᵀ)/2 на центрированном π-нормированном индикаторе блока g_B. Значит рождение ⇔ R_S(g_B) > ρ(A₀), а R_S(g) =
Σ λ_i(S)⟨g, v_i⟩²: разложение по собственным векторам S. Пусть f* — верхний собственный вектор S (оптимальная вещественная
наблюдаемая, R_S(f*) = λ_max(S) = w_ℝ), c = |⟨g_B, f*⟩| — косинус. Тогда c²λ_max + (1 − c²)λ_min ≤ R_S(g_B) ≤ c²λ_max + (1 − c²)λ₂(S).

Одной фразой: **достижимость рождения на разбиениях — геометрия одного косинуса: рождение на 2-блочном огрублении происходит
тогда и только тогда, когда индикатор блока достаточно близок к оптимальной наблюдаемой f* (c² выше порога, зажатого двумя
точными неравенствами); лучший косинус по разбиениям предсказывает, родит ли цепь вообще (AUC ≥ 0.8); PCCA рождает у ЭЭГ, а
случайные разбиения — нет, потому что индикатор PCCA близок к f*, а случайный — ортогонален.**
Контррасчёт: косинус к f* не ранжирует рождения (AUC ≤ 0.6) — рождение задаётся хвостом спектра S (λ₂(S) близко к λ_max), а не
направлением; тогда PCCA рождает по другой причине (метастабильность, не оптимальность).
