# Ворота 1 — SPEC-01 (2026-09-04, вечер), записано ДО поиска занятости

Мандат: «продолжи, сделай долгий заход, посчитай что-то интересное или необычное».

## Откуда взялось
CORE-01′ закончил тем, что «число уровней» — функция допуска g* с состоянием отказа. Допуск остаётся выбором.
Есть ли форма критерия уровня БЕЗ допуска? Единственная безмасштабная величина, которая есть у любого спектра, —
его собственная статистика расстояний. Уровень = отделимая шкала = наибольший логарифмический зазор спектра,
который аномально велик ОТНОСИТЕЛЬНО распределения остальных зазоров того же спектра. Нуль — не «нет медленной моды»,
а «зазоры такие же, как все остальные» — иерархия без выделенной шкалы.

## Гипотеза одной фразой
Уровень — выброс в статистике логарифмических расстояний спектра оператора переноса: в системах с уровнем наибольший
лог-зазор s_max = ln(t_k/t_{k+1}) — выброс относительно экспоненциального (пуассоновского) распределения остальных
лог-зазоров того же спектра; в иерархии без выделенной шкалы — одномерном синаевском (броуновском) ландшафте — лог-зазоры
низколежащего спектра пуассоновские, выбросов нет сверх номинала, а число уровней N(g*) — степенной закон по допуску с
показателем, растущим линейно с температурой (лог-зазор = разность барьеров / T).

## Собственные ожидания (до поиска)
1. Синай (точная диагонализация трёхдиагонального генератора, L = 1024…8192, T = 0.5…4 в единицах амплитуды ландшафта):
   лог-зазоры 12 низших мод — экспоненциальны (KS не отвергает на ≥ 85 % ландшафтов); выброс-тест на уровне 0.05 срабатывает
   в ≈ 5 % (калибровка нуля); N(g*) ∝ (g*)^(−α), α(2T)/α(T) ≈ 2.
2. Физические системы расходятся с допуском 3 в ОБЕ стороны: дипептид 300 K (g₁ = 2.1–2.3 при остальных ≈ 1.02) — уровень
   по выбросу, не по допуску; LJ13 0.25/0.28 (g₁ = 3.1–4.3 при под-уровне 1.6–2.3 и хвосте 1.05–1.4) — уровень по допуску,
   пограничный по выбросу (p ≈ 0.05–0.15). Сон — ни то ни другое. Дипептид 400–700 K — уровень везде.
3. Контррасчёт против себя: ITS ниже лага (t < τ, отношения ≈ 1.0–1.1) сжимают «остальные» зазоры к нулю и делают выбросом
   любой умеренный зазор — тогда тест переактивен на данных, и калибровать его надо не на Синае, а на суррогате с той же
   долей подлаговых мод; отсюда контроль по K и отсечение мод ниже лага.
4. Случайные обратимые матрицы (второй нуль-вселенная): расстояния отталкиваются (не Пуассон) — тест консервативен там;
   значит, «пуассоновость» — свойство иерархических (RG-подобных) ландшафтов, а не любой случайности.

## Что это даст, если подтвердится
Третий сертификат уровня, безмасштабный: «аномалия в статистике расстояний собственного спектра». И картину стены 6/7 изнутри:
Синай — система, где уровни есть на всех шкалах и ни один не выделен; число уровней там по построению есть функция допуска.
