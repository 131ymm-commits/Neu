# Ворота 1 — SORT-01: сорт рождённого уровня по постоянству против сорта по знаку памяти; переключение в исключительной точке; закон порога настойчивости s_c (2026-09-15; в личине; записано ДО поиска)

Откуда: VIRT-01 показал на квантовых населённостях, что сорт («транзиент» / «постоянный») задаётся стороной исключительной
точки эффективного генератора, а знак памяти D(2) отрицателен при обоих сортах. LIFE-02 на марковских цепях определял сорт II
по паре (τ = n*/t_ρ ≥ 1, d₂ > 0), где n* — первый n с D(n) < 0. Вопрос: был ли d₂ > 0 законом сорта или совпадением семейств?
И есть ли у постоянного (квантового, передемпфированного) сорта марковский аналог?

Личина (что делает морфизм «сжатие на разрез» с жордановой/гибридизованной парой): C_n = ⟨Pⁿ g, g⟩_π = Σ_k a_k λ_kⁿ с
биортогональными весами a_k, Σ a_k = 1. Если ведущая пара комплексна (ниже EP), C_n ≈ 2|a|ρⁿ cos(nθ + φ) — отношение
q_n = C_n/ρⁿ осциллирует и обязано опуститься ниже 1 за полпериода: рождение транзиентно, с возвратами каждый период 2π/θ.
Если ведущее собственное значение вещественно (выше EP) и a₁ > 1 (ненормальные веса), C_n/ρⁿ → a₁ > 1: рождение постоянно.
Знак памяти D(2) = C₂ − C₁² от стороны EP не зависит: он задаётся кривизной старта (для разреза персистентного ходока —
повторными пересечениями), и по LIFE-02 положителен во всём окне.

Гипотеза одной фразой: **на точном лифтированном пути сорт по постоянству переключается ровно в исключительной точке
(c < c_EP — транзиент с возвратами периода 2π/θ, c ∈ (c_EP, c_up) — постоянный с q_∞ = a₁ > 1), а знак памяти d₂ > 0 по обе
стороны — сертификат LIFE-02 «сорт II ⇔ d₂ > 0» не различает стороны EP и на марковских цепях; порог настойчивости s_c LIFE-02 —
не отдельный закон, а схлопывание окна рождений: максимальная по p щель лифтированной цепи при локальном шуме s падает ниже
щели описания.**

Что ожидаю числом (до пилота): c_EP(L) как в LIFT-01c; период возвратов при c = 2.5, L = 128 — 2π/θ с θ = arg λ ≈ √(k² − p²)…
(из фурье-блока: λ = (1−p)cos k ± i√((1−2p) − (1−p)²cos²k)); a₁ при c ∈ (π, 3.47) — из биортогонального разложения, > 1.
Для серии C LIFE-02 (lifted_local, s): окно (c_lo(s), c_up(s)) сужается с ростом s; s_c — где c_lo = c_up; ожидаю s_c ∈ (0.2, 0.25)
у обоих L (как в LIFE-02) — если да, порог объяснён без нового закона.

Контррасчёт: (i) на марковском пути постоянного сорта нет вовсе (a₁ ≤ 1 всегда на вещественной ветви) — тогда квантовый
постоянный сорт — специфика лиувиллиана; (ii) s_c не совпадает со схлопыванием окна (например, окно ещё открыто при s = 0.25,
а рождений нет из-за смены ведущей моды) — тогда порог — отдельный закон.

Ожидание по поиску (ворота 2): транзиентный рост и «pseudo-resonances» у ненормальных цепей — известны (Trefethen–Embree);
осцилляции автокорреляции у лифтированных цепей — известны (комплексные пары DHN, RMK); классификация рождённых огрублением
уровней по постоянству и её привязка к EP — не найдено (ожидание).
