## 2. Вердикты
- **P-F1 ✗ по абсолютной кромке**: δ flip-flop 0.0005 (медиана по всем b; 0.0034 при b = 1.5) < 0.01; по отношению — ≫ 3×
  (при ближайшем ρ градиентный контроль даёт 2·10⁻⁶: отношение ~270; при b = 1.5 против h = 2 — ×70). **K1 нет.**
- **P-F2 ✓, K2 нет**: Шлёгль δ = 4·10⁻⁶ — одномерная цепь обратима при любой химии; градиентная яма ≤ 4·10⁻⁴.
- **P-F3 ✓**: δ монотонна по b у 4/4 (с оговоркой о смешении со скоростью переключений).
- **P-F4 ✗; K3 сработал по букве**: рождений 0/20 у flip-flop, 0/16 и 0/4 у контролей; условие K3 «рождений у контролей ≥ чем
  у flip-flop» при 0 = 0 выполнено вырожденно — формулировка убийцы не различала «нет нигде» и «шум оценки»; записываю как
  дефект формулировки (семья кромок), содержательно — рождений нет ни у кого.

## 3. Чтение
1. **Ток неградиентного дрейфа доходит до оператора переноса, но слабо**: δ у flip-flop на 2–3 порядка выше, чем у обратимых
   контролей при том же бюджете оценки (это не шум), и на порядок ниже, чем у ЭЭГ (0.03–0.19) и термоакустики (0.02–0.08).
   При шуме, достаточном для переключений (σ = 1 при F_max = 6), переключатель почти обратим в L²(π): диффузия забивает
   циркуляцию. Контррасчёт «ненормальность дрейфа не доходит до масштаба переключений» верен по величине, хотя не по знаку.
2. Для программы это означает: **на её собственных моделях новых уровней при огрублении нет** — ни у Шлёгля (доказуемо), ни у
   flip-flop (эмпирически при рабочем шуме). Рождение при огрублении — свойство сильно ведомых или осцилляторных систем с
   диссипацией (мозг, термоакустика), а не бистабильных переключателей с шумом. Правило барьера и асимметрия часов
   (UNI-T2/T3) живут в другой части рамки — в квазипотенциале, а не в числовом образе; связывать их не из чего.
3. δ растёт там, где переключения часты (b = 1.5): ненормальность концентрируется в переходной области, где ток
   неградиентного поля действительно закручивает траектории; в глубоких ямах (b ≥ 2.25) оператор нормален до 10⁻⁴.

## 4. Границы
Один шум σ = 1 (ниже переключений нет за 4·10⁴ записей; выше — диффузионный режим); k = 50; δ ~ 10⁻³ близок к пределу оценки
(половины согласны при b ≤ 2.25, при b = 2.5 — нет); Шлёгль — одна fr, одна V; критичность (складка) и частота переключений
не разделены; K3 сформулирован вырожденно.

## 5. Возвраты
Разделить складку и частоту переключений: держать число переключений постоянным (подбирать σ по b) и смотреть δ(b);
осцилляторный контроль — ван-дер-Полевский или затухающий шумовой осциллятор с асимметричным демпфированием (модель того,
что даёт δ ≈ 0.1 у ЭЭГ).
