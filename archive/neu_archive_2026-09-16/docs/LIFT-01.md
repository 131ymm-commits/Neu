## 0. Система и наблюдаемая
Лифтированный путь: состояния (x, σ), x = 1..L, σ = ±1; шаг — переворот σ с вероятностью p, затем x → x + σ; у стены —
переворот и стояние (вариант A). p = 1/2 — обратимый конец (сайтовый процесс — симметричное блуждание, ρ = 1 − π²/2L²),
p → 0 — баллистический (ρ → 1, почти периодичность). Наблюдаемая: λ₂ 2-блочных лумпингов по L − 1 непрерывным разрезам сайтов
и по направлению σ против ρ самой лифтированной цепи; R = t_лумп/t_ρ = ln ρ/ln λ₂ — относительная форма; ω = λ_max(S), w —
числовой радиус. Список событий: положительные λ₂ > ρ (отрицательных не бывает по построению: λ₂(mid) = 1 − 2(1 − p)/L).

Ключевой факт: **λ₂ среднего разреза не зависит от p** (0.98438 при L = 128 при всех p от 1/2 до 0.002) — поток через середину
(1 − p)/L задан геометрией, — тогда как спектр лифтированной цепи ускоряется от диффузионного 1 − π²/2L² до 1 − 2.6/L (×67 по
зазору при L = 128). В окне p ≈ p* спектральная шкала t_ρ = L/2.6 становится короче шкалы огрублённого описания t_лумп ≈ L/2, и
описание «левая половина / правая половина» относится медленнее любой моды: рождение с u ≈ 0.22 при L ≥ 128, у половины всех
разрезов (центральных). По обе стороны окна рождений нет: при p > p* цепь ещё диффузионна (ρ выше), при p < p* — почти
периодична (ρ → 1). Обратимый конец p = 1/2: 0 рождений при всех L; нарушений «рождение при ω ≤ ρ» — 0 (P-L1 ✓, K0 нет).
Разрез σ (сама переменная лифтинга) не рождает ни при каком L: λ₂(σ) ≈ 1 − 2p* − (1 − p*)/L ≈ 1 − 5.2/L быстрее ρ = 1 − 2.6/L.

Наблюдения без предрегистрации: при p = 1/L для всех L точно R(mid) = 1/2 и R(σ) = 1/4, т.е. ρ = √λ₂(mid) = λ₂(σ)^{1/4} — точные
совпадения этой цепи, не объяснены. ω = w до 5-го знака везде, кроме p ≤ 0.005 (комплексные пары): правая опорная точка
числового образа вещественна, как в ROT-01.

**Вариант B границы («переворот и шаг назад») — вырожден**: x меняет чётность каждый шаг, цепь периодична (собственное значение
−1), ρ = 1 при всех p; сравнение R невозможно. Дефект контроля (класс C: не тот режим — периодичность), а не результат.

## 2. Вердикты
- **P-L1 ✓, K0 нет**: p = 1/2 — 0 рождений; 0 нарушений следствия ACH-01 (ω ≤ ρ ⇒ нет рождений) на 4 × 12 цепях.
- **P-L2 ✗ по кромке, K1 нет**: R(mid) при p* > 1 у 4/4 размеров (1.03, 1.06, 1.30, 1.29), но кромка 1.2 взята у 2/4 (только
  L ≥ 128). Причина — конечноразмерная константа c(L) = 2.1 → 2.6, кромка калибровалась под c ≥ 2.4 без знания c: семья
  «некалиброванная кромка» +1. Направление подтверждено, величина на малых L — нет.
- **P-L3 ✗, K2 нет**: доля рождающих разрезов f(p) при L = 64 — не монотонный рост к p*, а узкое окно (0 → 0.24 → 0.14 → 0),
  Спирмен −0.65 (кромка −0.8; убийство при > −0.5). Форма прогноза неверна (класс A по форме): рождения живут только в окне
  спектрального оптимума, шириной ~ множитель 2 по p.
- **P-L4 ✗** (0/4): арифметика предполагала p* ~ 1/L; фактически p* ≈ 2.6/L и переменная лифтинга быстрее спектра.
- **P-L5 — не решён** (вариант B периодичен), K3 не сработал по букве. Возврат: апериодичный вариант границы (ленивый шаг).

Итог одной строкой: **при оптимальном лифтинге спектр лифтированной цепи быстрее её собственного двухблочного описания на
~30 % (L ≥ 128), и у половины разрезов рождается уровень, которого нет ни в спектре, ни у обратимого предела; рождение живёт
только в окне спектрального оптимума и только у описаний по сайтам, не по направлению.**

## 3. Чтение в личине
1. Лифтинг — смена представления той же наблюдаемой динамики на ненормальное: спектр можно ускорить, а огрубление по сайтам видит
   лишь симметричную часть (ACH-01) и хранит диффузионную скорость потока через разрез. Рождение = разность между тем, что
   ускорил лифтинг (моды), и тем, чего он ускорить не может (описание). Это чистейшая форма «уровень описания, не динамики».
2. Мост к Jung 2609.05217: наше огрубление — ортогональный проектор; косой (спектральный) проектор на две медленные моды
   лифтированной цепи унаследовал бы ρ и рождения не дал. Рождение — цена ортогональности, т.е. цена того, что описание задано
   наблюдателем (разбиением), а не динамикой (собственными векторами).
3. Мост к Robichon–Monthus–Krauth: окно рождений совпадает с окном спектрального оптимума — там, где, по их аннотации,
   собственные значения сталкиваются и появляются комплексные пары (исключительная точка). Проверить на их графах и стационарных
   состояниях — возврат, полный текст пока недоступен.
4. Личина обязана сказать: ускорение по одношаговой автокорреляции — не то же, что по интегральному времени; рождённый уровень —
   транзиент по лагу (PERS-01), и для практики лифтированных МСМС важен интеграл. Мы измерили не «лифтинг бесполезен», а «марковская
   модель по огрублённому описанию на лаге 1 переоценивает шкалу лифтированной цепи на 30 %».

## 4. Границы
Одна конструкция лифтинга (переворот–движение, стена: переворот–стояние) — не обязательно та, что у Robichon–Monthus–Krauth;
сетка по p грубая (p* с точностью ×1.25–1.6, c(L) зависит от сетки); вариант B — вырожден; лаг 1 только; числовой радиус на
240 углах при L ≥ 128.

## 5. Возвраты
1. LIFT-01b: апериодичная граница (ленивый шаг у стены) как честный контроль правила стенки; тонкая сетка по p вокруг p*.
2. PERS-02: r(n) = ITS_лумп(n)/ITS_ρ(n) для лифтированной цепи — рождённый уровень как транзиент; интегральное время разреза.
3. Robichon–Monthus–Krauth: их графы и стационарные состояния (меандр, клин, V) — совпадает ли окно рождений с исключительной точкой.
4. OBL-01: косое против ортогонального огрубления (Jung).
5. Точные совпадения при p = 1/L (ρ² = λ₂(mid), ρ⁴ = λ₂(σ)) — объяснить или отбросить.

## 7. LIFT-01c — замкнутая форма окна рождений и исключительная точка (2026-09-14, вечер; по полному тексту Robichon–Monthus–Krauth 2609.05183; lift01c_lib.py, lift01c_run.py, lift01c_results.json, 239 с)
Полный текст (прислан Димой) даёт точный спектр лифтированного пути; в нашей параметризации фурье-блок моды k —
[[ (1−p)e^{ik}, p e^{−ik} ], [ p e^{ik}, (1−p)e^{−ik} ]], det = 1 − 2p, λ± = (1−p)cos k ± √((1−p)²cos²k − (1 − 2p)). Пилот (L = 32, 64)
и прогон (L = 128, 256, 512): ρ совпадает с формулой первой моды k = π/L до **10⁻¹⁴** — стенка «переворот и стояние» сохраняет
фурье-структуру точно (лифтированный путь с такой стенкой = лифтированное кольцо DHN длины 2L). Отсюда замкнутые формы:
**p_EP = sin k/(1 + sin k)** (исключительная точка ведущей пары, недиагонализуемость), ρ = √(1 − 2p) при p < p_EP (плоский
модуль комплексной ветви), **R_EP = ln ρ_EP/ln(1 − 2/L) → π/2** (не 3/2: LIFT-01b мерил на целой сетке c), окно рождений
среднего разреза **c ∈ (2 − 2/L, c_up(L)) → (2, 1 + π²/4 = 3.467)**.

Чтение в личине: **рождение при огрублении = окрестность исключительной точки.** Ниже EP гибридизованная (комплексная) пара
живёт на плоском модуле √(1 − 2p) ≈ 1 − p, описание половин — на 1 − 2/L: рождение ⇔ p > 2/L. Выше EP ведущая мода снова
вещественна и быстро возвращается к диффузионной шкале — окно закрывается при c = 1 + π²/4. Максимум превышения — ровно в
недиагонализуемой точке (жорданова клетка: сжатие жордановой пары на описание даёт транзиентный рост (1 + γt)e^{−γt}).
Это та же структура, что критическое затухание осциллятора населённостей в VIRT-01 (Λ-система) и окно η ≈ 3 у стаи (FLOCK-01).
Личина обязана сказать: арифметика элементарна и полностью следует из их формулы плюс λ₂(mid) = 1 − 2/L; наше — не формула,
а её прочтение как окна рождений уровня описания вокруг EP, подтверждённое численно на трёх L с точностью формулы.
