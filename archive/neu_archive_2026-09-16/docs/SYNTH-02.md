# SYNTH-02 — Петлевая грамматика рождений уровней (объединяющий синтез)

Дата: 2026-08-27. Статус: рабочий синтез по итогам ~60 предрегистрированных экспериментов программы (модельных и внешних; журнал — PRIORITY.md, карта границ — HUB-VALIDITY-MAP §§1–2, приоритет — HUB-PRIOR-ART §§1–2). Сила формулировок = сила данных; чьи кирпичи — сказано прямо.

## 1. Единый объект

**Рождение нового уровня — это пересечение критической точки годографом петлевой передаточной функции** L(iω), взятой вокруг до-рождения состояния. Всё, что программа мерила, — проекции этого события:

- **МАРШРУТ = как годограф пересекает критическую точку.** Пересечение на нулевой частоте → стационарная ветвь (фолд, если ветвь равновесий поворачивает; транскритика/питчфорк, если ветви обмениваются/расщепляются); на конечной частоте → осцилляторная ветвь (Хопф/NS); для карт заход через −1 → flip. Кирпичи: Найквист, графический Хопф Мис–Чуа/Мойола–Чен, секанс Тайсона–Отмера. Наше: предиктор-на-зоопарке 10/10 + суб-классификация по счёту аттракторов 4/4 (UNI-01).
- **РУЧКИ = координаты годографа.** Фаза — задержка/длина цепи (секансный порог k* = 7 точен, DEL-001; смена финала рождения по предсказанной τ*, UNI-04d 5/5+5/5). Усиление и его форма — кооперативность звена и композиция входов; несводимое AND-произведение работает только покрывая ВЕСЬ цикл — слабейшее непороговое звено разбавляет петлевую ультрачувствительность (ORD-001/002b; динамическое ядро — петлевой критерий Анджели–Феррелла–Сонтага, наша часть — гиперрёберный словарь, ε↔HIS-квадранты числом и кривая утечки окна 5→3→2). Шум/размер — облако вокруг годографа: детекция стягивается как Δb ~ Ω⁻¹, точка шумового типпинга мигрирует к детерминированной как ~V⁻¹-совместимо (0.38→0.85→0.985), а квазициклы — вращение ДО пересечения (k_det = 5 < k* = 7). Разрушение петли — обнуление годографа: DAG-твины молчат, нильпотентная плоскость (софтенинг цикло-специфичен), хаб-коллапс группового взаимодействия опасен ровно там, где рвёт петли.
- **ПРЕДВЕСТНИКИ = приближение годографа к критической точке.** Расстояние ↔ измеримая шкала затухания: MF Re λ против τ_sp в факторе ≤ 3 (цепи 7.2/18.9/80.6 ↔ 7.9/15.8/31.4; солнце τ/период 2.58, рысь 2.12). Маршруто-зависимость предупреждений — какая мода ведёт: истинный над-пуассонов CSD есть у Хопфа всегда и у фолда только на B-краю (Фано-трилогия, PRE-004b/008); транскритический «сигнал» — пуассоново масштабирование. Rate-физика едина: быстрее ведёшь параметр — позже по параметру переход (наша миграционная кривая ↔ ρ = 1.00 на 19 рампах живой горелки, UNI-08; рамка — Эшвин/Ричи).
- **ТРАЕКТОРНЫЕ СЕРТИФИКАТЫ = детекторы типа пересечения по одной записи.** Батарея: транзиент-C1 (ожидание/переезд — стационарные активированные), намотка ∧ амплитудная стойкость O2′ (осцилляторные; намотка одна видит присутствие вращения, не надкритичность — запись №59), чередование (flip), излом v5 (непрерывные). Дерево из них читает маршрут из одной записи (13/15 слепых CME; 61 рождение из 5 источников кластеризуется в одной плоскости (log S, z) — атлас, silhouette 0.365 при нуле −0.01).
- **СМЕРТЬ УРОВНЯ = обратный проход.** Те же сертификаты симметрично читают умирание (корь: вакцинация гасит намотку 12/12 и биеннальное чередование 8/12 → 0/12). Асимметрия прохода (гистерезис маршрута) — поименованный возврат (UNI-07).

## 2. Чьи школы — какие клетки (карта объединения)

| школа | их кирпич | как входит в грамматику |
|---|---|---|
| Найквист / Мис–Чуа / АФС / Тайсон–Отмер | критерии пересечения и петлевые характеристики | сама грамматика (§1, маршрут и ручки) |
| Шеффер–Дакос–Лентон | CSD-предвестники, эмпирические каталоги | «расстояние до точки» как координата; полы/нули — наша дисциплина поверх |
| Эшвин–Вечорек–Ричи–Дитлевсен | B/N/R-таксономия, rate-tipping | шумовое облако и скорость ведения ручки; наши кривые fr(V), lead, ρ=1.00 |
| МакКейн–Галла | квазициклы под порогом | вращение до пересечения; k_det < k*; ножка O2′ обязательна |
| Феррелл–Анджели–Сонтаг + higher-order (Баттистон, 2601.05169) | петлевые критерии; сводимость агрегатов | усиление-ручка; цикловая форма несводимости; ε↔HIS-квадранты |
| Bury–Sujith | DL-классификация типов; лабораторные данные | конкурент-инструмент дереву; их данные — наши внешние опоры |
| Гренфелл–Эрн; Лисиецки–Раймо; DO-школы | объяснённые переходы конкретных систем | внешние клетки атласа; смерть уровня; MPT как смена цикличности |

## 3. Что грамматика уже дала программе (сжато)

Один предиктор маршрута (10/10); одна плоскость для всех рождений (атлас, 61 точка); один переключатель финала рождения по предсказанной τ* (5/5+5/5); одна rate-физика от CME до горелки (ρ = 1.00); один рецепт сертификатов с картой границ (№57–59) и каталогом ловушек (кромки/полы/разрешение — семья №50, «жива не та ножка» №51). Незанятые оси программы (по аудиту HUB-PRIOR-ART-2): MW-читаемость близости рождения (горизонт ~4 шага, плато α), симметрия рождение/смерть как протокол, батарея-как-целое.

## 4. Возвраты арки (порядок работы)

UNI-06 (готовность ↔ петлевое расстояние на сетевом классе); UNI-07 (асимметрия прямого/обратного прохода — корь усилением охвата, ORD-гистерезис); годограф ИЗ ДАННЫХ (идентификация петли по записи — снимет зависимость от модели на внешних системах); flip-ось в атлас; 5-см NGRIP; LoRA-траектории (записи №42/44).
