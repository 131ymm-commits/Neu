# Ворота 1 — ARR-01 «Аррениус попытки: время жизни дефектного икосаэдра −41.47 ε» (2026-09-08)

Гипотеза записана в SYNTH-05 §9 как P-U11 ДО поиска (сегодня утром): «время захвата в −41.47 ε аррениусово по 1/T_q
(наклон = барьер выхода из дефектного икосаэдра) — „глубже закалка — дольше попытка“ как крамерсов барьер».
Честная оговорка о порядке: до записи этого файла сделан NEB (свой расчёт, не поиск) — барьер −41.47 → икосаэдр 1.04 ε
(TS −40.433 ε; обратный барьер 3.89 ε) — и один взгляд на страницу Дойла о путях LJ-кластеров (без чисел для LJ13).

## Гипотеза одной фразой
Длительность попытки — время первого достижения икосаэдра из −41.47 — растёт по Аррениусу с наклоном ≈ барьеру NEB (1.04 ε,
допуск ±30 %), т.е. попытка есть крамерсов выход через одно седло.

## Конкурирующая гипотеза (контррасчёт против себя)
Выход из −41.47 идёт не через седло −40.43 напрямую, а через семейство соседних дефектных изомеров (−41.44, −41.39 — на 0.03–0.08 ε
выше, барьеры между ними малы) и дальше через более высокие сёдла в жидкоподобные минимумы (−40.7…−40.0) с последующим
падением в икосаэдр: тогда наклон Аррениуса меньше барьера NEB (энтропийные обходы, множество каналов) или, наоборот, больше
(эффективный барьер через жидкость ≈ 1.5–2 ε); линейность может нарушаться (кривизна ln τ по 1/T).
