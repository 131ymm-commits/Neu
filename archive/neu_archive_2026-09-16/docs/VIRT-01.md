## 0. Утверждения (математика; численно проверены)
У слова «виртуальное состояние» два смысла, оба взяты: (A) антисвязанный уровень теории рассеяния — полюс резольвенты на
нефизическом листе у кромки непрерывного спектра (большая отрицательная длина рассеяния a); (B) виртуальное промежуточное
состояние теории возмущений — рамановский переход 1 → 3 через далеко отстроенный уровень 2 (населённость ~ Ω²/4Δ²).
1. **Замкнутая квантовая система рождений не даёт.** Эрмитов H — нормальный оператор, числовой образ = выпуклая оболочка спектра,
   и никакое ортогональное огрубление (сжатие) не имеет собственного значения вне оболочки (интерлейсинг Коши). Виртуальный
   уровень (A) — не рождённый уровень сжатия. Он — полюс **точной редукции** (дополнение Шура/проектор Фешбаха
   H_eff(E) = PHP + PHQ(E − QHQ)⁻¹QHP), продолженной за кромку, т.е. ядра памяти Мори–Цванцига; в марковском словаре — память
   D(n) (OBL-01), не сжатие Ω.
2. **Память эрмитовой динамики положительна при всех лагах**: для g и H = H† величина C(n) = ⟨g, e^{−nH}g⟩ — преобразование
   Лапласа положительной спектральной меры, и по Йенсену C(n) ≥ C(1)ⁿ, т.е. D(n) ≥ 0 (обобщение D(2) ≥ 0 обратимых цепей OBL-01).
   Значит сорт I (отрицательная память) у виртуального уровня невозможен, а сертификат знака памяти его от структурного
   рождения не отличит; отличает ω − ρ ≡ 0.
3. **Точная модель (A)**: полуцепочка H = −Σ(|n⟩⟨n+1| + h.c.) − V|0⟩⟨0|. Полюс z = 1/V, E = −(V + 1/V): связанное состояние при
   V > 1, виртуальное при V < 1; a = −1/(1 − V). Континуальная плотность у кромки ∝ √x/(x + κ²), κ = 1/a ⇒ C(n) ∝ n^{−1/2} при
   n ≪ a² и ∝ n^{−3/2} при n ≫ a²: подразумеваемая энергия описания E(n) − E_кромки = ε(n)/n с ε: 1/2 → 3/2; кроссовер при
   n_c = s*·a², s* = 0.6746 (интеграл командой). Виртуальный уровень = псевдоуровень описания с временем жизни a² и без плато.
4. **Эффективный осциллятор населённостей (B)** (адиабатическое исключение |2⟩; Ω_R = Ω²/2Δ, R_sc = γΩ²/4Δ², Γ₁ = R_sc,
   Γ₂ = R_sc + γ_g): w'' + (Γ₁ + Γ₂)w' + (Ω_R² + Γ₁Γ₂)w = 0, λ± = −Γ̄ ± √((Γ₂ − Γ₁)²/4 − Ω_R²), исключительная точка при
   γ_g = 2Ω_R. Автокорреляция населённости w(t) при w(0) = 1, w'(0) = −Γ₁:
   передемпфировано (γ_g > 2Ω_R): w = A e^{λ_s t} + B e^{λ_f t}, **A = (|λ_f| − Γ₁)/(|λ_f| − |λ_s|) > 1** ⇔ |λ_s| > Γ₁ ⇔ γ_g > 0 —
   описание лежит выше медленнейшей моды при ВСЕХ лагах (постоянное рождение, вес медленной моды в описании больше 1 —
   квантовая версия «сверхэкспоненциальных коэффициентов» Мори–Ширая); недодемпфировано (γ_g < 2Ω_R): w = e^{−Γ̄t}(cos ωt +
   β sin ωt), β = γ_g/2ω — выше спектра лишь конечное время (транзиент) и вновь на каждом периоде; в EP w = e^{−Γ̄t}(1 + (Γ̄ − Γ₁)t)
   — жорданова клетка. Отношение скоростей R(τ → 0) = |λ_slow|/Γ₁ растёт линейно до EP (1 + γ_g/2R_sc), достигает
   **1 + Ω_R/R_sc = 1 + 2Δ/γ** и убывает как 1 + Ω_R²/(γ_g R_sc) → 1 (паули-предел: населённости марковские). Кривизна на старте
   w''(0) = Γ₁² − Ω_R² < 0 ⇒ D(2) < 0 при любом сорте — знак памяти населённостей не сертификат сорта.
   Контроль: двухуровневая система с теми же (Ω_R, Γ₁, Γ₂) без уровня |2⟩ обязана дать то же самое, если виртуальный уровень —
   лишь способ создать когерентность.

## 2. Вердикты
- **K0 нет** (P-Q8 ✓: 0 рождений у эрмитовой цепочки, D ≥ 0, плато связанного уровня до 10⁻¹⁴; {2} не рождается).
- **P-Q1 ✓, K1 нет**: исключительная точка делит сорта — при r ≤ 0.95 жизнь конечна (2 → 41 лаг, растёт к EP), при r ≥ 1.0
  постоянна у 2/2 Δ. q_end = A совпадает с формулой п. 0.4 (r = 2: 1.075 против (|λ_f| − Γ₁)/(|λ_f| − |λ_s|) = 1.077).
- **P-Q2 ✓, K2 нет**: R_max = 6.76 (Δ = 20; кромка [5.84, 7.59]) и 8.56 (Δ = 40; [6.96, 9.04]); 4.48 < 6.76 < 8.56 — высота
  рождения растёт с «виртуальностью» Δ/γ, как предсказано (1 + 2Δ/γ в пределе лага → 0).
- **P-Q3 ✓, K3 нет**: D(2) < 0 у всех рождений при r ∈ [0.1, 3], включая постоянные — **сертификат знака памяти LIFE-02 на
  квантовые населённости не переносится** (назвал бы все рождения сортом I); сорт здесь читается по постоянству C_n > ρⁿ.
- **P-Q4 ✓**: описание самого виртуального уровня не рождает ничего.
- **P-Q5 ✓, K5 нет**: контроль без |2⟩ воспроизводит всё — отклонения R ≤ 0.084 (Δ = 20) и ≤ 0.027 (Δ = 40), убывают с Δ;
  смена сортов у контроля там же ((0.95, 1.0]); максимум щели Λ-системы при r = 0.95 / 1.0. **Виртуальный уровень — не причина
  рождения, а способ создать скрытую когерентность**; рождение — свойство пары (когерентность, населённость).
- **P-Q6 ✓**: R(r = 5) = 1.29 / 1.49, R монотонно убывает при r ≥ 1.05 — окно закрывается со стороны Паули (q_end → 1).
- **P-Q7 ✗ по кромке, K7 нет**: кромки при V = 0.9 и 0.95 ✓ (0.587 ∈ [0.50, 0.66]; 0.636 ∈ [0.55, 0.70] — как предсказано по
  дефициту ∝ 1/a: 0.565 и 0.62), но точки V = 0.6 (n_c не определён: ε ≥ 1.13 всюду) и V = 0.7 (n_c = 1.96 — ниже шага решётки)
  вне режима кроссовера, наклон по 4 точкам 2.63 ∉ [1.9, 2.4]. Класс **C** (не тот режим: a ≲ 3 узла — нет континуального
  режима 1/2) и семья «некалиброванная кромка» **+1** (малые a не проверены пилотом). Пост-хок, не в зачёт: наклон по
  a = 5, 10, 20 равен **2.24** ∈ [1.9, 2.4] — время жизни ∝ a² подтверждено там, где кроссовер существует.

Итог одной строкой: **виртуальный уровень рассеяния — не рождение, а псевдоуровень описания у кромки континуума с положительной
памятью и временем жизни s*a²; виртуальный уровень Рамана — скрытая настойчивая переменная (когерентность), и описание
населённостями рождает уровень выше любой моды лиувиллиана: транзиентный ниже исключительной точки, постоянный (вес медленной
моды A > 1) выше неё, с максимумом в EP, растущим как 2Δ/γ, и исчезающим в паули-пределе; сам виртуальный уровень ничего не
рождает, и без него (прямая связь) всё то же.**

## 3. Чтение в личине — словарь
| рамка (марковские цепи) | квантовая механика |
|---|---|
| описание C, ортогональный проектор E_C в L²(π) | проективное измерение населённостей (диагональ в HS-метрике); открытый канал Фешбаха |
| сжатие E_C P E_C (лумпинг) — наши рождения | PHP (эрмитово — рождений нет); e^{Lτ} на населённости (ненормально — рождения есть) |
| точная редукция с памятью (Мори–Цванциг, OBL-01) | самоэнергия Σ(E) = PHQ(E − QHQ)⁻¹QHP; резонансы и виртуальные уровни — её полюсы |
| ненормальность ω − ρ > 0 | лиувиллиан открытой системы; у замкнутой — ровно 0 |
| скрытая настойчивая переменная σ (LIFT, LIFE-02, FLOCK) | когерентность ρ₁₃, созданная виртуальным уровнем; её настойчивость 1/γ_g |
| окно рождений вокруг EP (LIFT-01c: c ∈ (2, 1 + π²/4), R_max = π/2) | окно по γ_g/2Ω_R: транзиент ниже EP, постоянно выше, пик R = 1 + 2Δ/γ в EP |
| два сорта по времени жизни (LIFE-02) | сорт по постоянству C_n > ρⁿ: недодемпфировано / передемпфировано; **не по знаку памяти** |
| «уровень параметром» (в спектре) | связанное состояние (полюс на физическом листе) |
| «уровень огрублением» (вне спектра) | виртуальный уровень / резонанс (полюс на втором листе); рождённый уровень населённостей |

Три ингредиента EMERG-01 у Рамана: ненормальность — лиувиллиан (γ_g > 0 обязательно: при γ_g = 0 когерентность и населённость
затухают одинаково, β = 0, рождения нет); ортогональность — проективное измерение; выравнивание — населённость почти совпадает с
медленной модой (A → 1 при γ_g → ∞, поэтому и рождение исчезает: описание становится собственной модой).
Личина обязана сказать: п. 0.4 — элементарная теория двухмодового осциллятора, и «релаксация наблюдаемых медленнее щели»
известна (Mori–Shirai, Haga, Naves et al.); наше — прочтение как рождения уровня описания вокруг EP с двумя сортами, тест на
точном лиувиллиане с контролем «без виртуального уровня» и вывод, что виртуальность (Δ/γ) задаёт высоту, а не факт рождения.

## 4. Границы
(A) один тип потенциала (контактный), одно описание (δ₀), решётка (a ≲ 3 — вне режима); (B) одна конфигурация Λ (симметричные
связи, равные распады, двухфотонный резонанс), один лаг на Δ (τ = 0.2/Ω_R), HS-метрика для «ортогональности», r-сетка из 16 точек,
эффективная модель ломается при γ_g ≳ γ/2 (пилот r = 10); численный радиус (u) не считался — только R и q.

## 5. Возвраты
1. VIRT-02: лаг как ручка (R(τ) от τ при фиксированном r; сравнение с 1 + 2Δ/γ при τ → 0 после зеноновского старта) и
   несимметричная Λ (разные Ω₁₂, Ω₂₃ — светосдвиг, ненулевой δ).
2. Сертификат сорта для квантовых населённостей — по постоянству q_n = C_n/ρⁿ, не по знаку памяти; перенести проверку на
   LIFE-02-семейства: там D(2) > 0 сопутствовал сорту II — совпадение или закон?
3. (A) в марковском обличье: h-преобразование Дуба с линейным h = 1 + (1 − V)n — блуждание Бесселя-3 со сдвигом |a|;
   «виртуальный уровень» = область размера |a|, где условный на выживание ходок ещё не чувствует дрейфа.
4. Мост к Robichon–Monthus–Krauth: гибридизация вееров = когерентность/населённость; сравнить их «onset» (δ → 0) с γ_g → 0 здесь.
