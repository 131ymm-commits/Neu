стороны — там, где уровни чётко не размечены, попробовать найти сами уровни».

## Что такое «найти уровень» в грамматике программы
Уровень — макропеременная с удержанием содержания: (1) у неё своя медленная динамика
(она живёт дольше, чем микро-флуктуации — зазор во временах), (2) она НЕ сводится к одной
микро-координате (коллективность: ψ′ > 0 — макро предсказывает своё будущее лучше, чем
любая одна микро-координата), (3) у её смены/рождения есть маршрут и часы, читаемые
батареей. Процедура обнаружения без разметки: микро-запись → дискретизация (k-средних по
координатам) → матрица переходов при лаге τ → спектр: число собственных чисел над зазором
(отношение соседних подразумеваемых времён ≥ 3) + 1 = число уровней-макросостояний →
их назначение (спектральная кластеризация по медленным собственным векторам) → проверка
(2) по ψ′ против случайных разбиений той же мощности → проверка (3) по CV времён
пребывания. Разметка (если есть) используется ТОЛЬКО для оценки чистоты, не для поиска.

## Гипотезы
### H-M1 (зазор времён находит уровни)
На молекулярной траектории (реальный дипептид аланина, если данные на GitHub; иначе —
собственная МД кластера Леннард-Джонса) спектр оператора переноса имеет зазор: отношение
подразумеваемых времён t₂/t₃ (или t_k/t_{k+1} для последнего медленного) ≥ 3; найденные
макросостояния совпадают с известными бассейнами (Рамачандран: C7eq/αR, C7ax/αL; кластер:
твёрдый/жидкий) с чистотой ≥ 0.9. Убийца: зазор < 1.5 (спектр непрерывный — уровней нет
при этом лаге) или чистота < 0.6 (нашли не то).

### H-M2 (найденный уровень коллективен: ψ′ > 0)
Дискретный ψ′ = I(S_t; S_{t+τ}) − max_j I(x_{j,t}; S_{t+τ}) для найденного макросостояния
S > 0 и выше 99-го процентиля ψ′ случайных разбиений микросостояний той же мощности
(невырожденность: случайные разбиения дают ψ′ около нуля с разбросом; лаг-суррогат —
перемешивание времени — даёт ≈ 0). Для кластера ожидание сильнее (ни одна координата
атома не задаёт «твёрдость»), для дипептида слабее (двугранный угол почти задаёт бассейн:
ψ′ мал, возможно ≈ 0 — это тоже результат: «уровень» дипептида есть перемаркировка
координаты, а не коллективный уровень). Убийца H-M2 для кластера: ψ′ не выше 99-го
процентиля случайных разбиений.

### H-M3 (часы переключений уровней — крамерсовы)
Времена пребывания в найденных макросостояниях — термоактивированные: CV ≥ 0.7
(экспоненциальная память отсутствует) — в отличие от периодического мерцания в обучении
(CV 0.02–0.1). Убийца: CV ≤ 0.3 (переключения периодичны — тогда «уровень» ведом чем-то
внешним или детерминированным). Прогноз-направление: ≥ 0.7 у обеих систем.

### H-M4 (рождение уровня по температуре в LJ13)
Твёрдый (икосаэдрический) уровень LJ13 рождается при охлаждении; у T_m ≈ 0.28–0.34 (ед. LJ)
— динамическое сосуществование: бимодальная потенциальная энергия и переключения с
крамерсовыми часами (H-M3). По рампе T вниз/вверх — гистерезис (переохлаждение):
T_замерзания < T_плавления на ≥ 0.02 при одинаковой скорости; батарея на записи энергии
вдоль рампы читает переезд как «фолд» (S ≥ порога EXT-001) при ведомом ожидании (V мал?
— шум здесь тепловой, режим «шум ∧ рамп» — клетка, где S жива по TH-001). Убийца:
гистерезиса нет (|ΔT| < 0.01 при 5 репликах) — переход непрерывный/размытый конечным
размером. Честно: LJ13 — 13 атомов, «фазовый переход» конечного размера размыт; всё
измеряется относительно собственных нулей (реплики, суррогаты).

## Честные оговорки до поиска
- MSM/PCCA (Deuflhard, Schütte, Noé, Pande) — зрелая занятая область: «найти метастабильные
  состояния по спектру» — это их метод. Наша сторона — не метод, а СВЯЗКА: спектр (уровни
  как времена) + ψ′ (коллективность) + часы (механизм переключения) + рождение по ручке
  (батарея), с пререгом и нулями. Если связка тоже занята — взять чужое.
- Causal emergence в МД (ψ на белках) — возможно занято (Rosas 2020 применял ψ к…?),
  проверить.
- Реальные данные: mdshare/PyEMMA берут дипептид с FTP (не GitHub) — возможно, нет
  доступного клона; тогда честно — только собственная МД (кластер), а дипептид — возврат.

### H-N7 (MOL-003: коллективность уровня растёт к сосуществованию)
ψ′ найденного уровня LJ13 как функция T: калибровка/скан дали 0.012–0.051 при T = 0.22,
0.10–0.14 при 0.25, 0.146–0.182 при 0.28 — рост ×3–10. Прогноз-направление на свежих
сидах: ψ′(0.28) ≥ 2 × ψ′(0.22) на каждом сиде; убийца: ψ′(0.28) ≤ ψ′(0.22). Оговорка:
ψ′ зависит от долей состояний (при 1 % редкого состояния взаимная информация мала по
построению) — нужен контроль нормировки: ψ′ / I(S_t; S_{t+τ}) (доля «эмерджентной»
информации) — прогноз и на неё: растёт. Это прежде всего проверка того, что ψ′ измеряет
коллективность, а не редкость.

### H-N8 (LEV-EEG: уровни в неразмеченных многоканальных записях)
Если на диске есть многоканальные сегменты ЭЭГ (Delhi?), тот же конвейер (признаки —
каналы, стандартизованные; k = 30; τ = 0.1–0.5 с) найдёт 2–4 уровня с зазором ≥ 3 на
интериктальных записях; ψ′ > 0 против случайных разбиений (уровень коллективен по
каналам). Убийца: зазор < 1.5 (спектр непрерывный — уровней при этом лаге нет) —
тоже результат. Честно: микросостояния ЭЭГ (Lehmann) — занятый метод; наша сторона —
тот же конвейер, что на молекуле и кластере, с теми же нулями.
