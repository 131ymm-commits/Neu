# EST-01 — обратимая MSM на вложении запаздываний завышает верхнюю шкалу: калибровка и пересчёт архива (2026-09-09)

Возврат по поправке 2 HOR-02. Ворота 1 — gate1_hypotheses_est01.md (до поиска); ворота 2 — PRIORITY (`не найдено`, уверенность в
новизне низкая: механизм прост; соседи — Nüske и др. 2017 о смещении от неравновесного старта, Aristoff–Webber–Zuckerman 2026 о
модельном смещении при фиксированном лаге); ворота 3–4 — PREREG, gate.py пройден. Код: est01_run.py, est01_verdict.py;
est01_results.json. Наблюдаемая: f = t₁(обратимая ML-MSM)/t₁(необратимая) на замороженных словарях каждого ряда; телеграф
(L = 40, истинное t₁ = 20.3, 5 сидов) — f по k, m, τ.

## 1. Результат

**Механизм (телеграф):**

| по k (m = 4, τ = 1) | 2 → 1.00 | 4 → 2.02 | 10 → 3.06 | 30 → 3.96 | 100 → 4.25 |
|---|---|---|---|---|---|
| **по m (k = 30, τ = 1)** | 1 → 1.00 | 2 → 2.00 | 4 → 3.96 | 8 → 7.05 | |
| **по τ (k = 30, m = 4)** | 1 → 3.96 | 2 → 2.50 | 4 → 1.66 | 8 → 1.28 | |
| **m = 1 при k = 10/30/100** | 1.00 / 1.00 / 1.01 | | | | |

Спирмен по k, m: +1.0; по τ: −1.0; джекнайф по сидам — те же. **f ≈ m**: проход через m переходных микросостояний вложения
(…,1,1,−1) → (…,1,−1,−1) → … после симметризации становится симметричным блужданием, которое добирается до другого края с
вероятностью ~1/m (разорение игрока) — скорость переключения делится на m, t₁ умножается. Без вложения (m = 1) артефакта нет при
любом k; с ростом τ он тает (проход укладывается в один лаг).

**Архив (замороженные словари):** вложенных рядов 36 — f ≥ 1.5 у 22 (61 %; кромка 60 %), медиана 1.88; ЭЭГ Бонна (m = 5, шаг 2,
τ = 2) — медиана 2.15, ≥ 1.5 у 19/25; LR04 2.26, COVID Italy 2.08, корь 1.56; ≈ 1 — NGRIP m = 4 (1.02), EPICA (0.95), пятна (1.11),
COVID US/Germany (1.03/1.26), термоакустика (0.99, 0.30, 0.72 — у необратимой оценки |λ| вращательной моды даёт бо́льшую «шкалу»:
не та наблюдаемая для осцилляторов). Сырых рядов 24 (NGRIP m = 1, планктон, сон × 6, NGRIP-2D × 2, DUST-2D × 2, дипептид × 8,
LJ13 × 6) — f ∈ [0.8, 1.25] у 24/24, медиана 1.00. Сходимость: |Δf|/f ≤ 0.3 на половине ряда у 69 % (кромка 70 % — на границе,
f частично конечно-выборочный).

**Почему у NGRIP/EPICA артефакта нет, а у ЭЭГ есть:** множитель f ≈ m возникает, когда переход между уровнями идёт по
детерминированной цепочке переходных векторов — у чистого переключения (телеграф, флип φ, острые фронты ЭЭГ). У медленного
шумного ряда (NGRIP при t₁ = 250 отсчётов, EPICA) k-means не выстраивает переходные состояния в цепочку — переход размыт
шумом, и симметризация ничего не ломает.

**ζ-часть (P-E2, P-E4) — НЕ УСТАНОВЛЕНО, класс B**: у 33/36 вложенных рядов необратимый спектр содержит комплексные пары
(осцилляторные моды), модули которых равны, — реньевские лог-зазоры внутри пар нулевые, ζ по |λ| не определена (ζ = 0 или ∞).
Сырые переходы классов (14 «иерархий» по обратимой → 8 «континуум», 1 «выброс» по необратимой) — артефакт статистики, а не
результат; вердикт по ним не выносится.

**DUST-01/02 (описательно):** 1D δ¹⁸O m = 2, k = 20 на Wg — t₁ 18.2 → 12.3 (f = 1.48), ζ обратимая 4.88, необратимая не
определена (комплексный спектр); 2D — f 1.00–1.15. Отношение R = t₁(2D)/t₁(1D): Wg 1.09 (обр) → 1.41 (необр); W 1.64 → 1.90.
«Почти-выброс δ¹⁸O в одиночку» DUST-01 стоял на t₁, завышенном в 1.5 раза, — класс D (верно, но иначе): пыль действительно
добавляет шкалу, и добавляет больше, чем казалось, а спектральный «почти-выброс» 1D частично был оценщиком.

## 2. Вердикты
- **P-E1 ✓ (на кромке)**: 61 % ≥ 60 %; сырые 100 %. K1, K1b нет.
- **P-E3 ✓, K3 нет**: монотонности по k, m, τ; f(m = 1) = 1.00 — механизм «переходные состояния вложения» подтверждён.
- **P-E2 / P-E2′ / P-E4 — не установлено (класс B)**: наблюдаемая ζ по необратимому спектру недействительна.

## 3. Следствия для архива
1. **Абсолютные t₁** скалярных рядов с вложением в ZETA-01, ICT-01, HOR-01 (скалярная часть), DUST-01 (1D) — завышены на
   множитель f ∈ [1, m]; для ЭЭГ ×2 в медиане, для NGRIP/EPICA ≈ ×1. ICT-01: сравнение медиан t₁ между наборами (интериктальные
   37–39 против здоровых 11–21) — относительное при одном словаре, но f по сегментам разбросан 0.5–4, поэтому порядок наборов
   не гарантирован — граница ICT-01 (запись класса E: не проверено необратимым оценщиком).
2. **ζ и классы ZETA-01** — под вопросом в сторону завышения (инфлированное t₁ поднимает z₁), но пересчёт необратимым спектром
   невозможен; честная проверка — обратимый оценщик при τ ≥ m·шаг (f → 1.3) с тем же протоколом — возврат ZETA-01b, не сделан.
3. **HOR-01/02 β** — при фиксированных k, m множитель почти не зависит от n: N* 9.9 (обр) против 7.9 (необр) — выводы стоят.
4. **Правило для дальнейшего**: вложение запаздываний → необратимый оценщик для t₁ (ядра — по обратимому) или τ ≥ m·шаг;
   ζ — только по обратимому спектру и только при m = 1 или τ ≥ m·шаг.

## 4. Границы
Один сид микростатов; телеграф — одна L; «сырые» ряды — не проверка механизма на осцилляторах (у них необратимая |λ| — другая
величина); 69 % сходимости — f шумит на коротких рядах.
