# OBL-01 — знак памяти как след рождения; ортогональное против косого огрубления (2026-09-14, в личине; ревизия 3)

Ворота 1 — gate1_hypotheses_obl01.md; ворота 2 — PRIORITY (`занято, но с другой стороны`: Geyer 1992 — выпуклость автоковариаций
обратимых цепей; Мори–Цванциг с памятью — Hudson–Li, Li–Lei–Karniadakis; Jung 2609.05217 — косые проекторы); ворота 3–4 — PREREG

## 0. Утверждения (точные; 0 нарушений)
1. Для обратимой цепи и любой наблюдаемой h: C(2)C(0) ≥ C(1)² (Коши–Буняковский, C(2) = ‖Ph‖²) ⇒ D(2) = C(2) − Ω²C(0) ≥ 0:
   марковская экстраполяция Ωⁿ не может переоценивать удержание на втором шаге. Проверено на 6200 разбиениях обратимых цепей —
   0 нарушений (минимум d₂ = D(2)/Ω² = +0.0056).
2. Косое (спектральное) огрубление на собственную пару (l, r): Ω_obl = lᵀPr/lᵀr = λ точно — памяти нет, рождения невозможны
   (200 цепей, 0 нарушений при допуске 10⁻⁹). Рождение — свойство ортогонального проектора (описания, заданного наблюдателем).

## 1. Результат
**Случайные необратимые N = 6 (2000 цепей, 61 403 разбиения без отрицательных рождений; положительно рождающих 736).**
d₂ < 0 у **85 %** рождающих разбиений против **49 %** нерождающих (медианы d₂: −0.14 против +0.03). Но ранжирование по величине
−d₂ даёт AUC **0.550** (половины 0.539 / 0.561): у половины нерождающих разбиений память тоже отрицательна — это ненормальность
без рождения. Пост-хок (не в зачёт): AUC бинарного предиктора «d₂ < 0» = 0.68; P(рождение | d₂ < 0) = 2.1 % против 0.36 % при
d₂ ≥ 0 — отношение 5.8 при базе 1.2 %. Время жизни рождённого уровня: n* конечно у **99.6 %**, медиана **2**, p90 **3** —
экстраполяция Ωⁿ переоценивает удержание уже со второго-третьего лага; рождённые уровни случайных цепей — «уровни одного лага».

**Лифтированный путь (вариант A, p* из LIFT-01; средний разрез).** Знак противоположный прогнозу: d₂ = +2.3·10⁻³, +3.9·10⁻⁴,
+9.7·10⁻⁵ (L = 64, 128, 256) — память ПОЛОЖИТЕЛЬНА, ни один из 15 / 61 / 121 рождающих разрезов не имеет d₂ < 0, и в
пределах 50 лагов D(n) не меняет знак. Пост-хок с NMAX = 4000: n* = 227 / 87 / 165 лагов (0.65 L при L ≥ 128; n*/t_ρ ≈ 1.7),
максимум D(n) на n ≈ 0.4–0.6 L. Ошибка арифметики предрегистрации: «баллистика ⇒ C(n) линейна» не учла возвратный поток
(перевернувшиеся после пересечения) — C(2) убывает медленнее C(1).

## 2. Вердикты
- **P-O0 ✓, K0 нет**: обратимые — 0 нарушений; косое огрубление — 0 нарушений.
- **P-O1 половина ✓ / половина ✗; K1 сработал по букве** (AUC 0.5499 ≤ 0.55 при стандартной ошибке ~0.01 — кромка убийства в
  полосе шума, семья «K по букве» +1, 4-й случай). Класс B: гипотеза была про ЗНАК, а предрегистрирован ранг по ВЕЛИЧИНЕ;
  знак различает (85 % против 49 %), величина — нет. По существу контррасчёт прав: отрицательная память — сертификат
  ненормальности (что и было известно через Гейера), рождения — лишь в 5.8 раза чаще при ней.
- **P-O2 ✗, K2 сработал**: у лифтированного пути память положительна на десятки лагов (класс A: неверный знак из-за пропущенного
  возвратного потока).
- **P-O3 ✓, K3 нет** (99.6 %; n* медиана 2).

Итог одной строкой: **знак памяти не сертифицирует рождение — но время жизни рождённого уровня разделяет два его сорта: у
случайных цепей уровень живёт 2–3 лага и убивается любым многолаговым тестом; у структурной (лифтированной) цепи он живёт
~0.65 L лагов с положительной памятью — и пройдёт тест сходимости ITS на 50 лагах, оставаясь переоценкой шкалы на 50 %.**

## 3. Чтение в личине
1. Два сорта рождений — по знаку памяти: «случайное» рождение — ортогональная проекция схватила направление, вдоль которого
   оператор переносит на один шаг много, а дальше — нет (транзиент Трефетена в чистом виде, n* = 2); «структурное» рождение
   (лифтинг) — описание отслеживает медленный поток через разрез, а спектр ускорен за счёт скрытой переменной; память
   положительна, потому что перевернувшиеся возвращаются. Разделяет их не знак d₂, а n*/t_ρ: ≪ 1 и ≈ 1.7.
2. Для практики MSM: тест сходимости implied timescales по лагам (стандарт) ловит первый сорт и не ловит второй — у
   лифтированного пути r(n) растёт до n ≈ 0.5 L (PERS-01 видел убывающие r(n) у ЭЭГ — значит, там первый сорт).
3. Косой проектор Юнга — точный «нулевой» полюс: без памяти и без рождения, но и без вероятностного смысла (l, r — не индикаторы).
   Рождение — цена того, что описание обязано быть разбиением.
4. Личина обязана сказать: Гейер знал выпуклость у обратимых; мы измерили лишь, что её нарушение сопутствует рождению в 5.8 раза
   чаще базы — слабый маркер, не сертификат; и что сертификат нужно искать во времени жизни, которое пока измерено на двух
   семействах.

## 4. Границы

пуле по разбиениям (единица — разбиение; нуль d₂ общий по теореме, поэтому пул допустим).
