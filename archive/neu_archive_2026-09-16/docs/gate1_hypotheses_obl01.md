# Ворота 1 — OBL-01: знак памяти как след рождения; ортогональное против косого огрубления (2026-09-14, в личине; до поиска)

Относительная точка зрения: огрубление — проектор. Ортогональный (лумпинг, индикатор блока h) даёт марковский член Ω = C(1)/C(0) =
λ₂ лумпинга и ядро памяти; косой (спектральный, на собственную пару l, r) даёт Ω = λ и нулевую память — рождений у косого быть не
может по построению (Jung 2609.05217 — «ортогональный проектор вдали от равновесия неверно делит на систематическое и
стохастическое»). Наш вопрос: какой ЗНАК памяти оставляет ортогональное огрубление там, где оно рождает уровень.

Точное утверждение (доказуемо): для обратимой цепи и любой наблюдаемой h: C(2)C(0) ≥ C(1)² (Коши–Буняковский: C(2) = ‖Ph‖²,
C(1) = ⟨Ph, h⟩) — D(2) = C(2) − Ω²C(0) ≥ 0: марковская экстраполяция Ωⁿ недооценивает удержание. Для ненормальной цепи
C(2) = ⟨Ph, P*h⟩ и знак D(2) свободен.

Гипотеза одной фразой: **у рождающих разбиений ненормальных цепей память отрицательна с первого шага — D(2) < 0 у большинства
(≥ 50 %), −D(2) ранжирует разбиения на рождающие/нерождающие с AUC ≥ 0.7 внутри необратимых цепей; у лифтированного пути при p*
средний разрез имеет D(2) < 0 (баллистика: C(n) линейна, Ωⁿ выпукла); время жизни рождённого уровня n* = min{n: D(n) < 0}
конечно у ≥ 90 % рождающих разбиений в пределах 50 лагов; косое огрубление — тождественно без памяти (0 нарушений).**
Контррасчёт: знак D(2) у ненормальных цепей не связан с рождением (AUC ≤ 0.55) — память отрицательна и у нерождающих разбиений
просто из-за ненормальности, и «знак памяти» не сертификат рождения, а сертификат необратимости (что известно — Гейер).

Что это даст программе: сертификат рождения ИЗ ДАННЫХ, без оценки спектра — D(2) < 0 невозможно у обратимой динамики, и, если
гипотеза верна, характерно для рождённых огрублением уровней. Опасность: переоткрытие выпуклости автокорреляций обратимых цепей
(Geyer 1992, «initial sequence») — проверить в воротах 2.
