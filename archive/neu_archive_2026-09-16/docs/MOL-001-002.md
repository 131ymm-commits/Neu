## Процедура обнаружения уровня (заморожена до прогонов)
Уровень в грамматике программы — макропеременная с удержанием содержания: (1) своя медленная динамика, (2) несводимость к одной микро-координате, (3) свой механизм переключений. Конвейер: микро-запись → k = 30 микросостояний (k-средних++) → симметризованная матрица переходов при лаге τ → подразумеваемые времена → число уровней = 1 + число медленных мод до первого зазора ≥ 3 → назначение k-средними по медленным собственным векторам → ψ′ = I(S_t; S_{t+τ}) − max_j I(x_{j,t}; S_{t+τ}) против случайных разбиений микросостояний и суррогата времени → committed-пребывания (переключение засчитывается, если держится ≥ persist) → CV. Разметка (знак φ; энергетический провал) — только для оценки чистоты, не для поиска.

## Что это значит для программы
1. **Уровни можно находить, а не только сертифицировать.** Одна замороженная связка (спектральный зазор → коллективность ψ′ → часы) нашла уровни в двух системах разного класса (реальная молекула, атомный кластер) без разметки, с нулями и ответом «уровней нет» там, где их нет (LJ13 при 0.18 и 0.36).
2. **Часы в молекулярном мире — крамерсовы** (CV 0.67–1.16), в отличие от периодической катапульты в обучении (0.02–0.11): один сертификат, две физики переключений.
3. **Рождение уровня по ручке T — через редкое состояние, не через фолд:** второй уровень появляется в спектре как редкая мода и растёт по весу; гистерезиса нет. Это третий маршрут рождения в атласе — «рождение через редкое посещение» — родственный клетке «шум ∧ парковка» (TH-001): крамерсово ожидание есть, порога нет.
4. **Границы:** дипептид при 600 K (кинетика ускорена ради статистики; при 300 K в вакууме переходы редки); LJ13 — 13 атомов, все «фазы» конечноразмерны; зазор ≥ 3 — замороженный порог, при 0.32 отношение 2.6 остаётся «один уровень» (кромка); ψ′ считается на 8 квантильных бинах.
