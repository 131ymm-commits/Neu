## 1. Мир
- Истина W ∈ {0, 1}, P(W = 1) = π = 0,3. Обозначим s = 2W − 1.
- Шесть сигналов x₁…x₆ ∈ {−1, +1}:
  - **Источники 1, 2, 3, 5** — честные и независимые (при данном W) с надёжностями r₁ = 0,55, r₂ = 0,65, r₃ = 0,75, r₅ = 0,92: P(x_i = s) = r_i, иначе x_i = −s.
  - **Источник 4 — «с интересом»**, надёжность r_G = 0,85. Его честный ответ h₄ равен s с вероятностью r_G, иначе −s. Если W = 0 и честный ответ верен (h₄ = −1), источник врёт, то есть сообщает x₄ = +1, с вероятностью b; иначе сообщает x₄ = h₄. При W = 1 он сообщает h₄. Отсюда:
    - P(x₄ = +1 | W = 1) = r_G;
    - P(x₄ = +1 | W = 0) = (1 − r_G) + r_G·b.
  - **Источник 6 — пересказ источника 3.** С вероятностью c = 0,8 он повторяет x₃; иначе это независимый ответ с надёжностью 0,75: равен s с вероятностью 0,75, иначе −s.
- **Доля лжи b зависит от доверия к источнику 4:** b = B_MAX · clip(w̄₄ / W_REF, 0, 1), где B_MAX = 0,6, W_REF = logit(r_G) = ln(0,85/0,15), а w̄₄ — средний вес на источнике 4 у тех, кого он обслуживает (см. §3).

## 2. Агент
- Вероятность W = 1 при сигналах x — σ(z), где z = w₀ + Σ_{i=1..6} w_i·x_i и σ — логистическая функция.
- Эволюционируют два гена: **w₀** и **w₄**. Остальные веса закреплены на точных байесовских значениях честного мира (b = 0):
  - w₁ = logit 0,55, w₂ = logit 0,65, w₅ = logit 0,92;
  - w₃ = w₆ = L/2, где L = ln[ r(c + (1 − c)r) / ((1 − r)(c + (1 − c)(1 − r))) ] при r = 0,75, c = 0,8.
- Это точные веса, потому что вклад пары (x₃, x₆) в лог-отношение правдоподобий равен (x₃ + x₆)·L/2: при несовпадении сигналов он равен 0.
- Байесовский вес источника 4 при доле лжи b: w₄ᴮ(b) = (l₊ − l₋)/2, а к сдвигу добавляется (l₊ + l₋)/2. Здесь l₊ = ln[r_G / ((1 − r_G) + r_G·b)], l₋ = ln[(1 − r_G) / (r_G(1 − b))]; w₀ᴮ = logit π + (l₊ + l₋)/2.

## 3. Популяция и поколение
- **Устройство руки:** m групп по n особей, всего 400. У каждой особи гены w₀ и w₄; в руке COUNCIL ген w₄ один на группу.
- **Старт:** каждый ген ~ N(0; 0,01).
- **Поколение** (всего 3000 поколений):
  1. Для каждой группы k: w̄₄,k — среднее w₄ по группе (у COUNCIL — сам ген); b_k = B_MAX·clip(w̄₄,k / W_REF, 0, 1).
  2. **Эпизоды — общие для всех групп поколения.** Разыгрываются L = 40 эпизодов: W, честные ответы всех источников (включая h₄), решение пересказа и независимый ответ для источника 6, а также по одному равномерному u ∈ [0, 1) на эпизод. В группе k источник 4 сообщает x₄ = +1, если W = 0, h₄ = −1 и u < b_k; иначе x₄ = h₄. Остальные сигналы у всех групп одинаковы.
  3. **Выплата особи** — F = Π по 40 эпизодам P(истины) = Π σ(z)^W·(1 − σ(z))^(1−W). Считать в логарифмах.
     - z считается с весом, с которым особь действует: в DEMES и MYOPIC — свой ген w₄; в POOLED — среднее w₄ по своей группе; в COUNCIL — ген группы.
  4. **Отбор групп** (DEMES, POOLED, COUNCIL). Новая группа k выбирает группу-родителя с вероятностью ∝ среднему арифметическому F по особям группы; выбор m раз с возвращением. В MYOPIC (одна группа) отбора групп нет.
  5. **Отбор внутри группы.** n потомков новой группы — выбор n родителей из группы-родителя с возвращением, с вероятностью ∝ F. Потомок наследует оба гена от одного и того же родителя. Затем к каждому гену прибавляется N(0; 0,04).
     - В COUNCIL группа наследует ген w₄ группы-родителя плюс N(0; 0,04); w₀ — как у всех.
- **Руки:**

| Рука | m × n | Отбор групп | Вес в z |
|---|---|---|---|
| MYOPIC | 1 × 400 | — | свой w₄ |
| DEMES | 40 × 10 | да | свой w₄ |
| POOLED | 40 × 10 | да | среднее w₄ группы |
| COUNCIL | 40 × 10 | да | ген группы |

## 4. Оценка
- **Снимки** — каждые 10 поколений (g = 0, 10, …, 2990) и в последнем (g = 2999), после размножения и мутации.
  - Для каждой группы берётся средний генотип (w̄₀,k, w̄₄,k) и её доля лжи b_k = B_MAX·clip(w̄₄,k / W_REF, 0, 1).
  - Лог-потеря считается точно, перебором всех 2 × 64 сочетаний (W, x) с их вероятностями в мире с этим b_k: −Σ P(W, x)·ln P_агента(W | x).
  - Лог-потеря и w̄₄ усредняются по группам.
- **Итог зерна** — среднее по снимкам с g ≥ 1000 (их 201): w̄₄ (обозначим w_G) и лог-потеря.

## 5. Теория (сокращённый агент)
- **Близорукая точка** — b*, при котором b* = B_MAX·clip(w₄ᴮ(b*) / W_REF, 0, 1). Её даёт бисекция по b ∈ [0; B_MAX]. w_my = w₄ᴮ(b*).
- **Дальновидная точка** — w_far = argmin по w₄ от [min по w₀ точной лог-потери агента (w₀, w₄, закреплённые веса) в мире с b = B_MAX·clip(w₄ / W_REF, 0, 1)].
- **u** = (w_G − w_far) / (w_my − w_far).
