# ROCKET-01 — команда голов Claude строит в Factorio фабрику до запуска ракеты (06.10.2026)

Слова автора: «Ок а теперь пройди до конца. Построй космический корабль.» В Factorio 2.0 без дополнения Space Age конец игры — запуск ракеты из ракетной шахты.
**Тип:** разведочный опыт без гипотезы (совет оценит по итогам). Правда — от игры: статистика производства вех и `force.rockets_launched`.
**Мир:** отдельный сервер (слот 7), лабораторный стартовый набор FLE, все технологии исследованы (упрощение — честно в отчёте), один постоянный мир на всю кампанию.
**Команда:** эпизоды по очереди; голова читает общий журнал (`campaign/NOTES.md`), действует ≤ 40 шагами кода FLE, пишет журнал. Первая — главный инженер (план), дальше строители.
**Масштаб (по рецептам игры):** шахта 1000 стали, 200 процессоров, 200 электродвигателей, 1000 бетона; ракета 50 деталей; ≈ 250 процессоров ≈ 5000 электросхем.
FACTORIO-01 продолжается на слотах 0–5 параллельно.
