# OCREP-01 «ОЦЕНЩИК-ПОВТОР» — ворота 1: гипотеза (15.11.2026)

**Слова автора, 15.11.2026:** «делай только я спать». Это ответ на мою рекомендацию в итоге OCMIX-01: один опыт на третьем сдвиге — повтор C-086 вместе с контролем NB-IND (условие статуса «установлено») и пилот по верхушке; если верхушка переоценена — проверка вето (`journal/DECISIONS.md`).

**Главный вопрос Neu — оценщик, который не обманывается под давлением отбора.** OCREP-01 спрашивает:
- держится ли вывод C-086 (выученное согласие LR-AGREE лучше простого AGREE вне диапазона) на третьем сдвиге;
- специфичен ли он: даёт ли LR-AGREE больше, чем взвешивание голов только по надёжности (NB-IND);
- если на этом сдвиге у согласия есть самообман верхушки — снимает ли его вето.

## Опора (вес — только база класса для нового; C-086 — по реестру)
- C-086: OCCOR-01 (8,08 бита) и OCMIX-01 (7,18 бита; те же головы и код — верхняя оценка). Не установлено: в повторе не было NB-IND (совет 57).
- C-087 (OCCOR-01): LR-AGREE лучше NB-IND, мощность 0,182 — эффект, вероятно, завышен.
- C-088 (OCCOR-01): под жёстким отбором согласие обманывалось на 0,24–0,27; в OCMIX-01 этого не было (0,028–0,050).
- Литература — `docs/prior_art/2026-11-14_OCCOR-01.md`, `docs/prior_art/2026-11-14_OCMIX-01.md` и ворота 2 этого опыта.

## Оценщики (определения закреплены до пилота)
- **AGREE, NB-AGREE, LR-AGREE, NB-IND, FAM-AGREE, CONF** — код OCCOR-01 (`experiments/2026-11-14_OCCOR-01/analyze_occor.py`), без изменений.
- **VETO, MIX-LR** — код OCMIX-01 (`experiments/2026-11-14_OCMIX-01/analyze_ocmix.py`), без изменений.
- **Общее:** калибровка изотоническая по ID, по головам; выбор — наибольшая откалиброванная вероятность, ничья «поровну»; ИОИ = (1 − T) + max(0, C − T); верхушка — `top10_sel` (10 % выбранных ответов, граничный блок ничьих дробно).

## Задача и сдвиг (свежие)
- «Трёхзначное + двузначное», a ∈ [300, 399], b ∈ [10, 99]. ID — сумма < 400, OOD — сумма ≥ 400. Этих задач не было ни в OCCOR-01, ни в OCMIX-01.
- Подсказка — 4 примера той же задачи (зерно 7 500 000), одна у всех голов.
- Разбиение — зерном 7 510 000: пилот 30 %, тест 70 %. Тест не открывается до регистрации.
- Головы — те же девять Pythia (область C-086 — «эти 9 голов Pythia, сложение»). Проверка метода повторяется на пилоте; не прошедшие исключаются только по ней.

## Правила (уровни и веса — в PREREG по мощности пилота)
- **R1 (третий тест C-086):** ИОИ(LR-AGREE) − ИОИ(AGREE) < 0.
- **R2 (контроль на неспецифичность):** ИОИ(LR-AGREE) − ИОИ(NB-IND) < 0. Если R1 и R2 подтверждены, совет решает о статусе «установлено» для C-086 (CLAUDE.md: повтор с контролем на неспецифичность).
- **R3 (вето; по условию):** самообман верхушки VETO − LR-AGREE < 0.
  - **Условие включения закреплено до пилота** (совет 57): на пилоте самообман верхушки AGREE (`top10_sel`) больше 0,15 **и** мощность R3 при эффекте пилота, ужатом вдвое, не ниже 0,8.
  - Если условие не выполнено, R3 до регистрации снимается и идёт только описательно; серия тогда — два правила.
- Вердикт: «подтверждено» — верхняя граница ДИ < 0; «опровергнуто» — нижняя > 0; иначе «не решено». Правило с мощностью < 0,05 — «не проверено».
- **Описательно:** NB-AGREE, FAM-AGREE, CONF, MIX-LR; разложение R1 на ΔT и ΔC (доля C); верхушка всех оценщиков (`top10_sel`, `top10_all`); поддержка выбранного ответа VETO (любой головой, головой другой линии); кросс-подгонка; AUROC; перенос C-088.

## Что опровергнет
- R1: ДИ разности целиком выше 0 — C-086 на этом сдвиге неверен.
- R2: ДИ целиком выше 0 — LR-AGREE хуже взвешивания по надёжности.
- R3: ДИ целиком выше 0.

## Закреплено до данных пилота
1. Оценщики и правила — выше; код анализа — коммит до пилота.
2. Условие включения R3 — выше.
3. Интервал — бутстреп с поправкой на смещение (BC), вложенный, 10000 повторов (как OCMIX-01 после совета 56); уровень — 0,0025 на правило и сторону; серия — не выше 0,0025 на правило.
4. Пилот даёт только: головы теста (проверка метода), мощность (эффект ужимается вдвое) и решение по условию R3.
5. Проверка метода — как OCMIX-01 (не меньше 20 верных и 20 неверных на ID и OOD у каждой головы; ответов без числа не больше 5 %; голов не меньше 6). Если проходит меньше 6 голов — меняется сдвиг, а не правила.
