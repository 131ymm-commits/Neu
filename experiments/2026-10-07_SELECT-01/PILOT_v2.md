# SELECT-01: живая проверка run_sealed2 на Opus (пилот v2, 12.10.2026)

Ворота 1 перед PREREG основного прогона. Это пилот, а не проверка гипотез: числа ниже вывода не дают.

## Зачем
После пилота 2 сменился драйвер голов: run_sealed v1 → tools/run_sealed2.py (решение совета 29, пункт (А); проверка Opus — коммиты ba9c9ca и 3777f9c). Что нужно увидеть на живых вызовах Opus, прежде чем писать PREREG:
1. годный поток Opus (размышления, подпись, StructuredOutput) получает класс «годный»;
2. в modelUsage только claude-opus-5-5, фоновых вызовов других моделей нет;
3. версия CLI по init — 2.1.294, инструментов у головы нет (tools = [StructuredOutput]);
4. длительность вызова — для проверки таймаута 1800 с; размер записи журнала на вызов — для оценки объёма в git;
5. выход и размышления при effort high в сравнении с пилотом 2 на тех же промптах. В пилоте 2 effort не задавался. Его значение неизвестно: по строкам бинаря это default_effort модели с сервера, запасное значение — high (ERRORS № 77).

## Что запускается
5 вызовов на задаче пилота WH_7301. Эта задача в тест не входит: основной прогон — WH 8001–8200. Промпты те же, что в пилоте 2 (run/v2smoke_jobs.jsonl, sha256 b05ab838…):
- WH_7301|exec — исполнитель;
- WH_7301|B_blind|0, WH_7301|B_zayavka|0, WH_7301|C_N|0, WH_7301|D_N|0 — по одному оценщику каждой руки.

Конфигурация — по умолчанию из run_sealed2: claude-opus-5-5, effort high, MAX_THINKING_TOKENS 31999, CLAUDE_CODE_MAX_RETRIES 0, таймаут 1800 с, parallel 1.

Команда (из корня репозитория):

    python3 tools/run_sealed2.py run --jobs experiments/2026-10-07_SELECT-01/run/v2smoke_jobs.jsonl --task-from-id \
        --seed SELECT-01-v2smoke --journal experiments/2026-10-07_SELECT-01/run/v2smoke_journal \
        --streams .cache/select01_streams/v2smoke --max-calls 12

Пул исполнителя пишется только в журнал: pools/WH_7301.json пилота 2 не трогается.

## Что будет признано провалом
Хоть один вызов не «годный» без понятной внешней причины. Лимит аккаунта причиной провала не считается: это ожидание. Ещё провалы: чужая модель в modelUsage; версия не 2.1.294; таймаут. При провале основной прогон не начинается до разбора.

## Калибровка effort (решено до запуска)
Те же 5 заданий — при effort medium (run/v2smoke_medium_config.json, журнал run/v2smoke_medium_journal).
**Правило выбора effort основного прогона.** Из {medium, high} берётся уровень, у которого сумма выхода по 5 заданиям ближе к пилоту 2 по |log(сумма / 20 217)|. При равенстве берётся medium как более дешёвый. Довод: по пилоту 2 считаны бюджет, лимит и мощность, а равенство бюджета рук (B_blind ≥ C_N, D_N) проверено при его effort. Выбор делается по токенам, не по ответам. Ответы 5 вызовов вывода не дают.
