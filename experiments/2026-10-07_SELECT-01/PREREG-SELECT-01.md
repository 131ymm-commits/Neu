## 1. Вопрос
Исполнитель предлагает 8 планов и к каждому даёт заявку — свой прогноз итога. Заявки неточны. Вопрос: выбирает ли оценщик с ролевым промптом лучший план, чем базовый промпт при равном бюджете? Ролевых оценщиков два: C_N оценивает по правилам задачи, D_N — по правилам и с правом отказа. Выбор лучшего по заявке (A0) — это оценщик, которого обманывает отбор. Отсюда связь с главным вопросом программы: как построить оценщика, который не обманывается под давлением отбора.

Мера — нормированный регрет r = (оракул − выбранный) / (оракул − среднее пула). Правда кандидата — среднее итога по 1000 реализациям шума от секретной соли (`sim.py`). У случайного выбора (E) регрет в среднем 1.

## 4. Первичная проверка (статистика — без изменений с DESIGN.md и трёх линз)
- Семейство {C_N − B_blind, D_N − B_blind}. Тест — парный перестановочный по задачам (смена знаков), односторонний: H1 — регрет руки меньше. Статистика — среднее разностей, без обрезки. Монте-Карло 200 000, зерно 0. Холм, α = 0,05.
- **Бюджет равен** (`budget.equal` в analyze.py, как с трёх линз): B_blind не меньше каждой руки семейства и по «вход + выход», и по выходу — средние на задачу. Проверка общая на семейство: не прошла хоть для одной руки — не засчитывается ни одна (Левое, Скептик).
- **Итог руки в выборке** — одно из трёх значений:
  - «не измерено» — если losses.py ставит not_measured (§8);
  - иначе «засчитана» — если в analyze.py counts = true (Холм против B_blind отвергает, неокруглённый односторонний p против A0 ≤ 0,05, бюджет равен);
  - иначе «не засчитана».
- **«Установлено»** (статус в реестре): рука засчитана и в основной выборке, и в повторе, по одному правилу. Засчитана в одной выборке — «не повторилось». Ни в одной — «не доказано». Если повтор отменён, вердикт для реестра — «не установлено» при любом исходе основной выборки (Правое).
- Величина эффекта — среднее разностей с 95 % ДИ (бутстреп по задачам, 20 000, зерно 0): по каждой выборке (analyze.py) и по объединению задач обеих выборок. Объединение считает `pool.py` по per_task двух analyze, у каждого своя соль (Левое, Инженер). Пары: C_N − B_blind, D_N − B_blind, C_N − A0, D_N − A0. Объединённая оценка описательная, без p.
- Δ = 0,2 нормированного регрета нужна только для расчёта мощности. Тест идёт против 0. Величину ≥ Δ не утверждаем.
