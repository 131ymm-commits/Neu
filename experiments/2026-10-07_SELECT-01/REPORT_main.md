## Что это значит и чего это не значит
- **Что получено.** На 100 свежих задачах склада ролевой оценщик с правом отказа (D_N) выбирает из 8 планов лучше двух других оценщиков: базового голосования на том же бюджете (B_blind) и выбора по заявке исполнителя (A0). Ролевой оценщик без права отказа (C_N) от базового не отличается.
- **Почему так — не проверялось.** Ниже регрет даёт добавка ROLE_REFUSE к ROLE при свёртке ×5 большинством среди неотказавшихся. Добавка — одна строка промпта, заменённая двумя: при неуверенности «откажись: верни choice = −1», «отказ не наказывается сам по себе». Действует ли само право отказа, а не формулировка о неуверенности, лишний текст или фильтр голосов, опыт не показывает. Кроме того, D_N размышляет на 47 % дольше, чем C_N (средний выход на задачу 27 571 против 18 743).
- **Ограничения.** Один тип задач (WH), одна модель (Opus 5.5, effort medium), одна выборка. Контроля на неспецифичность в регистрации нет: специфичность к добавке об отказе оценивается только описательно (раздел «Оценка совета»). Соль технически ничем не закрыта — порядок «выборы → правда» доказан коммитами, а не замком.

**Критерии повтора — записаны до прогона WH 8101–8200** (регистрация c1b8169 не меняется):
- «установлено» — только если в повторе counts = true тем же analyze.py (sha256 06f4f5f8…), по тому же правилу §4 и при несработавшем правиле потерь;
- повтор не прошёл — «не установлено», без слова «тенденция»; объединённая оценка `pool.py` только описательна и отказ повтора не спасает;
- ожидаемая оценка в повторе меньше 0,185 (первая значимая оценка завышена отбором по значимости); мощность при эффекте вдвое меньше — около 0,4 или ниже. Отрицательный повтор вероятен и сам эффект не опровергает;
- специфичность (описательно): «совпали» — если D_N − C_N < 0 и D − C < 0 в обеих выборках. Тогда «установлено по §4; знаки в пользу добавки ROLE_REFUSE описательно». Иначе — «установлено против базы; вклад добавки об отказе не показан».

**Ошибка синтеза** (ERRORS № 82): «порядок кандидатов перемешивается на каждый вызов» — по коду перестановка одна на задачу; распределение позиций проверено файлом, вывод не меняется.

**На будущее — отметки, не линии** (новые линии заморожены): плацебо той же длины без −1; формулировка о неуверенности без права −1; проклятие победителя в заявках исполнителя (+384 → +464 с ростом k).
