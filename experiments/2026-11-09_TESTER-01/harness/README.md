# TESTER-01 — среда без снимков экрана

Игра идёт в Chromium (Playwright) с виртуальным временем. Голова видит экран текстом, жмёт кнопки по номерам, кликает по клеткам карты.
- `probe.js` — зонд в странице, встраивается до её скриптов:
  - `performance.now`, `Date`, `requestAnimationFrame` и таймеры идут только по `__T.advance(мс)`;
  - `Math.random` — с зерном;
  - ошибки страницы собираются;
  - на промежуточных кадрах видимая карта `#cv` не рисуется: её пиксели игры не читают.
- `adapters.js` — по одной правке на игру при загрузке. В Bäckerei `toTile` добавляется в уже существующий `window.BW`; Reifenwerk не правится. Плюс состояние игры текстом: сводка, объекты карты с клетками, люди, журнал.
- `env.js` — `GameEnv`:
  - `observe()` — экран по областям, номера элементов управления, состояние, новые ошибки;
  - `act()` — `click`, `map`, `drag`, `key`, `fill`, `select`, `click_xy`, `wait`;
  - `peek()` — подсмотр без перенумерации;
  - `screenshot()`;
  - `replay(file, trace)` — повтор следа на другой копии игры.
- Проверки:
  - `det_check.js` — два прогона и повтор следа совпали по состояниям (Bäckerei, 7 шагов);
  - `map_check.js`, `map_check2.js` — постановка весов через интерфейс в Bäckerei, выбор станка кликом по клетке в Reifenwerk;
  - `speed.js` — 600 кадров: Bäckerei около 30 мс, Reifenwerk около 1,3 с.
