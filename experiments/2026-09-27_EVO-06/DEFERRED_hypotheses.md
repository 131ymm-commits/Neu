## Г1. Проклятие победителя живёт в поколениях смены элиты
Статистика: в окне 121–150 для каждого прогона D = mean(C − T | elite_age = 0) − mean(C − T | elite_age ≥ 1); прогоны без обоих типов поколений выбрасываются.
Пары: (задача, сид) внутри ветви; задачи T3–T5 отдельно, сиды медианой.
Прогноз: SAME32 — медиана D > +1/32 = 0,031 и D > 0 в ≥ 70 % прогонов; SPLIT16+16 — |медиана D| < 0,01 (заявка не зависит от отбора).
Удивит: если у SAME32 D ≈ 0 при знаковом C − T > 0,03 — тогда завышение сидит в «старой» элите (выживает та, что удачно выглядит на свежих тестах), а не в новичках; или если у SPLIT D > 0,03.

## Г2. У FIXED32 на плато заявка стоит, а истина дрейфует вниз
Статистика: для прогонов, где claimed в окне 121–150 постоянна (плато), Δ = true(g=150) − true(g=121); отдельно доля прогонов с claimed(150) = 1,0 и true(150) < 0,9.
Пары: FIXED32 против SAME32 по (задача, сид); T3–T5 отдельно.
Прогноз: у FIXED32 плато в ≥ 80 % прогонов; медиана Δ ≤ 0 (нейтральный дрейф внутри класса «проходит 32 теста» истину не улучшает); доля «claimed = 1, true < 0,9» ≥ 50 % на T3–T5; elite_age(150) у FIXED32 больше, чем у SAME32, в ≥ 70 % пар, разница медиан > 20 поколений.
Удивит: медиана Δ > +0,02 на плато — дрейф без давления улучшает истину; или elite_age(150) у FIXED32 не больше, чем у SAME32 (элита сменяется без изменения ключа — тогда argmax берёт первого из равных, и «возраст» ничего не мерит).

## Г3. Текучесть элиты предсказывает ошибку заявки, а не размер выборки
Статистика: churn = доля поколений с elite_age = 0 в окне 121–150; ρ Спирмена между churn и abs_ct_late по 20 сидам внутри (задача, ветвь).
Пары: SAME32, SAME16, SPLIT16+16 на T4, T5; плюс парное (задача, сид) сравнение churn SAME16 − SAME32.
Прогноз: ρ > +0,3 у SAME32 и SAME16 на T4/T5; у SPLIT16+16 |ρ| < 0,2; churn у SAME16 больше, чем у SAME32, в ≥ 65 % пар. У ORACLE churn < 0,05.
Удивит: ρ < 0 у SAME (частая смена элиты снижает ошибку — усреднение по разным особям); или у ORACLE churn > 0,2 (равные истины на 1000 входах чаще, чем я думаю).

Общий ложный уровень: три гипотезы × ~3 порога, описательно, без поправки; любое «подтверждение» — повод для повтора на новых сидах, не вывод.
