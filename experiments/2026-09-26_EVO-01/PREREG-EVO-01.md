# PREREG-EVO-01 — эволюционирующий зоопарк программ: что вырастет, зависит от оценщика
Записано 26.09.2026 до основного прогона (сиды 0–19). Коммитится и пушится до прогона.

## Откуда вопрос
Человек: «нужно научить ИИ оценивать ИИ… оценивание — это ранжирование эволюционное, оно запускает гонку… оценивание правильное, улучшающее ответ и отвечаемого… создай эволюционирующий зоопарк», и: «процедурное создание сильного ИИ… просто оценивание. Зеркальные гены в ИИ». Проверяемая часть: при одинаковом бюджете оценивания исход эволюции определяется тем, как устроен оценщик. Плохой оценщик выращивает обман оценщика (Гудхарт), хороший — решение.

## Постановка
- Зоопарк: 300 программ-выражений над целыми (x, константы −3…7, + − × //, %, ifless), глубина ≤ 6. Турнирный отбор по оценщику (турнир 5), кроссовер 0,7, мутация 0,3, элитизм (1 лучший по оценщику), 150 поколений.
- Задачи (скрытая правда, x ∈ [−100, 100]):
  - T1: x² − 3x + 7;
  - T2: x > 0 ? x mod 7 : −x;
  - T3: 2·⌊x/3⌋ + x mod 5.
- **Настоящее качество** — доля точных ответов на 1000 скрытых входах. Отбор их не видит.
- Оценщики (ветви):
  - FIXED16 — одни и те же 16 тестов все 150 поколений;
  - RANDOM16 — 16 свежих случайных тестов каждое поколение;
  - RANDOM64 — 64 свежих;
  - COEVO16 — из 64 свежих кандидатов берутся 16 самых спорных для текущей популяции, спорность p(1−p). По числу ответов оракула равен RANDOM64;
  - MIRROR16 — «зеркальные гены»: своя популяция из 16 тестов. Каждое поколение 8 наименее спорных заменяются мутантами (±5) самых спорных, с вероятностью 0,25 — свежими случайными. Не больше 16 новых ответов за поколение, так что по бюджету ответов сравним с RANDOM16;
  - ORACLE — все 1000 скрытых входов, верхняя граница, не по бюджету.
- Для одной пары (задача, сид) начальное зерно общее у всех оценщиков, сравнение парное. Сиды 0–19, 3 задачи: 60 пар на сравнение.
- Метрика: настоящее качество лучшей по оценщику программы в конце. Ничья (равенство) не считается победой.

## Пилот (записан честно)
Сид 999, по одному прогону: T2 — FIXED16, COEVO16, ORACLE (до правки зерна); T3 — FIXED16, RANDOM16, COEVO16, MIRROR16.
- В T3 FIXED16 заявлял 0,25, а по правде было 0,04. MIRROR16 заявлял 0,88, а по правде 0,05.
- Параметры после пилота не менялись, кроме двух правок до него: зерно без hash() и размер 300/150.
- Сид 999 в тест не входит.

## Предсказания (60 пар: ≥ 40 — подтверждено, ложный уровень 0,007; ≤ 30 — опровергнуто; 31–39 — разницы нет)
- **P1 (Гудхарт):** RANDOM16 по правде лучше FIXED16.
- **P2 (острые тесты при равном бюджете ответов):** COEVO16 лучше RANDOM64. Пилот намекает на обратное; записываю как гипотезу Хиллиса (1990).
- **P3 (зеркальные гены при равном бюджете):** MIRROR16 лучше RANDOM16. Пилот намекает на обратное.
- **P4 (разведочно):** разрыв «оценщик минус правда» по ветвям; доля ORACLE, достигнутая каждой ветвью; кривые по поколениям.
