## 4. Оценщики и счёт (`analyze_ocshift.py`)
- **Восемь оценщиков толпы** — AGREE, NB-AGREE, LR-AGREE, NB-IND, FAM-AGREE, CONF (код OCCOR-01), VETO, MIX-LR (код OCMIX-01), без изменений. `test_ocshift.py` сверяет ИОИ, T и C с `analyze_ocrep.crowd`.
- **Общее:** калибровка — изотоническая по ID среды, по головам; выбор — наибольшая откалиброванная заявка, ничья «поровну»; ИОИ = (1 − T) + max(0, C − T).
- **ONE-BEST** — голова с наибольшей точностью на ID среды (при равенстве — первая по списку). T — её точность на OOD; C — средняя её заявка на OOD (изотоника по её logp на ID — та же, что у CONF). Между головами ничего не выбирается.
- **Самообман от отбора без сдвига** — на ID, кросс-подгонка в 5 частей (зерно 7 620 000 + 10·X + p): калибровка — по четырём частям, выбор головы и счёт — на пятой. Мера — T − C по всем задачам ID (отрицательная — заявка завышена).
- **Проверка метода в среде:** голова проходит, если на ID у неё не меньше 20 верных и 20 неверных ответов и ответов без числа не больше 5 %. Доля ответов без числа считается по всем задачам среды, ID и OOD вместе: это вид ответа, а не правда (на пилоте таких ответов не было, §3). Толпа и кандидаты ONE-BEST — прошедшие головы. Среда годна, если прошло не меньше 6 голов.
- **Бутстреп** вложенный, по средам независимо: 10000 повторов; зерно среды 7 630 000 + 10·X + p. В повторе — выборка ID с возвращением (переподгонка оценщиков и калибровки; ONE-BEST выбирается заново), затем выборка OOD. Части кросс-подгонки закреплены за исходными задачами: копии задачи остаются в одной части.
- **Среднее по средам** — по годным средам, с равными весами. Вывод — про эти десять сред, а не про «все сдвиги».

## 5. Правила (уровень 0,0025 на сторону; 10 000 повторов бутстрепа)
- **Область вывода.** Бутстреп перевыбирает задачи внутри сред, сами среды закреплены. Поэтому вердикты R1–R3 относятся к этим десяти средам, а не к сдвигу вообще (совет 60).
- **Происхождение правил.** R3 — слово автора. R1, R2 и R4 — инициатива Claude после разбора трёх готовых сдвигов (совет 60).
- **Вердикт R1–R3 — по трём интервалам вместе** (совет 58; совет 60, п. 4а–4б). Для средней по средам разности считаются три интервала уровня 0,0025 на сторону:
  - процентильный — квантили повторов 0,0025 и 0,9975;
  - BC — квантили Φ(2·z₀ ± 2,807), где z₀ — смещение повторов относительно точечной оценки;
  - обратный (basic) — [2·точка − q(0,9975); 2·точка − q(0,0025)], q — квантили повторов.
  - «Подтверждено» — верхние границы всех трёх < 0. «Опровергнуто» — нижние границы всех трёх > 0. Если вывод дают не все, вердикт — «не решено (только …)» с именами интервалов, давших вывод.
- **Граница BC за разрешением повторов.** Если за квантилем границы BC по построению меньше 0,0005 повторов (5 из 10 000; это z₀ дальше 0,24 в неблагоприятную сторону), её значение — крайний повтор: наибольший для верхней границы, наименьший для нижней. Условие «верхняя граница BC < 0» тогда значит: выше нуля нет ни одного повтора из 10 000. Метка — в json, в отчёте и в записи реестра.
  - При z₀ больше примерно 1 (так было у R2 на готовых сдвигах, §6) условие BC — уже не самостоятельный интервал. Поправку на смещение несёт обратный интервал: при нормальных повторах он равен «точка + (z₀ ± 2,807)·SE».
- **Строгая ветвь** (`verdict_strict`; п. 4 решения совета 60 дословно): вывод, чья сторона опирается на границу BC за разрешением повторов, читается как «не решено (BC не определён)». Она считается и печатается рядом с главным вердиктом и идёт в отчёт и в запись реестра. Главный вердикт она не меняет (§9).
- **R1 (одна голова против толпы):** D1 = среднее по средам [ИОИ(ONE-BEST) − наименьший ИОИ среди восьми оценщиков толпы]. Лучший из восьми берётся в каждой среде задним числом, по правде, — это фора толпе.
  - «Подтверждено» — верхняя граница < 0 у трёх интервалов: одна голова лучше даже лучшего задним числом оценщика толпы.
  - «Опровергнуто» — нижняя граница > 0 у трёх интервалов **и** значима проверка, верная после отбора (max-T по восьми фиксированным оценщикам, уровень 0,0025; §9). Если нижняя граница > 0, а max-T не значим — «не решено (фора отбора)».
- **R2 (самообман от отбора без сдвига):** D2 = среднее по средам [T − C у CONF на ID с кросс-подгонкой].
  - «Подтверждено» — верхняя граница < 0 у трёх интервалов **и** нормальная граница ниже нуля: точка + 2,807·SE < 0, где SE = √(Σ s²) / m, s — стандартное отклонение бутстрепа среды, m — число годных сред (совет 60, п. 3). Иначе — «не решено (нормальная граница)».
  - «Опровергнуто» — нижняя граница > 0 у трёх интервалов.
- **R3 (слово автора):** D3 = среднее по средам [ИОИ(CONF) − ИОИ(LR-AGREE)]. «Подтверждено» — верхняя граница < 0 у трёх интервалов (CONF лучше); «опровергнуто» — нижняя > 0 у трёх (LR-AGREE лучше).
- **R4 (различие между средами, C-089):** неоднородность D3. Q = Σ w (D3 среды − среднее с весами w)², w = 1 / s², s — стандартное отклонение бутстрепа среды. «Подтверждено» — p < 0,0025 и по бутстрепу с центрированием под нулевую гипотезу, и по χ² с (число сред − 1) степенями свободы. Иначе «не решено».
- **Иначе — «не решено».** Правило с мощностью < 0,05 (`power.json`) при «не решено» читается как «не проверено».
- **Предохранители R1–R3** (могут только отменить вывод):
  - **знак:** «подтверждено» требует точечной оценки < 0, «опровергнуто» — > 0; иначе «не решено (точка и ДИ расходятся)»;
  - **«без одного диапазона»** (совет 60, п. 5): знак точечного среднего сохраняется при исключении любого из пяти диапазонов (обеих его сред); иначе «не решено (без одного диапазона)». Число сред с тем же знаком, что среднее, печатается и идёт в запись реестра («в k из 10»).
- **Проверки метода опыта** (провал → все правила «не определено (проверка метода)»): годных сред не меньше 8 из 10; сверка цепочки прошла (ответы всех девяти голов совпали, расхождение logp в допуске, §3).
- **Защита LR:** в какой-то среде повторов с одним классом у головы в выборке ID больше 1 % — R1, R3, R4 «не решено».
- **Хвосты:** число повторов за границами BC и процентильного интервала; три интервала и вердикт по двум половинам повторов (разный вердикт половин — пометка «граница по Монте-Карло неустойчива»); z₀ и сдвиг «медиана повторов − точка». Вердикт они не меняют.
- **Статус «установлено»** этот опыт дать не может: нужен повтор с контролем на неспецифичность (CLAUDE.md). Подтверждённое правило идёт в реестр как «подтверждено» — и тогда, когда строгая ветвь даёт «не решено».
- **Ложный уровень серии.** Сторон семь (у R1–R3 по две, у R4 одна), по 0,0025. Ложное «подтверждено» по четырём правилам — не выше 0,01. Ложный вывод любого знака — не выше 0,0175 (совет 60 записал верхнюю оценку 0,02).

**Правило чтения R1** (совет 60, п. 9; записано до данных):
- D1 раскладывается на две части, сумма которых равна D1:
  - разность незнания — среднее по средам [(1 − T) ONE-BEST − (1 − T) лучшего из восьми];
  - разность самообмана — среднее по средам [max(0, C − T) ONE-BEST − max(0, C − T) лучшего из восьми].
  - Лучший из восьми — оценщик с наименьшим ИОИ в среде (в повторе выбирается заново).
- Сторона части — вывод трёх интервалов уровня 0,005 на сторону. Это описательно: вердикт R1 не меняется.
- Если R1 «подтверждено», запись реестра зависит от частей:

| Незнание | Самообман | Запись |
|---|---|---|
| в пользу одной головы | в пользу одной головы | «одна голова точнее, и её оценка честнее» |
| ноль не исключён | в пользу одной головы | «оценка одной головы честнее; по точности вывода нет» |
| в пользу одной головы | ноль не исключён | «одна голова точнее; о честности оценки вывода нет» |
| в пользу одной головы | в пользу толпы | «одна голова точнее, но её оценка обманывается сильнее» |
| в пользу толпы | в пользу одной головы | «оценка одной головы честнее, хотя сама голова менее точна» |
| иначе | | «знак D1 не отнесён ни к незнанию, ни к самообману» |

- Если R1 «опровергнуто» — те же строки для толпы.

## 8. Ограничения (записаны до данных теста)
- Одна задача (сложение) и те же девять голов. Свежие — диапазоны и подсказки. Вывод — про эти десять сред.
- **Свежие диапазоны — другой режим** (§3): головы там намного слабее. Мощность и основание гипотезы взяты с готовых сдвигов и здесь могут не держаться. Исход «не решено» или «опровергнуто» по R1 будет значить, что находка разбора зависит от режима.
- **R1 несимметричен по построению.** «Подтверждено» считается против лучшего задним числом оценщика — это консервативно. «Опровергнуто» требует ещё и проверки, верной после отбора (max-T): без неё выбор лучшего из восьми по тем же данным завышал бы преимущество толпы.
- **R2: бутстреп завышает самообман от отбора.** В повторе калибровка шумнее, и наибольшая из заявок завышена сильнее. На готовых сдвигах середина повторов уходила далеко от точки (z₀ больше +1). Поэтому в правиле есть нормальная граница (§5), а рядом печатается нормальное приближение той же точки без бутстрепа (среднее по задачам ID; независима от бутстрепа только стандартная ошибка; описательно).
- **BC при z₀ далеко от 0.** Граница BC уходит за разрешение 10 000 повторов уже при z₀ дальше 0,24; тогда вместо неё берётся крайний повтор, и поправку на смещение несёт обратный интервал (§5). Обратный интервал точен при нормальных повторах; при тяжёлом хвосте он может быть мягче настоящей границы BC, которую 10 000 повторов оценить не могут. Поэтому рядом печатается строгая ветвь.
- **Предохранитель «без одного диапазона»** смотрит только на точечные средние. Он ловит случай «среднее сделал один диапазон», но не меряет разброс между диапазонами — для этого R4 и описательная неоднородность D1.
- **Вес — с потолком** (§6): мощность перенесена с готовых сдвигов, где режим другой, поэтому в вес идёт меньшее из мощности и моего ожидания.
- **ONE-BEST в бутстрепе выбирается заново.** Если две головы близки по точности на ID, разность D1 в повторах может быть двугорбой, а интервал — широким.
- ИОИ не штрафует заниженную заявку. Рядом — Брайер выбранной заявки (описательно).
- Проверка метода — только по ID. В толпе могут остаться головы, которые вне диапазона почти не дают верных ответов: оценщик не знает, какие головы сломались, и это часть постановки.
- Среды одного диапазона делят диапазон, но не задачи и не подсказку. Различие «диапазон — подсказка» — описательно.
- Извлечение на двух видеокартах — новый порядок работы. Блок сверки с выводом OCREP-01 — в каждом прогоне.
- Литература: все источники — «сниппет». Близкий вывод (маршрутизаторы между моделями часто не обходят лучшую одну модель) уже высказан другими.
- Основание опыта — пост-хок разбор, где сравнивалось много вариантов. Опорой он не считается.
