## 2. Среды, головы, извлечение
- **Задача:** a + b, a ∈ [X00, X99], b ∈ [10, 99]. ID — сумма < (X+1)00, OOD — сумма ≥ (X+1)00.
- **Диапазоны:** X = 4, 5, 6, 7, 8. Ни одна задача этих диапазонов раньше не использовалась.
- **Среда — пара (диапазон, подсказка):** у диапазона две подсказки теста (p = 0, 1; по 4 примера; зерно 7 600 000 + 1000·X + p). **Десять сред по 2200 задач** (в среде 955–1020 задач ID, остальные OOD). Задачи сред не пересекаются (зерно разбиения 7 610 000 + X); 12 примеров трёх подсказок диапазона в задачи не идут.
- **Пилот:** третья подсказка (p = 9), свои 300 задач на диапазон.
- **Головы** — те же девять Pythia: 1.4b, 1.4b-deduped, 2.8b (main, step133000, step123000, step113000), 2.8b-deduped, 6.9b, 6.9b-deduped.

- **Сверка цепочки** — в каждом прогоне извлекаются первые 96 задач пилота OCREP-01 с его подсказкой; ответы и logp сверяются с закоммиченным выводом OCREP-01 (§3).

## 4. Оценщики и счёт (`analyze_ocshift.py`)
- **Восемь оценщиков толпы** — AGREE, NB-AGREE, LR-AGREE, NB-IND, FAM-AGREE, CONF (код OCCOR-01), VETO, MIX-LR (код OCMIX-01), без изменений. `test_ocshift.py` сверяет ИОИ, T и C с `analyze_ocrep.crowd`.
- **Общее:** калибровка — изотоническая по ID среды, по головам; выбор — наибольшая откалиброванная заявка, ничья «поровну»; ИОИ = (1 − T) + max(0, C − T).
- **ONE-BEST** — голова с наибольшей точностью на ID среды (при равенстве — первая по списку). T — её точность на OOD; C — средняя её заявка на OOD (изотоника по её logp на ID — та же, что у CONF). Между головами ничего не выбирается.
- **Самообман от отбора без сдвига** — на ID, кросс-подгонка в 5 частей (зерно 7 620 000 + 10·X + p): калибровка — по четырём частям, выбор головы и счёт — на пятой. Мера — T − C по всем задачам ID (отрицательная — заявка завышена).
- **Проверка метода в среде:** голова проходит, если на ID у неё не меньше 20 верных и 20 неверных ответов и ответов без числа не больше 5 %. Толпа и кандидаты ONE-BEST — прошедшие головы. Среда годна, если прошло не меньше 6 голов.
- **Бутстреп** вложенный, по средам независимо: 10000 повторов; зерно среды 7 630 000 + 10·X + p. В повторе — выборка ID с возвращением (переподгонка оценщиков и калибровки; ONE-BEST выбирается заново), затем выборка OOD. Части кросс-подгонки закреплены за исходными задачами: копии задачи остаются в одной части.
- **Среднее по средам** — по годным средам, с равными весами. Вывод — про эти десять сред, а не про «все сдвиги».

## 5. Правила (уровень 0,0025 на сторону; вердикт — по ДИ BC и процентильному вместе, совет 58)
- **R1 (одна голова против толпы):** D1 = среднее по средам [ИОИ(ONE-BEST) − наименьший ИОИ среди восьми оценщиков толпы]. Лучший из восьми берётся в каждой среде задним числом, по правде, — это фора толпе.
  - «Подтверждено» — верхняя граница < 0 у обоих ДИ: одна голова лучше даже лучшего задним числом оценщика толпы.
  - «Опровергнуто» — нижняя граница > 0 у обоих ДИ **и** значима проверка, верная после отбора (max-T по восьми фиксированным оценщикам, уровень 0,0025; §9). Если нижняя граница > 0, а max-T не значим — «не решено (фора отбора)».
- **R2 (самообман от отбора без сдвига):** D2 = среднее по средам [T − C у CONF на ID с кросс-подгонкой]. «Подтверждено» — верхняя граница < 0; «опровергнуто» — нижняя > 0.
- **R3 (слово автора):** D3 = среднее по средам [ИОИ(CONF) − ИОИ(LR-AGREE)]. «Подтверждено» — верхняя граница < 0 (CONF лучше); «опровергнуто» — нижняя > 0 (LR-AGREE лучше).
- **R4 (различие между средами, C-089):** неоднородность D3. Q = Σ w (D3 среды − среднее с весами w)², w = 1 / s², s — стандартное отклонение бутстрепа среды. «Подтверждено» — p < 0,0025 и по бутстрепу с центрированием под нулевую гипотезу, и по χ² с (число сред − 1) степенями свободы. Иначе «не решено».
- **Иначе — «не решено».** Правило с мощностью < 0,05 (`power.json`) при «не решено» читается как «не проверено».
- **Проверки метода опыта** (провал → все правила «не определено (проверка метода)»): годных сред не меньше 8 из 10; сверка цепочки прошла (ответы всех девяти голов совпали, расхождение logp в допуске, §3).
- **Защита LR:** в какой-то среде повторов с одним классом у головы в выборке ID больше 1 % — R1, R3, R4 «не решено».
- **Хвосты:** число повторов за каждой границей каждого ДИ; интервалы по двум половинам повторов; метка «граница BC не определена» (меньше 5 повторов за границей). Вердикт они не меняют.
- **Статус «установлено»** этот опыт дать не может: нужен повтор с контролем на неспецифичность (CLAUDE.md). Подтверждённое правило идёт в реестр как «подтверждено».
- Ложное «подтверждено» по серии из четырёх правил — не выше 0,01.

**Описательно** (вес 0, без вердикта; ДИ BC 99 %, где он считается):
- таблица по средам: восемь оценщиков и ONE-BEST — T, C, самообман, ИОИ, Брайер; верхние 10 %; оракул; доли выбора;
- ONE-BEST против каждого из восьми (среднее по средам); то же по Брайеру (ИОИ не штрафует заниженную заявку);
- неоднородность D1 по средам; разложение различий «диапазон — подсказка»;
- контроль AGREE той же среды для R3 (совет 59): ИОИ(CONF) − ИОИ(AGREE), ИОИ(LR-AGREE) − ИОИ(AGREE);
- самообман от отбора на ID у всех восьми (только точка) и у ONE-BEST (у неё тоже есть отбор — головы по точности);
- где выбор отходит от ответа ONE-BEST: доля задач и точность там;
- вторая калибровка после отбора (POST), слияние FUSE-MIN, ONE-BEST с заявкой min(CONF, LR-AGREE);
- толпа без лучшей головы против лучшей из оставшихся.

## 8. Ограничения (записаны до данных теста)
- Одна задача (сложение) и те же девять голов. Свежие — диапазоны и подсказки. Вывод — про эти десять сред.
- **Свежие диапазоны — другой режим** (§3): головы там намного слабее. Мощность и основание гипотезы взяты с готовых сдвигов и здесь могут не держаться. Исход «не решено» или «опровергнуто» по R1 будет значить, что находка разбора зависит от режима.
- **R1 несимметричен по построению.** «Подтверждено» считается против лучшего задним числом оценщика — это консервативно. «Опровергнуто» требует ещё и проверки, верной после отбора (max-T): без неё выбор лучшего из восьми по тем же данным завышал бы преимущество толпы.
- **R2: бутстреп завышает самообман от отбора.** В повторе калибровка шумнее, и наибольшая из заявок завышена сильнее. На готовых сдвигах середина повторов уходила далеко от точки (z₀ больше +1). Поэтому рядом — оценка вторым способом, без бутстрепа (среднее по задачам ID, нормальное приближение; описательно).
- **BC при z₀ далеко от 0.** Одна из границ держится на единичных повторах; метка — в json. Вердикт — по обоим ДИ, поэтому это может только отменить вывод.
- **ONE-BEST в бутстрепе выбирается заново.** Если две головы близки по точности на ID, разность D1 в повторах может быть двугорбой, а интервал — широким.
- ИОИ не штрафует заниженную заявку. Рядом — Брайер выбранной заявки (описательно).
- Проверка метода — только по ID. В толпе могут остаться головы, которые вне диапазона почти не дают верных ответов: оценщик не знает, какие головы сломались, и это часть постановки.
- Среды одного диапазона делят диапазон, но не задачи и не подсказку. Различие «диапазон — подсказка» — описательно.
- Извлечение на двух видеокартах — новый порядок работы. Блок сверки с выводом OCREP-01 — в каждом прогоне.
- Литература: все источники — «сниппет». Близкий вывод (маршрутизаторы между моделями часто не обходят лучшую одну модель) уже высказан другими.
- Основание опыта — пост-хок разбор, где сравнивалось много вариантов. Опорой он не считается.

## 9. Что изменилось после пилота (до регистрации; данные теста не открывались, сравнения оценщиков на пилоте не считались)
- **Проверка метода — только по ID** (в HYPOTHESIS было «на ID и на OOD»). Причина — утечка: по правде OOD из толпы убирались бы головы, сломавшиеся вне диапазона, а это фора толпе. Нашёл сам, проверяя правила по первой линзе. Счёт по OOD записывается, но состав толпы не решает.
- **R1, сторона «опровергнуто»** — добавлена проверка, верная после отбора (max-T по восьми фиксированным оценщикам, уровень 0,0025). Причина: лучший задним числом оценщик выбирается по тем же данным, и «нижняя граница > 0» одна была бы завышена. Проверка может только отменить «опровергнуто». Сторона «подтверждено» не менялась.
- **Допуск сверки цепочки** по logp — ЗАПОЛНИТЬ.
- **Описательно добавлено:** самообман от отбора у ONE-BEST; верхние 10 % у ONE-BEST; R2 вторым способом (без бутстрепа).
- **Сухой прогон и прогон правил на готовых сдвигах** повторены финальным кодом (§0, §6).
- **Совет 60** — ЗАПОЛНИТЬ.
