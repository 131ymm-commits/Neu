## 9. Как читать
- **Что установлено этим опытом:** ничего — статус «подтверждено». Для «установлено» нужен повтор на сидах 120–139 теми же скриптами (по слову автора).
- **Что подтверждено:**
  1. в этом мире доля поколений с экзаменом снижает завышение показателя — на схеме с чередованием, на новых сидах, во всех пяти задачах;
  2. чередование с экзаменом даёт больше правды, чем чередование со случайным отбором той же доли. Чистой паузы в опыте нет: случайный ключ — это пауза плюс дрейф.
- **Что ограничено сверху:** добавка экзамена к снижению завышения по сравнению со случайным ключом при половине поколений — в среднем по T2–T6 меньше 0,05. Оговорки: ноль в интервал не входит; на T2 разность 0,085; правда ветвей разная.

- **Чего не утверждаю.**
  - Порог М3 не проверялся.
  - Причины различий между задачами — объяснение не проверялось.

  - Что при равной правде экзамен отбирает против завышенных программ — мера P2 описательная, объяснение не проверялось.
  - На живое не переносится без оговорки: в мире нет обучения при жизни, «детство» здесь — расписание отбора.
