- **Узор переносов** κ(j) — вектор переносов столбикового сложения a + b по разрядам a, считается только из слагаемых.

    - На ID: (c1, 0, 0, …).
  - Значит, страты по узору переносов — две страты по c1 в каждой области, одинаково определённые вне диапазона и на ID.

## 4. Меры и нули
- **F** — доля задач области (вне диапазона или ID), где какой-нибудь неверный числовой ответ набрал не меньше голосов, чем верный (`ocdiv2.false_major`).
- **N3c (первичный нуль).** Внутри каждой головы её неверные числовые смещения переставляются между её же задачами с неверным числовым ответом внутри страты c1 области.
  - Верные ответы и ответы без числа остаются на месте.
  - Это `ocdiv3.permute_wrong` со стратами c1 вместо Nd8.
  - Картина «кто где ошибся» сохраняется точно, поэтому трудность задачи в смысле «кто ошибается» нуль сохраняет полностью.
- **Δ3c = F − F₀(N3c)** — избыток ложного большинства от совпадения самих неверных ответов на одной задаче.
- **K — совпадение при совместной ошибке** (для В3):
  - для пары голов — доля задач области, где обе дали неверное числовое смещение и оно одно и то же, среди задач, где обе дали неверное числовое смещение;
  - K = среднее по парам минус то же при N3c.
  - Под N3c множество совместных ошибок пары то же, меняется только, какое смещение у кого. Поэтому K сравним между областями с разной точностью: на ID F в 9,5–19,1 раза меньше, чем вне диапазона (C-106), и разность Δ3c «вне диапазона минус ID» мерой зависимости не служила бы.
- **Вторичные** (описательно):
  - Т4 = F − F₀(N0) — связь с OCDIV-02 и OCDIV-03;
  - N3 со стратами-клетками «c1 × u» (u — цифра десятков суммы), 20 клеток на область;
  - разность Δ3c «вне диапазона минус ID» — мера скептика;
  - относительная мера (F − F₀)/F₀.
- **Nd8 не берётся.** N3c и так сохраняет картину ошибок точно. Страты по d̂ потребовали бы моделей, обученных на пилоте, и переноса между подсказками, который в OCDIV-03 не проверен. Это отступление от слов совета 71 («Nd8 — вторичная») выносится на три линзы.
- **Бутстреп и интервал** — как в OCDIV-03:
  - строки задач с возвращением, B = 10 000; страта строки идёт со строкой;
  - на точку — 1000 перестановок нуля, на повтор — 10;
  - M4 — точка ± z·ст. откл. повторов среднего.
  - Новые зёрна — по потоку на нуль, записываются в PREREG.

## 5. Правила (уровень 0,0025 на сторону)
- **Р1-Т (главное, «тысячи», вид «pos»):** Δ3c вне диапазона. Две части, обе обязательны:
  - А — нижняя граница M4 среднего восьми сред больше 0;
  - Б — односторонний t по средам (среды как выборка, df = n − 1) больше квантиля Стьюдента t(0,9975; n − 1): вывод на новые среды того же семейства.
  - «Подтверждено» — А и Б. «Опровергнуто» — верхняя граница M4 меньше 0 и t меньше −t(0,9975; n − 1). Только А — «в среднем этих сред, на новые среды не переносится». Иначе — «не решено».
- **Р1-Л («длина», вид «pos»):** Δ3c вне диапазона, только часть А. При трёх средах часть Б почти без мощности, поэтому вывод — о трёх средах «длины».
- **Р2-Т (специфичность, «тысячи», вид «двусторонний»):** K вне диапазона минус K на ID, по средам. Части А и Б, как в Р1-Т; знак — любой. Направление вывода — по знаку.
- **Знак по средам** (к каждому правилу) — интервал среды при 0,0025 / n целиком > 0, < 0 или накрывает 0. Если хоть одна среда < 0 — пометка «знак по средам разный».
- **Опыт определён**, если годны не меньше 6 сред «тысяч» из 8. Для Р1-Л — не меньше 2 из 3. Невырожденность среды (оракул ≥ 0,1) — по пилоту, до PREREG.
- **Множественность:** три правила. Ложное «подтверждено» серии — не больше 0,01 (Р2 двусторонний), с ложным «опровергнуто» — не больше 0,015. Уровень номинальный: перенос M4 на 0,0025 для среднего сред не проверен.
- **Мощность** каждого правила и каждой части — по пилоту до PREREG. Модель «новая среда»: точка среды ~ N(μ, τ² + s²); μ, τ — по средам пилота; s — пересчёт на число задач теста.
  - Если мощность «подтверждено» у правила ниже 0,2, правило становится описательным. Решение — по этому порогу в PREREG.

## 6. Чтение исходов (заранее)
- **Р1-Т подтверждено.** На «тысячах» головы дают одно и то же неверное число на одной задаче чаще, чем по своим частотам, при той же картине «кто где ошибся» и том же узоре переносов. Это переносится на новые среды семейства. Механизм не проверен: им займутся описательные разборы (§7).
- **Р1-Т только в части А.** Эффект есть в этих средах, обобщение не показано.
- **Р1-Т не подтверждено.** Совпадение ответов из разложения OCDIV-03 на свежих задачах со стратами c1 не повторилось. C-107 — «не подтверждено» или «опровергнуто» по правилу.
- **Р2-Т:**
  - K вне диапазона больше — совпадение при совместной ошибке сильнее под сдвигом;
  - меньше — слабее;
  - «не решено» — специфичность не показана.
- «Установлено» — только после повтора с контролем на неспецифичность (CLAUDE.md). Р2 — этот контроль, Р1-Л — второе семейство.
