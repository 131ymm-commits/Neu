## 4. Статистики (код — `ocdiv4.py`; «так же, как в X» сверено по коду X)
- **Смещения** d = ответ − правда — `ocdiv2.dmat`; ответ без числа — не голос. **F** — `ocdiv2.false_major`: доля задач области, где какой-нибудь неверный числовой ответ набрал не меньше голосов, чем верный.
- **N3c** — `ocdiv3.permute_wrong` со стратами c1 (`ocdiv4.strata_c1`): внутри головы неверные числовые смещения переставляются между её задачами с неверным числовым ответом внутри страты; верные ответы и «без числа» на месте.
  - Узор переносов внутри области принимает два значения, их различает c1 — проверено перебором всех пар (a, b) всех 11 сред (тест кода).
- **Δ3c** = F − F₀(N3c) — `ocdiv4.d3c_stream`: точка — 1000 перестановок; повтор бутстрепа — строки задач с возвращением, страта идёт со строкой, 10 перестановок; B = 10 000 (как `ocdiv3.t4_stream`).
- **K** — `ocdiv4.k_stream`: по парам голов доля совпавших смещений среди задач, где обе дали неверное числовое смещение; среднее по парам минус то же при N3c. Под N3c множества совместных ошибок пар не меняются (тест кода).
- **K вне диапазона минус K на ID** — по средам; повторы двух областей независимы (строки областей не пересекаются).
- **Зёрна:** поток на меру — 9 500 000 + 10 000 · (номер потока) + смещение среды (`ocdiv4.seed_of`, `off4`: 100 · номер семейства + номер X); повтор бутстрепа — то же + 5000. Пилот — 9 600 000 + …; проверка метода — 9 490 000 + смещение.
- **Интервал M4** — `ocdiv3.mean_entry`: точка среднего сред ± z · ст. откл. повторов среднего, z = 2,807 (уровень 0,0025). Повтор, где хоть одна среда даёт NaN, исключается целиком.
- **t по средам** — `ocdiv4.t_envs`: среднее / (ст. откл. по средам / √n), df = n − 1; порог — `scipy.stats.t.ppf(1 − 0,0025, n − 1)`.
- **Знак по средам** — интервал среды (точка ± z′ · ст. откл. повторов среды, z′ при 0,0025 / n) целиком > 0, < 0 или накрывает 0.

## 5. Правила (уровень 0,0025 на сторону)
- **Р1-Т (главное, «тысячи», 8 сред)** — Δ3c вне диапазона, две части, обе обязательны.
  - Часть А: нижняя граница M4 среднего восьми сред больше 0.
  - Часть Б: односторонний t по средам (df = 7) больше t(0,9975; 7).
  - «Подтверждено» — А и Б. «Опровергнуто» — верхняя граница M4 меньше 0 и t меньше −t(0,9975; 7). Только А — «в среднем этих сред (на новые среды не переносится)». Иначе — «не решено».
- **Р1-Л («длина», 3 среды)** — Δ3c вне диапазона, только часть А. Вывод — о трёх средах «длины».
- **Р2-Т — описательно:** решающая мощность по пилоту 0,104 < 0,2 (HYPOTHESIS §5; ERRORS № 202). Считается и печатается как в правиле, вердикта не даёт.
- **Первичный нуль Р1 — вопрос совету 72** (§8, п. 3): N3c или N0 со стратами c1. Константа `N3C_FIT` в `ocdiv4.py` задаётся по решению совета: True — N3c, False — N0c. Код считает обе меры.
- **Знак по средам** — у каждого правила: интервал среды при 0,0025 / n целиком > 0, < 0 или накрывает 0. Если есть среды и > 0, и < 0 — пометка «знак по средам разный».
- **Опыт определён по семейству**, если годны и невырождены не меньше 6 сред «тысяч» из 8 (для Р1-Т) и 2 сред «длины» из 3 (для Р1-Л). Невырождены по пилоту все 11 сред (оракул ≥ 0,1).
- **Чтение (заранее):**
  - Р1-Т подтверждено — на «тысячах» головы дают одно и то же неверное число на одной задаче чаще, чем по своим частотам, при той же картине «кто где ошибся» и том же узоре переносов, и это переносится на новые среды семейства;
  - только часть А — то же в этих восьми средах;
  - Р1-Л — то же в трёх средах «длины»;
  - причину совпадения не пишу без проверки.
  - «Установлено» — только после повтора с контролем на неспецифичность (CLAUDE.md). Р2 стал описательным, поэтому специфичность для сдвига этот опыт как правило не проверяет.

## 8. Что изменилось после пилота
1. **Положительный контроль, как записан в HYPOTHESIS §7, годность нуля не проверял** (ERRORS № 201).
   - Вброс заменял случайные неверные ответы и ломал естественные совпадения. K при δ = 0,02…0,1 падает, прирост Δ3c при δ ≤ 0,2 меньше нуля.
   - Новый вброс — ВБРОС-ПО-ЗАДАЧАМ — закреплён в `HYPOTHESIS-ADDENDUM.md` (d33c4c9b) до повторного разбора. Правило годности прежнее.
2. **Мощность двустороннего Р2-Т считалась в одну сторону** (ERRORS № 202). Исправлено: решающая мощность 0,104 < 0,2, Р2-Т описательный и так.
3. **Годность N3c по новому вбросу — «нет».** Прирост растёт монотонно и достигает +0,02 при δ ≈ 0,148. Часть А находит заложенный прирост в 0,998 наборов, часть Б — в 0,587: заложенный прирост от среды к среде разный (τ = 0,0122).
   - По букве гипотезы первичным становится N0 со стратами c1.
   - Рекомендация Claude — оставить N3c первичным. Положительный контроль проверяет чувствительность нуля, а её показывает часть А. Часть Б меряет разброс эффекта между средами; для настоящего эффекта он оценён на пилоте прямо (τ = 0,0068, мощность Р1-Т 0,998).
   - Запасной нуль N0c не сохраняет картину «кто где ошибся». Его мощность — в §3: у Т4 по N0 знак по средам пилота разный.
   - **Решение — совет 72.** Отступление от буквы гипотезы, если совет его примет, записывается здесь и в DEVIATIONS.
4. Константы PREREG в `ocdiv4.py`: `RULES_ACTIVE` = {Р1-Т: правило, Р1-Л: правило, Р2-Т: описательно}; `NONDEG` = все 11 сред; `N3C_FIT` — по решению совета.
