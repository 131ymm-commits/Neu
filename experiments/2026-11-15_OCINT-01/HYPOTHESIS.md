# OCINT-01 «ОЦЕНЩИК-ИНТЕРВАЛ» — гипотеза (15.11.2026, 15:23 UTC; до кода опыта и до любых его данных)

## Откуда вопрос
- **Слова автора:** «продолжи» (15.11.2026) — ответ на рекомендацию после OCSHIFT-01: сначала починить метод интервалов.
- **Главный вопрос Neu** — оценщик, который не обманывается под давлением отбора. Слова автора 15.10.2026: «оценка должна быть у самой оценки». Интервал — это оценка нашей оценки. Здесь спрашивается, обманывается ли он сам.
- **Что случилось в OCSHIFT-01** (совет 61, ERRORS № 166): у правила R2 точечная оценка −0,0819 легла вне всех трёх интервалов бутстрепа (BC, процентильного, обратного). Повторы бутстрепа с возвращением смещены относительно точки почти на три своих стандартных отклонения. Вывод пришлось опирать на нормальную границу и счёт сред.

## Что именно оценивается
- **Оцениваемая величина** — θ(n): математическое ожидание статистики при нашем размере выборки (в среде около 1000 задач ID для калибровки и 1200 задач OOD). Это свойство оценщика, каким он реально используется, а не предел при бесконечной калибровке.
- **Статистики** (как в OCSHIFT-01, код тот же):
  - S2 — T − C у CONF на ID с кросс-подгонкой (самообман от отбора без сдвига);
  - S3 — ИОИ(CONF) − ИОИ(LR-AGREE) вне диапазона;
  - S1 — ИОИ(ONE-BEST) − ИОИ(CONF) вне диапазона (одна голова против оценщика по уверенности);
  - S4 — ИОИ(POST-IN CONF) − ИОИ(CONF) и S5 — ИОИ(POST-IN CONF) − ИОИ(ONE-BEST): вторая калибровка после отбора (нужны следующему опыту).
- **Способы построить интервал** (для одной среды и для среднего по десяти средам):
  - с возвращением (как было): M1 процентильный, M2 BC, M3 обратный;
  - с центром в точечной оценке: M4 — точка ± z · ст. отклонение повторов бутстрепа; M5 — точка ± наибольшее из двух хвостовых отклонений центрированных повторов бутстрепа («огибающая»);
  - половинные выборки без возвращения (половина задач ID и половина задач OOD, копий нет): M6 — точка ± z · ст. отклонение; M7 — точка ± огибающая.

## Механизм (предположение, проверяется правилом А)
- Выборка бутстрепа с возвращением несёт веса-кратности. Для подгонки с весами действующий размер выборки — n / 2 (формула Киша: среднее квадрата кратности равно 2). У половинной выборки размер тоже n / 2.
- Если так, то сдвиг повторов бутстрепа — не странность копий, а эффект размера: статистика при калибровке на половине данных. Тогда повторы обоих способов смещены одинаково, а правильный интервал для θ(n) ставится вокруг точки, с разбросом от повторов.
- Следствие, которое можно проверить на готовых данных: по сдвигу при половинном размере видно, какая часть самообмана от отбора исчезает с ростом калибровочной выборки. По числам OCSHIFT-01 (сдвиг −0,0106 при точке −0,0819) — малая; это оценка в уме, проверяется описательно.

## Правила (уровень 0,0025 на сторону у каждого; серия из трёх — ложное «подтверждено» не выше 0,0075)
- **А (эффект размера; настоящие данные — 13 сред: десять сред OCSHIFT-01 и части test трёх прежних сдвигов).** Для S2 в каждой среде считается отношение r = сдвиг центра повторов бутстрепа / сдвиг центра половинных выборок (сдвиг — среднее повторов минус точка).
  - «Подтверждено» — знак сдвигов совпал во всех 13 средах и медиана r лежит в [0,67; 1,5].
  - «Опровергнуто» — медиана r вне [0,5; 2] или знаки разошлись хотя бы в четырёх средах. Иначе «не решено».
  - Числа здесь без случайной ошибки отбора сред: это свойство этих 13 сред. Ошибка Монте-Карло — в отчёт.
- **Б1 (интервалы с возвращением обманываются; миры с известной правдой).** Для среднего по десяти средам статистики S2 покрытие θ(n) процентильным интервалом M1 при номинале 0,90 ниже 0,5.
  - «Подтверждено» — верхняя граница односторонняя (уровень 0,0025, Клоппер — Пирсон) ниже 0,5. «Опровергнуто» — нижняя граница выше 0,8.
- **Б2 (интервал вокруг точки не обманывается; те же миры).** Покрытие интервалом M7 при номинале 0,90 в одной среде не ниже 0,85 — для каждой из S2, S3 и S1.
  - «Подтверждено» — у всех трёх нижняя граница (уровень 0,0025 / 3 на каждую) выше 0,85. «Опровергнуто» — у какой-то из трёх верхняя граница ниже 0,85.
- **Выбор способа для следующих предрегистраций** (правило решения, не гипотеза): годны способы с центром в точке (M4–M7), у которых покрытие в одной среде не ниже 0,88 и покрытие среднего по десяти средам не ниже 0,85 для всех пяти статистик (точечные оценки покрытия). Из годных берётся самый узкий; при равенстве — M7. Если годных нет — так и записать.

## Миры с известной правдой
- Параметрическая модель голов: общая трудность задачи (связанные ошибки голов), собственный шум головы, сигнал уверенности — зашумлённый запас правильности; вне диапазона способности падают, а сигнал уверенности получает прибавку (калибровка ломается); неверные ответы частью общие для голов.
- Десять миров с разными параметрами (тяжёлый режим, как в OCSHIFT-01: лучшая голова верна на ID в 0,3–0,55 задач). Параметры выбираются по зерну до прогона; миры пилота — с другим зерном.
- Правда θ(n) — среднее статистики по 2000 независимым выборкам мира того же размера, что среда теста. Это правда от кода.
- Покрытие меряется при номиналах 0,90 и 0,98, а не при 0,995: при 0,995 для оценки покрытия нужны десятки тысяч опытов. Это ограничение записывается в отчёт.

## Что описательно (вес 0)
- Зависимость статистик от размера калибровочной выборки на настоящих данных (доли 1/4, 1/2, 3/4) и оценка предела.
- Проверка ширины на настоящих данных: разброс статистики между четырьмя непересекающимися четвертями среды против разброса, предсказанного каждым способом внутри четверти.
- Таблица устойчивости: вердикты зарегистрированных правил линии «оценщик» (OCCOR-01, OCMIX-01, OCREP-01, OCSHIFT-01), пересчитанные выбранным способом на уровне 0,0025. Статусы в реестре это не меняет; решает совет.

## Чего опыт не даёт
- Миры — модель, а не настоящие головы. Опора на настоящие данные — правило А и проверка ширины на четвертях.
- Хвосты на уровне 0,0025 прямо не проверяются.
- OCGEO-01 в таблицу устойчивости не входит: там другой оценщик и другие данные.
