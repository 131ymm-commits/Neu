# LEVEL-01 — ворота 1: гипотезы до поиска (26.09.2026)
Просьба человека: «Создай новый уровень из агентов. У тебя же есть система по созданию уровней». Рамка — архив, EMERG-01. Уровень — свойство пары «динамика + описание»: медленная переменная описания, которой нет у членов по отдельности. Ингредиенты: необратимость, огрубляющее описание, выравнивание. Сорт — по времени жизни.

Перенос на головы Claude:
- микро-уровень — ответы отдельных голов по раундам;
- описание — огрубление «мнение группы» (медиана в логарифмах и доля голов в главном кластере);
- динамика — головы в кольце видят прошлые ответы двух соседей и обновляются; это необратимо и диссипативно (разнообразие схлопывается).

Разнообразие на старте даёт смесь моделей: два ответа по умолчанию, два Sonnet, два Haiku. В DIV-01 они давали разные ответы (П2).

Гипотезы (разведка, без вердикта):
- **H1. Рождение.** Со связью разнообразие схлопывается: D к последнему раунду меньше 0,2 от D₀. Без связи (контроль: те же головы переотвечают в изоляции) — нет.
- **H2. Макро медленнее микро.** Среднее |Δ log медианы группы| за раунд меньше среднего |Δ log ответа головы|. Это грубый прокси «отделённой медленной моды» архива. Строгий критерий архива (λ₂ описания вне спектра) требует длинных траекторий и здесь недоступен.
- **H3. Уровень не равен лучшему члену.** Итоговое мнение группы не совпадает с исходным ответом ни одной головы. Кто победил в консенсусе — не обязательно самый точный (Lorenz 2011, по памяти).
- **H4. Сорт.** Удар: в раунде T+1 одна голова получает ложную «подсказку соседа» с ответом ×3. Структурный уровень возвращается к своему значению за 1–2 раунда; транзиентный уходит за ударом.

Точность по правде от кода считается отдельно: уровень может родиться и ошибаться.
