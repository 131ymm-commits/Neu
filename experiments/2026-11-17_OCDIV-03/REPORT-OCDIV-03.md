## Для главного вопроса

- **При перестановочном нуле N0 (частоты ошибок голов сохранены) ложное большинство F₀ уже 0,4919–0,9393; в T_X49_p3 F₀ > F** (совет 71, Н5). Наблюдаемое F — 0,5613–0,8769: какой-нибудь неверный ответ набирает не меньше голосов, чем верный. Сверх нуля — в среднем этих пяти сред +0,0250 (П1). Избыток над N0 трудностью, видимой во входе, не объясняется (П2 с чтением Н1); трудность, которую признаки входа (c1, n9, u, v) не видят, нуль Nd не исключает.
- **Что сохраняют нули (проверено по коду):** счёт идёт по смещениям «ответ − правда» (`ocdiv2.dmat`), N0 и Nd переставляют смещения головы между задачами (`ocdiv2.permute_cols`). Общая для голов систематическая ошибка с одним и тем же смещением на всех задачах в нуле уже учтена. Т4 ≠ 0 значит, что смещения голов (и нулевые, то есть верные ответы, и неверные) разложены по задачам согласованнее или рассогласованнее, чем при перестановке; какая часть — от совпадения неверных смещений, показывает разложение ниже.
- **Где сидит избыток (описательно, разложение по N3; M4 при 0,005):** трудность по входу −0,0031 [−0,0095; +0,0033]; совместность ошибок сверх неё −0,0030 [−0,0089; +0,0029]; совпадение самих неверных ответов +0,0309 [+0,0239; +0,0379]. N3 сохраняет, на каких задачах ошибается каждая голова, и переставляет её неверные смещения внутри страты Nd8, а не по всей среде; «совпадение неверных ответов» — избыток над совпадением внутри страты (совет 71, Н6). Разложение последовательное: вклады зависят от порядка нулей N0 → Nd8 → N3. В среднем избыток даёт совпадение неверных смещений на одной задаче. «Совместность ошибок» по средам разного знака: T_X19 +0,0110, T_X29 −0,0056, T_X39 +0,0124, T_X49 −0,0163, T_X59 −0,0163. «Совпадение ответов» больше нуля в 4 средах из 5 (T_X49_p3 — −0,0021). Механизм совпадения — объяснение не проверялось.
- **Не свойство сдвига:** на ID ложное большинство редко (F до 0,0794), но тоже чаще нуля N0 (Т4-ID +0,0477). N0 трудность задач не сохраняет, поэтому на ID вклад трудности от совпадения ответов не отделён. Точка Т4-ID может быть смещена отбором толпы по ID (PREREG §4, Н5) — довод, не проверено.
- **Т4 из формул ступени 1 DISTILL-01** (условная независимость, неверные ответы без совпадений) до прогона попала в X19, X29 и X39 с ошибкой −0,0098, −0,0046, +0,0115, а в X49 и X59 ошиблась по знаку (−0,0941, −0,0395). Там же отрицателен член трудности. Совпадение с ERRORS № 197 (при совпадающих неверных ответах G другого вида) — довод, не проверено.
