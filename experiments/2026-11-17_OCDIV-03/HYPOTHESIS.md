## 4. Меры и нули
- **Толпа среды и голоса** — как в OCDIV-02, тем же кодом: проверка метода `ocdiv2.prepare_id` (только по ID), смещения `ocdiv2.dmat`, ложное большинство `ocdiv2.false_major`.
  - F — доля задач вне диапазона, где какой-нибудь неверный числовой ответ набрал не меньше голосов, чем верный. Ответ без числа — не голос.
- **N0 — нуль OCDIV-02**, `ocdiv2.permute_cols` без страт: внутри каждой головы ответы переставляются между задачами вне диапазона среды.
  - Т4 = F − F₀(N0) с теми же зёрнами и тем же порядком счёта, что в `ocdiv2.env_analysis`. Совпадение до бита проверяет тест кода.
- **Nd — нуль с трудностью** (совет 69: формалист «нужно», скептик, инженер). `permute_cols` внутри страт.
  - **Страты — по предсказанной трудности задачи d̂(j).** Это средняя по толпе среды вероятность ошибки p̂_h(j) = σ(w_h · x(j)).
  - **x(j) — только признаки входа**, без ответов голов:
    - c1 — перенос из разряда единиц;
    - n9 — число девяток в двух младших цифрах a;
    - u и v — цифры десятков и единиц суммы, каждая one-hot по 10 значениям.
  - **w_h** — гребневая логистическая регрессия ошибки головы h (λ = 1, свободный член без штрафа). Обучение — на задачах вне диапазона пилота 2 «тысяч», все пять сред (p = 1; места с 400; в тест не входят).
  - Метки теста в нуль не входят.
  - **S = 8 страт** — правило. Задачи вне диапазона среды упорядочены по (d̂, номер задачи) и разбиты на S равных подряд идущих групп. Страта — по входу, ответы не читаются.
  - Т4ᵈ = F − F₀(Nd).
  - Страты по точности голов на ID (вопрос совета 69) не берутся: перестановка внутри головы и так сохраняет точность головы, а страты — свойство задач.
- **Т4-ID** (совет 69: интуит, скептик): та же F − F₀(N0) на задачах ID среды, те же головы и тот же код.
- **Бутстреп и интервал** — как в OCDIV-02.
  - Строки задач — с возвращением, B = 10 000. На каждый повтор — 10 перестановок нуля, на точку — 1000. Страта строки идёт вместе со строкой.
  - Среднее по годным средам с равными весами; M4 — точка ± z·ст. откл. повторов среднего.
- **Зёрна.** N0 — зёрна OCDIV-02, `SEED_NULL_TEST` и `SEED_NULL_BOOT_TEST` плюс смещение среды. Смещение = 100·(номер семейства) + 10·(номер X) + p; у «тысяч» номер семейства 0, и с зёрнами теста OCDIV-02 они не пересекаются.
  - Nd, Т4-ID и описательные нули — новые зёрна, по своему потоку на нуль. Зёрна записываются в PREREG.

## 5. Правила (уровень 0,0025 на сторону; вид «pos»)
- **П1 (повтор C-105):** Т4.
- **П2 (главное):** Т4ᵈ при S = 8.
- **П3 (контроль):** Т4-ID — правило, если его мощность «подтверждено» по пилоту 2 не меньше 0,2. Иначе — описательно, как Т2 в OCDIV-02. Решение — по этому порогу в PREREG.
- **Вердикт правила:** «подтверждено» — нижняя граница M4 среднего пяти сред больше 0; «опровергнуто» — верхняя меньше 0.
- **Предохранитель по интервалу** (совет 69, скептик). Вердикт держится, только если M4 при 0,0025 даёт тот же вердикт и в каждой из пяти выборок «без одной среды» (среднее четырёх). Иначе — «не решено (предохранитель)».
- **Пометка «общий»** (совет 69, формалист) — только после «подтверждено».
  - Интервал хотя бы двух сред, невырожденных по пилоту 2 (все пять), целиком больше 0.
  - Интервал среды — точка ± z′·ст. откл. повторов среды, z′ — при 0,0025 / 5 (поправка на число сред).
  - Иначе — пометка «сосредоточенный».
- **Опыт определён**, если годны не меньше 4 сред из 5. Среда годна, если проверку метода проходят не меньше 6 голов, как в OCDIV-02.
- **Мощность** каждого правила и каждого условия (предохранитель, пометка «общий») — по разбору пилота 2 до PREREG. Модель «новая среда», как в OCDIV-02. Для Т4ᵈ на пилоте — с кросс-подгонкой: w_h для среды пилота учатся на четырёх других средах.
- **Множественность:** не больше трёх правил по 0,0025. Ложное «подтверждено» серии — не больше 0,0075; с ложным «опровергнуто» — не больше 0,015.

## 6. Чтение исходов (заранее)
- **П1 и П2 подтверждены.** Ложное большинство превышает то, что даёт трудность, видимая во входе (в пределах восьми страт). Согласие голов вне диапазона обманывает и после такой поправки.
- **П1 подтверждено, П2 нет.** Эффект в пределах точности опыта объясним трудностью по входу. Для оценщика: поправка на трудность по входу — кандидат на средство.
- **П1 не подтверждено.** C-105 на «тысячах» не повторился: область C-105 в реестре сужается до «длины».
- **П3 подтверждено.** Эффект не специфичен для сдвига: это свойство толпы на сложении. В реестре C-105 формулировка «на сдвиге» меняется.
- Причину эффекта пишу, только если она проверена. Разложение §7 — описательно.

## 7. Описательно (вес 0; M4 при 0,005, где есть интервал)
- Т4ᵈ при S = 2, 4 и 16. Т4 со стратами по числу переносов (как в OCDIV-02). Т4 со стратами-клетками «c1 × u» (20 клеток).
- **Разложение Т4** (вопрос DISTILL-01: совпадение ответов или трудность, которой признаки не видят). Нуль N3: внутри головы неверные числовые ответы переставляются между её же задачами с неверным числовым ответом, внутри страты Nd (S = 8). Картина «кто где ошибся» сохраняется.
  - Т4 = [F₀(Nd) − F₀(N0)] + [F₀(N3) − F₀(Nd)] + [F − F₀(N3)]:
    - трудность по входу;
    - совместность ошибок сверх неё;
    - совпадение самих неверных ответов.
  - N3 опирается на картину ошибок теста, поэтому только описательно.
- **Т4 из формул**, ступень 1 DISTILL-01. Те же w_h; условная независимость и неверные ответы без совпадений (`distill.false_major_indep`).
  - Считается по задачам теста и толпе пилота до прогона, число — в PREREG.
  - В отчёте — сравнение с Т4 и с Т4 − Т4ᵈ.
- **Гомоплазия** H − H₀, как в OCDIV-02.
- **ПАРЫ-ПРОИЗВОДИТЕЛЕЙ** (совет 69, интуит).
  - Для пары голов r_ij — доля задач вне диапазона, где обе ошиблись одним и тем же ответом, минус то же при N0. Нуль сохраняет точность и ответы каждой головы, так что точность учтена.
  - Контраст — среднее r по парам одного производителя минус среднее по парам разных; среднее по средам.
  - Нуль контраста — полный перебор 105 способов выбрать две непересекающиеся пары «одного производителя» среди семи голов, то есть точное p. Наименьшее p = 1/105, поэтому только описательно.
- **ДЕТЕРМИНИЗМ-НА-3** (совет 69, инженер).
  - Три задания из 35 выбираются зерном 8 990 000 (`numpy.random.default_rng(...).choice(35, 3, replace=False)` по упорядоченному списку). Повторяются под другими именами.
  - Совпадение ответов и logp — `ocdiv2.repeat_check`.
- **Прибор** (ЗАЩИТА-ANSWER_LOGP). `trunc_check.py` OCDIV-02 на выводе теста; печатаются только счета, без точности.
  - Если есть ответы с n_tok больше числа цифр + 1, П1 и П2 пересчитываются описательно, с такими ответами как «без числа». Вердикт — по основному счёту.
