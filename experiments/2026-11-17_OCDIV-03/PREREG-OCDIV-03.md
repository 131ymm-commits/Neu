## 4. Статистики
- **F** — доля задач вне диапазона, где какой-нибудь неверный числовой ответ набрал не меньше голосов, чем верный.
  - Голоса — головы толпы; ответ без числа — не голос.
  - Толпа среды — головы, прошедшие проверку метода `ocdiv2.prepare_id` (только по ID). Среда годна при не меньше 6 головах.
- **Т4 (П1)** = F − F₀(N0); N0 — перестановка ответов внутри головы между задачами вне диапазона среды.
  - Код и зёрна — OCDIV-02: точка — 1000 перестановок, зерно 8 420 000 + смещение.
  - Повторы — 10 000, по 10 перестановок, зерно 8 470 000 + смещение. Смещение = 10·(номер X) + 3.
- **Т4ᵈ (П2)** = F − F₀(Nd); Nd — та же перестановка внутри 8 страт по d̂(j). Зёрна 8 800 000 и 8 810 000 + смещение.
  - d̂(j) — среднее по толпе среды σ(w_h · x(j)). x(j) = (c1, n9, u, v) — только вход. w_h — на задачах вне диапазона пилота 2 (все пять сред), λ = 1.
  - Страты — порядок (d̂, номер задачи), 8 равных подряд идущих групп.
- **Т4-ID (П3)** = F − F₀(N0) на задачах ID. Зёрна 8 820 000 и 8 830 000 + смещение.
- **Описательные нули и разложение** — общий поток повторов (зёрна 8 840 000 и 8 850 000 + смещение), B = 2000.
- **Пары** — r_ij при 200 перестановках N0 (зерно 8 860 000 + смещение); контраст — точный перебор 105 структур.
- **Бутстреп** — строки задач с возвращением, B = 10 000; страта строки идёт со строкой.
- **Интервал M4** — точка ± z·ст. откл. повторов среднего, z = 2,807 (уровень 0,0025). Повтор, где хоть одна среда даёт NaN, исключается целиком.
- **Оцениваемая величина** — среднее по годным средам с равными весами; вывод — о пяти средах теста.
- **d̂ в повторах бутстрепа не пересчитывается** (совет 70, Н7): страты считаются один раз по всем задачам среды и идут вместе со строками.
- **Отбор толпы и Т4-ID** (совет 70, Н5; тело `S.prepare`, `analyze_ocshift.py`, стр. 104–126, и `ocdiv2.prepare_id`):
  - толпа отбирается только по предельным величинам каждой головы: число верных и неверных на ID (не меньше порога `MIN_EACH` в масштабе теста) и доля «без числа» на ID (не больше 0,05);
  - доля «без числа» по всем задачам считается, но порог для неё снят (`MAX_NONE = 1,0` внутри `prepare_id`);
  - подвыборки ID нет; `seed_cv` задаёт только части кросс-подгонки, в Т4 они не входят;

## 5. Правила (уровень 0,0025 на сторону)
- **П1** — Т4; **П2** — Т4ᵈ (S = 8); **П3** — Т4-ID: **правило** (мощность «подтверждено» по пилоту — 1,000 ≥ 0,2; §6).
- «Подтверждено» — нижняя граница M4 среднего больше 0; «опровергнуто» — верхняя меньше 0.
- **Предохранитель по интервалу** (совет 69): тот же вердикт M4 при 0,0025 в каждой из пяти выборок «без одной среды» (среднее четырёх). Иначе — «не решено (предохранитель)».
- **Пометка «общий»** — после «подтверждено». Интервал среды (точка ± 3,29·ст. откл. повторов среды; уровень 0,0025 / 5) целиком больше 0 хотя бы в 2 средах. Иначе — «сосредоточенный». Невырождены по пилоту 2 все пять сред.
- **Опыт определён**, если годны не меньше 4 сред из 5.
- Знаки: Т4 > 0 — ложное большинство чаще, чем при нуле.
- **Н1 — условие чтения П2** (совет 70; вердикт П2 не меняет):
  - **шаг 0, без правды:** страта d̂ «пустая», если каждое её значение d̂ есть и в соседней страте. Пустых страт в среде больше 2 из 8 — в этой среде чтение «страты пусты», шаг 1 там не засчитывается. Считается по каждой среде;
  - **шаг 1, по правде теста:** разность ошибки большинства толпы между верхней и нижней стратой d̂ по задачам теста. Ошибка большинства на задаче — ложное большинство (`ocdiv2.false_major`). M4 при 0,0025 — бутстреп задач внутри каждой из двух страт, B = 10 000;
  - чтение П2 «сверх трудности, видимой во входе» — если нижняя граница больше 0 хотя бы в 4 годных средах (годные — §4: не меньше 6 голов после `prepare_id`, без правды). При n_годных < 4 — «П2 неинформативно»;
  - не прошло — вердикт П2 остаётся, чтение: «П2 неинформативно: страты d̂ на тесте не различили трудность (перенос моделей p = 1 → p = 3 не подтверждён)»;
  - правда теста определяет только чтение, на вердикт П2 не влияет. Порог записан до прогона.
- **Чтение** — по HYPOTHESIS §6:
  - П1 и П2 подтверждены, Н1 пройдено — ложное большинство сверх трудности, видимой во входе;
  - П3 подтверждено — эффект не специфичен для сдвига.
- **Н3, описательно, задано заранее** (M4 при 0,005):
  - Т4 − Т4ᵈ по средам — та часть Т4, которую даёт трудность, видимая во входе;

- **Ожидания** (`expect_ocdiv3.json`, `tools/self_calibration.py`): вероятность = 0,95 × мощность (HYPOTHESIS §7а). E4 и E5 — по ветви Н2 (§3): если пилот не проходит Н1 — 0,5 каждое.

## 7. Множественность
- Три правила по 0,0025: ложное «подтверждено» серии — не больше 0,0075; с ложным «опровергнуто» — не больше 0,015.
- Уровень номинальный: перенос M4 на уровень 0,0025 для среднего пяти сред не проверен (как в OCDIV-01 и OCDIV-02).
