## 1. Программа головы (HYPOTHESIS, 394b7be2) и что уточнено до регистрации
- **Ответ программы:** a + b − Σ_j 10^j · D_j по разрядам j, куда есть перенос. P(D_j = 1) = σ(w · x_j), не больше 3 признаков, жадно по BIC.
  - Кандидаты в признаки: pos (разряд), top (старший перенос), newplace (перенос в новый разряд), prop (перенос протянут, а не порождён), chain (длина цепочки), c1, nines, ood, phi = Φ_j − 1 (запас переноса по Wen и др.).
  - Коэффициенты — две значащие цифры, проверка — по округлённым.
- **«Прочие» ошибки** (не потеря переноса) — доля ε головы.
  - Их смещения взяты по частотам головы на построении, как у B1; остаток — равномерно по справочному множеству V.
  - Уточнение после ERRORS № 209 сделано на заглушках, до пилотов и данных.
- **Смесь λ (совет 74, п. 1).** Вероятность ответа у каждого соперника — (1 − λ)·p + λ/|V|.
  - λ = 1e-3, одна для всех соперников, фаз и сред. Выбрана по суждению, без пилотных исходов. Записана в код коммитом 3e12bfd2 до пересчёта пилотов.
  - **|V|** — справочное множество задачи: целые с числом цифр от n − 2 до n + 1, где n — цифр в верной сумме; |V| = 10^(n+1) − 10^max(n − 3, 0). Для суммы из 4 цифр |V| = 99990.
  - Числовой ответ с p = 0 (в том числе вне V) даёт log(λ/|V|).
  - Прежняя обрезка на 1e-300 давала одной задаче вклад до −690,78 нат (ERRORS № 211).
- **Соперники:**
  - B1 — частоты смещений головы без учёта входа, 30 самых частых;
  - Φ-база — та же программа с одним признаком phi и той же «прочей» частью (тест на заглушке: программа = Φ-база → m1_phi = 0);
  - ящик — бустинг деревьев глубины 3 на признаках задачи; предсказывает класс исхода (верно / набор потерянных переносов / прочее);
  - B0 — «верно с частотой головы, иначе любое число из V» (только описательно).
- **Строится** по семейству («тысячи», «длина») на всех собранных ответах (§2), для каждой из семи голов.

## 4. Меры (код — `distill02.py`, часть 2)
- **m1** — среднее по головам разности лог-вероятностей ответа головы «программа − B1» на числовой ответ (со смесью λ).
- **m1_phi** — то же, «программа − Φ-база».
- **m2 (решающая, совет 74, п. 4)** — доля объяснимого против одного ящика: Σ_h(программа − B1) / Σ_h(ящик − B1).
  - Не определена, если ящик не лучше B1.
  - Может быть больше 1: программа лучше ящика.
- **m2_max** — прежняя мера: от лучшего из ящика и программы. Описательно; смещена вверх, потому что знаменатель подтягивается к программе.
- **m3** — ln(K наблюдённое / K из программ):
  - K — среднее по парам голов доли одинаковых смещений среди задач, где обе дали неверное числовое смещение;
  - K из программ — среднее по R = 20 выборкам, где каждая голова отвечает по своей программе независимо при данном входе. «Без числа» — на тех же местах, что у голов.
- **Разбивка m3 (описательно, совет 74, п. 5):** K = Kc + Ko.
  - Kc — доля одинаковых смещений «потеря переноса» (−Σ 10^j по разрядам с переносом), Ko — «прочих».
  - m3_c = ln(Kc / Kc из программ), m3_o = ln(Ko / Ko из программ).
- **Бутстреп:** строки задач с возвращением, B = 4000; одни строки для всех мер среды.

- **Хрупкость (совет 74, п. 1).**
  - Вклад задачи i среды e: c_{e,i} = (1/H_e) Σ_h Δ_{e,i,h} / n_{e,h}; Σ_i c_{e,i} — точка меры среды.
  - Правило помечается «хрупкий», если по всем средам правила max |c| > 0,5 · |Σ c|.
  - Δ: для m1 — программа − B1; для m1_phi — программа − Φ-база; для m2 — отдельно числитель (программа − B1) и знаменатель (ящик − B1), «хрупкий» — если хоть один.
  - По каждой среде и «доля задач, на которые приходится больше половины суммы» — описательно.
  - Пометка стоит рядом с вердиктом и его не меняет.
- **Чувствительность к λ** — описательно: m1, m1_phi, m2 при λ = 0 (прежняя обрезка), 1e-4 и 1e-2. В точке, без бутстрепа; стоит рядом с вердиктом и его не меняет (скептик (б)).
- **M4** — точка среднего сред ± z · ст. откл. повторов среднего (`ocdiv4.mean_entry`), z = 2,807 (0,0025).
- **t по средам** — `ocdiv4.t_envs`.
- **Знак по средам** — `ocdiv4.env_signs` при 0,0025 / n.
