## Критерий истины (главная мера всех трёх проверок)
Человек: «Выработай критерий истины. Интегрированного показателя. Как и ошибки, которая должна падать. Он должен быть считаем».

**Интегральная ошибка истины (ИОИ)** — `truth.py`:
- для каждого поколения берётся особь, лучшая по оценщику;
- T — её доля верных ответов на 1000 скрытых входах, C — что заявил оценщик;
- **ИОИ = среднее по поколениям от (1 − T) + max(0, C − T)**, шкала 0…2, меньше — лучше;
- составляющие: «незнание» (1 − T) и «самообман» (оценщик обещает больше правды — Гудхарт); среднее по поколениям учитывает скорость.

Пересчёт для EVO-01/02 сделан после факта и только описательно (`../truth_retro_EVO01_02.log`): критерий отделяет самообман зеркального и «острого» оценщика (до 0,6) от случайных тестов (0,01–0,1).

## A. Зеркальный оценщик с притоком новизны
- Задачи T1–T3 (из EVO-01).
- Ветви MIRROR_0, MIRROR_25, MIRROR_50, MIRROR_100: зеркальный зоопарк 16 тестов; каждое поколение 8 наименее спорных заменяются мутантами (±5) самых спорных, из них доля f заменяется свежими случайными.
- Ветвь BASE — 16 свежих случайных тестов, как RANDOM16.
- **PA1:** MIRROR_50 имеет ИОИ меньше, чем MIRROR_0.
- **PA2:** MIRROR_100 имеет ИОИ меньше, чем MIRROR_0.
- Разведочно: монотонность по f; лучшая MIRROR против BASE.

## B. Две головы: «профдеформация» против структуры задачи
- Структурные задачи («две профессии»):
  - T2: x > 0 ? x mod 7 : −x;
  - T4: x < 0 ? x² + 1 : x mod 6;
  - T5: x < 10 ? 3x − 2 : ⌊x/4⌋.
- Неструктурные:
  - T1: x² − 3x + 7;
  - T3: 2⌊x/3⌋ + x mod 5;
  - T6: x³ − x.
- Ветви BASE и TWO — из EVO-02 без изменений.
- **PB1:** на структурных задачах у TWO ИОИ меньше, чем у BASE.
- **PB2:** на неструктурных задачах TWO не лучше BASE: побед TWO ≤ 30 из 60 — подтверждено; ≥ 40 — опровергнуто; 31–39 — разницы нет.

## C. Размножение и смерть, версия 2
- Задачи T1–T3; LIFE2 против BASE.
- Устройство LIFE2:
  - энергия += доля верных − средняя по популяции;
  - у каждой особи своя продолжительность жизни (геометрическая, в среднем 20);
  - смерть по возрасту или при энергии < −0,5;
  - освободившиеся места заполняют потомки, родители — пропорционально энергии;
  - численность постоянна, 300.
- Пилот на сиде 999 (в тест не входит):
  - версия 1 обваливала численность до 50–90 к 30-му поколению из-за одновременного старения;
  - версия 2 держит 300, смертей 8–49 за поколение;
  - замещается около 5 % особей в поколение, а в BASE — 100 %. Отбор мягче, это свойство ветви.
- **PC (двусторонне):** LIFE2 лучше BASE в ≥ 40 из 60 — «помогает»; BASE лучше в ≥ 40 — «вредит»; иначе «разницы нет». Ожидание: вредит (отбор мягче).

## Общие правила
- Сиды 20–39 × 3 задачи = 60 пар на проверку.
- ≥ 40 из 60 — подтверждено, ложный уровень 0,007; ≤ 30 — опровергнуто; 31–39 — разницы нет. Для PB2 и PC правила записаны отдельно выше.
- Ничья по ИОИ не считается победой.
