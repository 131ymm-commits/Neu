## 0. Что эта сверка проверяет и чего не проверяет
Черновик называл её проверкой модели М3. Два независимых критика показали, что это неверно (`docs/2026-11-27_deferred_selection_critique/c2_lenses.md`, `c2_math.md`), и я проверил их доводы кодом:
- М3 описывает установившийся уровень обмана; рост завышения во времени из неё не выводится;
- зеркальный набор тестов EVO-03 устроен иначе, чем «постоянный показатель плюс экзамен»: в наборе остаются самые спорные тесты, а не выученные; у свежих тестов есть своё проклятие победителя;
- порог М3 выведен для отбора по величине оценки, а в мире EVO отбор турнирный.

Поэтому сверка проверяет **не формулы М3**, а два общих ожидания рамки: свежая проверка снижает завышение заявки; на постоянных тестах оно копится. Она также показывает, на что похож спад с дозой — на разбавление с полом или на отклик поведения. Подтверждения не дают веса модели М3.

Главному вопросу программы сверка отвечает так: сколько свежей правды нужно оценщику, чтобы отбор его не обманывал.

## 2. Данные и меры
- EVO-03 `runs/`: MIRROR_0, _25, _50, _100 — задачи T1–T3 × 20 сидов (20–39).
- EVO-01 `runs/`: FIXED16, RANDOM16 — T1–T3 × 20 сидов (0–19).
- EVO-06 `runs/`: FIXED32, SAME16, SAME32 — T1–T6 × 20 сидов (80–99).
- Скрипт проверяет число прогонов (3 × 20 и 6 × 20), длину `hist` = 151, поколения подряд и отсутствие NaN; при нарушении останавливается.
- Из прогона берутся только `hist[g].claimed` (C) и `hist[g].true` (T), g = 0…150.
- Окна, как в EVO-06 §7.5: раннее — поколения 11–40, позднее — 121–150.
- **Позднее завышение** W = средняя (C − T) в позднем окне.
- **Доза** q — доля свежих случайных тестов в наборе: из 16 тестов за поколение меняются 8, каждый из них свежий с вероятностью f; q = f/2 = 0; 0,125; 0,25; 0,5. Допущение: мутанты «±5» считаются несвежими. Оно не проверено: мутант — тоже новый вход.
- **Наклон** — наклон прямой наименьших квадратов W по q через четыре дозы, для каждой пары (задача, сид).
- **Рост завышения** d = W минус средняя (C − T) в раннем окне.

## 3. Предсказания с вердиктом
Задачи ведут себя по-разному (пилот, §5), поэтому предсказания заданы по задачам. Единица проверки — сид: внутри одной задачи 20 сидов независимы; в проверке C берётся среднее по трём задачам внутри сида, потому что задачи одного сида делят скрытые входы.

| № | Предсказание | Данные | Вероятность «подтверждено» (моя) |
|---|---|---|---|
| A | на T2 четверть свежих тестов снижает завышение: W(MIRROR_0) − W(MIRROR_25) > 0 | EVO-03, T2, 20 сидов | 0,80 |
| B | на T3 завышение убывает с дозой: наклон < 0 | EVO-03, T3, 20 сидов | 0,60 |
| C | по трём задачам вместе наклон < 0 | EVO-03, T1–T3, 20 сидов (среднее по задачам) | 0,70 |

- **Проверка.** Перестановка знаков на 20 значениях по сидам, статистика — среднее; p считается полным перебором 2²⁰ раскладов знаков, то есть точно. Уровень 0,005 на каждую сторону.
- **Исходы.** «Подтверждено» — p в предсказанную сторону ≤ 0,005. «Обратный эффект» — p в обратную сторону ≤ 0,005. Иначе «не решено». Если значений меньше 8 или все нулевые — «n мало».
- **Ложный уровень серии** из трёх: подтверждений — не больше 0,015; любого направленного вердикта — не больше 0,03. A, B и C считаются на одних прогонах и зависимы; оценка сверху это учитывает.
- **Мощность** (оценка Монте-Карло, `power.py` → `power.json`; сценарии — по пилоту из трёх сидов, оценка грубая):

  | Проверка | Сценарий «как в пилоте» | Мощность | Сценарий «вдвое слабее» | Мощность |
  |---|---|---|---|---|
  | A | эффект в 70 % сидов | 0,91 | эффект в 50 % сидов | 0,61 |
  | B | средний наклон −0,256 при разбросе 0,33 | 0,70 | −0,128 | 0,16 |
  | C | −0,27 при разбросе 0,30 | 0,86 | −0,135 | 0,23 |
- **Величина эффекта** — среднее по сидам с бутстреп-интервалом 95 % (Монте-Карло, 4000 повторов, сиды пересэмплируются целиком, генератор с зерном 0).
- **Что пойдёт в реестр.** Три утверждения о мире EVO-03, по одному на проверку. Модели М3 вес не начисляется.
- **Вес опоры** (правило CLAUDE.md): «подтверждено» — log₂(мощность по сценарию пилота / 0,005): A — 7,5 бита, B — 7,1, C — 7,4. «Не решено» — log₂((1 − мощность)/(1 − 0,005)): A — −3,4, B — −1,7, C — −2,8. «Обратный эффект» — зеркально подтверждению, со знаком минус. Каждое из трёх утверждений получает свой вес. Но A, B и C считаются на одних прогонах: если их когда-нибудь складывать как опоры одного более общего утверждения, это одна группа, и берётся наибольший по модулю вес.

## 6. Как читать исход
- **A «подтверждено»** → на T2 четверть свежих тестов убирает завышение. Пилот подсказывает, что это происходит через решение задачи; в отчёте дать долю решённых прогонов по дозам. Причина сверх этого — «объяснение не проверялось».
- **B «подтверждено»** → на задаче, которая не решается, завышение убывает с дозой. B1 описывает форму спада и о механизме не говорит.
- **C** → общий знак по трём задачам; читать вместе с разбивкой по задачам. Если знаки по задачам расходятся (ожидаю этого для T1), так и записать: общего закона дозы нет, есть разные режимы.
- **«Не решено»** → мощности не хватило; вывода нет.
- **«Обратный эффект»** → ожидание рамки для этой задачи неверно.
- Ни один исход не подтверждает и не опровергает формулы М3: для них нужен мир, где доля экзамена, выгода обмана и жёсткость заданы (опыт «Детство» из описи; только по слову автора).
