# LEVEL-05 — искусственный новый уровень для LLM: организации из 5, 10 и 20 голов на задаче новой сложности (замысел, 28.09.2026)

**Слова человека:** «Возьми проект Neu. Создай искусственно новый уровень в агентской среде для LLM. Возьми 5, 10, 20 и создай новую сложность». Модель голов — claude-opus-5-5 (как в LEVEL-04).

## Что значит «новый уровень» здесь
По системе появления уровней Neu (архив, «Грамматика переходов», SYNTH-06) уровень — пара (оператор, описание): у целого есть свойство, которого нет у частей, и целое описывается своими макропеременными короче, чем через части; признаки — сертификаты (повторяемость ≈ 10 оборотов, зазор t1/t2, стационарность). LEVEL-04 дал ландшафт на **последовательной** задаче (цепочка x → x² + c mod p, L = 200): одиночка отказывается, звенья по 40 без проверки ошибаются, проверка соседом и дублирование поднимают до 2/3–3/3.

## Новая сложность
Задача, которую одна голова в принципе не проходит (горизонт ≈ 10 шагов арифметики по модулю без ошибки), а организация из N голов — может, и где **структура** задачи требует не только цепочки, но и сборки:
- **Семейство M(N): произведение M = 10·N матриц 2×2 по модулю простого p** (p ≈ 10⁹, матрицы из зерна; правда — код). Ассоциативность позволяет дерево: N листьев по 10 матриц (на пределе одной головы), затем сборка ⌈log₂ N⌉ ярусов. При N = 5, 10, 20 — M = 50, 100, 200 матриц; ярусов 3, 4, 5.
- Сложность растёт по двум осям сразу: объём (M) и глубина сборки (ярусы), а ошибка на любом листе или стыке портит итог — нужна проверка.
- Контроли: одиночка на всей задаче M; одиночка на одном листе (калибровка ε); цепочка вместо дерева (та же работа, глубина N вместо log N).

## Организации (генотипы, как в LEVEL-04)
Размер N ∈ {5, 10, 20}; проверка v ∈ {0, 1} (сосед пересчитывает выход листа/узла, при расхождении — третий); дублирование r ∈ {1, 2}; топология — дерево или цепочка. Отбор in silico по ландшафту, как в фазе 3 LEVEL-04.

## Что мерим и что будет «новым уровнем»
- Точность на задаче M(N) по коду; вызовы; ε на операцию.
- **Сертификат уровня (предзаявлено):** (1) организация проходит M(N), где одиночка — нет (разрыв ≥ 0,5 по точности); (2) точность организации описывается макромоделью «ε листа × структура проверки» без знания отдельных голов (предсказание из фазы калибровки попадает в ИД наблюдаемого); (3) повторяемость на новых зёрнах.
- Предсказание «масштаба»: при фиксированной ε точность дерева без проверки падает как (1 − ε)^(10N + ярусы·…), с проверкой — почти не падает; переход «уровень есть / нет» — между 10 и 20 без проверки.

## Цена (прикидка)
Лист — 1 вызов (10 умножений 2×2), узел сборки — 1 вызов; дерево без проверки ≈ 2N вызовов, с проверкой ≈ 4N, с дублированием ≈ 8N. Ландшафт 3 размера × 8 генотипов × 3 зерна ≈ 1500 вызовов; калибровка ≈ 100.

## Порядок
Литература (ворота 2) и совет → калибровка ε на листе (пилот, зёрна вне теста) → рецензия → PREREG → прогон → совет оценивает.
