## Моя ошибка (ERRORS № 52)
Задачи взяты без калибровки трудности — нарушено правило CLAUDE.md «сложность задач выбирать пилотом, начиная с заведомо трудного уровня». Семейства оказались либо по силам одной голове, либо недоступны никому; зоны, где ансамбль мог бы что-то добавить, в разведке не было.

## Что из этого следует для «нового уровня»
Уровень у копий одной модели может появиться только там, где (1) задача на горизонте одной головы — ошибка есть, но не систематическая, и (2) у частей разная информация или разные операции, а не разные слова в промпте. Следующий шаг матрёшки: задачи из ветви организаций (произведение M матриц 2×2 mod p при M, где одиночка проходит 0,3–0,6 — калибровкой) и разделение работы между участниками уровня (каждый участник получает свой кусок), а не одинаковую задачу. Совет оценивает эту разведку по правилу 28.09.
