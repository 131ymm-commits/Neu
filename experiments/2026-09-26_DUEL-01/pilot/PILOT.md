# DUEL-01, пилот: раунд 0
Составители дали 8 задач COL3 на 16 вершинах со скрытой структурой: гиперкуб, циркулянт, лестница Мёбиуса, «ромбы». Решатели точно посчитали все 8 задач (24 ответа из 24). Разница в баллах — только ширина интервалов, например 1002 [990; 1015] против [1001,5; 1002,5]. Очки составителя от +0,001 до +0,02, то есть это шум ширины.

Вывод пилота: в пределах LIMITS (COL3 до 16 вершин) у составителя нет преимущества — соперники раскрывают любую структуру. Нужна другая область задач: оценочные величины без точного ответа в уме (TWIN, PART большого n) или COL3 заметно крупнее. Турнир в нынешнем виде не создаёт трудности. Решение — через совет до PREREG.

Чистота: при составлении задач (duel-set0) головы получили сообщение человека (ERRORS № 31), при решении — нет (`tools/audit_heads.py`).
