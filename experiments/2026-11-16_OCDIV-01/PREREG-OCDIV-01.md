## 4. Статистики и оцениваемая величина
- **q(i, j)** — среди задач среды, где у обеих голов ответ — число и обе ошиблись, доля задач с равными ответами. Q-нов — среднее q по 19 парам толпы от разных производителей. Q-py — по 15 парам шести разных Pythia: 1.4b, 1.4b-deduped, 2.8b, 2.8b-deduped, 6.9b, 6.9b-deduped. Счёт — по всем задачам среды, ID и OOD.
- **δ** (описательно) — коэффициент при метке «пара разнородной толпы» в МНК по всем 34 парам: q = α + β·(средняя точность пары) + δ·[пара разнородной толпы].
- **Оценщики по среде** — `ocpost.post_stats`: CONF, POST-CV, ONE-BEST, FIXED-нов, POST-IN, SHIFT, wc CONF, wc POST, wc FIXED — код OCPOST-01. AGREE и CONF для D5 — `ocdiv.agree_conf`, тот же путь, что `analyze_ocshift.core`; равенство проверено тестом.
- **Оцениваемая величина** — среднее статистики по годным средам с равными весами. Это вывод о пяти средах теста.
- **Бутстреп:**
  - оценщики — по средам независимо: выборка ID с возвращением, затем OOD; B = 10 000, зерно 7 980 000 + 10·X + p;
  - D1 — выборка задач среды с возвращением, одна на все головы обеих толп; B = 10 000, зерно 7 985 000 + 10·X + p;
  - части кросс-подгонки — зерно 7 620 000 + 10·X + p (правило OCSHIFT-01).
- **Интервал M4** — точка ± z·ст. откл. повторов среднего, z = Φ⁻¹(0,9975) = 2,807. Перенос M4 на уровень 0,0025 для этих статистик и для среднего пяти сред не проверен (CLAUDE.md, совет 65). Уровень — номинальный.
- **Годность.** Проверка метода — только по ID: у головы не меньше 20 верных и 20 неверных ответов на ID и не больше 5 % ответов без числа. Среда годна, если проверку прошли не меньше 6 голов толпы. Опыт определён, если годны не меньше 4 сред из 5 и ревизии голов совпали.

## 5. Правила (уровень 0,0025 на сторону)
- **D1 (уровень толп; изменено после пилота 2 — §8, п. 5):** Q-нов − Q-py.
  - «Подтверждено» — верхняя граница < 0, «опровергнуто» — нижняя > 0.
  - Предохранитель «без одного диапазона» — как в OCPOST-01: знак среднего сохраняется при исключении любой одной среды. Иначе — «не решено (без одного диапазона)».
  - **Чтение** (записано до данных теста). Вывод — о двух толпах: ошибки этой разнородной толпы совпадают чаще или реже, чем у шести Pythia. Вклад производителя не отделён от вклада точности: толпы разной точности, их диапазоны в пилоте не пересекаются. δ — описательно, вес 0.
- **D2 (C-090 вне семейства Pythia):** wc CONF разнородной толпы < 0. Те же стороны и предохранитель.
- **D3 (предсказание совета 65):** C − T вне диапазона у FIXED-нов.
  - «Подтверждено (не переносится)» — интервал целиком вне полосы [−0,02; +0,02]; знак записывается.
  - «Опровергнуто (переносится)» — интервал целиком внутри полосы.
- **D4 (C-100 вне семейства Pythia):** wc POST разнородной толпы. «Подтверждено» — интервал целиком в полосе ±0,02, «опровергнуто» — целиком вне.
- **N (отрицательный контроль):** wc FIXED-нов, то же правило.
  - N «опровергнуто» — D4 «не определено (отрицательный контроль N опровергнут)».
  - FIXED-нов вне толпы хоть в одной годной среде — D3 и N «не определено (голова FIXED вне толпы в годной среде)».
- **D5 — описательно.** Мощность «подтверждено» по пилоту 0,013 < 0,2 (правило HYPOTHESIS). Интервал считается и печатается, вердикт — «описательно».
- **Правила чтения** (вердикты не меняют):
  - D4 «подтверждено» при подтверждённом D2 — «вторая калибровка снимает самообман на ID и у разнородной толпы»; при неподтверждённом D2 — «в полосе», не «снят»;
  - N не подтверждён — к D4 добавляется: «несмещённость счёта T − C без отбора не показана».
- **Описательно** (вес 0; M4 при 0,005, где есть интервал):
  - δ; Q-нов и Q-py по средам; типы ошибок; q у пар «новая голова — Pythia»;
  - пары одного производителя (две Qwen, две SmolLM) против пар разных производителей с точностью пары в пределах ±0,05;
