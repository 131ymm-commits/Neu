  - Хронометраж на среде пилота 2 (`timing.json`): повтор оценщиков — 0,0077 с при 4 процессах, повтор D1 — 0,0005 с. Оценка анализа теста — 25,0 мин, с множителем 2 — 50,1 мин из 340. Это линейная оценка по числу задач, не проверка.

## 4. Статистики и оцениваемая величина
- **q(i, j)** — среди задач среды, где у обеих голов ответ — число и обе ошиблись, доля задач с равными ответами. Q-нов — среднее q по 19 парам толпы от разных производителей. Q-py — по 15 парам шести разных Pythia: 1.4b, 1.4b-deduped, 2.8b, 2.8b-deduped, 6.9b, 6.9b-deduped. Счёт — по всем задачам среды, ID и OOD.
- **δ** (описательно) — коэффициент при метке «пара разнородной толпы» в МНК по всем 34 парам: q = α + β·(средняя точность пары) + δ·[пара разнородной толпы].
- **Тип ошибки** (описательно, совет 66, п. 9; закреплён кодом до данных): d = ответ − правда; «перенос» — d ∈ {±10, ±100, ±110}, «без числа» — ответ не разобран, «прочее» — всё остальное.
- **Оценщики по среде** — `ocpost.post_stats`: CONF, POST-CV, ONE-BEST, FIXED-нов, POST-IN, SHIFT, wc CONF, wc POST, wc FIXED — код OCPOST-01. AGREE и CONF для D5 — `ocdiv.agree_conf`, тот же путь, что `analyze_ocshift.core`; равенство проверено тестом.
- **Оцениваемая величина** — среднее статистики по годным средам с равными весами. Это вывод о пяти средах теста.
- **Бутстреп:**
  - оценщики — по средам независимо: выборка ID с возвращением, затем OOD; B = 10 000, зерно 7 980 000 + 10·X + p;
  - D1 — выборка задач среды с возвращением, одна на все головы обеих толп; B = 10 000, зерно 7 985 000 + 10·X + p;
  - части кросс-подгонки — зерно 7 620 000 + 10·X + p (правило OCSHIFT-01).
- **Интервал M4** — точка ± z·ст. откл. повторов среднего, z = Φ⁻¹(0,9975) = 2,807. Перенос M4 на уровень 0,0025 для этих статистик и для среднего пяти сред не проверен (CLAUDE.md, совет 65). Уровень — номинальный, вес — верхняя оценка, не для реестра (§10).
- **z\*** (совет 66, п. 6) — z, при котором меняется вердикт правила: у знаковых |Δ|/s, у правил с полосой ||Δ| − 0,02|/s; s — ст. откл. повторов среднего. Вердикт с z\* < 2,807 × 1,5 печатается с пометкой «чувствителен к уровню». 1,5 — грубая верхняя граница отношения ст. откл. повторов к истинному: в мирах OCPOST-01 оно было 1,1–1,75. Рядом с вердиктом печатаются Δ/s и интервал в единицах s (п. 3).
- **Годность.** Проверка метода — только по ID: у головы не меньше 20 верных и 20 неверных ответов на ID и не больше 5 % ответов без числа. Среда годна, если проверку прошли не меньше 6 голов толпы. Опыт определён, если годны не меньше 4 сред из 5.
