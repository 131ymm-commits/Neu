Объяснение не проверялось. У совета 67 две версии: состав видов ошибок (интуит) и разные знаменатели q, то есть разная точность толп (формалист); обе — в опись.
- **Пары одного производителя** (описательная строка PREREG §5; толкование — пост-хок) совпадают в ошибках чаще пар разных производителей при близкой точности: 0,5134 против 0,4210. Сравнений 10, пары не независимы (делят головы), производителей с парой всего два. Правилом это не было; вес 0.
- **Знак C − T вне диапазона против изменения точности *(пост-хок: выбрано и написано после просмотра сырого вывода, ERRORS № 180)* — ожидаемо по построению калибровки на ID.** Заявка настроена на точность ID, поэтому вне диапазона C − T примерно равно разрыву точности ID − OOD. Пример: OLMo-2 — 0,7747 → 0,6384, C − T +0,0673; TinyLlama — 0,5495 → 0,7449, C − T −0,1045. Знак противоположен у 6 голов из 7: при p = 0,5 одностороннее p = 0,0625 (точный биномиальный хвост). Исключение — Falcon3-1B: точность падает (0,7824 → 0,7162), а C − T −0,0089. Находкой это не считается.
- **Толпа из семи голов против одной *(пост-хок: выбрано и написано после просмотра сырого вывода, ERRORS № 180)*:** бюджет 7:1. Вне диапазона незнание у CONF 0,0202, у ONE-BEST — 0,1041; оракул 0,9997 — у потолка. Сравнения при равном бюджете нет; к главному вопросу это не относится.

## Что дальше

- **Первым из описи** (совет 67, единогласно) — сдвиг, при котором точность и у этих голов падает: например, четырёхзначные суммы на тех же семи головах. Около 35 заданий на процессоре раннеров, без денег. Без такого сдвига вопрос «оценщик вне диапазона» и D3 на этих головах упираются в потолок. В тот же PREREG:
  - безусловная доля задач, где обе головы ошиблись одним ответом, с разбивкой по видам ошибок, заданной заранее;
  - доля задач, где неверный ответ набрал не меньше голосов, чем верный, против перестановочного нуля;
  - доля разрыва ID–OOD, которую снимает калибровка (OCDIV-01 для неё — только пилот);
  - D3 на голове с разрывом ID–OOD не меньше 0,1;
  - мощность — симуляцией до прогона; время на задачу у самой медленной головы — пилотом на сиде вне теста.
- **Головы Claude** — после этого или параллельно, на том же трудном сдвиге. Условия: ключ API автора в секретах репозитория, счётчик трат с остановкой, сухой прогон с ценой вызова.

- Стенограмма — `docs/council/2026-11-16_OCDIV-01-report_session67.md`. Итог — принято единогласно: Левое (формалист) — за, Правое (интуит) — за, Скептик — за, Инженер — за; заседание 520 с, перебор 0 с.
- **Правки «нужно» 1–8 внесены в этот отчёт:**
