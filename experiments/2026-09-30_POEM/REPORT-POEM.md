# «Арена стихов» — отчёт пилота (30.09.2026)

PREREG: `PREREG-POEM.md` (коммит ac04039, до холостого прогона; итог холостого прогона — d2ffe57). Отклонения: `DEVIATIONS.md` (№1 — два дефекта сверки честности, исправлены после счёта раунда 1; исход защитников на затронутых заказах от исправления не зависел). Совет-проектировщик: 18.

## Итог
16 заказов подано (2 нападающих × 4 × 2 раунда), **16 честных** (независимые проверки по прозе совпали с проверками нападающих на всём пуле текстов).

| рука | попытка 1 | итог (после обратной связи) | тема узнана слепой головой |
|---|---|---|---|
| одиночка без библиотеки | 15/16 | **16/16** | 15/16 |
| команда поэт → редактор без библиотеки | 15/16 | **16/16** | 15/16 |
| одиночка с библиотекой | 16/16 | 16/16 | 16/16 |
| команда с библиотекой | 16/16 | 16/16 | 16/16 |

- **Первичное правило (описательно в пилоте):** Δ = команда − одиночка (обе без библиотеки) = 0,00, 95 % ИД Ньюкомба (метод 10) −0,19…+0,19 — шире границы эквивалентности δ = 0,15, по правилу «не решено». Несогласных пар по итогу 0, по попытке 1 — 2 (одна в пользу каждой руки).
- **Положительный контроль:** с библиотекой одиночка 16/16 против 16/16 без — **арена не различает руки**: потолок.
- Очки нападающих: 0 за оба раунда. Заказы раунда 2 были жёстче (5 строк по 30 букв без «е» с акростихом, 94 буквы во всём тексте, лесенка гласных 7–12 с разным числом гласных у соседних слов, растущие по длине слова без повторов) — и всё равно прошли все руки, большинство с первой попытки и без инструмента.
- Слепая тема: свидетель узнан 15/16, свидетель с перемешанными строками — тоже 15/16: мера не отличает связный текст от перемешанного (темы заказов слишком разные); как защита от бессмыслицы она слаба (так и оговорено советом).

## Чистота
Судит только код (`poemlib.py`, интерпретатор проверок = CPython на тестах). Аудит голов (`audit_heads.json`, 336 голов): пересланных сообщений нет, CLAUDE.md нет, путей к правде нет. Ручной аудит команд защитников: руки без библиотеки не запускали команд ни разу; руки с библиотекой вызывали только `poemlib.py` (нарушений 0 из 132 вызовов защитников пилота). Все «проходы» без инструмента перепроверены кодом.

## Моя калибровка (PREREG)
P(одиночка без библиотеки ≤ 50 %) = 0,6 → нет (100 %); P(с библиотекой выше) = 0,85 → нет (равны); P(|Δ| ≤ 0,15 точечно) = 0,55 → да (0); P(> 25 % снято) = 0,5 → нет (0 % после исправления прибора). Я переоценил известную слабость «модель не видит букв»: у этой модели на заказах такого рода её почти нет.

## Что это значит
Вторая площадка соревнования — и снова потолок. Модель без инструмента пишет русские стихи с точным числом букв, гласных, повторов, рифмами по заданному правилу и акростихами; нападающий той же модели не находит ограничения, на котором она ломается, а редактор и библиотека ничего не добавляют, потому что исправлять нечего. Сравнение «система голов против одной» на этих площадках невозможно: у одной головы нет ошибок, которые система могла бы поймать.
