## Может ли оценщик провалить перевод (пост-хок, мутанты; вердиктов PLAN не меняет)

Мутантов делает скрипт механически (`harness/mutants.py`), головы не участвуют: одна правка в переводе — сравнение (`<`↔`<=`, `==`↔`!=`), плюс-минус, логика (`&&`↔`||`), сдвиг, константа N→N+1. До 25 мест на файл, зерно 17. Всего 358 мутантов; не собрались 0 — в доли не входят; живых 358. Сравнение — 100 000 входов на функцию, как в оценке. Первый прогон упал на байте 0xA0 в выводе сравнения (ERRORS № 194); числа — из повтора `gha_out/linux01_mutants2/`.

Доля убитых: KUnit — 0,595, сравнением — 0,866. Зависания (считаются убийством): KUnit — 6, сравнение — 10. По видам правки (убил KUnit / убило сравнение из живых): константа — 100/175 из 199; логика — 18/18 из 18; плюс-минус — 37/41 из 44; сдвиг — 6/6 из 6; сравнение — 52/70 из 91.

«Выжили оба» разобраны по одному (`harness/review_survivors.py` → `mutants_survivors_review.json`; чтение кода (Claude), тестом не доказано):
- мёртвый код — 29: в gcd у Haiku и Opus медленный путь стоит после безусловного `return binary_gcd(...)` (ключ efficient_ffs включён), и правка там не исполняется;
- эквивалентные правки — 18: например, убран короткий выход, после которого цикл даёт тот же ответ, или флаг кавычек 1 → 2, который сравнивается только с нулём;
- слепое пятно — 1: opus/cmdline, строка 23 (`matches!(c as u8, 9..=13 | 32 | 160)`, 13 → 14). Байта 14 нет ни в генераторе сравнения, ни в тестах KUnit; isspace всех трёх переводов совпадает с ядром (9–13, 32, 160) по чтению кода. Из пробельных байтов генератор сравнения даёт только 9, 32 и 160 (ERRORS № 195).

**Итог замера.** Из 311 мутантов, меняющих поведение, сравнение с оригиналом поймало 310 (0,997), тесты KUnit модуля — 213 (0,685). Мутантов, которых поймал бы только KUnit, нет. Тесты модуля — слабый судья перевода: почти каждую третью ошибку в одну правку они пропускают. Сильнее всего — в int_log: из 63 правок таблицы логарифмов KUnit пропустил 62, сравнение поймало 63 (место правки сверено по строкам таблицы).

## Чего записка не утверждает

- Что Линукс можно перевести: шесть малых модулей без драйверов, работа вне ядра.
- Что переводы эквивалентны оригиналу: 100 000 случайных входов на функцию — выборка, не доказательство; пробельные байты 10–13 генератор не даёт, и isspace переводов на них проверен только чтением кода.
- Что классы выживших мутантов (мёртвый код, эквивалентные) верны: разбор — чтение кода, тестом не доказан.
- Что переводы идиоматичны или безопасны: мерилось только поведение.
- Что исход повторится: каждая голова переводила каждый модуль один раз.
