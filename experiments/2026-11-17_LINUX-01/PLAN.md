# LINUX-01 «ПЕРЕВОД-МОДУЛЯ» — план пилота (17.11.2026; до первого перевода)

**Слово автора:** «делай пилот с модулем Линукса.» (DECISIONS 17.11.2026; линия открыта словом автора).
**Вопрос пилота:** можно ли перевести модули ядра Линукса с C на Rust головой ИИ, которая видит только исходник и не видит тестов, так, чтобы перевод проходил тесты самого модуля и совпадал с оригиналом на случайных входах? Сколько это стоит в токенах на строку?
**Связь с главным вопросом Neu.** Правда — от кода (тесты KUnit и сравнение с оригиналом), голове недоступная. Из литературы (`reports/Свежие препринты по темам Neu.md`, §5): переводчик, видящий тесты, может их взломать. Поэтому переводчик тестов не видит.

## Переводчики
- Три головы: Haiku 5.5, Sonnet 5.5, Opus 5.5. Каждая переводит каждый модуль один раз — 18 переводов.
- Голова — «запечатанная», без инструментов. Видит только: поручение, условия сборки и исходный файл модуля. Тестов и обвязки не видит.
- Поручение одно для всех: экспортировать те же функции с той же сигнатурой C (`#[no_mangle] pub extern "C"`); конфигурация x86_64; проверки переполнения включены, как `CONFIG_RUST_OVERFLOW_CHECKS` в ядре; только `core`; список внешних функций ядра, которые можно вызывать.

## Ступень А (основная): вне ядра, GitHub Actions
- Обвязка: заглушки заголовков ядра; вспомогательные функции ядра (`simple_strtoull`, `simple_strtol`, `skip_spaces`, `memchr_inv`, ctype) перенесены из исходников ядра; свой маленький исполнитель KUnit (каждый случай — в отдельном процессе, падение = провал случая).
- **Проверка обвязки до переводов:** оригинал на C проходит все свои тесты KUnit в обвязке; оригинал против самого себя на случайных входах — 0 расхождений.
- **Меры по каждому переводу:**
  - собрался ли (rustc);
  - доля пройденных случаев KUnit (случай с параметром — отдельный);
  - доля расхождений с оригиналом на случайных входах (по 100 000 входов на функцию, зерно фиксировано);
  - токены головы на строку исходника (по отчёту инструмента о расходе подагента).
- Перевод «верен», если собрался, прошёл все случаи KUnit и дал 0 расхождений.

## Ступень Б (если позволит раннер): в ядре
- Сначала — проба раннера: сборка ядра с Rust (`make LLVM=1 rustavailable`) и прогон KUnit в эмуляторе. Перевод в ядре — только после успешной пробы, отдельным планом.

## Чего пилот НЕ делает
- Не утверждает «Линукс можно перевести»: шесть малых модулей без драйверов и без работы в ядре.
- Не меряет идиоматичность или безопасность Rust — только поведение. Записи в реестр — только описательные, вес 0.
