## 4. Статистики и оцениваемая величина
- **Оценщики по среде** — `ocdiv.stats_div` (`ocpost.post_stats` и `ocdiv.agree_conf`): CONF, POST-CV, ONE-BEST, FIXED-нов, SHIFT, AGREE; wc CONF, wc POST, wc FIXED на ID.
- **Т1** — C − T вне диапазона у POST-CV.
- **Т2** — ИОИ(AGREE) − ИОИ(POST-CV) вне диапазона.
- **Т3** — r = Σ(C − T вне диапазона) / Σ(T на ID − T вне диапазона) по головам списка; C — собственная заявка головы, откалиброванная на ID (`ocpost.calibrate`). Список — все семь голов (у всех разрыв на пилоте 2 не меньше 0,10). Если знаменатель среды не больше нуля, Т3 в этой среде не определена и в среднее не входит.
- **Т4** — F − F₀ вне диапазона.
  - F — доля задач, где какой-нибудь неверный ответ набрал не меньше голосов, чем верный (голоса голов толпы, ответ без числа — не голос).
  - F₀ — то же при перестановочном нуле: внутри каждой головы пары «верно ли, d» переставляются между задачами вне диапазона среды. Точка — по 1000 перестановкам, каждый повтор бутстрепа — по 10.
  - Оговорка (литература, arXiv 2605.29800, «сниппет»): перестановка сохраняет предельные частоты голов и проверяет независимость только в этом смысле.
  - Вариант со стратами по числу переносов — описательно.
- **Оцениваемая величина** — среднее статистики по годным средам с равными весами; вывод — о пяти средах теста.
- **Бутстреп** — по средам независимо: выборка ID с возвращением, затем OOD; B = 10 000, зерно 8 350 000 + смещение среды. У Т4 — выборка задач вне диапазона, зерно 8 470 000 + смещение. Части кросс-подгонки — зерно 8 200 000 + смещение. Смещение — 100·(номер семейства) + 10·(номер X) + p.
- **Интервал M4** — точка ± z·ст. откл. повторов среднего, z = 2,807. Перенос M4 на уровень 0,0025 для этих статистик и для среднего пяти сред не проверен; уровень номинальный.
- **z\*** — z, при котором меняется вердикт; пометка «чувствителен к уровню» — при z\* < 2,807 × 1,5 (как в OCDIV-01).
- **Годность.** Проверка метода — только по ID: не меньше 20 верных и 20 неверных и не больше 5 % ответов без числа. Среда годна, если проходят не меньше 6 голов. Опыт определён, если годны не меньше 4 сред из 5.

## 5. Правила (уровень 0,0025 на сторону)
- **Т1** — «подтверждено (самообман остаётся и после второй калибровки)», если нижняя граница больше +0,02. «Опровергнуто (честен)» — если интервал целиком в полосе ±0,02. Иначе «не решено», знак записывается.
- **Т2 — описательно.** Мощность «подтверждено» по пилоту 2 — 0,000 < 0,2 (правило HYPOTHESIS, как D5 в OCDIV-01). Интервал считается и печатается, вердикт — «описательно». Мощность обратной стороны («согласие хуже») — 0,541.
- **Т3** — «подтверждено (замечает частично)», если интервал r целиком внутри (0; 1). «Опровергнуто», если интервал целиком не меньше 1 (не замечает) или целиком не больше 0, сторона записывается. Иначе «не решено».
- **Т4** — «подтверждено», если нижняя граница больше 0; «опровергнуто», если верхняя меньше 0. Предохранитель «без одной среды» — как в OCPOST-01.
- **Описательно** (вес 0; M4 при 0,005):
  - D3 — C − T вне диапазона у FIXED-нов;
  - ИОИ AGREE − CONF;
  - wc CONF, wc POST, wc FIXED — переносы C-090 и C-100 на новый сдвиг;
  - Т4 со стратами по числу переносов;
  - незнание и самообман отдельно у всех оценщиков; оракул;
  - C − T вне диапазона и точность ID и OOD у каждой головы;
  - безусловное совпадение ошибок пар по видам ошибок («перенос» — |d| из нулей и единиц, кончается нулём; «прочее»), пары одного производителя против разных;
  - повтор на другом раннере.
