## 4. Статистики и оцениваемая величина
- **Оценщики по среде** — `ocdiv.stats_div` (`ocpost.post_stats` и `ocdiv.agree_conf`): CONF, POST-CV, ONE-BEST, FIXED-нов, SHIFT, AGREE; wc CONF, wc POST, wc FIXED на ID.
- **Т1** — C − T вне диапазона у POST-CV.
- **Т2** — ИОИ(AGREE) − ИОИ(POST-CV) вне диапазона.
- **Т3** — r = Σ(C − T вне диапазона) / Σ(T на ID − T вне диапазона) по головам списка (все семь). C — собственная заявка головы, откалиброванная на ID (`ocpost.calibrate`).
  - Если знаменатель среды не больше нуля, Т3 в ней не определена и в среднее не входит.
  - Повтор бутстрепа, в котором Т3 хоть одной среды не определена, исключается из M4 целиком; доля таких повторов печатается (совет 68).
- **Т4** — F − F₀ вне диапазона.
  - F — доля задач, где какой-нибудь неверный ответ набрал не меньше голосов, чем верный (голоса голов толпы, ответ без числа — не голос).
  - F₀ — то же при перестановочном нуле: внутри каждой головы пары «верно ли, d» переставляются между задачами вне диапазона среды. Точка — по 1000 перестановкам, каждый повтор бутстрепа — по 10.
  - Перестановка сохраняет предельные частоты голов и проверяет независимость только в этом смысле (arXiv 2605.29800, «сниппет»).
  - Основной нуль — без страт; вариант со стратами по числу переносов — описательно.
- **Гомоплазия** (совет 68, описательно) — доля задач вне диапазона, где самый частый неверный числовой ответ набрал не меньше 3 голосов, против того же перестановочного нуля. Ещё — заявка и точность AGREE на этих задачах и на остальных.
- **Проверка метода** — только по ID: не меньше 20 верных и 20 неверных и не больше 5 % ответов без числа, долю «без числа» тоже по ID (`prepare_id`, совет 68).
  - Зарегистрированный `analyze_ocshift.prepare` считал эту долю по всем задачам среды. Это не правда о верности ответов, но поведение голов вне диапазона входило бы в состав толпы.
  - Среда годна, если проверку проходят не меньше 6 голов; опыт определён, если годны не меньше 4 сред из 5.
- **Оцениваемая величина** — среднее статистики по годным средам с равными весами; вывод — о пяти средах теста.
- **Бутстреп** — по средам независимо: выборка ID с возвращением, затем OOD; B = 10 000.
  - Зёрна: бутстреп — 8 350 000 + смещение среды; Т4 — 8 470 000 + смещение; нуль точки — 8 420 000 + смещение; части кросс-подгонки — 8 200 000 + смещение.
  - Смещение = 100·(номер семейства) + 10·(номер X) + p.
- **Интервал M4** — точка ± z·ст. откл. повторов среднего, z = 2,807. Перенос M4 на уровень 0,0025 для этих статистик и для среднего пяти сред не проверен; уровень номинальный.
- **z\*** — z, при котором меняется вердикт; пометка «чувствителен к уровню» — при z\* < 2,807 × 1,5.

## 5. Правило, проверки построения и описательное (уровень 0,0025 на сторону)
- **Т4 — единственное правило с вердиктом:**
  - «подтверждено» — нижняя граница больше 0;
  - «опровергнуто» — верхняя меньше 0;
  - предохранитель «без одной среды» — как в OCPOST-01;
  - вердикт — по среднему пяти сред. Вывод формулируется о пяти средах, из которых 3 вырождены по пилоту 2.
- **Т1 и Т3 — проверки построения без вердикта** (совет 68). Исход печатается по тем же границам: у Т1 — нижняя граница больше +0,02 или интервал в полосе ±0,02; у Т3 — интервал внутри (0; 1) или целиком вне. В счёт выводов он не входит.
  - Находкой об оценщике их исход не называется: сведения даёт величина r.
  - r печатается отдельно для невырожденных и вырожденных сред.
- **Т2 — описательно.** Мощность «подтверждено» по пилоту — 0,000 < 0,2 (правило HYPOTHESIS, как D5 в OCDIV-01). Обратную сторону («согласие хуже», мощность 0,228) в правило не превращать: её знак виден по пилоту.
- **Описательно** (вес 0; M4 при 0,005, где есть интервал):
  - Т4 по невырожденным средам; Т4 со стратами по числу переносов;
  - D3 — C − T вне диапазона у FIXED-нов;
  - ИОИ AGREE − CONF;
  - wc CONF, wc POST, wc FIXED — переносы C-090 и C-100 на новый сдвиг;
  - незнание и самообман отдельно у всех оценщиков; оракул;
  - C − T вне диапазона и точность ID и OOD у каждой головы;
  - гомоплазия;
  - безусловное совпадение ошибок пар по видам ошибок («перенос» — |d| из нулей и единиц, кончается нулём; «прочее»), пары одного производителя против разных;
  - повтор на другом раннере.
