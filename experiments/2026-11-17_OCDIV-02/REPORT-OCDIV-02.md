# OCDIV-02 «ОЦЕНЩИК-ТРУДНЫЙ-СДВИГ» — отчёт (17.11.2026)

Главный вопрос Neu — оценщик, который не обманывается под давлением отбора. В OCDIV-01 сдвиг был лёгким: вне диапазона калибровки семь открытых голов пяти производителей ошибались не чаще, чем на нём. Здесь сдвиг трудный: длина слагаемого растёт от 3 до 7 цифр, а подсказка — только из примеров диапазона калибровки (ID). Проверяется, складываются ли ошибки разных голов вне диапазона в ложное большинство чаще, чем при независимых ошибках с теми же частотами (Т4). Ещё проверяется, сколько разрыва точности ID − OOD остаётся не замеченным в заявке головы (Т3, r).
- **Предрегистрация — коммит 55e7a62b** (`PREREG-OCDIV-02.md`; совет 68 — три линзы, принято 3 из 4). Запуск теста — коммит c78b50d2, анализа — c1b8bb20.
- **Данные** — GitHub Actions, процессор раннера: 35 заданий (7 голов × 5 сред «длины», X = 9, 99, 999, 9999, 99999; подсказка только из ID, p = 3), задач в среде — 2200. Ещё одно задание повторено под другим именем на другом раннере.
- **Счёт** — GitHub Actions: `gha_out/ocdiv2_sum_test/analysis.json`, B = 10000, M4 — точка ± z·ст. откл. повторов, z = 2,807. Производные числа — `report_derived.json` (этот же скрипт).
