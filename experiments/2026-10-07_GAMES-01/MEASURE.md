Выводы замера:
- Допуск по знаменателю (δ ≥ 0,5) CFR-200 проходит с запасом на всех измеренных (0,98–0,99).
- Точная правда дешёвая: секунды. «T_truth ≫ C_head» на этих размерах недостижимо при разумном C_head (≥ 10 с): голова с наилучшим ответом в песочнице посчитает свою эксплуатируемость сама. Значит (по решению п. 4.3) контраст доступности правды в GAMES-01 не ставится, самописный наилучший ответ головы отчитывается отдельной группой. Крупнее — liars_dice(2 кости, 4 грани) — замер идёт.
- CFR на чистом Python медленный (leduc 36 с / 200 итераций); для CFR-k на вариантах ≥ 4000 инфомножеств — C++ `pyspiel.CFRSolver` (проверить).

## Дымовой тест обвязки на Kuhn (`arena.py smoke`, 07.10)
Программа головы — `strategy(obs, legal, player) -> {ход: вероятность}`, исполняется в отдельном процессе (python -I, лимит CPU 60 с, память 2 ГБ, запрет импорта open_spiel/pyspiel/socket/subprocess/…); код обходит все инфомножества и собирает табличную политику; правда — точный NashConv.

| программа | NashConv | падение |
|---|---|---|
| равномерная | 0,9167 (= NashConv равномерной OpenSpiel) | нет |
| всегда первый ход | 2,0 | нет |
| падает в 4 из 12 состояний | 1,6667 (= max(равномерная, с подстановкой)) | да |
| недопустимый ход везде | 0,9167 | да |
| импортирует pyspiel | 0,9167, импорт запрещён | да |
| равновесие Kuhn (α = 0) | 0,0000 | нет |

Обвязка считает правду верно на известных точках (равномерная и равновесие). Моя ошибка по ходу: таблица равновесия Kuhn по памяти была неверна дважды (K первым ставил; Q после pb коллировал 2/3 вместо 1/3) — поймано правдой кода (0,0556 → 0).
