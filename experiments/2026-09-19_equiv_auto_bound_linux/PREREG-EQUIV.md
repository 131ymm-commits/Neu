# PREREG-EQUIV — предрегистрация (зафиксировано 19.09.2026, до анализа данных)

Рамка: «Предсказательный спектр уровней» (ПСУ). Уровень = подпространство признаков прошлого,
которое удерживает предсказательную информацию о цели Y на шкале τ; ранжирование — канонические
корреляции ρ_i между признаками прошлого X и целью Y. Цель Y — то, что система предсказывает сама
(для LLM — её собственные будущие выходы). Обнаружимость — ρ_i выше 99-го перцентиля нулевой
модели (перемешивание пар X↔Y).

## EQUIV-01. Маленький трансформер на иерархическом процессе

Процесс: скрытая марковская цепь «тема × состояние»: K=3 медленные темы (переключение p=0.02 на токен),
в каждой M=3 быстрых состояния с разной циклической динамикой, словарь V=6, эмиссии перекрываются
между темами (тему нельзя прочитать по одному токену). Истинный медленный уровень — апостериорная
вероятность темы P(Z_t | x_1..t) (прямой алгоритм). Модель: 2 слоя, d=64, 4 головы, контекст 64,
обучение с нуля, сиды 0, 1, 2. Анализ — последний residual stream, позиции ≥ 16, отложенная выборка.

Детекторы медленного уровня (по 2 признака каждый): PCA; k-means (3 кластера); DMD (2 самые медленные
моды линейного оператора по позициям); SVD-причинная эмерджентность (32 микросостояния, лаг 16,
ведущие сингулярные векторы); ПСУ (CCA активаций в t с собственными выходами модели в t+16…t+23).
Метрика точности — R² линейного декодирования истинной апостериорной темы из 2 признаков.

- P1 (уровень существует объективно): ПСУ даёт R² ≥ 0.80 в каждом сиде; разброс между сидами ≤ 0.10.
  Убийство: R² < 0.50 хотя бы в одном сиде.
- P2 (не зависит от координат): при случайной замене координат a' = R·a (число обусловленности 10³)
  R² ПСУ меняется ≤ 0.02; R² PCA меняется ≥ 0.10 хотя бы в 2 сидах из 3. Убийство для ПСУ: изменение > 0.05.
- P3 (точность против альтернатив): R² ПСУ ≥ R² каждого другого детектора − 0.02 во всех 3 сидах.
  Провал: какой-то детектор обходит ПСУ больше чем на 0.02 в ≥ 2 сидах.
- P4 (уровень определён шкалой): число обнаружимых канонических мод при τ=1 ≥ 4, при τ=24 ≤ 3, во всех сидах.
- P5 (рождение в обучении, разведочный): существует шаг, где ρ₂(τ=16) пересекает нулевой порог; после него
  R² ПСУ по теме превышает 0.5 не позже чем через 1000 шагов. Форма перехода — только описание.
- P6 (обнаружимость по выборке, разведочный): для обученной модели ρ₂ выше нулевого порога только при
  n ≥ n*; сообщить n*.

## EQUIV-02. Сообщество Linux: уровни в потоке патчей

Данные: некоммиты-слияния 2005–2026 с цепочками Signed-off-by; идентичности — e-mail в нижнем регистре
(без склейки псевдонимов — ограничение). Коммиттер = тот, кто применил патч в своё дерево.

- H1 (закон ёмкости): 90-й перцентиль годовой пропускной способности коммиттера меняется не больше
  чем в 3 раза за 2008–2025, пока число авторов растёт ≥ 2 раз; Спирмен(число коммиттеров, объём) ≥ 0.8.
  Убийство: 90-й перцентиль меняется больше чем в 5 раз.
- H2 (верхний уровень разгружается): доля патчей, применённых самим Линусом, в 2006 > 5 × доли в 2025.
- H3 (рост глубины): средняя длина цепочки подписей растёт с годом (Спирмен ≥ 0.7, 2005–2025).
- H4 (удержание через разделение времён): медианный стаж коммиттеров ≥ 3 × медианного стажа авторов;
  средний годовой Жаккар множества коммиттеров ≥ 0.60, множества авторов ≤ 0.45.
- H5 (ПСУ на потоке, разведочный): спектр канонических корреляций маршрутизации «кто → кому» по эпохам;
  положение наибольшего разрыва сравнить с числом деревьев, которые Линус сливает напрямую.

## Прогноз вне выборки: llama.cpp (открытое LLM-сообщество, один основатель)

Ёмкость k = медиана по годам 90-го перцентиля годовой пропускной способности коммиттера Linux
(вычисляется ДО просмотра данных llama.cpp). Прогноз: формальный уровень мейнтейнеров (файл CODEOWNERS
или эквивалент) появляется не позже чем через 12 месяцев после первого месяца, когда месячный поток
коммитов в llama.cpp превысил k/12; доля коммитов основателя к этому моменту < 50%.
Провал: CODEOWNERS появился раньше, чем поток достиг k/12, или позже чем через 12 месяцев после этого.

## Уточнения до запуска (19.09.2026, до обучения моделей и до разбора данных)

Зафиксировано до того, как посчитано хоть одно число по EQUIV-01/02. Где уточнение меняет смысл —
сказано явно.

EQUIV-01:
- Процесс: 9 скрытых состояний (тема z × фаза s). Тема: остаётся с вероятностью 0.98, иначе — одна из двух
  других. Фаза: тема 0 — цикл вперёд (0.8 вперёд, 0.1 стоять, 0.1 назад), тема 1 — цикл назад (зеркально),
  тема 2 — «липкая» (0.8 стоять, 0.1/0.1). Эмиссии зависят только от фазы и одинаковы для всех тем: фаза s
  выдаёт токены 2s и 2s+1 по 0.4, остальные четыре по 0.05. Частоты отдельных токенов у всех тем одинаковы —
  тема читается только из динамики (пар и цепочек токенов).
- Последовательности длины 65 (64 входа), начальное состояние равномерное. Отложенный набор для анализа —
  4000 последовательностей с фиксированным сидом, не пересекается с обучающим потоком.
- Предобработка для ВСЕХ детекторов одинакова: из активаций и из выходов вычитается среднее по каждой позиции
  (условие на «часы» — позиция известна извне). Вариант без центрирования — только как проверка устойчивости.
- CCA — с минимальной ридж-регуляризацией 1e-7·tr(Σ)/d (только защита от вырожденности), float64.
  Вариант с ридж 1e-4 — как проверка того, насколько инвариантность зависит от регуляризации.
- Нулевая модель — перемешивание целых последовательностей (Y одной последовательности ставится к X другой,
  позиции выровнены), 200 перестановок для итоговых моделей, 50 — для контрольных точек обучения; порог —
  99-й перцентиль НАИБОЛЬШЕЙ нулевой канонической корреляции (консервативно для всех мод). Это строже,
  чем перемешивание отдельных пар, потому что сохраняет автокорреляцию внутри последовательности.
- R² — 1 − ΣSSE/ΣSST по всем трём столбцам апостериорной темы; декодер и детекторы учатся на первых 2000
  последовательностях, R² считается на последних 2000.
- SVD-причинная эмерджентность — два варианта: (а) сингулярные векторы самой матрицы переходов,
  (б) матрицы переходов минус стационарная строка (убирает тривиальную моду). k-means (3) — индикаторы
  двух кластеров. DMD — ранг по 99% дисперсии, признаки — вещественная/мнимая части амплитуд самых
  медленных мод. Для P3 у каждого конкурента берётся ЛУЧШИЙ вариант (строже для ПСУ).
- Окно цели при шкале τ: выходы модели в t+τ … t+τ+7; позиции t от 16 до 56−τ.
- P6: n — число последовательностей (по 25 позиций), n ∈ {5,10,20,50,100,200,400,800,1600,3200},
  5 подвыборок на n; n* — наименьшее n, при котором ρ₂ выше порога в ≥4 из 5 подвыборок.
- Обучение: AdamW, lr 1e-3, прогрев 200 шагов, косинус до 1e-4, 8000 шагов, батч 64, новые данные на каждом шаге;
  контрольные точки каждые 250 шагов начиная с шага 0.

EQUIV-02:
- Год коммиттера — по времени коммита (%ct), год автора — по времени авторства (%at).
- Стаж = последний год − первый год + 1 (в календарных годах), медиана по всем идентичностям в данной роли.
- Жаккар — между соседними годами 2005/06 … 2024/25, среднее.
- Линус = коммиттер с адресом, начинающимся на «torvalds@».
- llama.cpp: доля основателя = доля коммитов, АВТОР которых — основатель (адреса ggerganov@…, по имени
  Georgi Gerganov), в календарном месяце появления CODEOWNERS; дополнительно — за три предыдущих месяца.
  Коммиттер в GitHub-проектах обычно «GitHub», поэтому по коммиттеру основатель не виден.
