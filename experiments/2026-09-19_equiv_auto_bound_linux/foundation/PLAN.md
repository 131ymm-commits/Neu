# Основание 1.3 — карта корпуса

**Что это.** Не организация — **протокол.** Как интернет: никто не владеет, нет рубильника, есть набор правил, по которым независимые узлы говорят друг с другом. Для того, что человечество разучилось делать: **рождать и растить детей.**

**Статус:** версия 1.3, оба языка (`ru/`, `en/`). Форк легитимен и ожидаем.

---

## Ядро — протокол

| Файл | О чём |
|---|---|
| `README` | Ядро на одной странице: пять принципов, двенадцать обязательств, честный предел. |
| `01_PROTOCOL` | **Несущий.** Двенадцать MUST. Кто может основать узел (кто угодно — разрешения выдавать некому). Суверенитет во всём остальном. Чего сеть не делает никогда. |
| `02_COMMUNION` | **Правоприменение без полиции.** Евхаристическое общение: признание, разрыв, граф, форк. Почему взятка убивает то, что покупает. Где механизм ломается. |
| `03_SOVEREIGNTY` | «Чья земля, того и вера». Разные веры — все в своём праве. Формы: кампусы, общежития, заводские городки. |

## Обоснование — почему так

| Файл | О чём |
|---|---|
| `04_EVOLUTION` | Движок. Герметизм → наука. **Рак тоже приспособлен**: среда задаёт, что есть приспособленность, а среда = протокол. |
| `05_ATTACHMENT` | Единственная содержательная аксиома. Кибуцы: день работал, **сломала ночь**. Вершина смертна → преемник. |
| `06_BOUNDARY` | **Вред = схлопывание границы в полюс, а не вещество.** Списка запретов не существует **по типу объекта**. Меры границы тоже нет — **доказано** → центральный судья невозможен математически. |

## Механизмы

| Файл | О чём |
|---|---|
| `07_ECONOMY` | Деньги как физика. Суррогатство: капитализм против феодализма. **Дед заказывает внука** (гипотеза бабушки; **бабка и есть вершина**; узел = деревня). Генетический антитраст. Корпорации. **Рекомендатель = новый виток эволюции.** |
| `08_DATA` | Наблюдение без контроля. **Контроль ≠ надзор** (мать в каждом слове, но подстраивается). ИИ — леса Выготского. **Игра стирания.** Бесплатная версия = контрольная популяция. |
| `09_VIRTUES` | Две добродетели = **две оси границы**: стирание держит **I**, ежегодный выход в чужой мир впускает **J**. Обмен между узлами — четыре функции. |

## Исполнение

| Файл | О чём |
|---|---|
| `10_PRECEDENTS` | **SOS: 75 лет, 137 стран, основатель-насильник, культура молчания.** Кибуцы, Макаренко, детдома, пансионы, харедим, заводские городки, деды с бабками. |
| `11_START` | **Парадокс N=1.** Одиночный узел — это SOS. N=2 хуже, чем ничего. Настоящий старт — **софт**, не узел. Анти-Гмайнер: автор публикует и уходит. |
| `12_JURISDICTION` | **Мастер-ключ: узел никогда не берёт опеку.** Бабка — законный родитель, узел = жилкооператив + школа. Суррогатство — опция, не фундамент. Данные — актив. **Окно закрывается.** |
| `13_GRADUATE` | **Отказ говорить — это и есть замер.** Выпускники становятся сетью. **Кто сторожит сторожей? — Дети. Когда вырастут.** |
| `14_RESILIENCE` | **Подхват существует, чтобы узлы могли умирать.** SOS стала too big to fail → не исправилась. **Разрыв общения НЕ отменяет обязанность принять детей.** |
| `15_MIRROR` | Математика ИИ и его **пределы**. Приватность **фальсифицируема**. Дневник ≠ досье. Единая модель = скрытый центр. **Крик наружу.** |

## Три нерешённых

1. **Все узлы могут ошибаться вместе двадцать пять лет.**
2. **Первая когорта платит за наше незнание.**
3. **Оплата не спасает женщину, у которой нет выбора.**

**Проект, который скажет, что решил их, — соврёт.**
