# LEVEL-03, пилот: смена поколений (ρ = 0,15), 250 шагов со связью и без
Данные: `out.json`.

| | Итог | Смен консенсуса | Новички с предпочтением против группы сохранили своё | Выбрали первый названный вариант |
|---|---|---|---|---|
| Связь | с шага 2 все за ЗЕЛЁНЫЙ, до конца | 0 | **0 из 19** | 111 из 250 (порядок уравнен) |
| Без связи | 0–3 за СИНИЙ, блуждание | 0 (консенсуса нет) | 44 из 44 | 135 из 250 |

**Вывод.** Новички приходят со своим предпочтением. Без группы все 44 его сохраняют, а в группе все 19 новичков с противоположной привычкой подчиняются с первого же шага. Смена поколений не порождает рекуррентности: норма группы наследуется новичками полностью. Это жёстче «конформизма» — это **передача нормы**, культурная наследственность без мутаций. Смещение к первому варианту убрано рандомизацией порядка (111 и 135 из 250).

**Чтение по «Грамматике переходов».** Эпоха, как в LEVEL-01 и LEVEL-02. Коллективное состояние голов Claude — поглощающая норма: рождается за 1–2 шага и не отмирает при полной смене состава. По спектральной рамке это не уровень с конечным временем жизни, а бесконечно долгое состояние: t₁ → ∞, система неэргодична в C.

**Что это значит для поиска уровня.** Рекуррентность у голов Claude, видимо, возможна только при силе, сравнимой с групповым давлением. Кандидаты:
- смена группы, которую видит голова (подгруппы, кольцо с малым числом соседей — как в LEVEL-01);
- новичок, который не видит группу при первом выборе;
- внешнее поле с реальной ценой несогласия.

Модель без LLM, откалиброванная на этих долях (конформизм 1,0), даёт t₁ = ∞, поэтому сертификаты SYNTH-06 здесь не применимы.
