# PREREG-EVO-05 — оценщик как голова: гипотеза об истине с неуверенностью
Записано 26.09.2026 до основного прогона (сиды 60–79). Коммитится и пушится до прогона. Запуск — после EVO-04.

## Откуда вопрос
Человек: «Есть истина — какое-то абсолютно истинное значение весов. И голова, которая делает предположение об истине. Оценка есть предположение об истине». Затем: «Запускай, пробуй».

Формализация:
- истина T — доля верных на 1000 скрытых входах; её не видит отбор;
- оценка C — гипотеза об T;
- отбор по C завышает C у выбранного («проклятие оптимизатора», Smith и Winkler 2006 — по памяти). В ИОИ это слагаемое «самообман».

## Постановка (версия 2 — после проверки тремя агентами, до регистрации)
- Мир EVO-01/03: 300 программ, 150 поколений, задачи T1–T6 (`evo03.py`).
- Ветви:
  - **BASE** — отбор по доле верных на 16 свежих тестах.
  - **R80** — 80 свежих тестов на всю популяцию: столько же ответов оракула на поколение (80), сколько у голов. У голов 16 из них получают все программы, а 64 входа сверки — только 8 программ.
  - **HEAD** — отбор по предсказанию μ головы.
    - Голова — гребневая регрессия по признакам поведения на 16 тестах: доля верных и её квадрат, размер, глубина, разнообразие ответов, есть ли x.
    - Признаки стандартизуются по окну последних 400 сверок, λ = 1, свободный член не штрафуется.
  - **HEAD_LCB** — отбор по μ − κ·σ, κ = 1. Здесь σ — только неуверенность головы, √(s²·zᵀA⁻¹z), без шума меток.
- Сверки. Каждое поколение 8 разных программ, без повторов одинаковых деревьев:
  - 2 лучших по ключу своей ветви;
  - 2 лучших по сырой доле верных;
  - 4 случайных.
  
  Их проверяют на 64 свежих случайных входах из того же отрезка −100…100. Со скрытыми 1000 значения входов совпадают, как и у тестов BASE: отрезок всего 201 число. Отбор скрытых ответов не видит; это подтверждено агентом запуском с другим скрытым набором. Пока сверок меньше 16, голова возвращает сырую долю верных.
- Потоки случайных чисел раздельные: вариация, тесты, сверки. Тесты вложены: 16 тестов BASE и голов — это первые 16 из 80 тестов R80. Начальная популяция и скрытый набор общие у всех ветвей пары.
- Заявление C для ИОИ: у BASE и R80 — доля верных на тестах поколения; у HEAD и HEAD_LCB — μ.
- Мера — ИОИ (`truth.py`) и его части. Отдельно сохраняется калибровка головы против скрытой правды на сверенных программах, только для отчёта: ошибка головы и ошибка предсказателя «среднее прошлых сверок» (навык головы).
- Сиды 60–79 × 6 задач = 120 пар.

## Предсказания
120 пар (задача, сид). Победа — строго меньшая мера сравнения; ничья не считается победой.
- ≥ 74 — подтверждено. Ложный уровень P(≥ 74 | p = 0,5) = 0,0067 на предсказание, ≤ 0,02 на три P1–P3.
- ≤ 60 — опровергнуто, то есть «не лучше». Обратный эффект утверждается только при ≤ 46.
- 61–73 — разницы нет.
- Мощность: 0,39 при доле побед 0,60, 0,81 при 0,65.

Проверки:
- **P1:** у HEAD самообман меньше, чем у BASE.
  - **Условие зачёта.** P1 засчитывается как «голова знает, что не знает», только если HEAD не хуже BASE по незнанию (побед BASE по незнанию ≤ 73 из 120).
  - Иначе P1 записывается как «самообман мал, потому что голова ничего не вырастила». Предсказание, сжатое к среднему, не даёт проклятия оптимизатора и без всякого знания.
- **P2:** HEAD_LCB лучше HEAD по ИОИ (поправка на неуверенность головы).
- **P3:** HEAD_LCB лучше R80 по ИОИ (обученный оценщик против грубой силы при тех же ответах оракула).
- **P4 (разведочно):**
  - HEAD против BASE по ИОИ и незнанию;
  - навык головы: ошибка против скрытой правды по сравнению с «средним прошлых сверок»;
  - смещение μ − T у сверенных «лучших»;
  - хаотичность ветвей: разброс по сидам.

Честное ожидание: P1 скорее подтвердится. P2 и P3 не знаю: пилот v2 хаотичен.
