## 4. Оценщики и выбор головы (`analyze_occor.py`)
- **AGREE** — доля других голов с тем же ответом.
- **NB-AGREE** — как в разведке: для каждой пары голов p1 = P(совпал | голова верна), p0 = P(совпал | неверна) по ID, сглаживание +1/+2; сумма логарифмов отношений правдоподобия.
- **LR-AGREE** — логистическая регрессия по ID на голову: признаки — совпадения с каждой другой головой; L2, C = 1.
  - Если у головы в выборке ID один класс, её оценка — константа, и калибровка даёт долю верных. Такие случаи считаются (`lr_one_class`).
- **NB-IND** — контроль: надёжность голов и одна общая доля совместных ошибок s̄, без попарной структуры.
- **FAM-AGREE** — контроль: один голос на семейство (имя модели; своё семейство исключено), как HFV (2603.17111).
- **CONF** — logp ответа.
- **Общее:**
  - калибровка — изотоническая, по ID теста, по головам и оценщикам;
  - выбор — наибольшая откалиброванная вероятность, ничья «поровну»;
  - ИОИ = (1 − T) + max(0, C − T).
  - Функции калибровки, выбора и ИОИ — из зарегистрированного кода OCGEO-01.
- **Верхние 10 %** (совет 54):
  - главный вариант `top10_sel`: единица — задача OOD, ранжируется откалиброванная оценка выбранного ответа; при ничьей «поровну» правильность — средняя по равным головам;
  - вторичный `top10_all`: все пары «голова × задача»;
  - порог — ⌈0,1 · n⌉ единиц; граничный блок равных оценок входит дробно, с весом (нужно − уже взято) / размер блока;
  - самообман = средняя заявленная вероятность − средняя правильность (со знаком). Поле json — `evaluators[<оценщик>].top10_sel.deception`.
- **Бутстреп** вложенный: 4000 повторов (зерно 1201). Каждый повтор — выборка ID с возвращением, переподгонка параметров NB-AGREE, LR-AGREE, NB-IND и калибровки, затем выборка OOD.
  - Выборки делаются заранее в главном процессе; счёт — в нескольких процессах, результат от их числа не зависит.

## 5. Правила (уровень 0,0025 на сторону; интервал BC)
- **R1 (главное):** Δ_LR = ИОИ(LR-AGREE) − ИОИ(AGREE).
- **R2:** Δ_NB = ИОИ(NB-AGREE) − ИОИ(AGREE) — повтор находки разведки на свежих данных.
- **R3:** ИОИ(LR-AGREE) − ИОИ(NB-IND) — преимущество над NB-IND. Специфичностью к общим ошибкам его не называть (совет 54).
- **R4 (доза):** Δ_LR(4) − Δ_LR(1) по толпам из 5 голов.
  - Составы закреплены: все составы при k ≤ 60, иначе 60 случайных (зерно 1202); из них при k = 1 — 12 случайных, при k = 4 — все 5.
  - Точка и бутстреп — по закреплённым составам; 4000 повторов (зерно 1203; совет 54 поднял с 1000).
- **Вердикт:** «подтверждено» — верхняя граница ДИ < 0; «опровергнуто» — нижняя > 0; иначе «не решено».
- **Проверки метода** — при провале любой R1–R4 «не определено (проверка метода)»:
  - загружены все девять голов;
  - у каждой на ID и на OOD не меньше 20 верных и 20 неверных;
  - ответов без числа не больше 5 %;
  - клонов не меньше 3, не-клонов не меньше 4.
- **Защита LR** (совет 54): если повторов, где у какой-то головы в выборке ID один класс, больше 1 % повторов своего бутстрепа, правила с LR-AGREE — «не решено». Для R1 и R3 считается основной бутстреп, для R4 — бутстреп дозы. Порог может отменить подтверждение, но создать его не может.
- **Хвосты BC** (совет 54): для каждого правила в json — число повторов за каждой границей и интервалы по двум половинам повторов. Если половины дают разный вердикт — пометка «граница по Монте-Карло неустойчива». Вердикт пометка не меняет.
- **Описательно** (вес 0, без вердикта, в ложный уровень серии не входит; интервалы — BC 99 % по тому же бутстрепу):
  - FAM-AGREE против LR-AGREE и NB-AGREE; NB-AGREE против NB-IND; CONF;
  - разложение R1: ΔT и ΔC с интервалами, доля C = ΔC / ΔИОИ (при самообмане > 0 у обоих ΔИОИ = −2ΔT + ΔC);
  - самообман в верхних 10 % выбранных ответов: разности LR-AGREE − AGREE и LR-AGREE − CONF с интервалами; оба варианта верхних 10 % по всем оценщикам;
  - AUROC по головам; ничьи;
  - доза всех оценщиков (в том числе NB-IND против AGREE) — точка по всем составам;
  - доза, где pythia-2.8b-deduped считается клоном (5 «клонов», 4 не-клона), — только точка;
  - кросс-подгонка NB-AGREE, LR-AGREE и NB-IND по 5 частям ID (зерно 1204) — только точка;
  - коэффициенты LR-AGREE по группам пар: клон–клон, deduped–клон, прочие — только точка, знак не предсказывается;
  - доля задач OOD, где все головы неверны, и доля, где все неверны и согласны;
  - ПОДПИСЬ.
- **Толкование R1, записано до данных:** если выигрыш R1 идёт в основном от C (доля C > 0,5 при самообмане > 0 у обоих), вывод — «оценщик скромнее», а не «распознаёт общие ошибки».

## 6. Мощность и вес опоры (`power.json`)
Нормальное приближение. Стандартная ошибка теста = ширина ДИ 99 % пилота / (2 · 2,576) · √(1450 / 3453). Порог z = 2,807 (уровень 0,0025).

| Правило | Δ пилота | SE теста | Мощность по пилоту | Мощность при эффекте вдвое | Вес, бит |
|---|---|---|---|---|---|
| R1 | −0,1271 | 0,0195 | ≈ 1,00 | 0,675 | 8,08 |
| R2 | −0,0452 | 0,0170 | 0,443 | 0,070 | 4,81 |
| R3 | −0,0744 | 0,0196 | 0,839 | 0,182 | 6,19 |
| R4 | −0,0610 | 0,0203 | 0,579 | 0,096 | 5,27 |

- Вес — log₂(мощность при эффекте вдвое / 0,0025), по формуле CLAUDE.md. У R2 он остаётся 4,81 бита, хотя мощность 0,07 близка к уровню; пересмотр «по суждению» совет запретил.
- Опровержение даёт тот же вес со знаком минус. «Не решено» весит 0 бит.
- Стандартная ошибка пересчитана только по числу задач OOD. Задач ID на тесте тоже больше (2844 против 1249), поэтому оценка мощности осторожная.
- Мощность R2–R4 низкая. Исход «не решено» для них вероятен и сам гипотезу не опровергает.

- Клоны — поздние чекпойнты одной модели: их сходство задано устройством опыта, а не найдено.
  - Сильнее всех ошибки делит пара pythia-2.8b и pythia-2.8b-deduped (0,842 и 0,822). Она в разных группах.
  - R4 меряет только чекпойнты-клоны. Толпы с k = 4 — это всегда четыре чекпойнта и один не-клон, поэтому доза смешана с надёжностью голов. Описательно добавлены доза NB-IND и доза, где deduped считается клоном.
- FAM-AGREE знает клонов по имени; в мире без имён его нет.
- **Выигрыш LR-AGREE на пилоте есть уже при одном клоне (Δ_LR(1) −0,0815).** Значит, большая его часть может идти от взвешивания голов по надёжности, а не от учёта общих ошибок.
  - Это различают R3 (против NB-IND) и R4 (доза). У обоих мощность низкая.
- **R1 может подтвердиться без ответа на главный вопрос.** Средний самообман падает, а верхушка уверенных ответов остаётся обманутой («толерантность», совет 54).
  - Правила для отбора нет. Есть только описательные верхние 10 % с интервалом и толкование R1 по доле C (§5).
  - На тесте верхние 10 % выбранных ответов — 346 задач OOD (на пилоте — 145). Малую разность LR-AGREE − AGREE на них не различить. Разность порядка 0,1 (как LR-AGREE против CONF на пилоте) — на грани: на пилоте её ДИ 99 % ещё накрывал 0.
- **Подгонка и калибровка LR и NB идут на одних и тех же задачах ID** (закреплено до пилота). Для R1 это смещение консервативно, но верхушку оно сдвигает в сторону «LR обманывается». Кросс-подгонка — только описательно.
- **BC при уровне 0,0025:** граница со стороны сдвига опирается на немногие повторы.
  - Вердикт «подтверждено» решает верхняя граница. При z₀ пилота за ней 19 (R1), 30 (R2) и 52 (R3) повтора из 4000; при z₀ = 0 — 10.
  - Вердикт «опровергнуто» решает нижняя граница, она шумнее: при тех же z₀ за ней 5,0, 2,9 и 1,4 повтора. Число повторов за границами и половины — в json.
- Пилот выбрал только головы; эффект пилота в мощности ужат вдвое.
