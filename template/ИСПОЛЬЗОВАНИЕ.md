# Шаблон «Реестр утверждений» — как пользоваться

Универсальный каркас для любого исследования, которое человек ведёт вместе с ИИ. Протокол — `PROTOCOL.md`.

## Новый проект за минуту
1. Скопировать эту папку `template/` себе (или весь репозиторий Neu).
2. Выполнить: `./init_research.sh ~/my-research "Моё исследование"` — появится готовый git-репозиторий с первым коммитом.
3. Создать пустой репозиторий на GitHub и выполнить две команды, которые напечатает скрипт.

Если работаете с Claude Code, достаточно сказать Claude: «создай исследование по шаблону template из репозитория Neu» — он сделает шаги 2–3 сам (создание репозитория на GitHub может потребовать одного вашего клика).

## Что внутри
- `PROTOCOL.md` — протокол: четыре части, статусы утверждений, алгоритм, роли, таблица адаптации под разные области.
- `CLAIMS.md` — реестр утверждений.
- `sources/SOURCES.md` — происхождение всех материалов и список «чего не хватает».
- `studies/_TEMPLATE/` — шаблоны PLAN (до) и REPORT (после).
- `journal/` — чат с ИИ (`export_chat.py`), решения, ошибки ИИ.
- `CLAUDE.md` и `.claude/skills/research-ledger/` — правила и навык, по которым Claude ведёт репозиторий сам.

## Отличие от PROTOCOL.md в корне Neu
Протокол Neu написан под вычислительные эксперименты программы. Этот шаблон — обобщение: единицей служит не эксперимент, а утверждение, поэтому он годится и для опроса, и для архива, и для продукта.
