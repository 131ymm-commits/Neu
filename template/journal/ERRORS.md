# Ошибки и допущения ИИ
Записи не удаляются; исправление дописывается к записи. Каждой ошибке — класс, чтобы со временем было видно, какие ошибки повторяются.

## Классы
| Класс | Что это | Пример |
|---|---|---|
| A | неверно по существу: вывод или число ошибочны | неверно истолковал источник |
| B | не та наблюдаемая: мерили не то, что утверждали | метрика не соответствует вопросу |
| C | не тот режим: верно в одних условиях, не в этих | механизм прогноза не тот, хотя счёт угадан |
| D | верно, но иначе: результат держится, объяснение другое | |
| E | не проверено: утверждал без проверки | «ничего нет», проверив не всё |
| F | слишком сильно: формулировка сильнее данных | «доказано» при 3 сидах |
| M | по памяти: число или факт без опоры в файлах | |
| K | некалиброванный порог: ложный уровень предположен, а не посчитан | разброс по 3 сидам |
| P | процесс: действие с репозиторием или средой (удаление, перезапись, лимит) | |

## <дата сессии>
1. [класс] <что произошло> — <как обнаружено> — <исправлено где / не исправлено>
