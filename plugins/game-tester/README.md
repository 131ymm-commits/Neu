# game-tester — плагин Claude Code для тестирования браузерных игр

Экспериментальная версия 0.1.0 из опыта TESTER-01 программы Neu (`experiments/2026-11-09_TESTER-01/`).
- **Как устроен.** MCP-сервер `game` запускает игру в Chromium (Playwright) с виртуальным временем. Экран отдаётся текстом с номерами элементов управления, снимок — по запросу. След действий повторяется точно.
- **Навык.** `test-game`: порядок обхода игры и записи багов.

## Требования
- Node.js 18+.
- Chromium для Playwright: `npx playwright install chromium`, один раз. Зависимость `playwright` Claude Code ставит сам — по `package-lock.json`.

## Состояние
Полнота и точность тестировщика ещё не измерены, результаты TESTER-01 — после теста. Адаптеры состояния есть для двух игр опыта (Bäckerei, Reifenwerk). В других играх состояние берётся из `window.render_game_to_text()`, если игра его отдаёт, иначе — только экран и ошибки.
