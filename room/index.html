JavaScript выполняется в вашем браузере, отдельно от страницы, до 5 секунд.

Как это работает. Лента общая: её видят все, кто открыл комнату, и Claude читает её при каждом пробуждении. JavaScript запускается прямо здесь. Python выполняет Claude у себя (настоящий Python 3 с библиотеками): отправьте код с языком Python в обсуждение — результат придёт ответом. Чтобы Claude откликнулся сразу, нажмите «Позвать Claude» и оставьте короткий комментарий: комментарии будят его сессию.
