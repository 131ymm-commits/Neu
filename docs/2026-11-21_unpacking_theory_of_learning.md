# Теория распаковки: обучение как подбор глубины знания под запас ученика (гипотеза, 21.11.2026)

Запрос автора 21.11.2026: «мне интересны только те философские зауми, которые прилагаются к чему-то реально работающему. Итак обучение. Вводи новые или оперируй старыми понятиями и категориями. Или вот ещё создай новую теорию!»

**Статус: гипотеза Claude.** Опытом не проверена. Данные статьи AMD (arXiv 2608.07169) породили гипотезу и потому опорой не считаются. Вес опоры: база «гипотеза_neu» +0,23 бита, сверх базы 0 бит. Составные части известны (см. §6, всё по памяти); моё — сборка, операционные определения и предсказания.

## 1. Исходное наблюдение

У знания две независимые координаты, а обычно называют одну.

- **Длина** — сколько места занимает запись. Закон короче таблицы.
- **Глубина** — сколько работы нужно, чтобы из записи получить действие. Закон глубже таблицы: из него ответ надо вывести.

Сжатие уменьшает длину и увеличивает глубину. «Регенераторам нужен ток» — коротко и глубоко. Готовая последовательность команд с координатами — длинно и мелко.

## 2. Три величины

Все три определены так, чтобы их можно было посчитать.

| Величина | Определение | Как мерить |
|---|---|---|
| **Глубина записи** C(m, x) | число решений, которые ученик должен принять сам, чтобы применить запись m к ситуации x | число «дыр»: незаданных аргументов, порядка шагов, координат, условий. Каждая метка `<X>` — одна дыра |
| **Запас ученика** B(θ) | наибольшее число дыр, которое ученик заполняет верно в 80 % случаев | давать записи с 0, 1, 2, 4, 8 дырами и считать успех по правде от кода или игры |
| **Шум подачи** n | число показанных записей, не относящихся к ситуации | считать по выдаче поиска |

Четвёртая — **ценность** V(m, x): прирост у читателя с неограниченным запасом. Это потолок записи.

## 3. Закон

    ΔK(m, θ, x) = V(m, x) · P[ C(m, x) ≤ B(θ) ] − λ · n

- Запись даёт прирост, только если её глубина не превышает запас ученика.
- Каждая лишняя запись стоит λ.
- **Обучать — значит выбирать запись с наибольшей ценностью при глубине чуть ниже запаса ученика и без лишнего.**

Второе следствие — про **охват**. Мелкая запись (образец) применима только рядом с ситуацией, из которой взята. Глубокая (закон) — широко. Ученику с малым запасом нужно много мелких записей и хороший поиск; ученику с большим — мало глубоких.

Что такое «понимание» в этих словах: ученик понимает закон, если B ≥ C этого закона, то есть может сам вывести из него образцы. Проверка: убрать образцы, оставить закон, дать ситуацию вне диапазона образцов.

## 4. Что закон объясняет в данных AMD (задним числом, не опора)

| Факт статьи | Объяснение |
|---|---|
| Отрезок кодом — 49,40 %, тот же текстом — 23,21 % | у текста глубина выше запаса модели 4B |
| Стратегия одна — +7 п. п., с отрезками — ещё +25 | стратегия глубокая, отрезки мелкие |
| Пять отрезков вместо одного — 33,34 % против 49,40 % | шум подачи |
| Прирост наибольший у 4B; у 1,7B точность 21,43 %; у 14B прирост мал | при 1,7B запас ниже глубины даже образцов; у 14B мала ценность: она многое выводит сама |
| Самый сильный учитель не лучший для 4B | предположение: сильный учитель пишет короче и пропускает шаги, его записи глубже. В статье не проверялось |

## 5. Предсказания (новые; каждое проверяемо правдой от кода или игры)

1. **Переворот.** Есть запас, выше которого образцы помогают меньше закона, а вне диапазона образцов — вредят. Слабому ученику лучше образец, сильному — закон; кривые пересекаются.
2. **Горб.** Прирост от памяти как функция запаса ученика имеет максимум: слева запас ниже глубины, справа мала ценность.
3. **Радиус.** Польза образца падает с расстоянием от ситуации-источника; польза закона падает медленнее, но только у ученика с B ≥ C.
4. **Размер отрезка.** Есть оптимум длины отрезка. Слишком длинный — ученик ошибается внутри; слишком короткий — сборка отрезков сама требует запаса.
5. **Цена ложной записи.** Вред ложной записи тем больше, чем она мельче: образец с нулевой глубиной копируется без проверки, ложный закон чаще игнорируется. Отсюда: отбор образцов должен быть строже отбора правил.
6. **Сильный учитель через упрощение.** Если записи сильного учителя разложить до глубины ≤ B ученика, порядок учителей в таблице 3 статьи выправится: лучший учитель даст лучшего ученика.

Предсказание 5 относится к главному вопросу программы: что делает ошибающийся оценщик с памятью.

## 6. Что из этого следует для практики

**Ученик с замороженными весами (память поверх мотора).** Запас B не меняется. Обучение системы — это рост библиотеки записей с C ≤ B и качества поиска. Мера прогресса — **покрытие**: доля ситуаций, для которых находится запись с C ≤ B.

**Ученик с обучаемыми весами.** Обучение переносит распаковку внутрь: после тренировки на образцах семейства глубина законов этого семейства для ученика падает. Порядок подачи — каждая новая запись чуть ниже текущего запаса.

**Порядок работы учителя:**
1. Измерить запас ученика (лесенка из 0, 1, 2, 4, 8 дыр).
2. Каждую запись перед показом привести к глубине ≤ B: заполнить лишние дыры или разрезать.
3. Показывать одну ближайшую запись; непохожую не показывать.
4. Там, где ученик проходит без записи, заменять образец более коротким правилом и проверять, что результат не упал. Память со временем должна укорачиваться при том же результате.
5. Ложные записи вычищать по числам игры, начиная с самых мелких.

## 7. Кто раньше (всё — по памяти, поиск не делался)

- Зона ближайшего развития — Выготский.
- Теория когнитивной нагрузки: новичкам лучше разобранные примеры; у опытных эффект обращается («expertise reversal») — Sweller, Kalyuga. Предсказание 1 — тот же эффект, перенесённый на модели.
- Логическая глубина как время распаковки кратчайшего описания — Bennett.
- Разрыв способностей учителя и ученика в дистилляции — Mirzadeh и др., 2020 (цитируется в статье AMD).
- Обучение по возрастающей сложности — curriculum learning.

Что, насколько я знаю, не сделано: глубина как счёт дыр, измеряемый тем же инструментом, что и запас ученика; предсказания 5 и 6. Уверенность в новизне низкая; до любой предрегистрации нужен поиск.

## 8. Чем теорию можно опровергнуть

- Запас B не окажется устойчивой величиной: ученик заполняет 4 дыры в одной задаче и 0 в другой без видимой причины.
- Переворота нет: образцы лучше закона при любом запасе.
- Вред ложной записи не зависит от её глубины.
