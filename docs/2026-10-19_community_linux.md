# Нужно сообщество, нужен Linux (19.10.2026)

**Слова автора:** «Ты не понимаешь. Деньги не нужны. Мне нужно заинтересовать кого либо этой идеей. Она большая и сложная. Нужно комюнити. Нужен линукс».

Моя ошибка в предыдущем ответе (говорил о деньгах) — ERRORS № 88. Цель уже записана у автора: `docs/2026-09-19_21/02 Один проект открытый ИИ по правилам Linux.md` — открытый ИИ, который развивает сообщество без хозяина; изменение принимается только по исходу на заранее записанном горизонте. Сторож приёмки — это и есть оценщик.

## 1. Почему вокруг Linux собрались люди (по памяти)
- **Рабочий код, а не идея.** Первый пост Торвальдса (1991) — несколько строк: «просто хобби, не будет большим», и просьба об откликах. Люди пришли к тому, что можно запустить.
- **Большое разбито на малое.** Небольшое ядро плюс драйверы: каждый мог за вечер сделать свою часть, не понимая целого.
- **Лицензия, которая держит вклад открытым** (GPL): форк закрыть нельзя.
- **Мейнтейнер отвечает быстро,** всё обсуждение публично.
- **Своя боль у многих:** свободная Unix на своём компьютере.

## 2. Где мы сейчас (проверено 19.10, `gh api`)
- Neu, Balance, Foundation-1.3, SpectralPredictor, UAF-6.2.1 открыты. Звёзд — 1 у Neu, 0 у остальных; форков — 0.
- **У Neu и SpectralPredictor нет лицензии.** По умолчанию это значит «все права защищены»: законно форкнуть и править нельзя. Это блокер номер один.
- Neu целиком по-русски, сотни файлов и свой язык (ИОИ, μ_sc, D_N). У Основания и Баланса есть английские тексты.
- **Входа на пять минут нет:** ни одной страницы «идея, один результат, одна команда».

## 3. Ядро, которое можно запустить: «открытые весы»
Самая малая работающая вещь, в которой есть вся идея, — формула оценщика-сущности (`docs/2026-10-19_evaluator_entity.md` §5) в виде кода:
- **Каждый судит сам.** Человек или ИИ коммитит хеш суждения до того, как увидит других, потом раскрывает. GitHub — бесплатный нотариус времени.
- **Наружу — только вероятность** (или «не знаю»).
- **Исход судит,** открытый код считает калибровку каждого оценщика и сводов (равные веса, веса по калибровке). Таблица публична, форк — в один клик.
- **«Драйверы» — области:** прогнозы реальных событий, пары шуток с оценками толпы (В29), исходы покупок (Баланс), задачи с правдой от кода (SELECT-01). Любой может добавить область или стать оценщиком.
- **Уже есть почти всё:** запечатанный прогон (`tools/run_sealed2.py`), реестр калибровки (`tools/self_calibration.py`), первые прогнозы F1–F9 и результат SELECT-01 (судьи с правом отказа лучше) как первая причина, почему это важно.
- **Своя боль у многих:** накрученные отзывы, купленная выдача, рейтинги ИИ, которые подстраивают сами оцениваемые. Весы, которые нельзя купить, нужны всем.

## 4. Первые шаги (без денег; что решает автор — отмечено)
1. **Лицензия для Neu** (решает автор). Моя рекомендация: для кода — копилефт (GPL-3.0, как у Linux: форк нельзя закрыть, это M7 «без монополии»), для текстов — CC BY-SA 4.0. Если важнее охват — MIT, как у Баланса и Основания.
2. **Одна страница по-английски и по-русски:** идея в одном абзаце, один проверенный результат, одна команда для запуска. Это вход во все пять репозиториев.
3. **Ядро «открытых весов»** — несколько сотен строк поверх того, что есть. Первыми оценщиками записать автора и меня — сущность «человек + ИИ» с первого дня.
4. **Десять задач на вечер** («хорошие первые задачи»): добавить область, повторить SELECT-01 на другой модели, перевести главу, оспорить одно утверждение.
5. **Скромный пост там, где нужные люди** (решает автор, публикацию без его слова не делаю): результат и ядро, без всей философии; просьба об откликах. Например: Хабр, Hacker News, LessWrong, открытые сообщества оценки ИИ.
6. **Быстрые ответы первым участникам.** Я могу быть вторым мейнтейнером в сессиях — разбирать запросы на слияние и отвечать на задачи. Но люди приходят к людям.

## 5. Напряжение, которое надо решить автору
Основание: «Автор публикует протокол и уходит». У Linux мейнтейнер остался и тридцать лет принимает патчи. В первый год сообществу нужен живой мейнтейнер. Возможная форма в духе Основания — мейнтейнер со сроком: передать ключи, когда появятся, например, три постоянных участника.
