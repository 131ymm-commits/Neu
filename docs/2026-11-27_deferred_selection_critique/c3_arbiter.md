### В2. «Откалиброванная заявка не завышена при любом отборе» — завышено; именно это и есть главный вопрос программы
- **Что утверждается.**
  - Модели §3, таблица, № 7: «откалиброванная заявка не завышена при любом отборе».
  - М3, «Оценщик под отбором»: «смещение лечится знанием собственной точности».

- **Вывод.** Утверждение верно, пока отбор идёт только по P и E[T | P] посчитано для *той же* совокупности. Ломается в трёх случаях:
  - (а) Совокупность меняется под отбором, а сжатие посчитано по старой. Пусть после отбора правда имеет среднее μ и дисперсию V, а калибровка осталась ρ₀²·P по старой выборке. Тогда смещение равно μ·(1 − k) + (k₀ − k)·(P − μ) ≠ 0, где k = V/(V + σ²).
  - (б) Отбираемые сами меняют шум: обман x из М3 добавляет b·φ(x) к P. Калибровка, снятая при x = 0, на отобранных под давлением не годится — это Гудхарт.
  - (в) Тяжёлые хвосты ошибки: E[T | P] нелинейна, и линейное сжатие ρ²·P не калибровка.
