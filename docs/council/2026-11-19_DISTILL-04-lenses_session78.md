5. **Отрицательный контроль всей цепочки через `family_rule`.** Две заглушки:
   - «прочие» берутся по таблице смещений → П1-Т «меньше», m_M < 0, АБ сохранён;
   - М ≡ Т → «не решено».

   Плюс серия при нуле М ≡ Т: 2000 миров, СТОП при ≥17 решающих. По scipy у голов ложный СТОП при доле 0,005 равен 0,027, срабатывание при 0,01 — 0,78. Сиды не пересекаются с пилотом. Запасной вариант — 200 миров с подписью «грубая проверка цепочки, уровень не калибрует».
6. **Нормировка.** По чтению кода (Интуит, Скептик) Т тоже нормирован: `other_valid` берёт y ≥ 0 и y ∉ S, делит на сумму плюс q_rest. Остаётся недостача: равномерный остаток (π_U/|V| у М, q_rest/|V| у Т) частично ложится на S. В `test_prog_m` добавить проверку на заглушке: сумма по V у М, Т и М+Т ≤ 1 с допуском 1e-12, недостача у М и у Т печатается по задачам. Правило решения фиксируется до замера:
   - разность недостач М−Т мала → нуль не меняется, строка «направление влияния недостачи не проверялось, величина ≤ …»;
   - иначе → симметричное правило для обеих программ (остаток только на V \ S, сумма «прочих» = ε, тест |Σ−ε| ≤ 1e-12). Изменение записать в §9 как сделанное после пилота. П1-Т пилота дать в обеих версиях. Ненормированное сравнение идёт описательной ветвью. Если знак между версиями расходится, вердикт «больше» не выносится.
7. **Опись:** «Т = 10 из 14 самых частых» — ветвь, описательная. Нуль-Т не меняется.
8. **Направленные слова.** «Главный риск» и «самое неуверенное» снабдить ссылкой на число 0,0069. Направление поправки, знак смещения сравнения М/Т (поле выбора Т шире; смещения через тысячу на test6 теряют смысл) и влияние ничьих в top3 (у М их больше) помечаются: «направление не проверялось».
