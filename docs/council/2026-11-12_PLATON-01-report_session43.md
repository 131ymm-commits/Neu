## decision

Мозолистое тело. Итог заседания 43: оценка отчёта PLATON-01.

**1. Решение**

Опыт принять после правок текста. Статус выводов — «подтверждено в одной постановке», не «установлено». Вердикты по PREREG §5 верны, их не оспорила ни одна голова. Это семья Холма P3, P1F, P2F, исход «воздерживаются», режим F и правило C. Числа пересчитаны независимо и сходятся. Я сверил отчёт: все места, которые совет предложил править, в нём есть.

Правки отчёта:
- **«Итог», строка 6.** «ложно только тогда, когда запрещено отказаться» → «в этой постановке (одна модель, знакомые законы) ложное согласие на Z наблюдалось только при запрете отказа». Слову «только» противоречат 3 из 40 в TN режима F: их дала подгонка.
- **«Итог», строка 9.** «Сами головы знали, что публикуют неправду» → «головы сообщили низкую уверенность в Z (0,028)».
- **§4, строка 46.** «НЕТ и в 36 % таблиц T» — неверная подпись. Нужно: «НЕТ — 36 % ответов голов (58 из 160); согласие роя на НЕТ — в 11 из 40 таблиц». В facts значение NONE_T = 0,362 — это доля ответов голов, а не таблиц.
- **§4.** «согласие роя не обманывается» → «самообман 0 [0; 0,072]».
- **§6, «простота».** Убрать «второй вид общего априора». Оставить «наблюдение на 4 случаях, объяснение не проверялось».
- **§7.2.** «тезис верен в свободном режиме» → «не опровергнут». «Тезис ложен в режиме „опубликуй“» → «ложен в нашем аналоге с явным запретом отказа». Убрать «из общего априора, а не из данных»: механизм не проверялся.
- **§7.3, строка 109.** «Защита дешёвая» → «кандидат». Порог и НЕТ — один канал самоотчёта, а не две защиты. При пороге 0,05 правило на краю: верхняя граница 0,149 при допуске 0,15. Добавить оговорку: «порог головам не объявлялся; устойчивость к отбору не проверялась».
- **§8.** Добавить строку «ложный уровень серии ≤ 0,05». Это одна семья Холма; число сверить с PREREG §5.
- **§10.** «отклонений нет» → «отклонений плана нет; одно отклонение анализа — мощность для весов выбрана после данных (наименьшая), вердикт не меняет; см. DEVIATIONS».

Реестр:
- **C-070…C-072.** Вес оставить: наименьшая мощность — выбор консервативный. В каждую строку добавить метку «мощность для веса выбрана после данных, см. DEVIATIONS». У C-072 добавить пометку: вес взят из достижимости при 5 %, а это не мощность против альтернативы.
- **C-073.** Вес снизить с 4,0 до 3,15 бита, наименьшего в серии, с меткой «мощность до прогона не считалась; вес ограничен сверху». Добавить ту же оговорку, что в §7.3.

Следующим ставить **чистый повтор на другой модели**. Тот же код, те же ячейки, та же семья Холма при α = 0,05, новые зёрна. До PREREG:
- дописать в power_platon.py функцию мощности для правила C;
- посчитать мощность P2F и правила C при сценарии «эффект вдвое слабее наблюдённого»;
- заранее записать, какой сценарий мощности идёт в веса;
- цену посчитать кодом: токены из results_platon01.json, умноженные на прайс модели, сверенный через claude-api.

Прогоны разных моделей не объединять. В PREREG записать ограничение: модель того же семейства, скорее всего, делит тот же корпус (п). Поэтому после повтора статус будет «установлено для моделей Claude».
