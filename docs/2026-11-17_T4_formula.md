# Т4 «до самого простого», потом до формулы (17.11.2026)

Слова автора (дословно): «И смотри давай такая задача. Мы упрощает для. До и самых простых и тупых. А потом до формул? Можем? А потом анализировать эти формулы.»
Здесь — первый пример на нашем же правиле Т4 из OCDIV-02. Это ступень «символьная модель» лестницы Neu: игрушка → символьная модель → настоящие головы.

## 1. Самая простая модель
- k голов отвечают на задачи; голова либо верна, либо даёт неверное число.
- Все неверные ответы разные (совпадений неверных ответов нет).
- На задаче j каждая голова ошибается с вероятностью p(j); при данной задаче головы ошибаются **независимо**.
- Задачи разной трудности: p(j) меняется от задачи к задаче.

## 2. Формула
Ложное большинство (`false_major` в `experiments/2026-11-17_OCDIV-02/ocdiv2.py`, стр. 147–153): какой-нибудь неверный ответ набрал не меньше голосов, чем верный. Если неверные ответы не совпадают, это «верных не больше одного и хоть один неверный». Отсюда:
- G(p) = p^k + k·(1 − p)·p^(k−1) = k·p^(k−1) − (k − 1)·p^k; при k = 7: **G(p) = 7p⁶ − 6p⁷**.
- F = среднее G(p(j)) по задачам.
- Перестановочный нуль (`permute_cols`) разносит ответы каждой головы по задачам. Тогда у каждой головы ошибка на любой задаче — с её средней частотой p̄, и **F₀ = G(p̄)**.
- **Т4 = F − F₀ = E[G(p)] − G(E[p])** — неравенство Йенсена.

## 3. Анализ формулы
- G''(p) = 42·p⁴·(5 − 6p): G выпукла при p < 5/6 и вогнута при p > 5/6 (сверено численно, разностной производной).
- Следствие 1. **Т4 > 0 получается без всякого совпадения ошибок** — только из разной трудности задач, если ошибки голов в основном ниже 5/6. Пример: половина задач с p = 0,2, половина с p = 0,8 → F = 0,2885, F₀ = 0,0625, Т4 = +0,2260.
- Следствие 2. **При очень высокой ошибке Т4 < 0.** Пример: половина задач с p = 0,9, половина с p = 1,0 → F = 0,9252, F₀ = 0,9556, Т4 = −0,0305.
- Следствие 3. Если все головы ошибаются всегда (p = 1), F = F₀ = 1 и Т4 = 0 — «ноль по построению» вырожденных сред.
- Числа примеров посчитаны кодом: `python3 -c "g=lambda p,k=7:k*p**(k-1)-(k-1)*p**k; print((g(.2)+g(.8))/2-g(.5), (g(.9)+g(1))/2-g(.95))"`.

## 4. Что это значит для OCDIV-02 и OCDIV-03
- В OCDIV-02 знаки Т4 по средам идут так же, как предсказывает формула: +0,1272 при X = 9 (ошибок меньше), −0,0065 при X = 999 (ошибок много), 0 при X = 9999 и 99999 (верных нет). **Совпадение только по знаку; объяснение не проверялось.**
- Значит, Т4 > 0 в OCDIV-02 может целиком давать разная трудность задач, без общих ошибок голов. Это количественная форма возражения совета 69.
- Для OCDIV-03 нуль со стратами по трудности убирает член Йенсена внутри страты: внутри страты p почти одинаково, и E[G(p)] ≈ G(E[p]). Остаток после страт — кандидат на настоящее совпадение ошибок.
- Следующий шаг формулы (предложение): добавить совпадение неверных ответов (доля q общих неверных ответов при совместной ошибке) и разные p у разных голов. Тогда Т4 разложится на член трудности и член совпадения, и OCDIV-03 будет мерить второй. Проверка формулы — численно на GitHub Actions, затем описательно (пост-хок) на данных OCDIV-02.
