# Экономия токенов: «код → дешёвые головы → Opus» (09.11.2026; проект, не замер)

**Основание — слова автора 09.11:** «Давай придумаем систему в рамках которой ты тратишь токены только на самое важное (размышление и общяя организация) и ищешь бесплатные варианты для не самого важного… Если мы сможем найти какие-то рабочие варианты количество "рабочих" токенов вырастит в разы.»

Числа — из `journal/token_ledger.json` (`tools/token_ledger.py`). Цена — по прейскуранту API. Как лимит подписки взвешивает модели и кеш, я не проверял.

**Вывод.** В многоходовой работе платят не за ответ, а за повторное чтение контекста на каждом ходу. Дешевле всего обходится то, что сделано без лишнего хода, без длинного контекста или не на Opus.

## Три яруса
| ярус | кто | что делает | проверка |
|---|---|---|---|
| Т0 — код | этот контейнер; позже GitHub Actions или процессор Kaggle | повтор следа, детекторы, оценка, проверка банка, случайный обход игры («обезьяна»), статистика, аудит | правда по построению |
| Т1 — дешёвые головы | Haiku 5.5 — уже есть в подписке; потом открытая модель на GPU Kaggle или бесплатные API | поиск и чтение файлов, сводки логов, черновики, разбор отчётов, массовая игра | код или выборочная проверка Opus |
| Т2 — Opus | я и совет | замысел, PREREG, суждения, которые не проверить кодом, итоговые отчёты; головы опытов — только когда вопрос о самом Opus | совет, повтор |

**Правило маршрутизации.** Задача уходит на самый дешёвый ярус, результат которого можно проверить. Учёт — `token_ledger.json` после каждой сессии. Цель — доля Opus падает, а объём работы Т0 и Т1 растёт.

## Рычаги — по величине (оценки до замера)
1. **Haiku 5.5 вместо Opus для рутины.** По прейскуранту в 40 раз дешевле за токен ($0,10 / $0,50 против $4 / $20).
   - Для тестировщика — это вопрос самого продукта: хватит ли дешёвой модели, если у неё хорошая среда. Пилот на Haiku на тех же копиях обойдётся по прейскуранту в $1–3.
2. **Меньше ходов и короче контекст у голов.** В пилоте средний контекст хода — 100–200 тыс. токенов. Цена растёт примерно как ходы × контекст. Отсюда три меры:
   - пачка действий за один вызов `game_act`;
   - эпизоды: сессия заканчивается заметками, следующая начинается с них и с чистым контекстом;
   - наблюдения разностью (уже сделано).

   Ожидаю удешевление в 2–4 раза. Не замерял.
3. **Код вместо головы.** «Обезьяна» с автоматическими оракулами (ошибки консоли, NaN, застывшее время, деньги из ничего) находит падения бесплатно. В TESTER-01 это заодно нижняя планка: голова должна её превзойти.
4. **Моя дисциплина.** Шаг стоит ≈ $0,20 при любом выходе. Поэтому:
   - команды объединять;
   - не будить себя частыми событиями;
   - чтение многих файлов отдавать подагентам на Haiku;
   - большой вывод в контекст не печатать.
5. **Бесплатное снаружи.** Только для коротких вызовов без длинной истории: дневные потолки малы для многоходовых сессий.

**Правила:** соблюдать условия бесплатных уровней (один аккаунт — один потолок, без обходов); банк багов, соли и правду наружу не отправлять.
