# Прогоны Neu в Google Colab

Слова автора, 14.11.2026: «Теперь так же подключаемся к колабу».

## Что можно и чего нельзя
- **Полностью сам — нельзя.** У бесплатного Colab нет программного способа запустить ноутбук; всегда нужна кнопка в браузере. Программный запуск есть у платной Colab Enterprise (Google Cloud с оплатой) — не подключалась.
- **Можно в один клик автора.**
  1. Я кладу ноутбук в репозиторий.
  2. Автор открывает его ссылкой в Colab и нажимает «Среда выполнения → Выполнить все».
  3. Ноутбук пишет результат в папку **Neu_colab** на Google Диске автора.
  4. Я читаю результат через подключённый Google Диск и коммичу.

  Копировать руками ничего не нужно.

## Ссылка на ноутбук
Репозиторий открытый, поэтому Colab открывает ноутбук прямо с GitHub:
`https://colab.research.google.com/github/131ymm-commits/Neu/blob/<ветка>/<путь>.ipynb`

## Порядок для опыта
1. Код опыта и PREREG — коммит и пуш до прогона. Ноутбук вкладывает код целиком и печатает sha256 для сверки с регистрацией.
2. Автор: ссылка → «Выполнить все» → разрешить доступ к Диску. Для видеокарты — «Среда выполнения → Сменить среду → GPU».
3. Я: результат из `Neu_colab/<опыт>/` через Google Диск → коммит. Числа в отчёт — только из этих файлов.
