# Прогоны Neu на Modal — только бесплатные кредиты

**Слова автора, 14.11.2026:** «давай модал но там только бесплатные прогоны».

## Правило
- На Modal идут только прогоны за счёт бесплатных кредитов плана Starter: $30 в месяц по странице цен Modal и выдаче поиска.
- **Способ оплаты в аккаунт Modal не добавляется.** По выдаче поиска (сторонние сайты; страница Modal о биллинге не прочитана), без способа оплаты Modal ничего не списывает: когда кредиты кончаются, задания останавливаются. Если Modal когда-нибудь потребует карту, прогоны на Modal прекращаются до слова автора.
- **Каждое задание** задаёт `timeout` у своих функций и самую дешёвую подходящую видеокарту. Workflow ограничен 60 минутами.
- **Перед большим прогоном** в PREREG записывается оценка стоимости по тарифу Modal. Она должна быть заметно меньше остатка кредитов месяца. Остаток автор видит в панели Modal (Usage).

## Как устроено
- Задания — `modal_jobs/<имя>.py`: приложение Modal с `@app.local_entrypoint() def main(out: str)`.
- **Workflow** `.github/workflows/neu-modal.yml`:
  1. запускается пушем изменённого задания;
  2. выполняет `modal run modal_jobs/<имя>.py --out modal_out/<имя>` на раннере GitHub;
  3. коммитит результаты в ту же ветку.
- **Ключи** — секреты репозитория GitHub. Добавляет их автор; в чат и в код они не попадают. Без ключей workflow ничего не делает. Способов два:
  - **один секрет `MODAL`** (с 14.11.2026, проще) — вся строка, которую Modal показывает при создании токена: `modal token set --token-id ak-… --token-secret as-… --profile=…`. Части `ak-…` и `as-…` workflow находит сам и прячет их в журнале (`::add-mask::`);
  - два секрета: `MODAL_TOKEN_ID` (часть `ak-…`) и `MODAL_TOKEN_SECRET` (часть `as-…`).
- **Почему через GitHub, а не из этой сессии.**
  - Главное: прокси сессии не пропускает gRPC и HTTP/2 (README прокси, раздел «Not supported through the proxy»), а клиент Modal говорит по gRPC. Проверено 14.11.2026 по README; запуск не пробовался — README велит не обходить.
  - Кроме того, защищённая форма сессии хранит один заголовок на хост, а Modal передаёт ключ в двух.
  - Раннер GitHub ходит в сеть напрямую.

## Подключение (делает автор, один раз)
1. **modal.com → Sign up**, войти через GitHub или Google. Способ оплаты **не добавлять**.
2. **В Modal: Settings → API Tokens → New Token.** Modal показывает не два поля, а команду: `modal token set --token-id ak-… --token-secret as-… --profile=…` и `modal profile activate …`. Секрет показывается один раз. Эту строку **не присылать в чат**.
   - Правка 14.11.2026: прежде здесь стояло «появятся Token ID и Token Secret». Это моё предположение без проверки (ERRORS № 147).
3. **На GitHub** открыть форму нового секрета: https://github.com/131ymm-commits/Neu/settings/secrets/actions/new. Это настройки репозитория Neu, не аккаунта.
   - **Name:** `MODAL`;
   - **Secret:** вся строка из Modal целиком, как есть;
   - кнопка **Add secret**.
4. **Написать Claude «готово».** Я запущу пробу `modal_jobs/probe.py`: несколько секунд процессора и видеокарты T4.
