# S2. Управление, оценивание, исследование операций, надёжность, контроль качества

Вопрос: как часто сверяться с настоящим измерением, когда между сверками система ведёт себя по внутренней модели.

Статусы чтения: «полный текст» не получен ни по одному источнику. «Аннотация» — только там, где видна страница с аннотацией (Booker 1999 по DOI; Janner 2019 по arXiv; Sutton 1990 по каталогу ICML). Остальное — «сниппет» (выдача поиска) или «по памяти». Имена и годы из задания проверены по выдаче; расхождения отмечены в разделе 4.

## 1. Итог

- Самое вероятное к переносу — **порог доли проверок** из Калмана с пропадающими измерениями (Sinopoli и др. 2004): если внутренняя модель уводит ошибку в `a` раз за раунд, а настоящая проверка приходит с долей `q`, то ошибка ограничена только при `q > q_c`. По лекционной формуле для диагонализуемого случая `q_c = 1 − 1/a²` (сниппет, не сверено с оригиналом). Это прямая формула «критической частоты проверок», но условия (линейность, гауссовость, стирание, а не отбор) у нас не выполнены.
- Второй по практичности — **Young (1974) / Daly (2006)**: оптимальный интервал между сохранениями `τ ≈ √(2δM)`. Переносится как `1/q* ≈ √(2δM)`, где `δ` — цена одной настоящей проверки, `M` — среднее число раундов до выхода ошибки за допуск. Нужны две оценки, которых у нас сейчас нет.
- Третье — **правило доверительной области** (Alexandrov и др. 1998; Conn — Scheinberg — Vicente): отношение «фактический прирост по правде / предсказанный моделью» решает, принять ли шаг по прокси и насколько сузить допустимый отбор по ней. Это ровно вопрос «предсказанное улучшение против настоящего».
- Для обнаружения, что прокси разошлась с правдой, годится **CUSUM** (Page 1954; Lorden 1971): статистика по разности «прокси минус экзамен» даёт сигнал «пора чаще проверять». Оптимальность Лордена доказана для одного изменения при независимых наблюдениях; у нас дрейф непрерывен.
- Для числа экзаменов, нужных для заданной ошибки, — **коэффициент информации** Russo — Van Roy: суммарный регресс ≤ √(Γ̄·H(A*)·T). Из него при желаемом регрессе ε за шаг получается T ≳ Γ̄·H/ε² (вывод, не из источника).
- Главный общий риск: все найденные формулы выведены для процессов, где модель независима от выбора, а ошибка стационарна. Наш показатель выбирается по себе, поэтому каждую формулу надо сначала проверить на пилоте (ворота CLAUDE.md), а не переносить.

## 3. Пять лучших кандидатов

**1. Порог доли проверок (Калман, п. 1).** Посчитать: в пилоте (на сиде, не входящем в тест) измерить `a` — среднее отношение рассогласования прокси между раундами без проверки, оценённое по логам, которые ещё не открыты; затем `q_c = 1 − 1/a²`, и проверить, что при `q < q_c` рассогласование растёт, а при `q > q_c` ограничено. Это единственная из найденных формул, которая даёт порог в явном виде. Обязательная оговорка: `p_c` зависит от метрики (Censi), поэтому порог надо задать мерой ИОИ заранее (`experiments/truth.py`).

**2. Оптимальный интервал между экзаменами (Young–Daly, п. 2).** Посчитать: `q* ≈ 1/√(2δM)` при оценке `δ` (стоимость одного экзамена в раундах отбора) и `M` (медиана раундов до выхода ошибки за допуск). Главное — проверить, что `M` дрейфовая, а не пуассоновская: иначе формула смещена. Это самая дешёвая проверка: две оценки из пилота, без новой теории.

**3. Коэффициент доверия к прокси (Alexandrov и др., п. 3).** Посчитать `ρ_t = (истинный прирост) / (предсказанный прирост)` на каждом экзамене и сравнить правило «сужать отбор по прокси при `ρ < η`» с фиксированным `q`. Это превращает вопрос «сколько проверок» в адаптивное правило с порогами, которые можно предрегистрировать. Условие сходимости (малая ошибка модели в радиусе) у нас не выполнено; поэтому правило — гипотеза для проверки, а не теорема.

**4. CUSUM по разности «прокси минус экзамен» (Page — Lorden, п. 8).** Посчитать ARL и задержку обнаружения при порогах `h`, сравнить с фиксированным расписанием `q`. Лордена-оптимальность здесь не гарантирована (дрейф непрерывен), так что результат — эмпирическое сравнение, а не вывод.

**5. Информационный коэффициент как граница числа экзаменов (Russo — Van Roy, п. 13).** Посчитать `Γ̄` из пилота как отношение квадрата регресса к взаимной информации между выбором и экзаменом, затем `T ≳ Γ̄·H/ε²`. Даёт число экзаменов, нужных для заданного регресса, и совпадает по форме с границей Хёфдинга с объединением из S4 (п. 7). Нужна байесовская постановка, которой у нас пока нет.

Честная пометка: MOPO (п. 6) — самый близкий к «оценке у самой оценки» по смыслу, но его гарантия не переносится, пока головы не дают честной оценки собственной ошибки. Macevicz & Oster (1976) с «бэнг-бэнг» расписанием (сначала рост, потом размножение) не подтверждён данными по колониям однолетних общественных насекомых (выдача по обзорам); для нашей задачи это предупреждение, что релейные решения часто не совпадают с наблюдаемым.
