## Итог

1. Поправка на отбор без знания априорного распределения реализуется формулой Твиди, но она требует стационарной маргинальной плотности наблюдений f(P) и известного σ. Отбор по поколениям эту стационарность ломает — это первое, что надо проверить в пилоте.
2. Для отбора по одному известному правилу (top-k или порог) точная условная поправка даёт Lee, Sun, Sun, Taylor (2016): распределение оценки при условии события отбора. Она не требует prior, но требует знать событие отбора в явном виде.
3. Граница Russo–Zou (смещение ≤ σ√(2I)) переводит «сколько бит о тестах утекло в отбор» в единицы разброса правды. Константы в версии 2016 г. под вопросом (поздняя статья использует исправленную версию); единица I — нат (по памяти), бит надо переводить через ln 2.
4. Адаптивная граница Dwork et al. и Feldman–Frostig–Hardt говорит, что доля свежих проверок q (или число классов m, аналог разнообразия голов) входит в завышение как k/n и √(k·log n/(m·n)). Это прямой кандидат на формулу для порога M3.
5. Gelman–Carlin (Type M) даёт коэффициент завышения значимой оценки как функцию мощности при заданном истинном эффекте. Это измеримая величина, а не теоретическая граница, и её можно предрегистрировать.
6. Ожидаемый максимум из N шумных оценок ≈ σ√(2 ln N) (по памяти, стандартная асимптотика) совпадает по виду с верхней границей Russo–Zou при I = ln N. Это общая база для сравнения.

## Пять лучших кандидатов: что посчитать у нас

1. **Твиди на поколениях (п. 1).** Посчитать E[T | P] = P + σ²·(ln f)′(P) на игрушечном отборе по зашумлённой оценке при известном σ. Сравнить два варианта f: маргинальная плотность по всем кандидатам каждого поколения и по одному поколению. Ожидание: поправка работает только при стационарной f. Записать в PREREG как ветвь и проверку.
2. **Точное условное решение для порога и top-k (п. 12).** Для отбора по порогу посчитать условное (усечённое) среднее оценки при событии отбора. Сравнить с поправкой Твиди на тех же данных. Это даёт «точное» значение завышения без prior (правило: слово «точное» только при полном переборе или аналитической формуле).
3. **Бит-граница Russo–Zou как мера утечки (п. 8).** Перевести I в биты через ln 2 и сравнить верхнюю границу σ√(2I) с эмпирическим завышением по лучшему из N на зафиксированном шуме; проверить, что граница не нарушается. Отдельно: при I = ln N граница совпадает по виду с σ√(2 ln N) — проверить эту эквивалентность на числах.
4. **Формула порога для доли свежих проверок q (п. 7).** Адаптировать k/n и √(k·log n/(m·n)) из Feldman–Frostig–Hardt: m — число разных классов решений (аналог разнообразия голов), n — размер свежей проверки. Предсказание: при росте m завышение падает; проверить на таблице из пилота, но без открытия json из experiments/*/runs (ограничение брифа).
5. **Type M как предрегистрируемая величина (п. 10).** Для нашего SE и ожидаемого эффекта вычислить коэффициент завышения значимого отбора по Gelman–Carlin до прогона и записать. Это проверяемое предсказание, а не граница: отчёт сравнивает его с ИОИ.
