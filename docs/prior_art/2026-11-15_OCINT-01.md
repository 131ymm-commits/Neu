## Вопрос 1. Несостоятельность обычного бутстрепа для изотонической регрессии (Гренандер)

**Что известно.**
- Обычный (непараметрический) бутстреп для оценки Гренандера в точке несостоятелен: распределение бутстреп-оценки не сходится по вероятности к предельному. Это показано для двух вариантов: выборка из эмпирической функции распределения и из её наименьшей вогнутой мажоранты.
- Причина, по выдаче: бутстреп-версия оценки не имеет квадратичной аппроксимации вокруг точки, которая есть у исходной оценки (Sen, Banerjee, Woodroofe 2010, с. 1968 по пересказу).
- Средство: m-из-n бутстреп при m = o(n) — слабо состоятелен (в выдаче — условие из версии на arXiv). Подвыборки (subsampling) упоминаются как работающие при m → ∞, m/n → 0; в практике — лишь при большом n.
- Расширение: Cattaneo и соавторы (arXiv 2303.13598) — бутстреп-ассистированный вывод для обобщённых оценок типа Гренандера; обычный бутстреп там тоже не работает.

**Источники.**
- Sen B., Banerjee M., Woodroofe M. (2010). *Inconsistency of bootstrap: The Grenander estimator*. Annals of Statistics, 38(4). DOI 10.1214/09-AOS777 — **сниппет** (выдача, arXiv 1010.3825 не открывается).
- Kosorok M. R. (2008). Бутстреп для оценки Гренандера (arXiv 0805.2470). Festschrift для P. K. Sen, IMS Collections, vol. 1, с. 282–292 — **сниппет**. Журнал «Statistics & Probability Letters», который я искал, в выдаче не подтверждён; не указываю.
- Cattaneo и др., arXiv 2303.13598 — **сниппет**.

**Что это значит для OCINT-01.** Наша статистика — не сама оценка Гренандера, но подгонка изотонической калибровки внутри выбора. Общий механизм (бутстреп не воспроизводит кусочно-постоянную структуру изотонической оценки) известен. Прямо для нашей статистики (выбор лучшей заявки + калибровка) — не найдено. Правило А и Б1 в гипотезе опираются на этот механизм: m-из-n и подвыборки — известные средства, их надо учесть при выборе M6/M7.

**Чего не нашёл.** Точного m-из-n условия для изотонической (не Гренандер) калибровки с логистической подгонкой; сравнения с n/2 в этой литературе нет.

## Вопрос 2. Складной нож с удалением d, половинные выборки, подвыборки

**Что известно.**
- Shao J., Wu C. F. J. (1989). *A general theory for jackknife variance estimation*. Annals of Statistics, 17(3), 1176–1197 — **сниппет**. По выдаче:
  - для гладких оценок удаление ограниченного d даёт состоятельную и асимптотически несмещённую оценку дисперсии;
  - для негладких (выборочные квантили) нужно d → ∞ с n^{1/2}/d → 0 и n − d → ∞.
- Shao J., Wu C. F. J. (1991), журнал *Statistics*, т. 22 — **сниппет** (по описанию в другой статье): delete-d оценки состоятельны, когда d — доля от n, при слабой дифференцируемости статистики.
- **Случай d = n/2.** Условие квантилей (n^{1/2}/d → 0 и n − d → ∞) при d = n/2 выполняется. Но это достаточное условие, а не разбор случая «половина»; проверяется по полному тексту 1989/1991 (там же — масштабирующий множитель, который для d ∝ n меняется). **Не проверено.**
- Balanced repeated replication (BRR): в идеальном случае — несмещённая оценка дисперсии для стратифицированных выборок (Wikipedia, сниппет; первоисточник не найден).
- Politis D. N., Romano J. P., Wolf M. (1999). *Subsampling*, Springer — **сниппет**. По выдаче: состоятельность подвыборок при слабых условиях, включая случаи, где бутстреп не работает; блоковый размер и условия m/n → 0 в выдаче не видны.
- Половинный бутстреп Politis–Romano — **не найден**.

**Что это значит для OCINT-01.** Половинные выборки без возвращения (M6, M7) имеют классическую теорию в виде delete-d/BRR при разумной гладкости. Для негладкой статистики (выбор наибольшей заявки) гладкость не гарантирована. Поэтому проверка M6/M7 на мирах с известной правдой — необходима; классическая теория её не заменяет.

**Чего не нашёл.** Теоремы для delete-half и половинного бутстрепа именно для статистик с выбором среди K моделей.

## Вопрос 3. Действующий размер выборки бутстрепа с кратностями; .632

**Что известно (выдача).**
- Повтор с возвращением = взвешенная подгонка с кратностями; эффективный размер (Kish: (Σw)²/Σw²) меньше n. Источник — arXiv (тема: тесты правдоподобия на бутстреп-выборках), **сниппет**; формулы n/2 там нет.

**Моя проверка (не источник).**
- Для мультиномиальных кратностей: E w_i = 1, Var w_i ≈ 1 − 1/n, E w_i² ≈ 2, Σw² ≈ 2n, ESS = n²/(2n−1) ≈ n/2. Значит, n/2 — верная величина ESS для весов, но **это не размер выборки для любой статистики**.
- Контрпример: для выборочного среднего бутстреп-дисперсия (1−1/n)s²/n — правильная, без «половинения». Поэтому механизм n/2 для OCINT-01 **не может быть общим**: он должен работать через подгонку с весами, которая меняет форму функции (изотоническая, логистическая калибровка) и выбор. Это гипотеза, её надо проверять (правило А), а не считать известной.
- .632: доля различных наблюдений в бутстреп-выборке 1 − (1 − 1/n)^n → 1 − 1/e ≈ 0,632 (вывод, не источник). Коэффициент .632 в оценке ошибки Эфрон (1983) — это весовой коэффициент смеси оптимизма и кажущейся ошибки, а не размер выборки; связи между ними в литературе, которую я видел, нет.

**Источники.**
- Efron B. (1983). *Estimating the error rate of a prediction rule: improvement on cross-validation*. JASA, 78(382), 316–331 — **сниппет** (метаданные и PDF-ссылка; текста не открыл). Формулу .632 — **по памяти**.
- Efron B., Tibshirani R. (1997). *Improvements on cross-validation: the .632+ bootstrap method*. JASA, 92(438), 548–560 — **сниппет**. По выдаче: бутстреп-оценки — сглаженные варианты кросс-валидации с меньшим разбросом и повышенным смещением; .632+ поправляет смещение.

**Что это значит для OCINT-01.** Гипотеза «повторы ведут себя как выборка n/2» имеет под собой математику (ESS), но литературной опоры для связи с .632 и для статистик выбора не найдено. Это свободная ветвь с проверкой на мирах.

## Вопрос 4. Интервалы после отбора (проклятие победителя, post-selection)

**Что известно.**
- Smith J. E., Winkler R. L. (2006). *The optimizer's curse: skepticism and postdecision surprise in decision analysis*. Management Science, 52(3), 311–322. DOI 10.1287/mnsc.1050.0451 — **сниппет** (статус «по памяти» в OCSHIFT-01 теперь поднят до сниппета). По выдаче: выбор варианта с наибольшей оценкой даёт реализованное значение ниже оценки даже при несмещённых оценках; предлагаемое средство — байесовская поправка. Есть исправление к рис. 3 (ожидаемое «разочарование» больше, чем в статье); качественные выводы не меняются.
- Hong H., Kuffner T., Martin R. — по пересказу в препринте arXiv 2607.12445 (2026): бутстреп может не исправлять эффект отбора у методов, склонных к переобучению; связывается с феноменом дилатации Эфрона — **сниппет, пересказ второго порядка**.
- Rink и Brannath (Machine Learning, 2025): бутстреп с наклоном (tilting) и поправкой на множественность (maxT) для нижней границы качества выбранной модели — **сниппет**.
- Andrews и др. (2023): условный вывод через инверсию условного теста — **сниппет**.
- В препринте arXiv 2607.12445 (постселекционная конкордантность): наивный процентильный бутстреп теряет покрытие с ростом числа кандидатов K (одношаговый: 0,70 при K = 100, по собственным симуляциям авторов, не проверено) — **сниппет**.

**Что это значит для OCINT-01.** Наивный интервал вокруг выбранной заявки известно недо-покрывает; рекомендуемые средства — выбор-учитывающий бутстреп или условный/одновременный вывод. Это прямо подтверждает, что M1–M3 (с возвращением) — неадекватный выбор для S1/S3-подобных статистик. Но выбор-учитывающие методы в этих работах — для AUC/конкордантности и для нижних границ, не для калиброванной заявки ИОИ.

## Замечание для проверки (не вывод)
Гипотеза пункта 3 говорит, что размер n/2 объясняет сдвиг повторов **в целом**. Для выборочного среднего бутстреп даёт правильную дисперсию, поэтому механизм ESS работает только через подгонку с весами, меняющую форму функции. Это надо учесть в правиле А и в мирах (пилот на сиде вне теста), а не считать установленным.
