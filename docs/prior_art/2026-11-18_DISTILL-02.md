# Кто раньше: DISTILL-02 «ПРОГРАММА-ГОЛОВЫ»

Дата: 18.11.2026. Ворота 2 перед PREREG (CLAUDE.md, «Литература»). Гипотеза: `experiments/2026-11-18_DISTILL-02/HYPOTHESIS.md`. Прежняя разведка: `docs/prior_art/2026-11-17_DISTILL-01.md` и `experiments/2026-11-17_DISTILL-01/NOTE-DISTILL-01.md`. Здесь — только новое сверх неё.

## Зачем

Проверить, занято ли четыре пункта гипотезы:
1. дистилляция поведения LLM в короткую программу или формулу;
2. механизм ошибок переноса при сложении;
3. одинаковые неверные ответы у разных LLM и нуль для них;
4. генеративная модель ошибок «вычислителя» в готовой форме программы.

## Итог в три строки

- **Ни один пункт не свободен целиком.** Каждый занят с другой стороны: кто-то уже делает метод, механизм или нуль, но не в нашей форме.
- **Ближе всего к пункту 1** — SymTorch (Tan, Soubki, Cranmer, arXiv 2602.21307): символьная регрессия поведения LLM на сложении трёхзначных чисел, §4.5. Одна модель, одна задача, непрерывная формула, без ошибок по разрядам.
- **Ближе всего к пункту 4** — Wen и др. (arXiv 2606.03645): генеративная модель «шум на потенциале переноса → ошибка ±1». Проверена на одной модели (Qwen3-4B). Её признак Φ считается из входа. Это **сильный конкурент** для наших признаков (см. «Что меняет постановку»).

## 1. Работы arXiv с полным текстом (или частичным)

### 1.1. Tan E. S. Z., Soubki A., Cranmer M., «SymTorch: Symbolic Distillation of Neural Networks» — arXiv 2602.21307, 24.02.2026
**Статус:** полный текст (аннотация и §4.5 прочитаны дословно).
**Что занято.** Символьная дистилляция компонентов сети в замкнутую формулу (PySR). В §4.5 «Uncovering biases in LLM-learned arithmetic»: модель Llama-3.2-1B-Instruct, сложение двух трёхзначных чисел, символьная регрессия по «вход–выход». Таблица 1: для сложения «Expected Equation x0+x1», «LLM-Learned Operation» — формула с `inv(...)`. Авторы пишут: «reveals how, and where, the model's internal heuristics deviate from the intended operations».
**Наше отличие.** Одна модель. Формула дана по непрерывным операндам, не по разрядам. Нет вероятности ошибки по разрядам и нет переноса. Нет семи голов и нет проверки неверных чисел на свежих задачах. Вывод «есть ли перенос» не делается.
**Вес:** препринт — 0 бит.

### 1.2. Deng C. и др., «Language Models are Symbolic Learners in Arithmetic» — arXiv 2410.15580, 21.10.2024 (v2 — 26.01.2026)
**Статус:** полный текст (частично): аннотация дословно, разделы о подгруппах и энтропии прочитаны по найденным местам.
**Что занято.** Цитаты дословно:
- «LMs act as greedy symbolic learners, prioritizing the simplest possible shortcuts».
- Подгруппа — это «minimal mappings between a few input digits and a single output digit».
- Мера ошибок по входу: «subgroup entropy is a better measure for estimating errors in arithmetic learning tasks» (раздел о возмущениях, сложение и умножение как базы).
Сложение и умножение — два базовых оператора (раздел о выборе операторов в скачанном тексте). Модели дообучались (Gemma-2-2B, Llama-3.1-8B), не готовые головы.
**Наше отличие.** У них — символьные «короткие пути» и мера по входу для дообученных моделей. Наше — логистическая формула вероятности **ошибки** головы из ≤ 3 признаков, с проверкой неверных чисел. Энтропия подгрупп — **конкурент** как базовая мера трудности по входу.
**Вес:** журнал (TMLR 2026 по выдаче mlanthology; в тексте v2 — «Reviewed on OpenReview») × аннотация = 1,0 бит.

### 1.3. Wen L. и др., «The Shape of Addition: Geometric Structures of Arithmetic in Large Language Models» — arXiv 2606.03645, 29.05.2026
**Статус:** полный текст (частично): аннотация, §5.1–5.2, подпись к рис. 5. Статус в DISTILL-01 был «сниппет» — теперь текст скачан и прочитан по этим разделам.
**Что занято.** Цитаты дословно:
- «framing arithmetic errors as Geometric Slippages caused by internal neural noise pushing a continuous, latent Carry Potential across quantization thresholds».
- Φ_p = Σ_j r_{p+j}/10^j (формула 3): «the theoretical accumulation of numerical value flowing from lower-order positions». Φ — функция **входа** (сумм разрядов). Истинный перенос — целая часть Φ.
- Перцептивная оценка Φ̂ = Φ + ε, ε ~ N(0, σ²) (формула 4).
- Рис. 5: ошибки ±1 дают «periodic bathtub shape», пик у целых границ; теоретическая кривая «fits the data with high fidelity (R² = 0.80), estimating the model's internal noise level at σ ≈ 0.05».
Модель измерена на Qwen3-4B (раздел «we perform all experiments in the main text using the Qwen3-4B model»).
**Наше отличие.** Wen даёт вероятность ±1 по расстоянию Φ до границы, на одной модели, по «узкому» виду ошибки. Наше — вероятность потери переноса по признакам разряда и на семи головах, без Φ. **Признак Φ должен войти в PREREG как базовый** (см. ниже).
**Вес:** препринт — 0 бит.

### 1.4. Baeumel T. и др., «Modular Arithmetic: Language Models Solve Math Digit by Digit» — arXiv 2508.02513, 04.08.2025
**Статус:** полный текст (частично): §4.2 и вывод прочитаны дословно.
**Что занято.** Модели: LLaMA3-8B, LLaMA3-70B, OLMo 2 7B, Gemma 2 9B (не наши головы). Вывод дословно: «carry information is likely determined and processed by separate mechanisms, rather than being embedded in the digit-position circuits». То есть перенос — отдельная схема. Это механизм, согласный с моделью «потери переноса по разряду».
**Наше отличие.** Механизм, не поведение. Не формула, не вид ошибки, не семь голов.
**Вес:** препринт — 0 бит.

### 1.5. Yan Y. и др., «Do Large Language Models Truly Grasp Addition?» — arXiv 2504.05262, 07.04.2025
**Статус:** полный текст (частично): аннотация дословно.
**Что занято.** Вывод дословно: «current LLMs address elementary addition via pattern matching, not robust rule induction». Явные правила ухудшают результат на 29,49 % («explicitly providing rules degrades performance by 29.49%»).
**Наше отличие.** Диагностика, не программа. Важно как **предостережение**: программа «прочитанная вслух» не должна выдаваться за механизм.
**Вес:** препринт — 0 бит.

### 1.6. Yan Yao, «Addition in Four Movements» — arXiv 2506.07824, 09.06.2025
**Статус:** аннотация (дословно).
**Что занято.** Пробинг LLaMA-3-8B-Instruct: «mid layers expose digit-wise sums and carry indicators» — линейные пробы переноса. Это **внутреннее** представление переноса, не ошибка.
**Наше отличие.** Не поведение и не ошибки.
**Вес:** аннотация, работа на конференции с рецензией по выдаче поиска (Findings of EMNLP 2025) → класс «журнал» × аннотация = 1,0 бит. Отмечаю: venue по выдаче поиска, не проверен по странице ACL.

### 1.7. Ding K., «When LLMs Agree, Are They Right?» — arXiv 2607.08065, 09.07.2026
**Статус:** полный текст (частично): раздел «Confident errors are partly shared across families» и подпись к таблице 8 прочитаны дословно.
**Что занято.** Нуль для совпадения неверных ответов — **перестановка меток, которая сохраняет распределение неверных ответов каждой модели**:
- «we test the same-wrong-answer rate (among items both get wrong) against a label-permutation null that preserves each model's empirical wrong-answer distribution».
- Результат: наблюдаемая частота выше нуля для трёх тиров Claude, значимо для двух (p = .003, .005). Работа сама говорит: «exploratory», «No inferential claim in this paper is preregistered».
Домен — GPQA (вопросы с выбором), не сложение.
**Наше отличие.** Их нуль сохраняет распределение по модели, но не узор входа. Наш нуль переставляет смещения внутри страт по признакам входа. Идея нуля **занята**, наш вариант — нет. Кроме того, узор переносов как страту для нуля уже берёт OCDIV-04 (записка `docs/prior_art/2026-11-18_OCDIV-04.md`).
**Вес:** препринт — 0 бит.

### 1.8. Balasubramanian K. и др., «Dependence-Aware Label Aggregation for LLM-as-a-Judge via Ising Models» — arXiv 2601.22336, 29.01.2026
**Статус:** аннотация (дословно) и начало введения.
**Что занято.** Дословно: классические агрегаторы (Dawid–Skene, взвешенное большинство) «assume annotators are conditionally independent given the true label». Ising-модель зависимостей. Задача — агрегировать голоса при **известной** метке для обучения.
**Наше отличие.** Не нуль для совпадения ошибок, а агрегирование. Для пункта 3 не опора по нулю, а предупреждение: при зависимости голосов агрегатор переоценивает общее.
**Вес:** препринт — 0 бит.

### 1.9. Chlenski P. и др., «Surrogate Fidelity: When Can Open LLMs Explain Closed Ones?» — arXiv 2606.32008, 30.06.2026
**Статус:** полный текст (частично): определение «prediction fidelity» и вывод о нём.
**Что занято.** Мера верности суррогата по ответам. Дословно: «Prediction fidelity is a useful screen, but it consistently overstates agreement at the level needed for explanation».
**Наше отличие.** Относится к пункту 1 как к мере. Предупреждает: совпадение ответов завышает согласие, значит П1 («воспроизводит неверные числа») нужно проверять и по **неверным** числам, и по вероятностям, а не только по совпадению ответов.
**Вес:** препринт — 0 бит.

## 4. Что меняет постановку (рекомендация, не решение)

1. **Признак Φ (Wen) — обязательная база в PREREG.** Φ_p = Σ r_{p+j}/10^j считается из входа. Если логистика по трём признакам не обгоняет логистику по Φ-расстоянию до границы, П2 не даёт нового. Записать: сравнение с «Φ-базой» до прогона.
2. **Энтропия подгрупп (Deng) — вторая база по входу** для П1 и П2. Это входная мера трудности, которую не надо смешивать с нашими признаками.
3. **Символьная формула I/O (SymTorch §4.5) — база для П1.** Если наша программа не лучше непрерывной символьной формулы на тех же признаках, она не дистилляция, а описание.
4. **Нуль для П3.** Нуль Ding сохраняет распределение неверных ответов каждой модели. Записать в PREREG, что наш нуль сравнивается с ним, и почему наш берёт программу, а не распределение.
5. **Вид ошибки «−10^k».** Wen называет ошибки ±1 «off-by-one». Наша «потеря переноса» — это тоже сдвиг на один разряд. В PREREG разделить категории по правилу и записать, как они не пересекаются.
6. **Предостережение (Yan 2504.05262).** Программа, прочитанная вслух, не доказывает механизма. В отчёте писать «описание поведения», не «механизм», пока не проверено.
