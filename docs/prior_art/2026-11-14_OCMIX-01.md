## 2. Кто раньше

- **Ровно связки «уверенность головы для отбора, согласие других голов — вето» с проверкой самообмана на верхушке отбора вне диапазона калибровки в выдаче нет.**
- Части механизма описаны:
  - согласие как фильтр (2602.11619);
  - несогласие между моделями поверх уверенности одной модели (2604.17112);
  - общие ошибки делают согласие плохим проверяющим (2603.06612, 2502.04313, 2506.07962);
  - отбор по уверенности ломается при сдвиге (2307.02764).
- **Итог: занято частично.** Поиск ограниченный (выдача, без полных текстов), поэтому «свободно» не утверждается.

## 3. Что важно для постановки
- Вето отсекает только ответы без поддержки. Против общей ошибки голов оно не помогает: если две головы уверенно дают один неверный ответ, вето его пропускает (2603.06612, 2604.17112). Это надо видеть в разборе: верхушка VETO против CONF, доля поддержанных выбранных ответов.
- ODP-Bench (модели зрения) говорит обратное о сдвиге: согласие там переживает сдвиг лучше калибровки. Наш прежний результат (OCCOR-01, C-088) — против этого на арифметике с Pythia.
