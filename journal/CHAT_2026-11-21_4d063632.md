## Математика
Она короткая: одна целевая функция и определения записей памяти, без обучения и теорем.
- **Цель:** max по памяти 𝓜 от E[R(π^S(s; 𝓜))], то есть доля задач, решённых учеником с памятью. Никакой алгоритм эту максимизацию не выполняет, память строится по фиксированному рецепту.
- **Память:** только из успешных траекторий учителя, три уровня:
  - Workflow — словесная стратегия;
  - Subtask — метка, описание и исполнимый отрезок кода;
  - Function — имя функции, пример вызова, документация.
- **Выборка:** косинус вложений, одна ближайшая запись на уровень. Workflow и Subtask подставляются до начала задачи, Function — только после ошибки вызова.
