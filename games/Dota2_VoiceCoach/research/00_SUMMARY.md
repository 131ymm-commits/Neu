# 00. Сводка исследования (06.10.2026)

Четыре агента-исследователя искали в интернете по темам 01–04 (файлы рядом, у каждого факта
статус «полный текст / сниппет / по памяти / свой прогон»). Ниже — что из этого следует для игры
и что я, координатор, перепроверил вторым способом (по коду и дампам, а не по пересказу).

Ограничения поиска: из контейнера закрыты developer.valvesoftware.com, moddota.com, steamcommunity,
reddit, opendota/stratz и серверы реплеев Valve; открыты GitHub, npm, PyPI, Maven. Общий лимит
веб-поиска (200 запросов на ход) кончился к концу работы, поэтому часть фактов осталась на сниппетах.

## Главное за одну минуту

1. **Аркада Доты сейчас живёт на ПК игроков.** С августа–сентября 2026 Valve не даёт кастомкам
   выделенных серверов; матч хостит машина одного из игроков. Матч, созданный в аркаде, **не может
   слать HTTP** с сервера, но друзья подключаются; матч, запущенный из Tools/консоли, HTTP шлёт, но
   **подключиться к нему никто не может**. Единственный рабочий канал с внешним миром в аркаде —
   скрытая веб-панель `DOTAHTMLPanel` у клиента игрока (только GET, ответ в заголовке страницы
   до 4096 символов). Проверено: README Windy10v10AI (02.10.2026), см. таблицу ниже.
2. **10 героев под ИИ в кастомке — проверенный путь.** `Tutorial.AddBot` + встроенные боты на
   стандартной карте `dota`, поверх — свой ИИ на vscripts (`ExecuteOrderFromTable`). Так работает
   опубликованная и живая кастомка Windy10v10AI (TypeScript, ~22,7 тыс. строк ИИ с тестами,
   лицензия GPL-3.0 с исключением для Steam). Выключатель встроенных ботов глобальный (обе команды).
3. **Lua-боты (bot scripts) работают только в лобби «Local Host».** Лучший открытый набор —
   Open Hyper AI: MIT, 127 героев, патч 7.41/7.41a, русская локализация, свой HTTP из ботов
   (`CreateRemoteHTTPRequest`), разбор команд из чата. В опубликованной кастомке bot scripts, по
   единственному свидетельству (2017), не работают.
4. **Голос.** Цель «≤ 1 с от конца фразы до команды» достижима только без LLM на пути команды:
   нажми-и-говори → локальное распознавание → разбор по словарю. Лучший офлайн для русского —
   GigaAM v3 (MIT, CPU; WER 8,3% против 21% у Whisper large-v3 по замерам авторов); лёгкий запасной —
   Vosk с грамматикой; без установки — Web Speech в Chrome (облако Google). LLM — запасной разбор
   и характер агентов. Голосовые игры удавались там, где словарь маленький и виден игроку (EndWar).
5. **Оцифровка.** Готовых полей OpenDota хватает на статистический профиль (пул героев, сборки,
   тайминги, агрессия, варды, позиции). Для микро-стиля и модели решений нужен свой разбор .dem:
   в реплее есть все приказы каждого игрока (тип, точка, цель, способность), 30 тиков/с.
   Реплеи пабов живут ~1–2 недели — данные обычного игрока собирать сразу. Пабы топ-игроков
   (Immortal Draft, ≥ 8500) закрыты с 19.03.2025 — про-игроков оцифровывать по турнирным матчам.
   Приказы в реплее и в `ExecuteOrderFromTable` — одно перечисление (значения 0–35 совпадают).
6. **Этика.** Двойник человека — инструмент опознания. Обычных игроков оцифровывать только с
   согласия; известных про в публичной сборке без разрешения — безымянными «архетипами».
7. **ИИ героев.** RL «как OpenAI Five» без кластера невозможен; LLM — только макро и общение.
   Стиль игрока — вектор параметров на слоях (команда → режим героя → микро → исполнитель).

## Что это значит для игры (решения — в docs/DECISIONS.md)

- **Сразу играбельный прототип** — лобби Local Host с ботами OHA (хорошее микро на 127 героях уже
  есть) и нашим слоем «тренер»: боты сами опрашивают сервер тренера на localhost и поднимают
  желания нужных режимов. Это быстрее всего показывает, весело ли командовать голосом.
- **Итоговая кастомка** — свой ИИ на vscripts (основа — ИИ Windy10v10AI, если человек согласен на
  GPL-3.0; иначе пишем свой по их схеме), голос через веб-панель клиента, 2 тренера в аркаде.
- **Пробник платформы** — маленький аддон, который на ПК человека за один запуск отвечает на
  открытые вопросы (папка bots в аддоне, каналы к ботам, тренер без героя, HTTP в Tools).

5. Сколько матчей нужно на устойчивый профиль (пилот: ICC, формула Спирмена–Брауна).
