# Голосовой тренер Dota 2 (рабочее название)

Кастомка Dota 2 на двух игроков: каждый — тренер своей команды из пяти ИИ-агентов. Агенты играют
«цифровыми двойниками» реальных игроков — от звёзд до любого игрока, хоть с 2 MMR. Тренер не
кликает героев: он отдаёт приказы — сейчас текстом в коротком формате, в чате игры или на странице
тренера (`1 фарм лес. 23 ганг мид. все рош`; голос отложен по решению автора 07.10.2026, Д9), — а
каждый агент сам делает своё микро в своём стиле. Каждого героя ведёт свой агент Claude (решение автора
07.10.2026, Д11: «Нет играют не боты доты а агенты Клауд. За каждого Героя свой»).

Задача автора (06.10.2026): «Тренер доты. Голосовое управление 5 агентами с навыками известных
игроков. Отцифровать игроков по файлам или видео. В итоге — кастомка на 2 игроков… ИИ в начале —
поиск в интернете». Срок — около двух месяцев.

## Играть вдвоём — два файла (Д14)

1. **Вы (хост, Windows, Dota 2 с бесплатным дополнением Workshop Tools):** скачайте и запустите `ИГРАТЬ.bat`
   (https://github.com/131ymm-commits/Neu/blob/ccr-9d6c6e9e-yuegyb/games/Dota2_VoiceCoach/ИГРАТЬ.bat → «Download raw
   file»). Он сам поставит всё нужное, один раз спросит, как думать героям (с подпиской Max — ключ API из её
   кредита, без доплат; Д15), и запустит Доту с кастомкой — вы тренер Света.
2. **Друг:** при первом запуске лаунчер покажет файл `ДЛЯ_ДРУГА.html` — отправьте его другу один раз. Друг открывает
   его двойным щелчком: файл сам найдёт вашу игру и откроет пульт Тьмы в браузере. Дальше каждый раз так же.
3. **Закончить игру** — Enter в окне `ИГРАТЬ.bat`.

Windows может спросить «Защитник Windows предотвратил запуск» — «Подробнее» → «Выполнить в любом случае».
Как это устроено — `docs/DECISIONS.md`, Д14.

## Попробовать сейчас

Пошагово для Windows — `docs/FIRST_RUN.md` (команды без Доты → оцифровать себя → матч с ботами).
Коротко (нужен Python 3.11+):

```
cd games/Dota2_VoiceCoach/coach
python -m voicecoach.server
```
Открыть `http://localhost:8787` и писать команды: `1 фарм лес. 23 ганг мид. все рош` — на странице
видно, кому что ушло; шпаргалка там же и в `docs/COMMANDS.md`. Оцифровать себя (нужен открытый профиль OpenDota):
```
cd games/Dota2_VoiceCoach/digitizer
python -m twin.cli profile --account <ваш account_id> --limit 50 --name "Вася" --alias вася --out profiles/vasya.json
python -m twin.cli agent --profile profiles/vasya.json --out agents/vasya.json
```
