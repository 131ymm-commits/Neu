# Голосовой тренер Dota 2 (рабочее название)

Кастомка Dota 2 на двух игроков: каждый — тренер своей команды из пяти ИИ-агентов. Агенты играют
«цифровыми двойниками» реальных игроков — от звёзд до любого игрока, хоть с 2 MMR. Тренер не
кликает героев: он говорит голосом («Миракл, фарми лес, остальные на Рошана»), а каждый агент сам
делает своё микро в своём стиле.

Задача автора (06.10.2026): «Тренер доты. Голосовое управление 5 агентами с навыками известных
игроков. Отцифровать игроков по файлам или видео. В итоге — кастомка на 2 игроков… ИИ в начале —
поиск в интернете». Срок — около двух месяцев.

## Попробовать сейчас

Пошагово для Windows — `docs/FIRST_RUN.md` (голос без Доты → оцифровать себя → матч с ботами).
Коротко (нужен Python 3.11+):

```
cd games/Dota2_VoiceCoach/coach
python -m voicecoach.server
```
Открыть в Chrome `http://localhost:8787`, держать кнопку (или пробел) и сказать команду — на
странице видно, во что она превратилась. Оцифровать себя (нужен открытый профиль OpenDota):
```
cd games/Dota2_VoiceCoach/digitizer
python -m twin.cli profile --account <ваш account_id> --limit 50 --name "Вася" --alias вася --out profiles/vasya.json
python -m twin.cli agent --profile profiles/vasya.json --out agents/vasya.json
```

## Тесты

```
cd coach && python -m unittest            # разбор и сервер

cd game && pip install lupa && python -m unittest   # Lua под LuaJIT
```
