# Пилот промпта агента героя (07.10.2026)

**Что это.** Пилот (ворота 1), не опыт: без предрегистрации, в реестр утверждений не идёт, вердикта нет. Цель —
до первого матча у автора проверить, что промпт агента (`coach/voicecoach/agents.py`: `system_prompt`, `user_prompt`)
даёт решения, которые принимает разбор (`parse_decision`) и которые разумны в типовых ситуациях.

**Как.** Пять ситуаций собраны настоящим кодом кастомки: наблюдение строит `coach_obs.lua` на имитации Доты под LuaJIT
(`make_scenarios.py`; способности героев переименованы в настоящие), промпты — из `agents.py`. Каждую ситуацию отдал
голове Claude через Agent (подагент читал только два файла: системный промпт и сообщение игры), двумя моделями:
самой быстрой и средней (в файлах — `fast` и `mid`). Это не путь API: нет structured outputs, в контексте подагента
есть его собственный системный промпт, задержка не мерилась. В каждом запросе — последнее сообщение автора дословно
(правило ERRORS № 31). Ожидания записаны до ответов (`EXPECT.md`) и лежали вне папки, которую читали головы.

## Что поменял в промпте по пилоту

- Раунд 2 (после раунда 1): быстрая модель дважды поставила `retreat_hp: 0` (никогда не отходить) — в промпт добавлено
  «обычно 25–40; 0 — только осознанно»; в ситуации 5 сказала тренеру «Ставлю вард на руну», хотя руки ставят варды
  только у своих вышек, — в промпте уточнено, где руки ставят варды и что сказать тренеру честно; «после выкупа или
  возрождения выбери план».
- Раунд 3: быстрая модель мёртвой с 4200 золота не заказывала покупок ни в раунде 1, ни в 2 — сервер теперь сам
  дописывает в сообщение напоминание, когда герой мёртв или у фонтана, золота от 600 и очередь покупок пуста.

Правки — гипотезы для первого матча, а не проверенное улучшение: по одному ответу на ситуацию (урок ERRORS № 76).

## Что не проверено

Путь API (structured outputs гарантируют JSON — пояснения вокруг JSON, как в двух ответах быстрой модели, там
невозможны), задержка и цена, поведение на длинной игре (память агента, повторяющиеся решения), характеры из оцифровки.
