# Живой вызов мотора `cli` с настоящими промптами (08.10.2026)

**Что это.** Пилот, не опыт: без предрегистрации, в реестр утверждений не идёт. Цель — проверить на настоящем
Claude Code путь мотора `cli` (`coach/voicecoach/agents.py`, класс `CliBackend`, без подмен) и получить первые числа
для расчёта цены: сколько токенов уходит на решение, сколько думает модель, сколько ждать ответа.

**Как.** `live.py`: две ситуации прошлого пилота (`../2026-10-07_agent_prompt/s3_obs.json` — драка на миде, `s1_obs.json` —
линия на 2:30), системный промпт и сообщение — из текущего `agents.py`, вызов — `CliBackend.decide` с `effort="low"`.
Модели: самая быстрая (алиас Claude Code) и модель Claude Code по умолчанию — средняя. Claude Code 2.1.294 в облачном
контейнере сессии, Linux, вход сессии. Флаги — как у сервера: `-p --output-format json --safe-mode --system-prompt-file …
--tools "" --disallowedTools "mcp__*" --no-session-persistence --json-schema … --effort low`. Имена моделей в
`results.json` заменены метками `fast`/`mid`.

## Токены — что из этого следует для расчёта цены

Claude Code оборачивает наш промпт своим (схема ответа как инструмент и служебный текст), поэтому числа — верхняя
оценка для мотора `api`:
- общий кэшируемый префикс (системный промпт и обвязка) — 3817 токенов (`cache_read` во втором вызове);
- часть, своя у каждого вызова (наблюдение, приказы), — ≈ 2,3 тыс. токенов на 1,9 тыс. знаков сообщения: JSON
  с русскими словами и числами дорог в токенах;
- ответ: средняя модель — 0,3–0,4 тыс., быстрая — 0,6–1 тыс. токенов с думанием.

Расчёт цены матча по этим числам — `docs/CLAUDE_AGENTS.md`, раздел «Цена и задержка».

## Ограничения

Два вызова на модель — это пилот, а не замер: разброс задержки и длины ответа неизвестен. Наблюдение матча растёт
(память агента, голосовой чат), поэтому часть «своя у вызова» к середине игры больше. Цена — оценка Claude Code по
ценам API; при входе по подписке это не списание.
