## Метод

Из корня репозитория:

```
cd games/Dota2_VoiceCoach/experiments/2026-10-07_PARSE-02
python3 secondary.py s1        # согласие разметок → agreement.json (после коммита этой записи, до прогона)
python3 run_parse02.py new     # правда A, нынешний разборщик     → result.json, result_log.txt
python3 run_parse02.py old     # правда A, разборщик 75dc796       → result_prefix.json, result_prefix_log.txt
python3 run_parse02.py newB    # правда B, нынешний разборщик     → result_B.json, result_B_log.txt
python3 secondary.py after     # S2–S5 и сравнение с PARSE-01      → secondary_result.json
```

Правила зачёта (`eval_heldout.py`): команда совпала — то же действие, тот же набор позиций, каждый
ожидаемый параметр равен (лишние параметры не штрафуются; переспрос не совпадает с командой с
адресатом); фраза верна — все ожидаемые команды найдены, лишних нет; для `clarify: true` — также
переспрос при точных остальных командах; фраза-сведение (пустой список, `clarify: false`) верна, только
если разборщик ничего не выдал. Контекст создаётся заново для каждой фразы.

**Главная мера:** доля верных фраз по A, `summary.phrase_ok` из 80, 95% интервал Уилсона.
**Разбивка** — пять категорий поля `category` (simple, multi, modal, hard, asr), задана набором до
прогона. Полнота и точность по командам — точечно, без интервала (команды внутри фразы зависимы).

**Вторичные меры** (код — `secondary.py`, определения — в его заголовке):

- S1 — согласие A и B: обе `clarify: true`, либо обе `false` и списки команд равны как мультимножества
  (действие, отсортированные позиции, параметры равны как словари; пропуск параметра и `"auto"`
  различаются). Знаменатель — 80 id A. Считается до прогона разборщика. Из-за подсказок B (см. «Данные»)
  — верхняя оценка независимого согласия. S1′ — то же без фраз, где у A пустой список.
- S2 — доля верных по A среди согласованных фраз (знаменатель — S1), Уилсон.
- S3 — доля верных, если правда — B (`labels_B_eval.jsonl`: id, категория, текст — из A; ответ — из B),
  Уилсон; проверка: ответы разборщика совпадают с `result.json`.
- S4 — парное сравнение с разборщиком до правок на тех же 80 фразах по A: b — верно только у нового,
  c — только у старого; точный двусторонний тест Мак-Немара (биномиальный, полный перебор); разница
  долей с 95% бутстрэп-интервалом (10 000 повторов по фразам, сид 20261007). Это единственная проверка
  с порогом значимости в серии: общий ложный уровень — 0,05.
- S5 — строгая доля: ответ равен разметке A как мультимножество, параметры протокола v1 сравниваются
  полностью (лишний параметр протокола — ошибка; внутренние параметры разборщика, например
  `push.group`, не учитываются); для `clarify: true` — так же либо переспрос и точные остальные команды.
  Плюс число фраз, верных по главному правилу только за счёт переспроса.

**Сравнение с PARSE-01 — описательное, не проверка:** меняются и разборщик (75dc796 → 937e7cb), и
набор (автор, сторона, имена, доли категорий, asr, самоисправления в modal). Числа PARSE-01 — из
`../2026-10-06_PARSE-01/result.json` (первый прогон): simple 24/27, multi 13/27, modal 13/13,
hard 7/13, всего 57/80. Даются разницы PARSE-02 − PARSE-01 — общая, без asr (70 фраз) и по четырём
общим категориям — с 95% интервалом Ньюкомба (гибрид Уилсона). Слов «лучше/хуже» нет; ответ на
вопрос «обобщились ли правки» даёт только S4.

**Мощность.** При n = 80 и доле ≈ 0,7 полуширина 95% интервала ≈ 0,10. Для двух независимых долей по
80 фраз граница значимости на 5% (двусторонне) ≈ 0,14; с мощностью 80% обнаружима разница ≈ 0,20.
По категориям (n = 10–20) полуширина Уилсона 0,14–0,26 — сравнения описательные. Мощность S4 зависит
от числа несогласных пар b + c и до прогона неизвестна; при b + c = 12 значимо (p < 0,05) только
10 : 2 и крайнее.

## Ограничения (известны до прогона)

- Словарь набора частично подсказан автором разборщика: сленговые имена героев, примеры падежей и
  Dire-линии в промпте A взяты из того, что разборщик уже знает. Набор не меряет полноту сленга;
  для живой речи оценка завышена. Для PARSE-03 — только английские имена героев в промпте или
  предметный раздел промпта от другого агента.
- Порядок команд, `after_prev` и `urgent` не проверяются (в разметке их нет): в modal проверяется,
  что команды извлечены, но не «потом» и «срочно».
- Лишние параметры по главному правилу не штрафуются (это ловит S5); фраза-сведение засчитывается и
  разборщику, который просто ничего не понял.

## Правило после прогона

Первый прогон — единственная честная мера. Разбор ошибок и правки после него — пост-хок, вердикты не
меняют; набор PARSE-02 после правок переходит в регрессию. Следующая честная мера — записи живой речи
человека или PARSE-03. Результат оценивает совет голов (правило автора 28.09.2026), его оценка идёт в
отчёт.
