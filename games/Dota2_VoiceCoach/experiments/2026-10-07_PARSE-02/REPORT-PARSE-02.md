## Вторичные меры

- **S1 — согласие разметок: 80 из 80** (ДИ 0,954–1,000; S1′ без фразы с пустым списком — 79 из 79).
  Разметчик B совпал с A во всех фразах, включая порядок команд, хотя пояснения (`note`) у них разные
  (совпали 13 из 80, почти все пустые) и B, по аудиту, разметки A не видел. Тот же мотор с тем же
  протоколом дал тот же ответ — это предсказывал урок PRED-01 из CLAUDE.md («одинаковые головы на
  одинаковом промпте дают один ответ»), а я поставил на согласие ≥ 0,80 вероятность 0,3. Следствие:
  «правда» здесь — толкование Claude, а не независимая разметка; S2 = S3 = главной мере (45 из 80).
  Чтобы проверить правду, нужен другой источник: человек или записи живой речи.
- **S4 — правки по PARSE-01 против разборщика до правок (75dc796), те же 80 фраз:** новый 45, старый 41;
  b = 7 (верно только у нового: id 8, 23, 30, 47, 49, 66, 76), c = 3 (только у старого: id 32, 39, 43);
  точный тест Мак-Немара p = 0,3438; разница 0,05, бутстрэп-интервал от −0,025 до 0,125. Правила,
  выученные на PARSE-01, на новом наборе помогают мало и в трёх фразах вредят.
- **S5 — строгая доля:** 45 из 80, как главная; по главному правилу нет ни одной фразы, засчитанной
  только за счёт переспроса.

## Пост-хок: почему ошибся (35 фраз) — вердикты не меняет

Причины назначены по выходу разборщика, без проверки правками; одна фраза может иметь две причины.

| Причина | id |
|---|---|
| нет слова или формы: «петь», «вов» (молча пропало), «серый», «вава», «четверо», «впятером», «ама», «руне» | 1, 15, 27, 40, 56, 64, 69, 74 |
| нет глагола: «придержи» (ульт), «ходи за», «сентрю», «не трогаем», «тепайся», «зафармит» | 14, 15, 31, 36, 43, 44, 51 |
| приказ в 3-м лице («а петя фармит», «а джагг фармит лес») принят за сведения → переспрос | 25, 32, 51, 69 |
| «дима с серёгой идите ганкать» — второй адресат не взят | 25 |
| «пятый» как обращение не понят → переспрос «кому?» | 63 |
| уровень вышки словом: «тройку», «двойку» | 7, 27 |
| самоисправление не в том виде, что знает разборщик: «хотя нет лучше», «ой нет» с предметом и с другим глаголом | 48, 50, 55 |
| отрицание: относится к месту, а не к действию («не ставь в их лес, ставь в наш»), «не лезь в драку», идиома «не стой столбом» | 45, 46, 68 |
| местоимение «на неё» не связано с целью; названный адресат выпал из «всех» в фокусе | 37 |
| «коры … саппорты …» — вышел один вард всем | 39 |
| сведения без приказа («инвокер пропал с мида») → переспрос вместо молчания | 57 |
| «а ты купи» — ушло всем вместо переспроса | 62 |
| склеено или добавлено лишнее: «собираемся … и ломаем» → один пуш; «ставь ульт» → ещё и вард | 27, 29 |
| «дефай» без линии не взял линию из той же фразы | 26 |
| ошибки распознавания: «влес», «набазу», «тэпэ», «бэ ка бэ», «смог», «терминатора», «варт» | 71, 74, 75, 77, 78, 80 |

Проверено после прогона (тот же разборщик, контекст parse02): «вова ходи за петей» даёт follow Вове,
а «вов ходи за петей» — переспрос «кому?», причём «вов» не попадает и в список непонятых слов;
«петя фармит лес» отдельно — тоже переспрос «это сведения или приказ?».

Три потери против старого разборщика (id 32, 39, 43) пришлись на правила, добавленные после PARSE-01:
«сведения о враге → переспрос» сработало на приказ в 3-м лице (32), «не» только для следующего
действия — на «рошана пока не трогаем» (43); для 39 причина не проверялась.

## Что это значит для игры

- Словарный разборщик на новых фразах понимает около половины сложных команд и 4 из 5 простых.
  Латать правила под каждый набор почти не помогает (S4). Для игры этого мало.
- Варианты, которые стоит проверить следующим замером: (1) разбор языковой моделью — основной или
  запасной путь, когда словарь не уверен (решение Д3 это допускало); (2) переспрос вместо
  догадки — сейчас 14 лишних переспросов и при этом пропуски; (3) записи живой речи автора как
  настоящая правда. Какой вариант лучше — не проверялось.
- Вторая разметка той же моделью ничего не проверяет; для PARSE-03 правду должен дать человек или
  другой источник.
