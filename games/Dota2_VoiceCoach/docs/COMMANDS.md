# Язык команд тренера (протокол v1)

Код: `coach/voicecoach/protocol.py` (действия и параметры), `coach/voicecoach/textcmd.py` (короткий
формат), `coach/voicecoach/lexicon.py` (слова), `coach/voicecoach/parser.py` (свободная фраза). Примеры с ответами — `coach/tests/test_parser.py`.

## Короткий формат (основной ввод с 07.10.2026)

Голос отложен (решение Д9). Команды пишутся текстом — на странице тренера или в **командном чате
игры** (боты разбирают его сами). Строка разбирается строго: если хоть одно слово не из формата,
ничего не уходит, а в ответ — что не понято и, на странице, подсказка в этом формате.

**Строка:** команды через `.`, `,`, `;` или с новой строки. **Команда:** `[кому] действие [где/что] [!]`.

| Часть | Как писать |
|---|---|
| кому | `1`…`5`; несколько — `23`, `2,3`, `2 3`; `все` (или `0`); `все-1`, `все кроме 4,5`; имя из состава в любом падеже («петя», «пете»); свой герой («джагг»); роли `керри мидер оффлейнер хардер четверка пятерка саппы коры`. Для командных действий можно не писать — тогда всем. Обращение можно отделить запятой: «дима, стак древние» |
| действие | `фарм` (`ф`) · `пуш` (`п`) · `деф` (`д`) · `ганг` (`г`) · `сбор` · `рош` · `торм` · `смок` · `назад` · `фокус` (`бей`) · `драка` · `жди` · `сплит` · `вард` · `стак` · `купи` · `юз` · `бб` · `ульт` · `держи` (ульт) · `сейв` · `за` (идти за союзником) · `тп` · `иди` · `сам` · `отмена` · `доклад` (`?`) |
| запрет | `не` перед действием: `все не рош` → ждать, на Рошана не идти |
| где | линии `топ мид бот`, относительно своей стороны `сейф хард`; `лес` (свой), `их лес`, `древние`, `база`, `руна`, `рош`, `торм`, `аутпост`, `лотос`; для фарма ещё `линия` |
| вышка | `т1`…`т4` |
| цель | герой врага (`марс`, `пудж`, `ам`…) или позиция врага `в1`…`в5` |
| союзник | для `сейв` и `за`: номер, имя или свой герой — `4 сейв 1`, `5 за петя` |
| предмет | для `купи` и `юз`: `бкб блинк гем даст смок вард сентри тп форс глиммер линка аганим шард`… (сленг из словаря) |
| сентри | для `вард`: `4 вард руна сентри` |
| смок с гангом | `все смок ганг мид` |
| срочно / потом | `!` в конце (или слово `срочно`); `потом` в начале команды — выполнить после предыдущей |

Личные действия (`фарм`, `ганг`, `вард`, `купи`, `тп`, `иди`, `сейв`, `за`, `ульт`, `бб`…) без адресата —
ошибка «кому?». Командные (`рош`, `пуш`, `деф`, `назад`, `фокус`, `драка`, `жди`, `сам`, `отмена`…) без
адресата идут всем.

Примеры: `1 фарм лес. 23 ганг мид. 45 вард руна` · `все-1 пуш бот т2` · `3 ульт марс !` ·
`4 сейв 1` · `5 купи сентри` · `все смок ганг мид` · `потом все назад` · `все не рош`.

В чате игры: пишите в **командный** чат; боты отвечают своими словами («Фармлю», «Иду на Рошана»),
на ошибку формата отвечает один бот: «Не понял: …». Обычные сообщения («gg») боты не трогают.
Код: `coach/voicecoach/textcmd.py` (страница), `game/shared/coach_text.lua` (чат игры); общие
примеры — `coach/data/text_cases.json`.

## Свободная фраза (голос; отложен — решение Д9)

Тренер говорит как капитан: **кому — что — где/кого**. В одной фразе может быть несколько приказов.

| Часть | Как сказать | Во что превращается |
|---|---|---|
| Кому | имя игрока («Миракл», «Мираклу» — уже не обращение, а «помоги Мираклу»), роль («керри», «мидер», «тройка», «саппорты», «коры»), герой своей команды («инвокер»), «все», «остальные», «позиция 3» | позиции 1–5 |
| Что | глагол или сленг: фарми, пушим, дефаем, ганг, смок, на роша, отходим, фокус, заходим, ждём, сплит, вард, стакни, купи, бб, ульту, спаси, иди с, тп, отмена, играйте сами, доклад | `action` |
| Где | топ/мид/бот, лайт/хард (по стороне команды), наш/их лес, древние, база, руна, яма, т1–т4, «вторая башня» | `lane`, `area`, `place`, `tier` |
| Кого | вражеский герой сленгом («пуджа», «фантомку», «шторма»), «их керри» | `enemy`, `enemy_pos` |
| Что купить | бкб, блинк, гем, дасты, смоки, обсы, сентри, форс, глиммер, линка, аганим, шард, … | `item` |
| Связки | «потом» — выполнить после предыдущего; «срочно/быстро» — срочно; «не …» — запрет | `after_prev`, `urgent`, `hold{what}` |

Правила, которые разборщик применяет сам:
- адресат не назван: командные действия (пуш, деф, сбор, Рошан, смок, отход, фокус, драка, ждать) — всем;
  глагол во множественном числе («фармите») — всем; личное действие в ед. числе («купи бкб») — тому,
  кому был прошлый приказ, а если такого нет — переспрос «кому?»;
- «мид» в начале с глаголом в ед. числе — игрок («мид, пушь»), иначе линия («мид пушим», «го мид»);
- имя в косвенном падеже — союзник, а не адресат («помоги Мираклу», «иди с Топсоном»);
- короткие клички героев из двух букв («па», «та», «ам») узнаются, только если герой есть в матче;
- ошибка распознавания в имени («миракал») исправляется по похожести, но снижает уверенность.

## Действия

| action | Смысл | Параметры | Нужен адресат |
|---|---|---|---|
| farm | фармить | area: lane / jungle_own / jungle_enemy / ancients / auto; lane | да |
| push | давить линию | lane (top/mid/bot/auto), group, tier | нет (всем) |
| defend | защищать | lane или place=base, tier | нет |
| gank | ганг | lane, enemy, enemy_pos | да |
| group | собраться | place или lane | нет |

| smoke | смок | then=gank, lane, enemy | нет |
| retreat | отступить | place=base | нет |
| focus | бить цель | enemy или enemy_pos (без цели → engage) | нет |
| engage | начать драку | enemy | нет |
| hold | ждать, не делать | what — что запрещено | нет |
| split | сплит-пуш | lane | да |
| ward | поставить вард | place / lane, kind=sentry | да |
| stack | стакнуть лагерь | place=ancients | да |
| buy | купить | item (обязателен) | да |
| use_item | применить предмет («прожми бкб») | item | да |
| buyback | выкупиться | — | да |
| use_ult / save_ult | ультануть / держать ульту | enemy | да |
| save / follow | спасти / идти с союзником | ally (обязателен) | да |
| tp / move | телепорт / идти | place или lane (обязательно) | да |

## JSON команды

```json
{"v": 1, "seq": 17, "action": "farm", "agents": [1], "params": {"area": "jungle_own"},
 "urgent": false, "after_prev": false, "text": "миракл фарми лес", "confidence": 1.0, "clarify": ""}
```

`seq` даёт сервер (растёт), игра забирает команды с `seq` больше последнего виденного.
Команда с непустым `clarify` в игру не уходит — сервер возвращает тренеру переспрос.

## Как добавить слово

1. Дописать слово в нужную таблицу `lexicon.py` (в нормальной форме: строчные, «ё» → «е»).
2. Добавить фразу с ожидаемой командой в `CASES` в `tests/test_parser.py`.
3. `cd coach && python -m unittest` — всё должно пройти.
