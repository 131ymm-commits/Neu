# Решения

Каждое решение: что выбрано, из чего выбирали, почему, что его отменит. Новое решение — новой
записью внизу; старые не переписывать, отмену дописывать к записи.

## Д1. Два пути: сначала играбельный прототип, потом кастомка (06.10.2026)

**Выбрано.**
- **Прототип A** — обычное лобби Dota 2 с сервером «Local Host», 10 ботов Open Hyper AI (OHA) и наш
  слой «тренер». Боты сами опрашивают сервер тренера на localhost и поднимают желания режимов.
- **Продукт B** — кастомка на стандартной карте `dota`: 10 ботов через `Tutorial.AddBot`, свой ИИ на
  vscripts, тренер без героя, голос через веб-панель клиента, двое тренеров в аркаде.

**Из чего выбирали.**
- (1) Сразу B: месяц до первого играбельного матча, всё микро писать или переносить до того, как
  ясно, весело ли вообще командовать голосом.
- (2) Только A: быстро, но это не кастомка, и вдвоём не сыграть.
- (3) Гибрид «боты Valve в кастомке»: встроенный ИИ управляется только грубо (глобальные
  переключатели), канала «кастомка → бот» никто не проверял.

**Почему так.** A за 1–2 недели проверяет главное предположение — «командовать звёздами голосом
интересно, а агенты при этом сами делают микро» — на готовом хорошем микро (127 героев). Всё ядро
(протокол, разбор речи, намерения, оцифровка, сервер) общее для A и B, поэтому работа не теряется.

**Что отменит.** Если OHA в лобби Local Host не запустится или боты не смогут опрашивать сервер —
прототип переезжает в B сразу (запасной канал для A — файл, как в проекте bota).

## Д2. Ядро не зависит от Доты и проверяется здесь (06.10.2026)

Протокол команд и разбор речи — Python без зависимостей (`coach/`); намерения агентов и мост к
серверу — чистый Lua 5.1 (`game/shared/`), тесты под LuaJIT через `lupa`; оцифровка — Python без
зависимостей (`digitizer/`). Причина: Доту запускает только человек на Windows, каждая поездка «в
игру» дорогая. Всё, что можно проверить без игры, проверяется тестами до неё.

## Д3. Разбор речи: словарь на пути команды, LLM — запасной (06.10.2026)

На пути команды — словарный разборщик (`coach/voicecoach/parser.py`): миллисекунды, предсказуем,
правится добавлением слова. LLM (например, Claude Haiku) — только для фраз с низкой уверенностью,
асинхронно, с таймаутом; и для «характера» ответов. Причина: время до первого токена у быстрых
моделей ~1 с (сниппет, 03 §2) — с ней на пути цель «≤ 1 с» недостижима. Оговорка: подписка
Claude не даёт API; LLM в игре потребует отдельный API-ключ с оплатой за токены.

## Д4. Распознавание речи: по ступеням (06.10.2026)

- v0 — страница в Chrome (Web Speech API, ru-RU): ничего ставить не нужно, уже есть (`coach/web/`).
  Минусы: облако Google, клавиша работает, только пока окно браузера в фокусе.
- v1 — приложение на ПК: глобальная клавиша «нажми и говори», GigaAM v3 через sherpa-onnx (CPU),
  экстренные слова через Vosk с грамматикой. Выбор между ними — по пилоту на записях.
- Запасной — облачный Yandex SpeechKit или Deepgram, если локальное качество плохое.

## Д5. Оцифровка по уровням (06.10.2026)

- Уровень 1 (готов): профиль из матчей OpenDota — пул героев, сборки, тайминги, оси стиля
  (агрессия, фарм, риск, командная игра, обзор, механика), места вардов, фразы из чата.
- Уровень 2: свой разбор .dem (Manta/Clarity/gem-dota) — микро-стиль (реакция, доли приказов,
  кайт, ласт-хит), модель макро-решений.
- Мера «похож ли двойник» — от кода: статистика агента в матчах против профиля оригинала по тем же
  признакам (`twin/features.py`), позже — стилометрия.

## Д6. Этика оцифровки (06.10.2026)

Обычных игроков оцифровываем только с согласия (сам игрок, друзья). Известных про-игроков в
публичной сборке без письменного разрешения показываем безымянными архетипами («агрессивный мидер
по турнирам 2025 года»); в личной сборке человек называет агентов как хочет. Голос реальных людей
не клонируем. Пабы топ-игроков, закрытые Valve в 2025, не обходим.

## Д7. Обратная связь от агентов (06.10.2026)

Три слоя (03 §3): сразу — звук «принято» и строка распознанного текста; видимо — пинг и короткий
текст «Иду на Рошана»; голосом — только отказ, вопрос или важное. Переспрос закрывается одним
словом («Кому? — Мираклу»). Агент-звезда может не согласиться (параметр послушания из профиля
и настроек) и объясняет почему.

## Д8. Лицензия — ЖДЁТ РЕШЕНИЯ ЧЕЛОВЕКА

**Рекомендация: GPL-3.0 с исключением для распространения через Steam** (как у Windy10v10AI).
- За: можно законно взять ИИ Windy10v10AI (GPL-3.0, ~22,7 тыс. строк с тестами: мозг команды,
  исполнитель героя, способности, предметы, варды) — это недели работы; OHA (MIT) совместим.

- Против: весь код игры будет открытым под GPL; закрыть его потом нельзя.

До решения чужой GPL-код в репозиторий не копируется.

## Д9. Голос пока отложен; команды — текстом (07.10.2026, решение автора)

Слова автора: «Если проблема с речью. Пока оставь её. Пусть будут текстовые команды.»

Что показал замер (PARSE-02): трудность не в микрофоне, а в понимании свободных фраз — словарный
разборщик понял 45 из 80 новых фраз, и в напечатанном тексте эта трудность та же. Поэтому текстовые
команды — это **строгий короткий формат** («1 фарм лес. 23 ганг мид. все рош»), а не свободная фраза:
- разбор без догадок: каждое слово из словаря формата, иначе ошибка, и вся строка не уходит агентам;
- на непонятную строку — подсказка в коротком формате (из свободного разбора), тренер её подтверждает;
- один разбор в двух местах: страница тренера (Python, `coach/voicecoach/textcmd.py`) и чат игры
  (Lua, `game/shared/coach_text.lua`; боты слушают командный чат через `InstallChatCallback`, сервер
  не нужен); совпадение проверяется тестами на общих примерах и сотнях строк;
- голосовой ввод остаётся на странице в свёрнутом блоке; к нему вернёмся по слову автора.

## Д10. Стандартная карта и механики; тренер без героя — сразу за 5 агентов (07.10.2026, слова автора)

Слова автора: «Итак вопросы в игре будет стандартная карта доты и все механики доты но игра сразу за 5 агентов».

- Карта — стандартная `dota` (в `addoninfo.txt` `"maps" "dota"`), механики — штатные (герои, предметы,
  крипы, вышки, Рошан, руны, магазины): правила мы не меняем. Встроенные боты Valve в кастомке, по
  описанию API, работают только на карте dota.
- Тренер не играет героем и командует всеми пятью. В кастомке: в каждой команде 5 ботов и тренер;
  герой тренера (без него место в команде не дать) прячется у базы — невидим, неуязвим, вне игры,
  без приказов (`modifier_voicecoach_commander`); размер команды — 6 (как у Windy10v10AI: `MaxPlayers`
  в `addoninfo.txt` считает только людей, боты — сверх). Проверяется пробником (`commander_hidden`).
- В прототипе на лобби Local Host человек слот не занимает (пятеро ботов) и командует со страницы
  тренера; командный чат там доступен, только если занять слот (тогда агентов четыре) — это проверка
  чата, а не режим игры.

Дополнение к Д10 (07.10.2026), слова автора: «В общем давай сделай каркас. Нормальна карта доты вид сверху. Покаместь текстовое упровление. Агенты играют в доту. Делай». Каркас кастомки — `game/custom_game/`: стандартная карта, тренер без героя, камера сверху и дальше обычного (наклон 70°, дальность 1600 — проверить в игре), приказы текстом в поле HUD и в чате, агенты — боты Доты, которых ведут приказы тренера.

## Д11. Каждого героя ведёт свой агент Claude (07.10.2026, слова автора)

Слова автора: «Нет играют не боты доты а агенты Клауд. За каждого Героя свой».

Это поправка к каркасу из дополнения к Д10: там героями управлял встроенный ИИ ботов Valve (моя ошибка, `journal/ERRORS.md` № 83).

- 10 героев — 10 агентов Claude. У каждого свой промпт (характер оцифрованного игрока или архетип позиции,
  герой, команда), своя память и своя очередь решений. Встроенный ИИ ботов выключен
  (`SetBotThinkingEnabled(false)`): боты Доты остаются только местами в командах.
- Два уровня, потому что модель отвечает за секунды, а Доте нужны десятые доли секунды. Агент раз в несколько
  секунд и сразу по событию (приказ тренера, смерть, враг рядом, резкая потеря здоровья) выдаёт решение: план,
  цель, какие способности по кому, что купить и что качать, порог отхода, реплику тренеру. Исполнитель на Lua
  в игре выполняет решение рефлексами: добивает крипов, применяет способность, когда цель в радиусе, отходит
  по порогу, покупает у фонтана, качает способности. Сам исполнитель ничего не выбирает.
- Тренер командует агентами, а не героями: приказ в коротком формате уходит агентам-адресатам как сообщение,
  агент решает, как его выполнить, и отвечает своими словами.
- Где живут агенты: сервер тренера на ПК (`coach/voicecoach/agents.py`), игра ходит к нему по HTTP раз в
  секунду. Модель — через API-ключ Anthropic с оплатой за токены (подписка Claude не даёт API, Д3); для пробы
  по подписке — через Claude Code (`claude -p`): медленнее и в пределах лимитов подписки. Без сервера — запасной
  исполнитель приказов тренера, без агентов, и HUD об этом пишет.
- Цена и задержка — `docs/CLAUDE_AGENTS.md`: расчёт до замера; замер — журнал агентов первого матча.

**Что отменит.** Неприемлемые задержка или цена на замере: сначала реже решения и короче наблюдение; один агент
на команду вместо пяти противоречит словам автора — только с его согласия.

## Д12. Голосовой чат команды: агенты переговариваются, тренер слышит (07.10.2026, слова автора)

Слова автора: «Зделай голосовой чат зделай голосовой чат чтобы они переговаривались лицг с лиугом».

Как я понял (не уточнял, записано как предположение — ERRORS № 85): «лицг с лиугом» — «друг с другом»; «они» —
агенты героев; «голосовой чат» — переговоры пятёрки вслух, как в голосе Доты, а тренер их слышит. Голосовой ввод
тренера по-прежнему отложен (Д9).

- Реплика агента (`say`) идёт в чат своей команды, `to` — кому из союзников (пусто — всем). Союзники видят чат в
  каждом сообщении («Голосовой чат команды»: кто, кому, сколько секунд назад, новое помечено). Обращение к союзнику
  будит его сразу; ответ на обращение никого не будит — без бесконечного пинг-понга. Чужая команда чат не слышит.
- Тренер слышит чат голосами браузера (Web Speech API): страница `voice.html` сервера тренера (в браузере на ПК
  или на телефоне) и та же страница в скрытой веб-панели HUD игры — работает ли там речь, не проверено. У каждой
  позиции свой голос: один из русских голосов системы, своя высота и темп. Голоса синтетические, голоса реальных
  людей не клонируем (Д6).
- В HUD и в командном чате игры реплики видны текстом: «1 sniper → 2: Луна идёт к тебе».

**Что отменит.** Если чат забивает голосом игру или дорого стоит (лишние вызовы по обращениям) — реже реплики,
обращения только по важному; если автор имел в виду другое — переделать по его слову.

## Д13. Второй тренер подключается через интернет — пульт в браузере (08.10.2026, слова автора)

Слова автора: «А зделай программу чтобы в неё мог подключатся второй игрок со стороны через интернет».

Как я понял (не уточнял, записано как предположение — ERRORS № 87): второй игрок — второй тренер (игра с первого дня
задумана на двоих, каждый — тренер своей пятёрки); «со стороны через интернет» — с другого компьютера или телефона,
не из сети хоста; «программа» — сервер тренера на ПК хоста, к которому второй тренер подключается браузером, без
установки. В сам матч Доты он не входит: к игре, запущенной из Tools, никто не подключится (`research/00_SUMMARY.md`),
это — публикация в Workshop, неделя 6.

- **Пульт** — страница по ссылке с ключом: схема карты по координатам игры (линии и река — по настоящим вышкам,
  свои герои, видимые враги, вышки, счёт), свои герои (здоровье, уровень, золото, что делают, состояние агента),
  враги — видимые и пропавшие, поле приказа в коротком формате с подсказкой на ошибку, лента ответов и голосовой чат
  своих агентов голосами браузера. Работает и на телефоне.
- **Туман войны** — как у команды в игре: пульт строится только из наблюдений её героев; чужие наблюдения, чат и
  приказы туда не попадают. Вышки, фонтаны и счёт видят обе команды — они есть на пульте обеих.
- **Приказ с пульта** идёт тем же путём, что из HUD: сервер разбирает его коротким форматом (ошибка — сразу назад
  с подсказкой), кладёт в очередь, игра получает его в ответе на свой обмен раз в секунду и отдаёт агентам адресатов
  (`G:TeamCommand`). Ровно один раз: номер приказа, подтверждение игры (`cmd_ack` того же запуска сервера), срок 30 с —
  старый приказ не выстрелит в новом матче. Ответы игры («→ 12345: все назад», «Без агента не умею…») — назад на пульт.
- **Безопасность.** Пульт — отдельный порт (8788): на нём только страница и пути пульта, всё под ключом команды
  (случайный, хранится в `coach/logs/console_keys.json`, вне git; `--new-key` — сменить). Порт игры (8787) наружу не
  выставляется. Ограничены размер приказа и частота (не больше приказа в секунду в среднем); страница запрещает
  индексацию, встраивание и отправку адреса с ключом на другие сайты.
- **Как в интернет.** `--tunnel` запускает быстрый туннель Cloudflare (`cloudflared tunnel --url
  http://127.0.0.1:8788`): адрес https://….trycloudflare.com без учётной записи и без настройки роутера; сервер
  печатает готовую ссылку для друга. Ограничения (по описаниям Cloudflare в поиске, страницу целиком прочитать не
  удалось): тестовый режим без гарантий, до 200 запросов одновременно, адрес новый при каждом запуске. Другие пути:
  проброс порта (`--console-host 0.0.0.0`, без шифрования) или общая VPN-сеть.
- **Честность.** Хост запускает всё у себя и технически может подсмотреть за второй командой (журнал и состояние
  агентов на его ПК). Игра — на доверии, как между друзьями; честный вариант — сервер матча у третьей стороны (неделя 6).

**Что отменит.** Если автор имел в виду вход второго игрока в сам матч Доты — это публикация в Workshop (неделя 6),
пульт тогда остаётся запасным путём. Если нужен голос между тренерами — отдельная задача.

**Дополнение к Д13 после рецензии (08.10.2026, отчёт — `docs/reviews/2026-10-08_console_review.md`).**
- Платит хост: вызовы Claude обеих сторон идут по его ключу (или подписке). Предел `--max-calls` теперь у каждой
  стороны свой — соперник не исчерпает предел хоста; приказ тренера будит агента не чаще раза в 3 с, а пульт
  принимает 4 приказа сразу и дальше один в 2 с — поток приказов не множит вызовы. Дешевле — `--dire rules`.
- Что видит хост, кроме сказанного выше: консоль Доты печатает каждый приказ с пульта и каждую реплику агентов Тьмы,
  страницы сервера на его ПК (`/api/local/agents`, события Тьмы) открыты ему без ключа. Весь трафик пульта вместе
  с ключом видит Cloudflare: шифрование туннеля заканчивается у него.
- Приказ с пульта разбирается так же, как в игре (позиции и герои, без имён из файла состава), и описывается
  героями. Приказ привязан к матчу (`game_id`): в следующий матч не уйдёт, даже если тот начнётся быстрее 30 с.
- Порт игры (8787) больше не отвечает страницам чужих сайтов: раньше любой сайт, открытый в браузере хоста (например,
  по ссылке соперника), мог прочитать приказы и чат Света и отдать приказ — сервер разрешал это всем (CORS «*»).

## Д14. Игра вдвоём одним файлом: хост запускает ИГРАТЬ.bat, соперник открывает ДЛЯ_ДРУГА.html (09.10.2026, слова автора)

Слова автора: «все очень сложно сделай нормальный вход и конект. это просто ужас. придумай сам как сделать. я должен
запустить один файл и опонент должен запустить один файл все остальное делаеш ты».

Моя ошибка, на которую это ответ, — ERRORS № 89: запуск вдвоём я оставил шестью ручными шагами (установить туннель,
набрать команды, задать ключ, переслать ссылку, запустить Доту и кастомку).

- **Хост — один файл `ИГРАТЬ.bat`** (можно скачать отдельно, без репозитория). Он сам: находит Python или скачивает
  переносной (python.org, без установки в систему); подтягивает с GitHub свежие файлы игры (для копии из git —
  `git pull`); спрашивает ключ API Anthropic один раз и запоминает (без ключа — агенты на правилах, бесплатно, не
  Claude); выбирает самую новую из быстрых моделей по списку моделей ключа; ставит кастомку в Доту; скачивает
  туннель Cloudflare; поднимает сервер тренера, пульт Тьмы и туннель; запускает Доту с инструментами и сразу кастомку
  (`dota2.exe -tools -addon voicecoach +dota_launch_custom_game voicecoach dota` — так запускает аддоны шаблон ModDota).
- **Соперник — один файл `ДЛЯ_ДРУГА.html`.** Его делает лаунчер хоста при первом запуске и показывает в Проводнике;
  хост отправляет его другу один раз. Друг открывает файл двойным щелчком — файл находит игру и открывает пульт.
  Ничего ставить не нужно, только браузер.
- **Как файл находит игру.** Адрес туннеля новый при каждом запуске, поэтому лаунчер кладёт текущую ссылку на пульт в
  «ящик» — тему бесплатного сервиса ntfy.sh (без учётной записи; имя темы работает как пароль). Ссылка в ящике
  зашифрована и подписана общим секретом хоста и файла друга (HMAC-SHA256): сервис её не прочтёт, подделку и старьё
  файл отбросит. Секрет в ящик не уходит. Пульт, открытый из файла, помнит секрет (после «#» в адресе — на сервер это
  не уходит) и после перезапуска игры хостом сам переходит на новый адрес.
- **Запасной путь.** Ящик недоступен (сервис лёг или закрыт в стране) — у хоста ссылка уже в буфере обмена, у друга в
  файле поле «вставьте ссылку». На телефоне друга (файл .html из мессенджера может не открыться) — проще ссылкой.
