# Архитектура

## Слои (общие для прототипа и кастомки)

| Слой | Что делает | Частота | Где живёт | Статус |
|---|---|---|---|---|
| L0 Голос | нажми-и-говори → текст | по фразе | браузер (v0) / приложение на ПК (v1) | v0 готов (`coach/web/index.html`) |
| L0 Разбор | текст → команды протокола v1 | по фразе, мс | `coach/voicecoach/parser.py` | готов, 65 фраз в тестах |
| L0 Сервер тренера | очередь команд по комнате и команде, состав матча, ответы агентов | — | `coach/voicecoach/server.py` | готов |
| L1 Намерения | команда → намерение агента со сроком, очередью «потом», отменой | по команде | `game/shared/coach_intents.lua` | готов |
| L2 Желания режимов | желание режима = база бота + характер (persona) + пол/потолок намерения | ~3 Гц | там же, `desire()` | готов |
| L3 Микро | ласт-хит, кайт, скиллы, отход | 4–30 Гц | прототип: боты OHA; кастомка: свой ИИ | чужое / впереди |
| L4 Характер | параметры игрока: бонусы желаний, порог отхода, реакция, послушание, сборки | при старте | `digitizer/twin/agent_params.py` | уровень 1 готов |

## Прототип A: лобби Local Host + боты OHA

```
 Микрофон ─► Chrome: страница тренера ──POST /api/local/say──► Сервер тренера (Python, localhost:8787)
                (Web Speech, ru-RU)                              │ разбор → команды (seq)
                       ▲                                         │
                       │ GET /events (ответы, озвучка)            ▼
                       └──────────────────────────────── GET /api/local/commands?team=..&after=N
                                                                 ▲   (каждые 0.5 с)
 Dota 2, лобби «Local Host»: 10 ботов OHA ───────────────────────┘
   bots/coach/coach_bot.lua  — опрос сервера (CreateRemoteHTTPRequest), намерения (coach_intents.lua)
   bots/mode_*_generic.lua   — в конец каждого режима дописана обёртка GetDesire → coach.desire(...)
   bots/Customize/general.lua — имена и герои двойников, язык ru
 Тренер в лобби — зритель (1 человек). Второй тренер — второй зритель, его страница указывает на сервер хоста.
```

Почему так: в лобби Local Host сервер матча — ПК хоста, поэтому localhost доступен и ботам, и
серверу тренера. Боты OHA уже делают всё микро; мы только смещаем их выбор режима.

## Продукт B: кастомка

```
 Микрофон ─► приложение/страница тренера ──► облачный ретранслятор (комната, ключ, команда)
                                                  ▲
 Клиент Доты тренера (Panorama): скрытая DOTAHTMLPanel опрашивает ретранслятор (GET, ответ в <title>)
        │ GameEvents.SendCustomGameEventToServer
        ▼
 Сервер кастомки (ПК хоста, vscripts Lua/TS):
   мост (coach_bridge: команды → намерения)  →  мозг команды (раз в 1 с)  →  исполнитель героя (раз в 0.4 с)
   10 ботов: Tutorial.AddBot на карте dota; встроенный ИИ на линии, потом свой (схема Windy10v10AI)
   HUD тренера: субтитры, кто что делает, кнопки-дубли команд
 В Tools (локальный запуск) мост ходит на сервер тренера напрямую по HTTP (CreateHTTPRequestScriptVM).
```

Почему так: в аркаде сервер матча не может слать HTTP (с 08–09.2026), а клиент через веб-панель —
может (research/00_SUMMARY.md). Команды тренера приходят в его же клиент и уходят на сервер матча
игровым событием — чужой клиент для этого не нужен.

## Протокол

- Команда — JSON v1 (`docs/COMMANDS.md`): `action`, `agents` (позиции 1–5), `params`, `urgent`,
  `after_prev`, `seq`, `clarify`. Версия — `PROTOCOL_VERSION` в `protocol.py`.
- Сервер: `POST /api/{room}/say`, `GET /api/{room}/commands?team&after`, `POST /api/{room}/state`,
  `POST|GET /api/{room}/events` (long-poll), `GET /api/health` (`server.py`).
- Время жизни намерений (`TTL`) в Lua сверяется с `protocol.py` тестом
  (`game/tests/test_intents.py::test_ttl_matches_protocol`).

## Бюджет задержки (цель, проверяется пилотом)

| Участок | Цель | Чем меряем |
|---|---|---|
| конец фразы → текст | ≤ 0,5 с локально (GigaAM/Vosk), ~0,5–1 с Web Speech | время в логе страницы/приложения |
| текст → команда | < 10 мс (словарь) | `parse()` |
| сервер → игра | ≤ 0,5 с (опрос 0,25–0,5 с) | `seq` и время в логе бота |
| игра → смена режима бота | ≤ 0,3 с (GetDesire ~300 мс) | лог бота |
| **итого** | **≤ 1,5 с p95** | лог «фраза → первый тик в новом режиме» |
