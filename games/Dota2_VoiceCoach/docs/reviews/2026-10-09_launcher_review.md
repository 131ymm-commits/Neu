# Рецензия игры вдвоём одним файлом (Д14), 09.10.2026

Независимая проверка подагентом (Agent) по просьбе Claude: ИГРАТЬ.bat, лаунчер `coach/voicecoach/play.py`, ящик
(`rendezvous.py`, `web/rv.js`), файл друга (`web/friend.html`), обновлятор (`update.py`). Подагент получил дословно
последнее сообщение автора. Отчёт ниже — сокращённо: убраны ссылки на проверочные скрипты подагента (они остались вне
репозитория, в папке сессии) и часть подробностей; суть и числа — его. Номера строк — по коммиту bb3d354. Что сделано
по каждой находке — таблица в конце. Мои ошибки из неё — `journal/ERRORS.md`, № 90.

**Рецензия Д14 (коммит bb3d354).** Одна находка — блокер: на русской Windows лаунчер падает на шаге [6/6], при любой
найденной Доте. Кроме неё 12 важных и ряд мелочей. Тесты: 105 в `coach/` прошли, Playwright — 14 прошли.

## Блокер

**1. Лаунчер падает на шаге [6/6] на русской Windows.**
- Где: `play.py:204` — вывод `tasklist` читается с `text=True`; ИГРАТЬ.bat запускает Python с `-X utf8`, разбор идёт
  строгим UTF-8.
- Сценарий: русская tasklist пишет кириллицу в cp866 и когда процесса нет («ИНФОРМАЦИЯ: …»), и когда он есть
  («… КБ»). Получается `UnicodeDecodeError` — это `ValueError`, `except (OSError, SubprocessError)` его не ловит.
  Итог — трассировка, туннель гаснет, Дота не запускается.
- Проверка: подставной `tasklist` с выводом cp866. Что tasklist локализована — по памяти.
- Почему тесты не поймали: тест подменяет `running`, а прогон на Linux до этого места не доходит.

## Важно

2. **Файл друга уходит на мёртвую ссылку и там застревает** (`friend.html:79`, `rv.js:72`): берётся последняя ссылка
   за 12 ч без проверки, жив ли хост; «закрыто» уходит только по Ctrl+C. Хост закрыл окно крестиком — вкладка друга
   уходит на страницу ошибки Cloudflare, где нашего кода нет. Проверено в Chromium. Фраза Д14 «старьё файл отбросит»
   неверна для старья моложе 12 ч.
3. **Файл друга — замороженный код и на телефоне молча не работает.** Исправления дойдут до друга, только если
   переслать файл; без JavaScript (предпросмотр в мессенджере) — вечное «Ищу игру друга…», поле ручной ссылки скрыто.
   Рекомендация рецензента — постоянная https-страница (GitHub Pages) вместо файла.
4. **Второй запуск на Windows не ловится** (`play.py:320–325`): `ThreadingHTTPServer` ставит `SO_REUSEADDR`, на
   Windows это позволяет второму процессу занять порт (документация Microsoft; в CPython `socket_helper` поэтому
   ставит `SO_EXCLUSIVEADDRUSE`). Здесь не проверить.
5. **Ключ: любой сбой даёт «без Claude» навсегда** (`play.py:112–124`): три сбоя сети или Ctrl+C сохраняют
   `api_key=""`; подсказки `ИГРАТЬ.bat --ask-key`, `--dota`, `--new-friend` двойным щелчком не передать; 403 — это
   `permission_error` (в том числе по региону), а текст ответа выбрасывается.
6. **Ключ может уйти в публичный репозиторий по штатному пути:** после `input()` в окне остаётся «ключ> sk-ant-…»,
   FIRST_RUN просит прислать всё из окна, а чат выгружается в `journal/`.
7. **Недокачанный cloudflared принимается навсегда** (`play.py:141–163`): длина не сверяется, принимается любой файл
   больше 1 МБ. Проверено: сервер обещал 3 МБ, отдал 1,5 МБ — файл принят.
8. **Обновлятор:** `IncompleteRead` (не `OSError`) не ловится — bat делает `pause` и не запускает игру при целых
   файлах; сбой одного файла оставляет остальные заменёнными — новый play.py со старым console.py.
9. **ИГРАТЬ.bat переписывается, пока cmd его исполняет** (cmd читает .bat построчно, по смещению): `git pull` или
   update.py заменяют его на ходу.
10. **Обновление идёт прямо с рабочей ветки:** любой пуш сессии уезжает игрокам; слияние или удаление ветки молча
    остановит обновления.
11. **Часы хоста спешат больше чем на 5 мин — друг игру не найдёт никогда** (`rendezvous.py:99`, `rv.js:72`).
12. **Переустановка кастомки при открытой Доте** (`play.py:310–314` ловит только `SystemExit`) — `PermissionError`
    и трассировка. Не проверено на Windows.

## Мелочи

Надпись «друг закрыл игру» затирается каждую секунду (видна в 8 из 80 замеров); секрет дописывается к любой ручной
ссылке https с `/c/`; длина nonce не зафиксирована; поля `line` у модели в API нет (работает только запасной поиск по
имени); по Ctrl+C нет `agents.close()`, из .bat всплывает вопрос cmd «Завершить выполнение пакетного файла», умерший
cloudflared не перезапускается; ключ в `os.environ` наследуют cloudflared и Дота; `clip` получает UTF-16LE без BOM;
в bat `&` или `^` в пути ломают строки PowerShell, прерванная распаковка Python ломает запуск навсегда, без git в
PATH обновлений молча нет; дерево всего репозитория — 2,4 МБ на каждом запуске, флаг `truncated` не проверяется;
выделение мышью в окне (QuickEdit) останавливает вывод, и чтение журнала cloudflared встанет.

## Что проверено и чисто (по рецензенту)

bat: ASCII и CRLF, `set "X=…"` защищает пути с пробелами, кириллицей и `)`, `"%PROJ%."` обходит `\"` на конце.
Переносной Python: `._pth` включает изолированный режим, код — только стандартная библиотека. Шифр: поток HMAC плюс
подпись отдельным ключом, сравнение за постоянное время, Python и WebCrypto дают одно и то же. CSP пульта, no-referrer,
XSS нет. Обновлятор на настоящем GitHub: дерево не обрезано, недопустимых имён нет, SHA-1 каждого файла сверяется.
