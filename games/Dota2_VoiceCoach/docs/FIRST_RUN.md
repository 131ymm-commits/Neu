# Первый запуск на вашем ПК (Windows)

Шаги работают отдельно (пятый — игра вдвоём через интернет — после четвёртого; пробник будущей кастомки —
`game/probe_addon/README.md`, нужен Dota 2 Workshop Tools). После каждого пришлите, что получилось: это и есть проверка,
которую нельзя сделать без вашей Доты. Места, которые я не мог проверить сам, помечены **(проверить)**.

## 0. Подготовка (один раз)

1. Python 3.11 или новее: python.org → Download → при установке поставить галочку «Add python.exe to PATH».
2. Репозиторий: `git clone https://github.com/131ymm-commits/Neu.git` и `git checkout ccr-9d6c6e9e-yuegyb`
   (или скачать ZIP этой ветки на GitHub).
3. Браузер для страницы тренера (любой; голос — только Chrome, но он пока отложен).

## 1. Команды текстом без Доты — 5 минут

Голос пока отложен (ваше решение 07.10): команды пишутся текстом в коротком формате.
```
cd Neu\games\Dota2_VoiceCoach\coach
python -m voicecoach.server
```
Открыть `http://localhost:8787`, писать в поле и нажимать Enter: `1 фарм лес. 23 ганг мид. 45 вард
руна`, `все-1 пуш бот т2`, `3 ульт пудж !`, `все назад`, `все не рош`. Шпаргалка — на странице и в
`docs/COMMANDS.md`. На странице видно, кому что ушло («Вася: фармить — свой лес»). Если строка не по
формату, ничего не уходит, а в поле появляется подсказка — проверьте и нажмите Enter ещё раз (так
можно писать и обычной фразой: «вася фарми лес остальные на рошана» → подсказка `1 фарм лес. все-1 рош`).
Состав по умолчанию — демо: Вася, Петя, Коля, Дима, Саша (позиции 1–5); свой — после шага 3.

**Пришлите:** что неудобно в формате и какие короткие слова вам привычнее (их можно добавить).

## 2. Оцифровать себя — 10 минут

1. В Доте включить «Expose Public Match Data» (публичная история матчей) — в настройках клиента
   **(проверить, в каком разделе меню она сейчас)**.
2. Узнать свой account_id: число в адресе профиля на opendota.com или dotabuff.com.
3. Собрать профиль (OpenDota без ключа — около 60 запросов в минуту по умолчаниям в их коде;
   50 матчей займут около минуты):
```
cd Neu\games\Dota2_VoiceCoach\digitizer
python -m twin.cli profile --account 123456789 --limit 50 --name "Вася" --alias вася --request-parse --out profiles\me.json
```
   Ключ `--request-parse` просит OpenDota разобрать свежие матчи (реплеи Valve хранит ~1–2 недели).
   Через 10–20 минут запустите ту же команду без него — разобранных матчей станет больше.
4. Параметры агента:
```
python -m twin.cli agent --profile profiles\me.json --out agents\me.json
```
Профили и агенты в git не попадают (`.gitignore`): это ваши данные. Чужих людей оцифровываем только
с их согласия (docs/DECISIONS.md, Д6).

**Пришлите:** `profiles\me.json` целиком или блоки `style`, `hero_pool`, `warnings` — сверю, похоже ли
на вас (это первая проверка «похож ли двойник»).

## 3. Матч: команды в чате → боты — 30 минут

Боты — Open Hyper AI (MIT, 127 героев, патч 7.41). Мы ставим их в папку ботов Доты и добавляем
модуль тренера; ваша прежняя папка ботов сохраняется рядом.

1. Скачать OHA: https://github.com/forest0xia/dota2bot-OpenHyperAI → Code → Download ZIP →
   распаковать, например, в `C:\oha` (внутри будет `dota2bot-OpenHyperAI-main\bots\...`).
2. Состав: скопировать `game\prototype_oha\lineup.example.json` в `lineup.json` и вписать путь к своему
   агенту из шага 2 (позиция по порядку: 1 — керри … 5 — фулл саппорт; `null` — обычный бот OHA).
3. Установка:
```
cd Neu\games\Dota2_VoiceCoach\game\prototype_oha
python install.py --oha C:\oha\dota2bot-OpenHyperAI-main --lineup lineup.json
```
   Установщик сам найдёт Доту (или `--dota "D:\SteamLibrary\steamapps\common\dota 2 beta"`).
4. Сервер тренера: двойной щелчок по `game\prototype_oha\run_server.cmd` (его пишет установщик:
   там ваш состав и запасной канал `--inbox` — сервер дублирует команды в файл в папке ботов, и
   если боты не смогут ходить по HTTP, они через 3 неудачи сами перейдут на чтение файла). Окно не
   закрывать. Страница — `http://localhost:8787` в Chrome.
5. В Steam: Dota 2 → Свойства → Параметры запуска: `-condebug` (консоль будет сохраняться в
   `...\dota 2 beta\game\dota\console.log`).
6. В Доте (названия по английскому интерфейсу из инструкции авторов ботов): Play Dota → Custom
   Lobbies → Create → Edit: **Server Location — Local Host**, **Radiant Bots и Dire Bots — Local Dev
   Script**, режим — All Pick. Себя перенести в зрители/неназначенные: играют **пятеро ботов в каждой
   команде**, вы командуете со страницы тренера **(проверить: даёт ли лобби начать матч без людей в
   командах)**. Заполнить пустые слоты ботами, начать.
7. Во время матча пишите команды на **странице тренера** (второй монитор, телефон в той же сети —
   сервер с `--host 0.0.0.0`, или Alt-Tab): `1 фарм лес`, `23 ганг мид`, `все рош`, `все назад`. Боты
   отвечают в командный чат своими словами («Фармлю», «Иду на Рошана»), ответы видны и на странице.
   **Проверка чата (по желанию, отдельным матчем):** займите слот пятёрки и пишите те же команды в
   **командный чат** игры (Enter — чат команды **(проверить)**) — боты разберут их сами, без сервера;
   на ошибку формата отвечает один бот: «Не понял: …», обычный чат («gg») не трогают. В этом режиме
   агентов четыре — это проверка, а не игра: в итоговой кастомке тренер без героя командует пятью
   (решение Д10).
8. Вернуть всё как было: `python install.py --uninstall`.

**Пришлите:** из `console.log` строки с `[тренер]` (особенно «чат: команды короткого формата
включены», «чат: …» после ваших команд, «нет связи с сервером тренера», «читаю команды из файла» — по
ним видно, какой канал заработал; и ошибки Lua рядом, если есть) и что вы видели:
слушаются ли агенты, через сколько секунд, что раздражало. Если ботов не видно или они не двигаются —
лог сразу, это важнее всего.

## 4. Кастомка: героев ведут агенты Claude — 20 минут (нужен Dota 2 Workshop Tools)

Стандартная карта, по пятеро героев на сторону, вы — тренер без героя с камерой сверху, приказы текстом
в поле внизу экрана или в командном чате. Каждого героя ведёт свой агент (решение Д11): сервер тренера на
вашем ПК получает наблюдения героев и возвращает решения агентов. Установка и запуск —
`game/custom_game/README.md`: `python install_game.py`, затем сервер `python -m voicecoach.server --agents rules`
(сначала без Claude — проверить связь и руки), потом `--agents api --model <имя модели>` с ключом API
(`docs/CLAUDE_AGENTS.md` — цена и задержка), и в консоли Tools `dota_launch_custom_game voicecoach dota`.

Голосовой чат агентов — `http://localhost:8787/voice.html`, кнопка «Включить звук».

**Пришлите:** строки `[ТРЕНЕР]` из `console.log`, журнал `coach\logs\agents_*.jsonl` и сводку сервера после
Ctrl+C, снимок экрана и что неудобно.

## 5. Игра вдвоём: второй тренер через интернет (Д13) — 20 минут

Вы — тренер Света в Доте, друг — тренер Тьмы с пульта в браузере (на ПК или телефоне), по ссылке. Нужны шаги 0 и 4
(кастомка установлена, связь с сервером в Доте проверена).

1. **Туннель Cloudflare (один раз).** В окне PowerShell или «Командной строки»:
   ```
   winget install --id Cloudflare.cloudflared
   ```
   Закрыть окно и открыть новое (чтобы Windows увидела программу), проверить: `cloudflared --version` пишет
   версию. Если `winget` не найден — скачать `cloudflared-windows-amd64.exe` со страницы
   https://github.com/cloudflare/cloudflared/releases/latest, положить, например, в `C:\cloudflared\cloudflared.exe`
   и в шагах ниже добавлять к команде `--cloudflared C:\cloudflared\cloudflared.exe`. Учётная запись не нужна.
2. **Пробный запуск без Claude (бесплатно)** — проверить ссылку до трат:
   ```
   cd Neu\games\Dota2_VoiceCoach\coach
   python -m voicecoach.server --agents rules --remote dire --tunnel
   ```
   Сервер пишет строку «Пульт тренера (Тьма) на этом ПК: http://127.0.0.1:8788/c/…/» — откройте её у себя: должна
   открыться страница «Пульт тренера: Тьма», в углу «игра ещё не началась». Через 5–30 секунд появится строка
   `>>> Ссылка для тренера (Тьма) через интернет — отправьте её: https://….trycloudflare.com/c/…/`.
3. **Ссылку — другу** (в мессенджер). Ссылка — как пароль: у кого она, тот командует Тьмой. Друг открывает её в
   Chrome или Edge; если не открылась сразу — обновить через полминуты (новому адресу Cloudflare нужно время).
   Друг нажимает «Включить звук».
4. **Дота.** Окно сервера не закрывать. Запустить Доту с инструментами и в консоли
   `dota_launch_custom_game voicecoach dota` (как в шаге 4), взять любого героя — вы тренер Света. После начала
   у друга на пульте «игра на связи», его герои и карта; приказы друга вы увидите в консоли Доты, а он ваших — нет.
5. **С Claude.** Ctrl+C в окне сервера, затем ключ API (консоль Anthropic → API Keys) и запуск:
   ```
   set ANTHROPIC_API_KEY=ваш_ключ
   python -m voicecoach.server --agents api --model <имя модели> --remote dire --tunnel --max-calls 3000
   ```
   (в PowerShell ключ задаётся так: `$env:ANTHROPIC_API_KEY="ваш_ключ"`). Адрес туннеля при каждом запуске новый —
   ссылку снова отправить другу; ключ в ней прежний. Платите вы за обе команды; `--max-calls` — потолок вызовов
   каждой стороны (3000 — примерно 30–40 минут игры, по расчёту ≈ $1,5 на сторону на самой быстрой модели). Дешевле — `--dire rules` (Тьмой тогда играют правила, не Claude).
6. **После игры** — Ctrl+C: сервер напечатает сводку (вызовы, задержка, токены по сторонам) и закроет туннель.

**Пришлите:** что видел друг на пульте (снимок экрана), доходили ли его приказы, строки `[ТРЕНЕР]` из `console.log`,
журнал `coach\logs\agents_*.jsonl` и сводку сервера. Если ссылка не открылась — строки, которые сервер напечатал
про туннель.
