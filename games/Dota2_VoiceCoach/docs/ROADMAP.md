## Риски

| Риск | Вероятность | Что делаем |
|---|---|---|
| Патч Valve ломает ботов или API кастомок (было 8 раз за 2024–2026 у OHA) | высокая | тонкий слой интеграции, всё остальное тестами вне игры; быстрый цикл «лог → правка» |
| Канал через веб-панель (недокументированный) сломают | средняя | запасные пути: команды из чата, клавиши кастомки (`Game.CreateCustomKeyBind`), режим Local Host |
| Распознавание путает сленг | средняя | нажми-и-говори, маленький словарь, переспрос одним словом, пилот на записях |
| Только человек может запускать Доту — медленные итерации | точно | пробники с самодиагностикой; логи консоли (`-condebug`) присылать целиком |
| Нагрузка на ПК хоста (10 ИИ-героев + распознавание) | средняя | замер в пробнике; думание раз в 0,4 с; GigaAM на CPU |
| Права на имена про-игроков | средняя | архетипы в публичной сборке (Д6) |
