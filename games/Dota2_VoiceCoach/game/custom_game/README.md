# Кастомка «тренер доты»

Стандартная карта Доты со всеми механиками. В каждой команде пятеро героев и тренер без героя: его герой спрятан у
базы, камера смотрит сверху и дальше обычного, панели героя скрыты (Д10). **Каждого героя ведёт свой агент Claude**
(Д11, слова автора: «Нет играют не боты доты а агенты Клауд. За каждого Героя свой»): агент решает, что делать
герою, а исполнитель в игре выполняет решение рефлексами. Встроенный ИИ ботов Доты выключен. Тренер командует
агентами **текстом** в коротком формате — в поле внизу экрана или в командном чате (Д9).

```
1 фарм лес. 23 ганг мид. 45 вард руна      все-1 пуш бот т2      3 ульт марс !      все назад      сам
```

Полный формат — `docs/COMMANDS.md`, раздел «Короткий формат»; в игре — кнопка «?» рядом с полем.
Как устроены агенты, сколько это стоит и что проверено — `docs/CLAUDE_AGENTS.md`.

## Как играют агенты

Раз в секунду игра отправляет серверу тренера на вашем ПК наблюдение каждого героя: здоровье, мана, способности,
предметы, золото, крипы и вышки рядом, союзники, видимые враги и где видели невидимых, приказы тренера, события.
Агент героя думает раз в 4 секунды игры и сразу по событию (приказ тренера, смерть, враг рядом, резкая потеря
здоровья) и возвращает решение: что делать и где, кого бить, какие способности и предметы применять, что купить и
качать, когда отходить, что сказать тренеру. Исполнитель в игре 4 раза в секунду выполняет решение:

| Решение агента | Что делают руки |
|---|---|
| `farm` линия | идут к волне, добивают вражеских крипов, добивают своих (меньше половины здоровья), ждут на дальности атаки |
| `push` / `defend` линия | атакующим ходом к внешней вышке врага / к своей (упала — к следующей) |
| `fight` цель | бьют видимого героя; не видно — идут, где его видели последние 20 с, или на линию |
| `retreat`, `move`, `group`, `follow`, `save`, `roshan`, `hold` | к фонтану, к месту, к своим, за союзником, на помощь, бьют Рошана, стоят |
| `cast` | способность или предмет: по цели, в точку или без цели; до далёкой цели сначала подходят |
| `buy`, `level` | покупают по очереди у фонтана (или пока мёртв), вкладывают очки; без очереди — ульта, потом младшая способность |
| `retreat_hp` | ниже порога здоровья — к фонтану, потом обратно к решению |
| `buyback`, `say` | выкуп; реплика агента — в журнале HUD слева внизу и в командном чате |

**Голосовой чат команды** (Д12): агенты переговариваются — колы, просьбы, договорённости, ответы друг другу и тренеру.
Обращение к союзнику будит его ответить сразу. Слышно голосами браузера: откройте `http://localhost:8787/voice.html`
(в Chrome на ПК или на телефоне — тогда сервер с `--host 0.0.0.0` и адрес ПК вместо localhost) и нажмите «Включить
звук»; у каждой позиции свой голос. В игре HUD открывает ту же страницу в скрытой веб-панели — звучит ли так речь
внутри Доты, проверить; если звучит дважды, закройте страницу в браузере.

Слева вверху — кто ведёт героев («агенты на связи (Свет: Claude API …)» или «нет связи — запасной исполнитель»),
ниже — список героев: здоровье, что делает, «думает…», когда агент ждёт ответа модели, «агент: ошибка …» (или
«лимит», «пауза»), когда мотор не отвечает, и «без агента», когда героем правит запасной исполнитель.

**Без сервера агентов** героев ведёт запасной исполнитель: приказ тренера выполняется напрямую, без агента и
характера, без приказа — фарм своей линии. Так же — для одного героя, чей агент 20 с не дал решения (ошибка мотора,
предел вызовов). Варды руки ставят только у своей внешней вышки линии; смок, стаки, лес — пока не умеют ни руки, ни
запасной исполнитель. Покупка упрощена: без запаса магазина и тайной лавки (`docs/CLAUDE_AGENTS.md`).

## Запуск (Windows)

Шаги в интерфейсе Steam и Доты написаны по описаниям, здесь не проверены — помечены «(проверить)».

1. Установить Dota 2 Workshop Tools: Steam → Библиотека → Dota 2 → Свойства → DLC →
   «Dota 2 Workshop Tools DLC» (проверить).
2. В Свойствах Dota 2 → «Параметры запуска» дописать `-condebug` (консоль пишется в
   `…\dota 2 beta\game\dota\console.log`).
3. Установить кастомку (Python 3.10+):
   ```
   cd games\Dota2_VoiceCoach\game\custom_game
   python install_game.py
   ```
4. Запустить сервер тренера с агентами (окно не закрывать). Сначала — без Claude, чтобы проверить связь и руки:
   ```
   cd games\Dota2_VoiceCoach\coach
   python -m voicecoach.server --agents rules
   ```
   Потом — с Claude. По ключу API (рекомендую; ключ — в консоли Anthropic, оплата за токены, модель — её имя из
   документации Anthropic, для начала самая быстрая):
   ```
   set ANTHROPIC_API_KEY=<ваш ключ>
   python -m voicecoach.server --agents api --model <имя модели> --dire rules --max-calls 300
   ```
   `--dire rules` — соперник на бесплатных правилах (вдвое дешевле); `--max-calls` — предел платных вызовов каждой
   стороны за запуск. Модель думает с `--effort low` (по умолчанию); выключить думание — `--thinking disabled` у самой быстрой
   модели, `--thinking between_tools` у средней. Сколько стоит матч — `docs/CLAUDE_AGENTS.md` (у самой быстрой модели
   ≈ $3 за 10 агентов, у средней ≈ $44 — расчёт, не замер).
   По подписке через Claude Code (медленнее, лимиты подписки не опубликованы): `--agents cli` (Claude Code должен быть
   установлен нативным установщиком и выполнен вход). Сервер пишет, кто ведёт каждую сторону, и журнал в
   `coach\logs\agents_*.jsonl`.
5. Запустить Доту с инструментами (Steam → «Играть» → «Launch Dota 2 - Tools», проверить) и в консоли игры:
   ```
   dota_launch_custom_game voicecoach dota
   ```
6. В выборе героя взять любого героя — он нужен только как место в команде и будет спрятан.
7. После рога — приказы в поле внизу экрана (щёлкнуть по полю или F2 — проверить) или в командный чат.
8. Голосовой чат агентов — `http://localhost:8787/voice.html`, кнопка «Включить звук» (или слушать в игре — проверить).

Удалить: `python install_game.py --uninstall`. Состояние агентов во время игры: `http://localhost:8787/api/local/agents`.

## Второй тренер через интернет (Д13)

В сам матч Доты второй игрок пока не входит: игра, запущенная из Tools, к себе никого не пускает
(`research/00_SUMMARY.md`; вход в матч — публикация в Workshop, неделя 6 плана). Поэтому второй тренер командует своей
пятёркой с **пульта** — страницы в браузере на своём ПК или телефоне, по ссылке с ключом. На пульте: схема карты
(свои герои, враги, которых видит его команда, вышки, счёт), его герои и что они делают, поле приказа в том же
коротком формате, ответы агентов и их голосовой чат. Чужую команду пульт не показывает: туман войны — как в игре.

Хост (Windows):
1. Поставить туннель Cloudflare (один раз): `winget install --id Cloudflare.cloudflared` (или скачать
   `cloudflared-windows-amd64.exe` со страницы выпусков https://github.com/cloudflare/cloudflared/releases и указать
   путь `--cloudflared C:\путь\cloudflared.exe`). Учётная запись Cloudflare не нужна.
2. Запустить сервер тренера с пультом для Тьмы:
   ```
   python -m voicecoach.server --agents api --model <имя модели> --remote dire --tunnel
   ```
   Сервер напишет ссылку для этого ПК («Пульт тренера (Тьма) на этом ПК: http://127.0.0.1:8788/c/…/» — проверить
   у себя), а через несколько секунд — ссылку через интернет: «Ссылка для тренера (Тьма) через интернет — отправьте
   её: https://….trycloudflare.com/c/…/». Её и отправить другу.
3. Запустить кастомку как обычно (шаги ниже); хост — тренер Света.

Второй тренер: открыть ссылку в Chrome или Edge (на ПК или телефоне), нажать «Включить звук» (заодно экран телефона
не будет гаснуть), писать приказы в поле вверху; кнопки быстрых приказов кладут заготовку в поле, отдаёт её «Отдать».
Пульт принимает 4 приказа подряд, дальше — один в 2 с. Пока матч не идёт, пульт пишет «игра ещё не началась»;
приказ, отданный без игры, пролежит 30 с и пропадёт, в следующий матч не уйдёт.

- Адрес туннеля новый при каждом запуске сервера — ссылку нужно отправлять заново; ключ в ней сохраняется
  (`coach\logs\console_keys.json`). Сменить ключ (старые ссылки перестанут работать) — `--new-key`.
- Без cloudflared: проброс порта 8788 на роутере к ПК и `--console-host 0.0.0.0`, ссылка —
  `http://<внешний адрес>:8788/c/<ключ>/` (без шифрования); или общая VPN-сеть с адресом ПК в ней.
- Быстрый туннель Cloudflare — тестовый режим без гарантий работы, до 200 запросов одновременно (по описаниям
  Cloudflare в поиске; страницу целиком прочитать не удалось). Страницы таких адресов попадают в поиск Google —
  пульт запрещает индексацию, а без ключа на нём ничего нет.
- **Платит хост**: вызовы Claude обеих команд идут по его ключу. `--max-calls` — предел у каждой стороны свой;
  дешевле — `--dire rules` (агенты Тьмы на правилах, не Claude) или `--dire api` с отдельным пределом.
- Хост может подсмотреть за второй командой: консоль Доты печатает приказы с пульта и реплики агентов Тьмы, а
  журнал и состояние агентов лежат на его ПК. Трафик пульта вместе с ключом видит Cloudflare. Игра — на доверии.
- Сервер на ПК хоста не отвечает страницам чужих сайтов: ссылка, присланная соперником, не прочтёт приказы и чат Света.
- Не проверено здесь: сам туннель (cloudflared в этой среде не выходит в сеть), речь на телефонах.

## Что проверено без игры и что нет

Проверено здесь: имена всех функций, констант и полей событий Valve в коде сверены с опубликованными описаниями API
(`game/tests/test_api_names.py`); весь матч прогнан под LuaJIT на имитации Доты с настоящим сервером тренера —
наблюдения уходят на сервер, агенты отвечают, руки покупают стартовые предметы, идут на линии, добивают крипов,
отходят и возвращаются, применяют способности и качаются, приказ тренера доходит до агента и меняет его решение;
без сервера — запасной исполнитель (`game/tests/test_custom_game.py`). Что уходит в API Claude и в `claude -p` —
`coach/tests/test_agents.py`; живой `claude -p` с настоящими промптами — 4 решения из 4 приняты. Промпт агента
проверен на головах Claude (`docs/CLAUDE_AGENTS.md`). Пульт второго тренера: приказ с пульта доходит до агентов Тьмы
ровно один раз (под LuaJIT), чужой ключ и пути игры закрыты, туман войны, пределы (`coach/tests/test_console.py`),
страница — в Chromium на экране ПК и телефона (`coach/tests/test_console_page.py`).

Не проверено (узнаем только из вашего запуска):
- доходит ли HTTP из кастомки до сервера тренера на `127.0.0.1:8787`;
- слушаются ли герои-боты с выключенным встроенным ИИ наших приказов, срабатывают ли прокачка и покупка;
- настоящие задержка и цена агентов Claude (журнал сервера);
- камера сверху (наклон 70°, дальность 1600), клавиша F2, внешний вид интерфейса;
- звучит ли голосовой чат в скрытой веб-панели HUD и какие русские голоса есть в вашей системе;
- не мешает ли спрятанный герой тренера; все ли выбранные герои поднимаются (список — по памяти).

## Что прислать

Строки `[ТРЕНЕР]` из консоли или `console.log`, журнал `coach\logs\agents_*.jsonl`, вывод сервера после Ctrl+C (сводка:
вызовы, задержка, токены), снимок экрана и пару слов: как играют агенты, что неудобно, каких приказов не хватает.
