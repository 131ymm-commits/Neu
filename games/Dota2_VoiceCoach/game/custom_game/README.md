# Кастомка «голосовой тренер» — каркас

Стандартная карта Доты со всеми механиками. В каждой команде пятеро агентов (боты Доты) и тренер без
героя: его герой спрятан у базы, камера смотрит сверху и дальше обычного, панели героя скрыты.
Тренер командует **текстом** в коротком формате — в поле внизу экрана или в командном чате
(решения автора Д9 и Д10 в `docs/DECISIONS.md`).

```
1 фарм лес. 23 ганг мид. 45 вард руна      все-1 пуш бот т2      3 ульт марс !      все назад      сам
```

Полный формат — `docs/COMMANDS.md`, раздел «Короткий формат»; в игре — кнопка «?» рядом с полем.

## Что умеют агенты сейчас

Без приказа агенты играют сами (встроенный ИИ ботов Доты). Приказ тренера ведёт агента, пока не
истечёт (у каждого действия своё время) или пока тренер не скажет `сам` / `отмена`; приказ
повторяется раз в секунду.

| Приказ | Что делает агент |
|---|---|
| `назад` | идёт к своему фонтану |
| `иди топ` / `иди база` / `иди рош` | идёт к своей внешней вышке линии, на базу, к Рошану |
| `пуш бот`, `сплит топ` | атакующим ходом к внешней вышке врага на линии (упала — к следующей) |
| `деф мид`, `деф база` | к своей внешней вышке линии или на базу |
| `ганг мид`, `фокус марс`, `драка` | бьёт названного героя, если его видно; иначе идёт на линию врага |
| `рош` | бьёт Рошана |
| `сбор`, `сбор рош` | идёт к месту или к центру своей пятёрки |
| `жди` | стоит на месте |
| `за 2`, `сейв 2` | идёт за союзником / к нему на помощь |
| `фарм топ` | доходит до своей линии, дальше фармит сам |
| `ульт [цель]` | применяет ульту: по цели, в точку или без цели — как требует способность |
| `тп база`, `тп топ` | свиток телепорта, если есть и готов; иначе идёт |
| `бб` | выкупается, если мёртв и хватает золота |
| `юз <предмет> [цель]` | применяет предмет из инвентаря |
| `доклад` | отвечает: что делает, здоровье, золото |
| `купи`, `вард`, `стак`, `смок`, `фарм лес` | пока не умеют — играют сами и говорят об этом |

Слева — список агентов: герой, здоровье и чем занят; слева внизу — ответы агентов («Иду пушить»,
«Ульта в откате, 42 с»). Если тренеров двое, каждый командует своей пятёркой; если тренер один,
другой стороной играют боты без тренера.

## Запуск (Windows)

Шаги в интерфейсе Steam и Доты написаны по описаниям, здесь не проверены — помечены «(проверить)».

1. Установить Dota 2 Workshop Tools: Steam → Библиотека → Dota 2 → Свойства → DLC →
   «Dota 2 Workshop Tools DLC» (проверить).
2. В Свойствах Dota 2 → «Параметры запуска» дописать `-condebug` (консоль пишется в
   `…\dota 2 beta\game\dota\console.log`).
3. Установить кастомку (Python 3.10+):
   ```
   cd games\Dota2_VoiceCoach\game\custom_game
   python install_game.py
   ```
4. Запустить Доту с инструментами (Steam → «Играть» → «Launch Dota 2 - Tools», проверить) и в
   консоли игры:
   ```
   dota_launch_custom_game voicecoach dota
   ```
5. В выборе героя взять любого героя — он нужен только как место в команде и будет спрятан.
6. После рога — приказы в поле внизу экрана (щёлкнуть по полю или F2 — проверить) или в командный чат.

Удалить: `python install_game.py --uninstall`.

Вдвоём (два тренера) — после публикации в Workshop: игра, запущенная из Tools, к себе никого не
пускает (`research/00_SUMMARY.md`). Это неделя 6 плана.

## Что проверено без игры и что нет

Проверено здесь: имена всех функций Valve в коде сверены с опубликованными описаниями API
(`game/tests/test_api_names.py`); весь матч прогнан под LuaJIT на имитации Доты — тренер в команде,
по 5 ботов, герой тренера спрятан, приказы из поля и из чата превращаются в приказы героям, приказ
повторяется, «сам» отпускает агентов, ответы и список агентов уходят в интерфейс
(`game/tests/test_custom_game.py`).

Не проверено (узнаем только из вашего запуска):
- перебивает ли встроенный ИИ ботов наши приказы — поэтому приказ повторяется раз в секунду;
- камера сверху (наклон 70°, дальность 1600), клавиша F2, внешний вид интерфейса;
- не мешает ли спрятанный герой тренера;
- все ли выбранные герои поднимаются ботами (список — по памяти; кого не удалось, видно в журнале).

## Что прислать

Строки `[ТРЕНЕР]` из консоли или `console.log`, снимок экрана и пару слов: слушаются ли агенты, что
неудобно, каких приказов не хватает.
