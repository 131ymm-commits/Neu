# Пробник кастомки (трек B)

Маленький аддон на стандартной карте Доты, который за один запуск отвечает на вопросы, от которых
зависит итоговая кастомка на двоих (`research/00_SUMMARY.md`, «Открытые вопросы»): тренер без героя
и пятеро ботов, команды в чате и через веб-панель. Играть не нужно: пробник сам добавит ботов, спрячет
вашего героя, проверит каналы связи и напечатает итог в консоль.

| Проверка | Что узнаём |
|---|---|
| `server_http` | ходит ли сервер кастомки по HTTP к серверу тренера (в Tools должен) |
| `bots_added`, `heroes`, `bots_think` | поднимаются ли 10 ботов (по 5 в команде) через `Tutorial:AddBot` и думают ли они |
| `commander_hidden` | тренер без героя: ваш герой прячется у базы (невидим, неуязвим, вне игры), играют пятеро ботов |
| `chat_commands`, `text_parser` | команды короткого формата в командном чате («все назад», «1 иди мид») доходят до ботов |
| `html_panel_channel` | канал аркады: веб-панель клиента → игровое событие → сервер кастомки |
| `client_ui_loaded` | загрузился ли интерфейс пробника (Panorama) |
| `modifier_on_bots`, строки `[ПРОБНИК-БОТ]` | видят ли скрипты ботов то, что кладёт кастомка |
| `order_vs_native_ai` | перебивает ли встроенный ИИ наш приказ |
| `think_cost_ms` | сколько стоит обход 10 героев |

Всё, что проверялось без игры: имена функций Valve сверены с опубликованными описаниями
(`game/tests/test_api_names.py`), весь сценарий прогнан на имитации игры с настоящим сервером тренера
(`game/tests/test_probe.py`). Как поведёт себя настоящая игра — узнаем только из вашего запуска.

## Запуск (Windows)

Шаги в интерфейсе Steam и Dota написаны по описаниям, здесь не проверены — помечены «(проверить)».

1. Установить Dota 2 Workshop Tools: Steam → Библиотека → Dota 2 → Свойства → DLC →
   «Dota 2 Workshop Tools DLC» (проверить).
2. В Свойствах Dota 2 → «Параметры запуска» дописать `-condebug` — консоль будет писаться в файл
   `…\dota 2 beta\game\dota\console.log`.
3. Установить пробник (Python 3.10+):
   ```
   cd games\Dota2_VoiceCoach\game\probe_addon
   python install_probe.py
   ```
4. Запустить сервер тренера и открыть страницу тренера:
   ```
   cd games\Dota2_VoiceCoach\coach
   python -m voicecoach.server
   ```
   В браузере `http://127.0.0.1:8787/`, поле «Комната» — `probe`, команда — Свет (Radiant).
5. Запустить Dota 2 с инструментами: в Steam «Играть» → «Launch Dota 2 - Tools» (проверить).
   В окне выбора аддона — `voicecoach_probe`; либо в консоли игры:
   ```
   dota_launch_custom_game voicecoach_probe dota
   ```
6. В выборе героя взять любого героя за Свет: он нужен только как место в команде — при появлении
   пробник спрячет его у базы, а играть будут пятеро ботов. Дальше пробник всё делает сам.
7. Когда начнётся игра (после рога), две проверки команд:
   - в **командный чат** игры написать `все назад`, потом `1 иди мид` — боты Света должны пойти к
     фонтану, потом первый — в центр; бот ответит в чат «Понял»;
   - на странице тренера написать `все назад` — это канал через веб-панель (как в аркаде); в консоли
     появится строка `голос → клиент → сервер: retreat → позиции 1,2,3,4,5`.
8. Через полторы минуты после рога в консоли появится блок `===== ИТОГ =====`.

## Что прислать

Все строки, начинающиеся с `[ПРОБНИК]`, `[ПРОБНИК-БОТ]` и `[ПРОБНИК-UI]` (из консоли игры или из
`console.log`), и пару слов: пропал ли ваш герой, пошли ли боты к фонтану после «все назад» из чата и
со страницы, видна ли в левом верхнем углу жёлтая строка «Пробник, веб-панель: …».

Удалить пробник: `python install_probe.py --uninstall`.

## Если что-то не так

- Нет ни одной строки `[ПРОБНИК]` — аддон не запустился: проверьте шаг 5 (имя аддона, карта `dota`).
- `server_http НЕТ` — сервер тренера не запущен или его не пускает брандмауэр (порт 8787).
- `html_panel_channel НЕТ ответов` — веб-панель игры не достучалась до сервера тренера; это тоже ответ
  (для аркады придётся использовать другой адрес — https).
- Нет строк `[ПРОБНИК-БОТ]` — скрипты ботов из аддона в кастомке не грузятся; это тоже ответ (тогда
  управление героями пойдёт целиком из скриптов кастомки, как в Windy10v10AI).
