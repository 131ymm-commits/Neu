# Schwarzfall — «Германия. Блэкаут» (мод для RimWorld 1.5/1.6)

**Наши дни.** Посёлок под Кёльном, октябрь, 22:14: частота европейской сети падает ниже 49,8 Гц, автоматика гасит регион за регионом, и через одиннадцать минут темно от Гамбурга до Мюнхена. Сценарий стартует в первую ночь: четверо соседей, дом, машина с половиной бака, кладовая, аптечка и радиоприёмник на батарейках.

**Хронология катастрофы** (по реальным сценариям обвала сети и роману Марка Эльсберга «Blackout»): ночь 1 — темнота; дни 1–2 — вода (насосные станции без резерва) и связь (базовые станции разряжены); дни 3–5 — заправки не качают, магазины закрыты; дни 6–14 — холод, мародёры (рейды на 7-й, 11-й, 14-й день); недели 3–4 — АЭС без солярки для аварийных насосов, сброс давления, облако; с 29-го дня — сеть возвращают по частям: окна подачи с 6 утра, каждый день на час дольше, до полного восстановления (40–55 дней). Каждое утро в 8:00 — сводка по радио.

**Постепенное развитие** — не оружие, а энергия: ИБП из автомобильных аккумуляторов (ночи со светом) → Notstromaggregat (1200 Вт, 4 л солярки в сутки) → солнечная крыша в автономном режиме (900 Вт днём) → контроллер островной сети (радиус 25: батареи не теряют заряд в холод, посёлок живёт как маленькая страна) → синхронизация с общей сетью (сетевой ввод оживает в окна подачи). Сетевой ввод — 2000 Вт даром, пока сеть жива, и ничего во время блэкаута.

**Состав.** `About/`, `Defs/Scenario.xml` (сценарий «Schwarzfall: Германия, первая ночь», отключены космические события), `Defs/Conditions_Incidents.xml` (условие-блэкаут, облако с АЭС), `Defs/Research.xml` (пять исследований), `Defs/Buildings.xml` (ввод, ИБП, аггрегат, солнечная крыша, контроллер, радио), `Source/` (C#, Harmony), `Languages/`, `Textures/` (заглушки).

**Сборка.** .NET SDK и установленная игра:
```
cd Source
dotnet build -c Release -p:RimWorldDir="C:\Program Files (x86)\Steam\steamapps\common\RimWorld"
```
DLL ляжет в `Assemblies/`. Папку мода — в `RimWorld/Mods/`, порядок: Harmony → Schwarzfall. Новая игра → сценарий «Schwarzfall».

**Что не проверено (честно).** Игры и её сборок в среде разработки нет: мод не собран и не запускался. Сигнатуры API — по памяти для 1.5 (`CompPowerPlant.DesiredPowerOutput`, `GenLocalDate.HourOfDay(Map)`, `StorytellerUtility.DefaultParmsNow`, `ScenPart_*` в XML). Числа баланса (мощности, расход топлива, дни рейдов, ширина окон подачи) — первое приближение. Первый запуск: сценарий, ускорить время, смотреть подсказку условия и сводки радио.
