# Schwarzfall — «Германия. Блэкаут» (мод для RimWorld 1.4–1.6, чистый XML)

**В это можно играть сразу:** папку положить в `RimWorld/Mods/`, включить мод, новая игра → сценарий «Schwarzfall: Германия, первая ночь». Компилировать ничего не нужно, зависимостей нет.

**Наши дни.** Посёлок под Кёльном, октябрь, 22:14: частота европейской сети падает ниже 49,8 Гц, автоматика гасит регион за регионом, через одиннадцать минут темно от Гамбурга до Мюнхена. Четверо соседей, кладовая на первые дни, солярка из бака, инструменты, радио на батарейках и брошюра BBK «Что делать при блэкауте».

**Хронология** (по реальным сценариям обвала сети и роману Эльсберга «Blackout»); каждое событие приходит письмом от радио:
| День | Событие |
|---|---|
| ночь 1 | Европа без света |
| 1 | вода из крана кончилась, телефоны молчат |
| 3 | заправки не качают, магазины закрыты, больницы дожигают дизель |
| 6 | холод, чужие на дорогах; 7-й, 11-й, 14-й день — рейды; 9-й — похолодание |
| 14 | электростанции подняли островные сети, сельские районы — последними |
| 16 | торговый караван: бартер с соседями |
| 20 | облако с АЭС (сброс давления), 5–8 дней под крышей |
| 29 | сеть возвращают по частям: с синхронизацией можно ставить сетевой ввод |
| 45 | сеть восстановлена |

**Постепенное развитие** — вкладка исследований «Schwarzfall»: ИБП из автомобильных аккумуляторов (600 Вт·ч) → Notstromaggregat (1200 Вт, 4 топлива в сутки) → солнечная крыша в автономном режиме (900 Вт днём) → контроллер островной сети (буфер 3000 Вт·ч, КПД 0,9) → синхронизация с общей сетью (сетевой ввод, 2000 Вт). Космические и психические события сценария выключены: это Германия.

**Состав.** `About/`, `Defs/Scenario.xml` (сценарий и хронология событий), `Defs/Conditions_Incidents.xml` (письма-стадии, облако), `Defs/Research.xml`, `Defs/Buildings.xml`, `Textures/` (две простые текстуры; остальное — ванильные).

**Что не проверено (честно).** Игры в среде разработки нет, мод не запускался. XML проверен на синтаксис и на имена ванильных классов и дефов по памяти для 1.5 (`ScenPart_CreateIncident`, `IncidentWorker_MakeGameCondition`, `GameCondition_ToxicFallout`, `Building_Battery`, `CompPowerPlantSolar`, `ColdSnap`, `TraderCaravanArrival`). Если при загрузке игра покажет красные строки в логе — пришлите их, поправлю. Баланс (мощности, дни, размер рейдов — их задаёт рассказчик) — первое приближение.

**Что дальше.** Мысли колонистов «без света / со светом»; события помощи (THW привозит воду, Бундесвер — топливо за услугу); окна подачи по часам (нужен C#); звук аггрегата; настройки длительности.
