# Magnetics — магнитная ветка технологий для Mindustry (v146, Серпуло)

**Установка:** скопировать папку `magnetics/` (или `Magnetics.zip`) в папку модов Mindustry → в игре «Моды» → включить → перезапуск. Steam: `%APPDATA%/Mindustry/mods/` (Windows) или `~/.local/share/Mindustry/mods/` (Linux).

## Как проверено (сервер Mindustry v146 без графики, `tools/`)
- Загрузка: мод грузится без ошибок и предупреждений; 10 элементов на месте.
- 33 автотеста (`tools/checks.js`): каждое число из файлов применено в игре, дерево технологий подключено, все здания строятся.
- Симуляция в живом мире (`tools/sim_*.js`, 33 с): печь — 32 сплава при расчётных 33; криокамера — 21 при расчётных 22.
- Лента (`tools/conv.js`, установившийся поток): 0,08 → 10,0/с (как титановый), 0,09 → 11,9, 0,10 → 12,2, **0,11 → 14,9/с** — выбрано.
- Бой (`tools/combat_*.js`): 5 неподвижных «Булав» на 18 блоках, 25 с. «Гаусс» (сплав) снял 2518 из 2750 прочности, «Гаусс» (торий), «Копейщик» — всё; «Залп» (графит) — 2504; «Рябь» — 2137. Урон на уровне турелей той же ступени, дальность выше.

## Что не проверено (честно)
- Внешний вид: спрайты — перекраска ванильных (Mindustry, GPL-3.0) с медными витками; в игре с графикой не смотрелись.
- Баланс в кампании и против волн — только лабораторные замеры выше.
- Скорость ленты — одна прямая линия 30 клеток, без поворотов и развязок.
