# Magnetics 1.0 — магнитная эра для Mindustry (v146, Серпуло)

**Установка:** в игре «Моды» → «Импорт мода» → «Импорт файла» → `Magnetics.zip`. Или положить `Magnetics.zip` в `%APPDATA%\Mindustry\mods\` (Windows). Сохранения с версии 0.1 совместимы (имена прежние).

**Состав: 5 предметов, 30 построек, 3 летающих юнита. Все модели нарисованы кодом заново** (`tools/paint.py`; у ленты и моста из ванили взяты только маски силуэта; основания турелей — ванильные «block-N» из самой игры). Витрина — `showcase.png`.

- **Загрузка:** 38 элементов, 0 ошибок, 0 предупреждений; имена сверены со списком ванили (`tools/vanilla_names_v146.txt`), совпадений нет.
- **251 статическая проверка** (`tools/tests.py`, генерируется из `tools/spec.py`): каждое число, рецепт, стоимость, дерево технологий, план завода — применены в игре. Провалов 0.
- **Симуляция производства** (`tools/sim.py prod`, 34,5 с игрового времени): каждый станок выдал расчётное количество (печь 35 при ожидаемых 34,5; криокамера 23 при 23; сепаратор 70/35/35 при 69/34,5/34,5 …); генераторы работают на 100 %; бур 47 тория против 39 у лазерного (с водой 121 против 101); завод собрал 2 Искры за 34 с (план 15 с); ремонтная катушка подняла стену со 100 до 640; щит поднят.
- **Бой** (`tools/sim.py A/B/C`, неподвижные враги, прочность врагов после 5/10/20 с — `tools/sim_results.json`): Катушечник ≈ Дуэль (чуть сильнее), Гаусс ≈ Копейщик ≈ Залп, Разрядник ≥ Дуга, Маглев-зенитка сбивает 5 Горизонтов за 5 с (Рассеиватель — за 10), Рельсотрон уничтожает 5 Крепостей в линию за 10 с (Рябь за 20 с почти не ранит). Все три юнита уничтожают по 5 Кинжалов меньше чем за 15 с.

## Что найдено и исправлено тестами
- Имя «flux-reactor» занято ванильным зданием Эрекира → «Динамо потока».
- Бур без необязательного водяного ускорителя в движке всегда считается ускоренным (×1,6 дважды) → добавлен водяной ускоритель, как у ванильных буров.
- Маглев-зенитка была слабее Рассеивателя → усилена.
- В версии 0.1 у индукционной печи не было картинки пламени (могла показывать «ошибку» при работе) → в 1.0 у всех печей есть `-top`.

## Что не проверено (честно)
- Внешний вид в игре с графикой — только витрина `showcase.png`.
- Баланс в кампании и против волн — только лабораторные замеры выше.
- Порядок чертежей на заводе — по алфавиту (Индуктор, Магнетар, Искра).
