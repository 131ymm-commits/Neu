# Как проектировался Magnetics для Factorio

- `recon/` — разведка движка Factorio 2.0.77 (7 читателей-агентов, 30.09.2026): каждая цифра ванили — со ссылкой на файл игры или `prototype-api.json`/`runtime-api.json`. Графики в headless-сборке нет, поэтому про внешний вид там только структура спрайтов.
- `design_balance.md`, `design_appeal.md`, `design_engine.md` — три независимых проекта мода (приоритет: баланс / привлекательность / проверяемость).
- `FINAL_SPEC.md` — синтез после трёх судей (баланс, выполнимость и проверяемость, привлекательность); по нему написан мод.
