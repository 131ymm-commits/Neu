# Cascade — «Каскад»: медленная электрическая катастрофа для RimWorld (1.5/1.6)

**Замысел.** Не одноразовый удар, а буря, которая учится вместе с колонией. Геомагнитная аномалия нарастает 7–11 дней в четыре стадии: наводки (искры, мигание) → перегрузка (батареи текут, кабели взрываются, огонь) → ионный купол (незаземлённые сети гаснут волнами) → разряды (молнии в самые мощные постройки). Каждая стадия открывает смысл следующему исследованию: **заземление** (контур, радиус 12) → **экранированный кабель** (не искрит; под куполом держит ток, если сеть заземлена) → **молниеотвод** (радиус 20, принимает удары). Каскад приходит не раньше 25-го дня, не чаще раза в сезон, и только к колонии, где уже есть электричество.

**Состав.** `About/` — метаданные (зависит от Harmony). `Defs/` — условие с погодой «ионное сияние», инцидент, вкладка исследований «Каскад» с тремя проектами, три постройки. `Source/` — C# (условие с четырьмя стадиями, компоненты защиты, два Harmony-патча: сети с заземлением и экранированным кабелем не гаснут под куполом). `Languages/` — тексты. `Textures/` — временные схематичные текстуры.

**Сборка.** Нужны .NET SDK и установленная игра:
```
cd Source
dotnet build -c Release -p:RimWorldDir="C:\Program Files (x86)\Steam\steamapps\common\RimWorld"
```
DLL ляжет в `Assemblies/`. Папку мода целиком — в `RimWorld/Mods/`. Порядок загрузки: Harmony → Cascade.

**Что не проверено (честно).** Код написан без доступа к игре: в среде нет `Assembly-CSharp.dll`, собрать и запустить нельзя. Сигнатуры API взяты по памяти для 1.5 — возможны ошибки компиляции в мелочах (имена свойств `PowerNet.Map`, `CompPowerBattery.DrawPower`, `WeatherEvent_LightningStrike`). Балансовые числа (шансы искр, скорость разряда батарей, длительность купола 3 ч из 4) — первое приближение, не игрались. Первый запуск: `Dev mode → Debug actions → Incidents → Cascade_StormIncident`, смотреть стадии в подсказке условия.

**Что дальше.** Звук и нормальные текстуры; квест-письмо от союзника с чертежом заземления; в стадии 4 — шанс «сверхразряда», который оставляет на месте удара залежь компонентов (награда за пережитое); настройки мода (длительность, агрессивность).
